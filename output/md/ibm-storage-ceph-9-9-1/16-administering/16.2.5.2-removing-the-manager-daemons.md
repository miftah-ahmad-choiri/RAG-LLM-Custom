## Removing the manager daemons

Last Updated
: 2026-06-25

To remove the manager daemons from the host, you can just redeploy the daemons on other
hosts.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to all the nodes.
- Hosts are added to the cluster.
- At least one manager daemon deployed on the hosts.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Run the `ceph orch apply` command to redeploy the required manager daemons:

Syntax

```plaintext-ibm
ceph orch apply mgr "NUMBER_OF_DAEMONS HOST_NAME_1 HOST_NAME_3"
```

Copy to clipboard

If you want to remove manager daemons from `host02`, then you can redeploy the
manager daemons on other hosts.

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mgr "2 host01 host03"
```

Copy to clipboard

### Verification

- List the hosts,daemons, and processes:

Syntax

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps --daemon_type=mgr
```

Copy to clipboard
