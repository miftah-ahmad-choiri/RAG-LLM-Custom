## High availability for NFS services with active-passive servers

Last Updated
: 2026-06-25

Active-passive NFS service provides high availability by using a single active server with a standby server that takes over during failure.

In this deployment model, a virtual IP (VIP) is configured to provide a single access point for clients. The VIP is automatically reassigned to the standby node when the active node becomes unavailable, ensuring uninterrupted client access without requiring remount operations.

### Deployment model

- Only one NFS daemon actively serves client traffic at a time.
- A secondary node remains in standby and takes over during failure.
- A virtual IP (VIP) is used as the client access endpoint.
- The VIP automatically moves to the standby node during failover.

### Failover behavior

- The standby node takes over when the active node becomes unavailable.
- The virtual IP is reassigned to ensure continued client connectivity.
