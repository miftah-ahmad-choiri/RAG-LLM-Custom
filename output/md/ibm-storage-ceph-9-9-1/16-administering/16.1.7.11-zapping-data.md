## Zapping data

Last Updated
: 2026-06-25

The `zap` subcommand removes all data and file systems from a logical
volume or partition. Use the `zap` subcommand to zap logical volumes, partitions, or
raw devices that are used by Ceph OSDs for reuse. Any file system present on the given logical
volume or partition are removed and all data is purged.

Optionally, you can use the `--destroy` flag for complete removal of a logical
volume, partition, or the physical device.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the Ceph OSD node.

### Procedure

- Zap the logical volume:

Syntax

```plaintext-ibm
ceph-volume lvm zap VOLUME_GROUP_NAME/LOGICAL_VOLUME_NAME [--destroy]
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph-volume lvm zap osd-vg/data-lv
```

Copy to clipboard
- Zap the partition:

Syntax

```plaintext-ibm
ceph-volume lvm zap DEVICE_PATH_PARTITION [--destroy]
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph-volume lvm zap /dev/sdc1
```

Copy to clipboard
- Zap the raw device:

Syntax

```plaintext-ibm
ceph-volume lvm zap DEVICE_PATH --destroy
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph-volume lvm zap /dev/sdc --destroy
```

Copy to clipboard
- Purge multiple devices with the OSD ID:

Syntax

```plaintext-ibm
ceph-volume lvm zap --destroy --osd-id OSD_ID
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph-volume lvm zap --destroy --osd-id 16
```

Copy to clipboard

> 📝 **Note:** Note:
All the relative devices are zapped.
- Purge OSDs with the FSID:

Syntax

```plaintext-ibm
ceph-volume lvm zap --destroy --osd-fsid OSD_FSID
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph-volume lvm zap --destroy --osd-fsid 65d7b6b1-e41a-4a3c-b363-83ade63cb32b
```

Copy to clipboard

> 📝 **Note:** Note:
All the relative devices are zapped.
