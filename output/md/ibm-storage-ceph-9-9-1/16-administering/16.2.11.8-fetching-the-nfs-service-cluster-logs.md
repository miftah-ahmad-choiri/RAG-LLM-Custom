## Fetching the NFS service cluster logs

Last Updated
: 2026-06-25

With the Ceph Orchestrator, you can fetch the NFS service cluster logs. You need to be on
the node where the service is deployed.

### Prerequisites

- A running IBM Storage Ceph cluster.
- `cephadm` installed on the nodes where NFS is deployed.
- Root-level access to all the nodes.
- Hosts are added to the cluster.
- NFS service cluster created using the `mgr/nfs` module.

### Procedure

1. As a root user, fetch the *FSID* of the storage cluster:

Example

```plaintext-ibm
[root@host03 ~]# cephadm ls
```

Copy to clipboard

Copy the *FSID* and the name of the service.
2. Fetch the logs:

Syntax

```plaintext-ibm
cephadm logs --fsid FSID --name SERVICE_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[root@host03 ~]# cephadm logs --fsid 499829b4-832f-11eb-8d6d-001a4a000635 --name nfs.foo.host03
```

Copy to clipboard
