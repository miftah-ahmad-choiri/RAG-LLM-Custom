## NFS service container settings

Last Updated
: 2026-06-25

Learn how to configure the NFS service settings in the Ceph environment.

### Procedure

1. Retrieve the existing NFS service container configuration:
```plaintext-ibm
[ceph: root@host /]# ceph orch ls --service-type nfs --export

service_type: nfs
service_id: c_service
service_name: nfs.c_service
placement:
  hosts:
  - host1
  - host2
  - host3
spec:
  port: 2049
```

Copy to clipboard
2. Modify the container configuration to pass on
/etc/krb5.conf
and
/etc/krb5.keytab
files to the container from the host. These files will be
referred by NFS service at runtime to validate incoming service tickets and secure the communication
between NFS service and NFS client (
`krb5p`
).
```plaintext-ibm
[root@host ~]# cat nfs.yaml

service_type: nfs
service_id: c_service
service_name: nfs.c_service
placement:
  hosts:
  - host1
  - host2
  - host3
spec:
  port: 2049
extra_container_args:
  - "-v"
  - "/etc/krb5.keytab:/etc/krb5.keytab:ro"
  - "-v"
  - "/etc/krb5.conf:/etc/krb5.conf:ro"
```

Copy to clipboard
3. Make the modified
nfs.yaml
file available inside the cephadm
shell:
```plaintext-ibm
[root@host ~]# cephadm shell --mount nfs.yaml:/var/lib/ceph/nfs.yaml

Inferring fsid ff1c1498-73ec-11ee-af38-fa163e9a17fd

```

Copy to clipboard

```plaintext-ibm

  - host3

  port: 2049

  - "-v"
  - "/etc/krb5.keytab:/etc/krb5.keytab:ro"
  - "-v"
  - "/etc/krb5.conf:/etc/krb5.conf:ro"
```

Copy to clipboard

```plaintext-ibm
[ceph: root@host /]# ceph orch apply -i /var/lib/ceph/nfs.yaml
```

6. Verification: Validate whether the redeployed service has the required changes:
```plaintext-ibm
[ceph: root@host /]# ceph orch ls --service-type nfs --export

  hosts:
  - ceph-msaini-qp49z7-node1-installer
  - ceph-msaini-qp49z7-node2
  - ceph-msaini-qp49z7-node3

- -v
- /etc/krb5.keytab:/etc/krb5.keytab:ro
- -v
- /etc/krb5.conf:/etc/krb5.conf:ro
spec:
  port: 2049
```
