## Creating the NFS service cluster

Last Updated
: 2026-06-25

Create an NFS service cluster using the Ceph Orchestrator.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.
- All manager, monitor and OSD daemons are deployed.

### About this task

You can create an NFS service cluster using the `mgr/nfs` module of the Ceph Orchestrator. This module deploys the NFS cluster using `cephadm` in the backend.

This creates a common recovery pool for all NFS service daemons, new user based on `clusterid`, and a common NFS service config RADOS object.

For each daemon, a new user and a common configuration is created in the pool. Although all the clusters have different namespaces with respect to the cluster names, they use the same recovery pool.

### Procedure

1. Log into the
`cephadm`
shell.
For example,

```
[root@host01 ~]# cephadm shell
```
2. Enable the
`mgr/nfs`
module.

```plaintext-ibm
ceph mgr module enable nfs
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph mgr module enable nfs
```
3. Create the cluster.

```plaintext-ibm
ceph nfs cluster create CLUSTER_NAME ["HOST_NAME_1 HOST_NAME_2 HOST_NAME_3"]
```

Copy to clipboard

The CLUSTER_NAME is an arbitrary string and HOST_NAME_1 is an optional string signifying the hosts to deploy NFS service daemons.

For example,

```
[ceph: root@host01 /]# ceph nfs cluster create nfsservice "host01 host02"
NFS Cluster Created Successful
```

The NFS service cluster,
`nfsservice`
, is created with one daemon on
`host01`
and
`host02`
.

### What to do next

Verify the NFS service cluster.

- List the cluster details.

```plaintext-ibm
ceph nfs cluster ls
```

Copy to clipboard
- Show the NFS cluster information.

```plaintext-ibm
ceph nfs cluster info CLUSTER_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph nfs cluster info nfsservice
```
