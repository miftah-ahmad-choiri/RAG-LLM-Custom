## Stopping the removal of the OSDs

Last Updated
: 2026-06-25

You can stop the removal of only the OSDs that are queued for removal. This resets the
initial state of the OSD and takes it off the removal queue.

If the OSD is in the process of removal, then you cannot stop the process.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.
- Monitor, Manager and OSD daemons are deployed on the cluster.
- Remove OSD process initiated.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Check the device and the node from which the OSD was initiated to be removed:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph osd tree
```

Copy to clipboard
3. Stop the removal of the queued OSD:

Syntax

```plaintext-ibm
ceph orch osd rm stop OSD_ID
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch osd rm stop 0
```

Copy to clipboard
4. Check the status of the OSD removal:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch osd rm status
```

Copy to clipboard

### Verification

- Verify the details of the devices and the nodes from which the Ceph OSDs were queued for
removal:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph osd tree
```

Copy to clipboard
