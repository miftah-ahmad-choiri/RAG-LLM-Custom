## Deploying the Ceph monitor daemons using the command line interface

Last Updated
: 2026-06-25

The Ceph Orchestrator deploys one monitor daemon by default. You can deploy additional
monitor daemons by using the `placement` specification in the command line interface.
To deploy a different number of monitor daemons, specify a different number. If you do not specify
the hosts where the monitor daemons should be deployed, the Ceph Orchestrator randomly selects the
hosts and deploys the monitor daemons to them.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.

### Procedure

1. Log into the `cephadm` shell.

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. There are four different ways of deploying Ceph monitor daemons:

Method 1

- Use placement specification to deploy monitors on hosts:

> 📝 **Note:** Note:
IBM
recommends that you use the
`--placement`
option to deploy on specific
hosts.

Syntax

```plaintext-ibm
ceph orch apply mon --placement="HOST_NAME_1 HOST_NAME_2 HOST_NAME_3"
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mon --placement="host01 host02 host03"
```

Copy to clipboard

> 📝 **Note:** Note:
Be sure to include the bootstrap node as the first node in the command.

> 📝 **Note:** Important:

- Do not add the monitors individually as `ceph orch apply mon` supersedes and will
not add the monitors to all the hosts. For example, if you run the following commands, then the
first command creates a monitor on `host01`. Then the second command supersedes the
monitor on host1 and creates a monitor on `host02`. Then the third command supersedes
the monitor on `host02` and creates a monitor on `host03`. Eventually,
there is a monitor only on the third host.

```plaintext-ibm
# ceph orch apply mon host01
# ceph orch apply mon host02
# ceph orch apply mon host03
```

Method 2

- Use placement specification to deploy specific number of monitors on specific hosts with
labels:

1. Add the labels to the hosts:

Syntax

```plaintext-ibm
ceph orch host label add HOSTNAME_1 LABEL
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch host label add host01 mon
```

Copy to clipboard
2. Deploy the daemons.

Syntax

```plaintext-ibm
ceph orch apply mon --placement="HOST_NAME_1:mon HOST_NAME_2:mon HOST_NAME_3:mon"
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mon --placement="host01:mon host02:mon host03:mon"
```

Method 3

- Use placement specification to deploy specific number of monitors on specific hosts:

Syntax

```plaintext-ibm
ceph orch apply mon --placement="NUMBER_OF_DAEMONS HOST_NAME_1 HOST_NAME_2 HOST_NAME_3"
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mon --placement="3 host01 host02 host03"
```

Copy to clipboard

Method 4

- Deploy monitor daemons randomly on the hosts in the storage cluster:

Syntax

```plaintext-ibm
ceph orch apply mon NUMBER_OF_DAEMONS
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mon 3
```

Copy to clipboard
