## Removing the monitor daemons

Last Updated
: 2026-06-25

To remove the monitor daemons from the host, you can just redeploy the monitor daemons on
other hosts.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.
- At least one monitor daemon deployed on the hosts.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Run the `ceph orch apply` command to deploy the required monitor daemons:

Syntax

```plaintext-ibm
ceph orch apply mon “NUMBER_OF_DAEMONS HOST_NAME_1 HOST_NAME_3”
```

Copy to clipboard

If you want to remove monitor daemons from `host02`, then you can redeploy the
monitors on other hosts.

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mon “2 host01 host03”
```

Copy to clipboard

### Verification

- List the hosts,daemons, and processes:

Syntax

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps --daemon_type=mon
```

Copy to clipboard
