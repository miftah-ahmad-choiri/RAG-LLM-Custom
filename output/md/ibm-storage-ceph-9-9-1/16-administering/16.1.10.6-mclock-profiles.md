## mClock profiles

Last Updated
: 2026-06-25

An mClock profile is a configuration setting. When applied to a running IBM Storage Ceph cluster, it enables the throttling of the IOPS
operations belonging to different client classes, such as `background recovery`,
`scrub`, `snap trim`, `client op`, and `pg
deletion`.

The mClock profile uses the capacity limits and the mClock profile type selected by the user to
determine the low-level mClock resource control configuration parameters and applies them
transparently. Other IBM Storage Ceph configuration parameters are
also applied. The low-level mClock resource control parameters are the reservation, limit, and
weight that provide control of the resource shares. The mClock profiles allocate these parameters
differently for each client type.
