## Changing mClock profiles

Last Updated
: 2026-06-25

The default mClock profile is set to `balanced`. The other types of the
`built-in` profile are `high_client_ops` and
`high_recovery_ops`.

> 📝 **Note:** Note:
The
`custom`
profile is not recommended unless you are an advanced user.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the Ceph Monitor host.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Set the `osd_mclock_profile` option:

Syntax

```plaintext-ibm
ceph config set osd._OSD_ID_ osd_mclock_profile VALUE
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config set osd.0 osd_mclock_profile high_recovery_ops
```

Copy to clipboard

This example changes the profile to allow faster recoveries on `osd.0`.

> 📝 **Note:** Note:
For optimal performance the profile must be set on all Ceph OSDs by using the following
command:

Syntax

```plaintext-ibm
ceph config set osd osd_mclock_profile VALUE
```

Copy to clipboard
