## Updating the NFS service cluster

Last Updated
: 2026-06-25

You can update the NFS service cluster by changing the placement of the daemons on the hosts with `cephadm` in the backend.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Hosts added to the cluster.
- All Manager, Monitor, and OSD daemons deployed.
- NFS service cluster by using the `mgr/nfs` module.

### Procedure

1. Log into the
`cephadm`
shell.
For example,

```
[root@host01 ~]# cephadm shell
[ceph: root@host01 /]#
```
2. Update the cluster.

```plaintext-ibm
ceph orch apply nfs CLUSTER_NAME ["HOST_NAME_1,HOST_NAME_2,HOST_NAME_3"]
```

Copy to clipboard

The CLUSTER_NAME is an arbitrary string, HOST_NAME_1 is an optional string signifying the hosts to update the deployed NFS service daemons.

For example,

```
[ceph: root@host01 /]# ceph orch apply nfs nfsservice "host02"
```

This updates the
`nfsservice`
cluster on
`host02`
.

### What to do next

Verify the updated service cluster.

1. List the cluster details.

```plaintext-ibm
ceph nfs cluster ls
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph nfs cluster ls
```
2. Show the NFS cluster information.

```plaintext-ibm
ceph nfs cluster info CLUSTER_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph nfs cluster info nfsservice
```
3. List hosts, daemons, and processes.

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch ps --daemon_type=nfs
```
