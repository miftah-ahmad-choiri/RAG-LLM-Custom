## Viewing the NFS service cluster information

Last Updated
: 2026-06-25

You can view the information of the NFS service cluster using the Ceph Orchestrator. You
can get the information about all the NFS service clusters or specific clusters with their port, IP
address and the name of the hosts on which the cluster is created.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.
- All manager, monitor and OSD daemons are deployed.
- NFS service  cluster created using the `mgr/nfs` module.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. View the NFS service cluster information:

Syntax

```plaintext-ibm
ceph nfs cluster info CLUSTER_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph nfs cluster info nfsservice

{
    "nfsservice": [
        {
            "hostname": "host02",
            "ip": [
                "10.10.128.70"
            ],
            "port": 2049
        }
    ]
}
```

Copy to clipboard
