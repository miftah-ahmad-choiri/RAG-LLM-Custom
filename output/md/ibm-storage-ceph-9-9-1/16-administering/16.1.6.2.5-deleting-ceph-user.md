## Deleting Ceph user

Last Updated
: 2026-06-25

You can delete a user from the Ceph storage cluster using the command-line
interface.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### Procedure

1. To delete a user, use `ceph auth del`:

Syntax

```plaintext-ibm
ceph auth del TYPE.ID
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph auth del osd.6
```

Copy to clipboard
