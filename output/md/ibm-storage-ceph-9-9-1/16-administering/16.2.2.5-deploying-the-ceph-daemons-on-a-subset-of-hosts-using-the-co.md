## Deploying the Ceph daemons on a subset of hosts using the command line interface

Last Updated
: 2026-06-25

You can use the `--placement` option to deploy daemons on a subset of
hosts. You can specify the number of daemons in the placement specification with the name of the
hosts to deploy the daemons.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. List the hosts on which you want to deploy the Ceph daemons:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch host ls
```

Copy to clipboard
3. Deploy the daemons:

Syntax

```plaintext-ibm
ceph orch apply SERVICE_NAME --placement="NUMBER_OF_DAEMONS HOST_NAME_1 _HOST_NAME_2 HOST_NAME_3"
```

Copy to clipboard

Example

```plaintext-ibm
ceph orch apply mgr --placement="2 host01 host02 host03"
```

Copy to clipboard

In this example, the `mgr` daemons are deployed only on two hosts.

### Verification

- List the hosts:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch host ls
```

Copy to clipboard
