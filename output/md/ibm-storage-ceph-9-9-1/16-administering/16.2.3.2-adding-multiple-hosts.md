## Adding multiple hosts

Last Updated
: 2026-06-25

You can use the Ceph Orchestrator to add multiple hosts to an IBM Storage Ceph cluster at
the same time using the service specification in YAML file format.

### Prerequisites

- A running IBM Storage Ceph.

### Procedure

1. Create the `hosts.yaml` file:

Example

```plaintext-ibm
[root@host01 ~]# touch hosts.yaml
```

Copy to clipboard
2. Edit the `hosts.yaml` file to include the following details:

Example

```plaintext-ibm
service_type: host
addr: host01
hostname: host01
labels:
- mon
- osd
- mgr
---
service_type: host
addr: host02
hostname: host02
labels:
- mon
- osd
- mgr
---
service_type: host
addr: host03
hostname: host03
labels:
- mon
- osd
```

Copy to clipboard
3. Mount the YAML file under a directory in the container:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell --mount hosts.yaml:/var/lib/ceph/hosts.yaml
```

Copy to clipboard
4. Navigate to the directory:

Example

```plaintext-ibm
[ceph: root@host01 /]# cd /var/lib/ceph/
```

Copy to clipboard
5. Deploy the hosts using service specification:

Syntax

```plaintext-ibm
ceph orch apply -i FILE_NAME.yaml
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 hosts]# ceph orch apply -i hosts.yaml
```

Copy to clipboard

### Verification

- List the hosts:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch host ls
```

Copy to clipboard
