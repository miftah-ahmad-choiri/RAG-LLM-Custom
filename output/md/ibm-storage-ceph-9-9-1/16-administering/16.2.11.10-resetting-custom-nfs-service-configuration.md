## Resetting custom NFS service configuration

Last Updated
: 2026-06-25

Using the Ceph Orchestrator, you can reset the user-defined configuration to the default
configuration.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.
- All manager, monitor and OSD daemons are deployed.
- NFS service deployed using the `mgr/nfs` module.
- Custom NFS cluster configuration is set-up.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Reset the NFS service configuration:

Syntax

```plaintext-ibm
ceph nfs cluster config reset CLUSTER_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph nfs cluster config reset nfsservice
```

Copy to clipboard

### Verification

- List the service.

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ls
```

Copy to clipboard
- List the hosts, daemons, and processes.

Syntax

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps --daemon_type=nfs
```

Copy to clipboard
- Verify the custom configuration is deleted.

Syntax

```plaintext-ibm
/bin/rados -p POOL_NAME -N CLUSTER_NAME get userconf-nfs.CLUSTER_NAME -
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# /bin/rados -p nfs-pool -N nfsservice get userconf-nfs.nfsservice -
```

Copy to clipboard
