## Deploying the MDS service with the command-line interface

Last Updated
: 2026-06-25

Using the Ceph Orchestrator, you can deploy the Metadata Server (MDS) service by using
the `placement` specification in the command-line interface.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Hosts added to the cluster.
- All manager, monitor, and OSD daemons deployed.

### About this task

Ceph File System (CephFS) requires one or more MDS.

> 📝 **Note:** Note:
Ensure that you have at least two pools,
one for Ceph file system (CephFS) data and one for CephFS metadata.

For more information about
creating Ceph File Systems, see
Creating Ceph File Systems
.
To deploy the MDS service with the command-line interface, log in to the
`cephadm`
shell.

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard

Use one of the following options to
deploy MDS daemons using placement specification.

### Creating the MDS daemons through the command-line

#### Procedure

Use
ceph fs volume
to create the MDS daemons.
Creating the
MDS daemons creates the CephFS volume and pools associated with the CephFS, and also starts the MDS
service on the
hosts.

```plaintext-ibm
ceph fs volume create FILESYSTEM_NAME --placement="NUMBER_OF_DAEMONS HOST_NAME_1 HOST_NAME_2 HOST_NAME_3"
```

Copy to clipboard

> 📝 **Note:** Note:
By default, replicated pools are created for this command.

For
example,

```
[ceph: root@host01 /]# ceph fs volume create test --placement="2 host01 host02"
```

### Creating the pools, CephFS, and then deploying MDS service using placement specification

#### Procedure

1. Create the pools for CephFS.
```plaintext-ibm
ceph osd pool create DATA_POOL PG_NUM
ceph osd pool create METADATA_POOL PG_NUM
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph osd pool create cephfs_data 64
[ceph: root@host01 /]# ceph osd pool create cephfs_metadata 64
```
2. Create the file system for the data pools and metadata pools.
```plaintext-ibm
ceph fs new FILESYSTEM_NAME METADATA_POOL DATA_POOL
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph fs new test cephfs_metadata cephfs_data
```
3. Deploy MDS service using the
ceph orch apply
command.
```plaintext-ibm
ceph orch apply mds FILESYSTEM_NAME --placement="NUMBER_OF_DAEMONS HOST_NAME_1 HOST_NAME_2 HOST_NAME_3"
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph orch apply mds test --placement="2 host01 host02"
```

### Verifying the MDS service deployment

#### Procedure

1. List the service.For
example,

```
[ceph: root@host01 /]# ceph orch ls
```
2. Check the CephFS status.For
example,

```
[ceph: root@host01 /]# ceph fs ls
[ceph: root@host01 /]# ceph fs status
```
3. List the hosts, daemons, and processes.
```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph orch ps --daemon_type=mds
```
