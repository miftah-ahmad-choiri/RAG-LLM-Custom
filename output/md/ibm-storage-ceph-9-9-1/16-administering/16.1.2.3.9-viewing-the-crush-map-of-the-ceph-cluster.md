## Viewing the CRUSH map of the Ceph cluster

Last Updated
: 2026-06-25

View the The CRUSH map that contains a list of OSDs and related information on the IBM Storage Ceph dashboard. Together, the CRUSH map and CRUSH algorithm determine how and where data is stored. The dashboard allows you to view different aspects of the CRUSH map, including OSD hosts, OSD daemons, ID numbers, device class, and more.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Ceph Dashboard is installed.
- OSD daemons deployed on the storage cluster.

### About this task

The CRUSH map allows you to determine which host a specific OSD ID is running on. This is helpful if there is an issue with an OSD.

### Procedure

1. From the dashboard navigation, go to
Cluster
>
CRUSH map
.
2. To view CRUSH map information, select a CRUSH map from the
CRUSH map viewer
.
