## Configure active-passive NFS gateway

Last Updated
: 2026-06-25

Configure an active-passive NFS deployment by using a virtual IP managed by an ingress service.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Ensure that the Ceph cluster is deployed and healthy.
- Ensure that CephFS or Ceph Object Gateway backend storage is configured.
- Identify the hosts for the NFS service and ingress service.
- Ensure that the required ports are available and not in use.

### About this task

In an active-passive NFS deployment:

- Only one NFS daemon actively serves client traffic at a time.
- The ingress service (Keepalived) manages a virtual IP (VIP) by using VRRP mode.
- The VIP provides a single endpoint for client access.

### Configure NFS using specification file

#### Procedure

1. Create an NFS specification file.

```
vi nfs.yaml
```
2. Define the NFS configuration with placement count 1.

```plaintext-ibm
service_type: nfs
service_id: test
service_name: nfs.test
placement:
  count: 1
  hosts:
    - ceph-node-0
    - ceph-node-1
spec:
  port: 2049
  virtual_ip: 192.168.100.112
```

Copy to clipboard
3. Apply the specification.

```plaintext-ibm
ceph orch apply -i <nfs-spec.yaml>
```

Copy to clipboard
4. Create an ingress specification file.
5. Define the ingress configuration with placement count 1 and keepalive_only as true.

```plaintext-ibm
service_type: ingress
service_id: nfs.test
service_name: ingress.nfs.test
placement:
  count: 1
  hosts:
    - ceph-node-0
    - ceph-node-1
spec:
  backend_service: nfs.test
  first_virtual_router_id: 50
  keepalive_only: true
  monitor_port: 9049
  virtual_ip: 192.168.100.112
```

Copy to clipboard
6. Apply the specification.

```plaintext-ibm
ceph orch apply -i <ingress-spec.yaml>
```

Copy to clipboard

### Configure NFS using command line

#### Procedure

1. Log in to a Ceph node.
2. Run the command to configure active-passive gateway.

```plaintext-ibm
ceph nfs cluster create test '1 grim031 grim032' --ingress --virtual_ip 10.64.66.100 --ingress_mode keepalive-only
```

Copy to clipboard

#### What to do next

Verify that the services are properly implemented by performing one or both of the following steps.

- View the IP endpoints. IPs for the individual NFS daemons, and the virtual IP for the ingress service.

```plaintext-ibm
ceph orch ls --service_name=nfs.CLUSTER_NAME
ceph orch ls --service_name=ingress.nfs.CLUSTER_NAME
```

Copy to clipboard

For example,

