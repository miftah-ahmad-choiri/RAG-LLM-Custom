## Using Ceph administration socket

Last Updated
: 2026-06-25

Use the administration socket to interact with a given daemon directly by using a UNIX
socket file.

For example, the socket enables you to:

- List the Ceph configuration at runtime
- Set configuration values at runtime directly without relying on Monitors. This is useful when
Monitors are `down`.
- Dump historic operations
- Dump the operation priority queue state
- Dump operations without rebooting
- Dump performance counters

In addition, using the socket is helpful when troubleshooting problems related to Ceph Monitors
or OSDs.

Regardless, if the daemon is not running, a following error is returned when attempting to use
the administration socket:

```plaintext-ibm
Error 111: Connection Refused
```

Copy to clipboard

> 📝 **Note:** Important:
The administration socket is only available while a daemon is running. When
you shut down the daemon properly, the administration socket is removed. However, if the daemon
terminates unexpectedly, the administration socket might persist.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. To use the socket:

Syntax

```plaintext-ibm
ceph daemon MONITOR_ID COMMAND
```

Copy to clipboard

Replace:

- `MONITOR_ID` of the daemon
- `COMMAND` with the command to run. Use `help` to list the available
commands for a given daemon.

3. Alternatively, specify the Ceph daemon by using its socket file:

Syntax

```plaintext-ibm
ceph daemon /var/run/ceph/SOCKET_FILE COMMAND
```

Copy to clipboard
4. To view the status of a Ceph OSD named `osd.0` on the specific host:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph daemon /var/run/ceph/ceph-osd.0.asok status
{
    "cluster_fsid": "9029b252-1668-11ee-9399-001a4a000429",
    "osd_fsid": "1de9b064-b7a5-4c54-9395-02ccda637d21",
    "whoami": 0,
    "state": "active",
    "oldest_map": 1,
    "newest_map": 58,
    "num_pgs": 33
```
