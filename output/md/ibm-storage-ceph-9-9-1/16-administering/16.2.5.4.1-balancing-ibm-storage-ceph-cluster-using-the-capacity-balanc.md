## Balancing IBM Storage Ceph cluster using the capacity balancer

Last Updated
: 2026-06-25

Balance the cluster by using the capacity balancer module.

### Before you begin

Before you begin, make sure that you have a running
IBM Storage Ceph
cluster.

### Procedure

1. Check if the balancer module is enabled.

```plaintext-ibm
ceph mgr module enable balancer
```

Copy to clipboard
2. Turn on the balancer module.

```plaintext-ibm
ceph balancer on
```

Copy to clipboard
3. To change the mode use the following command. The default mode is
`upmap`
.

```plaintext-ibm
ceph balancer mode upmap
```

Copy to clipboard
4. Check the current status of the balancer.

```plaintext-ibm
ceph balancer status
```

Copy to clipboard
