## Renaming a zone group

Last Updated
: 2026-06-25

Use the zonegroup rename command to rename a zone group.

To rename a zone group, run the following command:

Syntax

```plaintext-ibm
radosgw-admin zonegroup rename --rgw-zonegroup=ZONE_GROUP_NAME --zonegroup-new-name=NEW_ZONE_GROUP_NAME
```

Copy to clipboard

Then, update the period:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin period update --commit
```

Copy to clipboard
