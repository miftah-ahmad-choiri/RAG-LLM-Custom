## Pulling a realm

Last Updated
: 2026-06-25

Pull a realm from the node containing the master zone group and master zone to a node
containing a secondary zone group or zone.

To pull a realm from the node containing the master zone group and master zone to a node
containing a secondary zone group or zone, run the realm pull command on the node
that will receive the realm configuration.

Syntax

```plaintext-ibm
radosgw-admin realm pull --url=URL_TO_MASTER_ZONE_GATEWAY--access-key=ACCESS_KEY --secret=SECRET_KEY
```
