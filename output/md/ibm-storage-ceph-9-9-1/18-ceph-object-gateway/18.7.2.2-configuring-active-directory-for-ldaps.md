## Configuring Active Directory for LDAPS

Last Updated
: 2026-06-25

Active Directory LDAP servers are configured to use LDAPs by default. Windows Server 2012
and higher can use Active Directory Certificate Services.

Instructions for generating and installing SSL certificates for use with Active Directory LDAP
are available in the following MS TechNet article:[LDAP over SSL (LDAPS) Certificate](https://www.ibm.com/links?url=http%3A%2F%2Fsocial.technet.microsoft.com%2Fwiki%2Fcontents%2Farticles%2F2980.ldap-over-ssl-ldaps-certificate.aspx).

> 📝 **Note:** Note:
Ensure that port
`636`
is open on the Active Directory host.
