## Installing the Red Hat Directory Server

Last Updated
: 2026-06-25

Red Hat Directory Server should be installed on a Red Hat Enterprise Linux 9 with a
graphical user interface (GUI) in order to use the Java Swing GUI Directory and Administration
consoles. However, Red Hat Directory Server can still be serviced exclusively from the command line
interface (CLI).

### Prerequisites

- Red Hat Enterprise Linux (RHEL) is installed on the server.
- The Directory Server node’s FQDN is resolvable using DNS or the `/etc/hosts`
file.
- Register the Directory Server node to the Red Hat subscription management service.
- A valid Red Hat Directory Server subscription is available in your Red Hat account.

### Procedure

- Follow the instructions in [Installing the Directory Server packages](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2Fdocumentation%2Fen-us%2Fred_hat_directory_server%2F11%2Fhtml-single%2Finstallation_guide%2Findex%23assembly_installing-the-directory-server-packages_installation-guide) and [Setting up a new Directory Server instance](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2Fdocumentation%2Fen-us%2Fred_hat_directory_server%2F11%2Fhtml-single%2Finstallation_guide%2Findex%23assembly_setting-up-a-new-directory-server-instance_installation-guide) of the Red
Hat Directory Server Installation Guide.
