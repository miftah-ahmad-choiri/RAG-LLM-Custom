## Viewing the garbage collection queue

Last Updated
: 2026-06-25

Before you purge deleted and overwritten objects from the storage cluster, use the
radosgw-admin command to view the objects awaiting garbage
collection.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the Ceph Object Gateway.

### Procedure

- To view the queue of objects awaiting garbage collection:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin gc list
```

Copy to clipboard

> 📝 **Note:** Note:
To list all entries in the queue, including unexpired entries, use the
`--include-all`
option.
