## Optimize the Ceph Object Gateway's data object storage

Last Updated
: 2026-06-25

Bucket lifecycle configuration optimizes data object storage to increase its efficiency
and to provide effective storage throughout the lifetime of the data.

The S3 API in the Ceph Object Gateway currently supports a subset of the AWS bucket lifecycle
configuration actions:

- Expiration
- NoncurrentVersionExpiration
- AbortIncompleteMultipartUpload
