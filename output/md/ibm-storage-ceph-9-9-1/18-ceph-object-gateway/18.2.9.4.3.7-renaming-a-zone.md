## Renaming a zone

Last Updated
: 2026-06-25

use the zone reanme command to rename a zone on a host.

To rename a zone, specify the zone name and the new zone name. Issue the following command on a
host within the zone:

Syntax

```plaintext-ibm
radosgw-admin zone rename --rgw-zone=ZONE_NAME --zone-new-name=NEW_ZONE_NAME
```

Copy to clipboard

Then, update the period:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin period update --commit
```

Copy to clipboard
