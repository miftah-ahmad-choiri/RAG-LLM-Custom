## Moving buckets between non-tenanted users

Last Updated
: 2026-06-25

The radosgw-admin bucket chown command provides the ability to change
the ownership of buckets and all objects they contain from one user to another.

To move buckets between non-tenant users, unlink a bucket from the current user, link it to a new
user, and change the ownership of the bucket to the new user.

### Procedure

1. Link the bucket to a new user:

Syntax

```plaintext-ibm
radosgw-admin bucket link --uid=USER --bucket=BUCKET
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin bucket link --uid=user2 --bucket=data
```

Copy to clipboard
2. Verify that the bucket has been linked to `user2` successfully:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin bucket list --uid=user2
[
    "data"
]
```

Copy to clipboard
3. Change the ownership of the bucket to the new user:

Syntax

```plaintext-ibm
radosgw-admin bucket chown --uid=user --bucket=bucket
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin bucket chown --uid=user2 --bucket=data
```

Copy to clipboard
4. Verify that the ownership of the `data` bucket has been successfully changed by
checking the `owner` line in the output of the following command:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin bucket list --bucket=data
```

Copy to clipboard
