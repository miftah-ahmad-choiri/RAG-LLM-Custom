## Get user information

Last Updated
: 2026-06-25

Use the user info command and the user ID to retrieve user
information.

To get information about a user, specify `user info` and the user ID
(`--uid=_USERNAME_`).

Example

```plaintext-ibm
[root@host01 ~]# radosgw-admin user info --uid=janedoe
```

Copy to clipboard

To get information about a tenanted user, specify both the user ID and the name of the
tenant.

```plaintext-ibm
[root@host01 ~]# radosgw-admin user info --uid=janedoe --tenant=test
```
