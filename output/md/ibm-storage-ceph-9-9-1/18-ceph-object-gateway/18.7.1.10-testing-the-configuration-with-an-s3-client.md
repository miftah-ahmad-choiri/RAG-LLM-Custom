## Testing the configuration with an S3 client

Last Updated
: 2026-06-25

Test the configuration with a Ceph Object Gateway client, using a script such as Python
Boto.

### Procedure

1. Use the
`RGW_ACCESS_KEY_ID`
environment variable to configure the Ceph
Object Gateway client. Alternatively, you can copy the base-64 encoded string and specify it as the
access key. Following is an example of the configured S3 client:
```
cat .aws/credentials

[default]
aws_access_key_id = ewogICaGbnjlwe9UT0tFTiI6IHsKICAgICAgICAidmVyc2lvbiI6IDEsCiAgICAgICAgInR5cGUiOiAiYWQiLAogICAgICAgICJpZCI6ICJjZXBoIiwKICAgICAgICAia2V5IjogInBhc3M0Q2VwaCIKICAgIH0KfQo=
aws_secret_access_key =
```

> 📝 **Note:** Note:
The secret key is no longer required.
2. Run the
aws s3 ls
command to verify the user.
```
[root@host01 ~]# aws s3 ls --endpoint http://host03

2023-12-11 17:08:50 mybucket
2023-12-24 14:55:44 mybucket2
```
3. **Optional:**You can also run the
radosgw-admin user
command
to verify the user in the directory.
