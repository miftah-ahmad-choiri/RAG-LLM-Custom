## Setting a zone

Last Updated
: 2026-06-25

Configuring a zone involves specifying a series of Ceph Object Gateway pools.

For consistency, use a pool prefix that is the same as the zone name. See the Pools
for details on configuring pools.

> 📝 **Note:** Important:
Zones should be set on a Ceph Object Gateway node that will be within the
zone.

To set a zone, create a JSON object consisting of the pools, save the object to a file, for
example, `zone.json`; then, run the following command, replacing
`ZONE_NAME` with the name of the zone:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin zone set --rgw-zone=test-zone --infile zone.json
```

Copy to clipboard

Where `zone.json` is the JSON file you created.

Then, as `root`, update the period:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin period update --commit
```
