## Retrieving the current policy

Last Updated
: 2026-06-25

You can use the get command to retrieve the current zonegroup sync
policy, or a specific bucket policy.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root or `sudo` access.
- The Ceph Object Gateway is installed.

### Procedure

- Retrieve the current zonegroup sync policy or bucket policy. To retrieve a specific bucket
policy, use the `--bucket` option:

Syntax

```plaintext-ibm
radosgw-admin sync policy get --bucket=BUCKET_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin sync policy get --bucket=mybucket
```
