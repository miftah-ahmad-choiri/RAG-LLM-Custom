## Authenticating with Ceph Object Gateway

Last Updated
: 2026-09-06

Configure the Red Hat Directory Server to authenticate Ceph Object Gateway users.

> 📝 **Note:** Important:
Before configuring LDAP, ensure the
`ceph`
and
`cephadm`
users are created in LDAP.

To configure the Red Hat Directory Server to authenticate Ceph Object Gateway users, perform the following steps:

1. Installing the Red Hat Directory Server
2. Configuring the Directory Server firewall
3. Labeling ports for SELinux
4. Configuring LDAPS
5. Adding a gateway user
6. Configuring the gateway to use LDAP
7. Using a custom search filter
8. Adding an S3 user to the LDAP server
9. Exporting an LDAP token
10. Testing the configuration with an S3 client
