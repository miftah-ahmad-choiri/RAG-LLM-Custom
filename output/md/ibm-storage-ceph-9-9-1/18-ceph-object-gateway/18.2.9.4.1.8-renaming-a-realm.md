## Renaming a realm

Last Updated
: 2026-06-25

Renaming a realm is applied locally, as a realm is not part of the period. When renaming
a realm with multiple zones, run the command on each zone.

### About this task

Renaming a realm does not get pulled with the
realm pull
command.

### Procedure

1. Rename the realm.
```plaintext-ibm
radosgw-admin realm rename --rgw-realm=REALM_NAME --realm-new-name=NEW_REALM_NAME
```

Copy to clipboard

> 📝 **Note:** Note:
Do NOT use
realm set
command to change the
name
parameter. That changes the internal name only. Specifying
--rgw-realm
would
still use the old realm name.
For
example,

```
[ceph: root@host01 /]# radosgw-admin realm rename --rgw-realm=test_realm --realm-new-name=test_realm2
```
2. Commit the changes.
```plaintext-ibm
radosgw-admin period update --commit
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# radosgw-admin period update --commit
```
