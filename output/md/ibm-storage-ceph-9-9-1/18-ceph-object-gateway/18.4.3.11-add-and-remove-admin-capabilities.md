## Add and remove admin capabilities

Last Updated
: 2026-06-25

The Ceph Storage Cluster provides an administrative API that enables users to run
administrative functions via the REST API. By default, users DO NOT have access to this API. To
enable a user to exercise administrative functionality, provide the user with administrative
capabilities.

To add administrative capabilities to a user, run the following command:

Syntax

```plaintext-ibm
radosgw-admin caps add --uid=USER_ID--caps=CAPS
```

Copy to clipboard

You can add read, write, or all capabilities to users, buckets, metadata, and usage
(utilization).

Syntax

```plaintext-ibm
--caps="[users|buckets|metadata|usage|zone]=[*|read|write|read, write]"
```

Copy to clipboard

Example

```plaintext-ibm
[root@host01 ~]# radosgw-admin caps add --uid=johndoe --caps="users=*"
```

Copy to clipboard

To remove administrative capabilities from a user, run the following command:

Example

```plaintext-ibm
[root@host01 ~]# radosgw-admin caps remove --uid=johndoe --caps={caps}
```

Copy to clipboard
