## Setting directional policy for zonegroups

Last Updated
: 2026-06-25

Set the policy for zone groups uni directionally with the sync policy engine.

### Before you begin

At least two running
IBM Storage Ceph
clusters with Ceph Object Gateway configured on the same version.

### About this task

In the following example, create a group policy and configure the data flow for the
movement of data from one zonegroup to another. Configure a pipe for the zonegroups to define the
buckets that can use this data flow. The system in the following examples includes 3 zones:
`us-east`
(the primary zone),
`us-west`
(secondary zone), and
`us-west-2`
(backup zone). Here,
`us-west-2`
is a replica of
`us-west`
, but data is not replicated back from it.

Zonegroup sync policies are
created with the new sync policy engine. Any change to the zonegroup sync policy requires a period
update and a commit.

### Procedure

1. On the primary zone, create a sync group with the status set to
`allowed`
.
```plaintext-ibm
radosgw-admin sync group create --group-id=GROUP_ID --status=allowed
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# radosgw-admin sync group create --group-id=group1
	   --status=allowed
```

> 📝 **Note:** Note:
Until a fully configured zonegroup replication policy is created, set the
`--status`
to
`allowed`
to prevent the replication from
starting.
2. Create the flow.
```plaintext-ibm

radosgw-admin sync group flow create --group-id=GROUP_ID --flow-id=FLOW_ID --flow-type=directional --source-zone=SOURCE_ZONE_NAME --dest-zone=DESTINATION_ZONE_NAME
```

Copy to clipboard

```
[ceph: root@host01 /]# radosgw-admin sync group flow create --group-id=group1 --flow-id=us-west-backup --flow-type=directional --source-zone=us-west --dest-zone=us-west-2
```
3. Create the pipe.
```plaintext-ibm
radosgw-admin sync group pipe create --group-id=GROUP_ID --pipe-id=PIPE_ID  --source-zones='SOURCE_ZONE_NAME' --dest-zones='DESTINATION_ZONE_NAME'
```

Copy to clipboard

```
[ceph: root@host01 /]# radosgw-admin sync group pipe create --group-id=group1 --pipe-id=pipe1 --source-zones='us-west' --dest-zones='us-west-2'
```
4. Update and commit the new period.
```plaintext-ibm
radosgw-admin period update --commit
```

Copy to clipboard
For example,

```
[ceph: root@host01 /]# radosgw-admin period update --commit
```

> 📝 **Note:** Note:
Updating and committing the period is mandatory for a zonegroup policy.
5. On the secondary zone, check the status of the buckets. The secondary zone has two
destinations.
```plaintext-ibm
radosgw-admin sync info
```
