## Get user quota usage stats

Last Updated
: 2026-06-25

Get the latest user quota usage stats to see how much of the quota a user has
used.

To see how much of the quota a user has consumed, run the following command:

Syntax

```plaintext-ibm
radosgw-admin user stats --uid=USER_ID
```

Copy to clipboard

> 📝 **Note:** Note:
You should run the
`radosgw-admin user stats`
command with the
`--sync-stats`
option to receive the latest data.
