## Setting a realm

Last Updated
: 2026-06-25

Set a specific realm with an input file name.

To set a realm, run the realm set command, specify the realm name, and
`--infile=` with an input file name.

Syntax

```plaintext-ibm
radosgw-admin realm set --rgw-realm=REALM_NAME --infile=IN_FILENAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin realm set --rgw-realm=test_realm --infile=filename.json
```
