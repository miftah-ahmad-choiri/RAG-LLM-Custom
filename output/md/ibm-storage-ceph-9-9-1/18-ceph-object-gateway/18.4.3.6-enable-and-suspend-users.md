## Enable and suspend users

Last Updated
: 2026-06-25

When you create a user, the user is enabled by default. However, you may suspend user
privileges and re-enable them at a later time.

To suspend a user, specify `user suspend` and the user ID.

```plaintext-ibm
[root@host01 ~]# radosgw-admin user suspend --uid=johndoe
```

Copy to clipboard

To re-enable a suspended user, specify `user enable` and the user ID:

```plaintext-ibm
[root@host01 ~]# radosgw-admin user enable --uid=johndoe
```

Copy to clipboard

> 📝 **Note:** Note:
Disabling the user disables the subuser.
