## Zones

Last Updated
: 2026-06-25

Ceph Object Gateway supports the notion of zones. A zone defines a logical group
consisting of one or more Ceph Object Gateway instances.

Configuring zones differs from typical configuration procedures, because not all of the settings
end up in a Ceph configuration file. You can list zones, get a zone configuration, and set a zone
configuration.

> 📝 **Note:** Important:
All
`radosgw-admin zone`
operations
**MUST**
be issued on a
host that operates or will operate within the zone.
