## Removing the Ceph Object Gateway using the Ceph Orchestrator

Last Updated
: 2026-09-09

Remove the Ceph Object Gateway daemons using the ceph orch rm
command.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to all the nodes.
- Hosts are added to the cluster.
- At least one Ceph Object Gateway daemon deployed on the hosts.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. List the service:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ls
```

Copy to clipboard
3. Remove the service:

Syntax

```plaintext-ibm
ceph orch rm SERVICE_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch rm rgw.test_realm.test_zone_bb
```

Copy to clipboard

### Verification

- List the hosts, daemons, and processes:

Syntax

```plaintext-ibm
ceph orch ps
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps
```

Copy to clipboard
