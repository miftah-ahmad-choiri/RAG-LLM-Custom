## Security

Last Updated
: 2026-06-25

As a storage administrator, securing the storage cluster environment is important. IBM Storage Ceph provides encryption and key management to secure the
Ceph Object Gateway access point.

### Prerequisites

- A healthy running IBM Storage Ceph cluster.
- Installation of the Ceph Object Gateway software.
