## Add a wildcard to the DNS

Last Updated
: 2026-06-25

Add the wildcard such as hostname to the DNS record of the DNS server.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Ceph Object Gateway installed.
- Root-level access to the admin node.

### Procedure

1. To use Ceph with S3-style sub-domains, add a wildcard to the DNS record of the DNS server that
the `ceph-radosgw` daemon uses to resolve domain names:

Syntax

```plaintext-ibm
bucket-name.domain-name.com
```

Copy to clipboard

For `dnsmasq`, add the following address setting with a dot (.) prepended to the
host name:

Syntax

```plaintext-ibm
address=/.HOSTNAME_OR_FQDN/HOST_IP_ADDRESS
```

Copy to clipboard

Example

```plaintext-ibm
address=/.gateway-host01/192.168.122.75
```

Copy to clipboard

For `bind`, add a wildcard to the DNS record:

Example

```plaintext-ibm
$TTL    604800
@       IN      SOA     gateway-host01. root.gateway-host01. (
                              2         ; Serial
                         604800         ; Refresh
                          86400         ; Retry
                        2419200         ; Expire
                         604800 )       ; Negative Cache TTL
;
@       IN      NS      gateway-host01.
@       IN      A       192.168.122.113
*       IN      CNAME   @
```

Copy to clipboard
2. Restart the DNS server and ping the server with a subdomain to ensure that the
`ceph-radosgw` daemon can process the subdomain requests:

Syntax

```plaintext-ibm
ping mybucket.HOSTNAME
```

Copy to clipboard

Example

```plaintext-ibm
[root@host01 ~]# ping mybucket.gateway-host01
```

Copy to clipboard
3. If the DNS server is on the local machine, you might need to modify
`/etc/resolv.conf` by adding a nameserver entry for the local machine.
4. Add the host name in the Ceph Object Gateway zone group:

1. Get the zone group:

Syntax

```plaintext-ibm
radosgw-admin zonegroup get --rgw-zonegroup=ZONEGROUP_NAME > zonegroup.json
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin zonegroup get --rgw-zonegroup=us > zonegroup.json
```

Copy to clipboard
2. Take a back-up of the JSON file:

Example

```plaintext-ibm
[ceph: root@host01 /]# cp zonegroup.json zonegroup.backup.json
```

Copy to clipboard
3. View the `zonegroup.json` file:

Example

```plaintext-ibm
[ceph: root@host01 /]# cat zonegroup.json
{
    "id": "d523b624-2fa5-4412-92d5-a739245f0451",
    "name": "asia",
    "api_name": "asia",
    "is_master": "true",
    "endpoints": [],
    "hostnames": [],
    "hostnames_s3website": [],
    "master_zone": "d2a3b90f-f4f3-4d38-ac1f-6463a2b93c32",
    "zones": [
        {
            "id": "d2a3b90f-f4f3-4d38-ac1f-6463a2b93c32",
            "name": "india",
            "endpoints": [],
            "log_meta": "false",
            "log_data": "false",
            "bucket_index_max_shards": 11,
            "read_only": "false",
            "tier_type": "",
            "sync_from_all": "true",
            "sync_from": [],
            "redirect_zone": ""
        }
    ],
    "placement_targets": [
        {
            "name": "default-placement",
            "tags": [],
            "storage_classes": [
                "STANDARD"
            ]
        }
    ],
    "default_placement": "default-placement",
    "realm_id": "d7e2ad25-1630-4aee-9627-84f24e13017f",
    "sync_policy": {
        "groups": []
    }
}
```

Copy to clipboard
4. Update the `zonegroup.json` file with new host name:

Example

```plaintext-ibm
"hostnames": ["host01", "host02","host03"],
```

Copy to clipboard
5. Set the zone group back in the Ceph Object Gateway:

Syntax

```plaintext-ibm
radosgw-admin zonegroup set --rgw-zonegroup=ZONEGROUP_NAME --infile=zonegroup.json
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin zonegroup set --rgw-zonegroup=us --infile=zonegroup.json
```

Copy to clipboard
6. Update the period:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin period update --commit
```

Copy to clipboard
7. Restart the Ceph Object Gateway so that the DNS setting takes effect.
