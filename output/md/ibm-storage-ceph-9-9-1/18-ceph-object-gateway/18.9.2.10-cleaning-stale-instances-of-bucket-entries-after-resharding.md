## Cleaning stale instances of bucket entries after resharding

Last Updated
: 2026-09-06

The resharding process might not clean stale instances of bucket entries automatically and these instances can impact performance of the storage cluster.

### Before you begin

Before you begin, make sure that you have a running
IBM Storage Ceph
cluster with a Ceph Object Gateway node.

### About this task

Clean stale instances manually to prevent them from negatively impacting the performance of the storage cluster.

> 📝 **Note:** Important:

- Before cleaning stale instances, contact [IBM Support](https://www.ibm.com/mysupport/).
- Use this procedure only in simple deployments, not in multi-site clusters.

### Procedure

1. List stale instances.

```plaintext-ibm
radosgw-admin reshard stale-instances list
```

Copy to clipboard
2. Clean the stale instances of the bucket entries.

```plaintext-ibm
radosgw-admin reshard stale-instances delete
```

Copy to clipboard

### What to do next

Verify the bucket resharding status.

```plaintext-ibm
radosgw-admin reshard status --bucket BUCKET
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# radosgw-admin reshard status --bucket data
```
