## Testing and validation

Last Updated
: 2026-06-25

As a storage administrator, you can do basic functionality testing to verify that the
Ceph Object Gateway environment is working as expected. You can use the REST interfaces by creating
an initial Ceph Object Gateway user for the S3 interface, and then create a subuser for the Swift
interface.

### Prerequisites

- A healthy running IBM Storage Ceph cluster.
- Installation of the Ceph Object Gateway software.
