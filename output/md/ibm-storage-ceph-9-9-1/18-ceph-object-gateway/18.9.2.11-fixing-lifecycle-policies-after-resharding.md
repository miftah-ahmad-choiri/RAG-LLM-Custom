## Fixing lifecycle policies after resharding

Last Updated
: 2026-06-25

For storage clusters with resharded instances, the old lifecycle processes would have
flagged and deleted the lifecycle processing as the bucket instance changed during a
reshard.

However, for older buckets that had lifecycle policies and have undergone resharding, you can fix
such buckets with the `reshard fix` option.

### Prerequisites

- A running IBM Storage Ceph cluster.
- A Ceph Object Gateway installed.

### Procedure

- Fix the lifecycle policies of the older bucket:

Syntax

```plaintext-ibm
radosgw-admin lc reshard fix --bucket BUCKET_NAME
```

Copy to clipboard

> 📝 **Note:** Important:
If you do not use the
`--bucket`
argument, then the command
fixes lifecycle policies for all the buckets in the storage cluster.

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin lc reshard fix --bucket mybucket
```

Copy to clipboard
