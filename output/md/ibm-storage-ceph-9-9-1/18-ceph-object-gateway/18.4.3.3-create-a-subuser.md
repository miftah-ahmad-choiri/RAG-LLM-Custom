## Create a subuser

Last Updated
: 2026-06-25

To create a subuser (Swift interface), you must specify the user ID
(`--uid=_USERNAME_`), a subuser ID and the access level for the subuser. If you DO
NOT specify a key or secret, `radosgw-admin` generates them for you automatically.
However, you can specify a key, a secret, or both if you prefer not to use generated key and secret
pairs.

> 📝 **Note:** Note:
`full`
is not
`readwrite`
, as it also includes the access
control policy.

Syntax

```plaintext-ibm
 radosgw-admin subuser create --uid=USER_ID --subuser=SUB_USER_ID --access=[ read | write | readwrite | full ]
```
