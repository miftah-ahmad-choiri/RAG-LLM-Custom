## Create a Swift user

Last Updated
: 2026-06-25

To test the Swift interface, create a Swift subuser. Creating a Swift user is a two-step
process. The first step is to create the user. The second step is to create the secret
key.

> 📝 **Note:** Note:
In a multi-site deployment, always create a user on a host in the master zone of the master
zone group.

### Prerequisites

- A running, and healthy IBM Storage Ceph cluster.
- Installation of the Ceph Object Gateway.
- Root-level access to the Ceph Object Gateway node.

### Procedure

1. Create the Swift user:

Syntax

```plaintext-ibm
radosgw-admin subuser create --uid=NAME --subuser=NAME:swift --access=full
```

Copy to clipboard

Replace `NAME` with the Swift user name, for example:

2. Create the secret key:

Syntax

```plaintext-ibm
radosgw-admin key create --subuser=NAME:swift --key-type=swift --gen-secret
```
