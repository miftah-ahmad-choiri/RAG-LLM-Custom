## Deploying the MDS service using the service specification

Last Updated
: 2026-06-25

Using the Ceph Orchestrator, you can deploy the MDS service using the service
specification.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Hosts added to the cluster.
- All manager, monitor, and OSD daemons deployed.

### About this task

> 📝 **Note:** Note:
Ensure that you have at least two pools, one for the Ceph File System (CephFS) data and one
for the CephFS metadata.

### Procedure

1. Create the
mds.yaml
file.
```plaintext-ibm
touch mds.yaml
```

Copy to clipboard
2. Edit the
mds.yaml
file.
```plaintext-ibm
service_type: mds
service_id: FILESYSTEM_NAME
placement:
  hosts:
  - HOST_NAME_1
  - HOST_NAME_2
  - HOST_NAME_3
```

Copy to clipboard
For example,

```
service_type: mds
service_id: fs_name
placement:
  hosts:
  - host01
  - host02
```
3. Mount the YAML file under a directory in the container.For
example,

```
[root@host01 ~]# cephadm shell --mount mds.yaml:/var/lib/ceph/mds/mds.yaml
```
4. Navigate to the
ceph/mds/
directory.For
example,

```
[ceph: root@host01 /]# cd /var/lib/ceph/mds/
```
5. Log into the
`cephadm`
shell.
```plaintext-ibm
cephadm shell
```

Copy to clipboard
6. Navigate to the
/ceph/mds/
directory.For
example,

```
[ceph: root@host01 /]# cd /var/lib/ceph/mds/
```
7. Deploy MDS service using service specification.
```plaintext-ibm
ceph orch apply -i FILE_NAME.yaml
```

Copy to clipboard
For
example,

```
[ceph: root@host01 mds]# ceph orch apply -i mds.yaml
```
8. Once the MDS services is deployed and functional, create the CephFS.
```plaintext-ibm
ceph fs new CEPHFS_NAME METADATA_POOL DATA_POOL
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph fs new test metadata_pool data_pool
```

### What to do next

Verify the MDS service deployment.

1. List the service.
```
[ceph: root@host01 /]# ceph orch ls
```
2. List the hosts, daemons, and
processes.
```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph orch ps --daemon_type=mds
```
