## Removing directory layouts

Last Updated
: 2026-06-25

Use the setfattr command to remove layouts from a
directory.

### About this task

> 📝 **Note:** Note:
When you set a file layout, you cannot change or remove it.

For more
information, see the
`setfattr(1)`
manual page.

### Procedure

1. Remove a layout from a directory.
```plaintext-ibm
setfattr -x ceph.dir.layout DIRECTORY_PATH
```

Copy to clipboard
For
example:

```
[user@client ~]$ setfattr -x ceph.dir.layout /home/test
```
2. Remove the
`pool_namespace`
field.
> 📝 **Note:** Note:
The
`pool_namespace`
field is the only field that you can remove
separately.

```plaintext-ibm
setfattr -x ceph.dir.layout.pool_namespace DIRECTORY_PATH
```

Copy to clipboard
For
example:

```
[user@client ~]$ setfattr -x ceph.dir.layout.pool_namespace /home/test
```
