## CephFS subvolumes

Last Updated
: 2026-06-25

You can create, list, fetch absolute path, fetch metadata, and remove Ceph File System
(CephFS) subvolumes. You can also create, list, and remove snapshots of these subvolumes. CephFS
subvolumes are an abstraction for independent Ceph File Systems directory trees.

Before working with  CephFS  subvolumes be sure that you have:

- A working IBM Storage Ceph cluster with  CephFS  deployed.
- A minimum read access on the Ceph Monitor.
- Read and write capability on the Ceph Manager nodes.
