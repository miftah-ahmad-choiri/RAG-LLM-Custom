## Unmounting Ceph File Systems mounted as kernel clients

Last Updated
: 2026-06-25

Learn how to unmount a Ceph File System that is mounted as a kernel client.

### About this task

For more information, see the
`umount(8)`
manual page.

### Before you begin

Before you begin, be sure that you have root-level access to the node that is
mounting.

### Procedure

Unmount a Ceph File System mounted as a kernel client.

```plaintext-ibm
umount MOUNT_POINT
```

Copy to clipboard

For example:

```
[root@client ~]# umount /mnt/cephfs
```
