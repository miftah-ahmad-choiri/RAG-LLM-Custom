## Getting custom metadata on the file system subvolume

Last Updated
: 2026-06-25

Learn how to get the custom metadata, the key-value pairs, of a Ceph File System (CephFS)
in a volume, and optionally, in a specific subvolume group.

### What to do next

Get the metadata on the CephFS
subvolume:

```plaintext-ibm
ceph fs subvolume metadata get VOLUME_NAME SUBVOLUME_NAME KEY_NAME [--group_name SUBVOLUME_GROUP_NAME]
```

Copy to clipboard

For
example:

```
[ceph: root@host01 /]# ceph fs subvolume metadata get cephfs01 sub0 test_meta --group_name subgroup0

cluster
```
