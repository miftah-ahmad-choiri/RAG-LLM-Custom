## Creating a snapshot for a Ceph File System

Last Updated
: 2026-06-25

You can create an immutable, point-in-time view of a Ceph File System (CephFS) by
creating a snapshot.

### About this task

> 📝 **Note:** Note:
For a new Ceph File System, snapshots are enabled by default.

### Procedure

1. Log into the
`cephadm`
shell.
```
[root@mds ~]# cephadm shell
```

Copy to clipboard
2. For existing Ceph File Systems, enable the snapshot feature.
```
ceph fs set FILE_SYSTEM_NAME allow_new_snaps true
```

Copy to clipboard
For
example:

```
[ceph: root@mds ~]# ceph fs set cephfs01 allow_new_snaps true
```
3. Create a snapshot subdirectory under the
`.snap`
directory.
```
mkdir NEW_DIRECTORY_PATH
```

Copy to clipboard
The following example creates the
`new-snaps`
subdirectory, informing
the Ceph Metadata Server (MDS) to start making
snapshots.

```
[ceph: root@mds ~]# mkdir /.snap/new-snaps
```

### Deleting snapshots

#### Procedure

> 📝 **Note:** Important:
Attempting to delete root-level snapshots, which might contain underlying
snapshots, will fail.

Delete snapshots.

```
rmdir NEW_DIRECTORY_PATH
```

Copy to clipboard

For
example:

```
[ceph: root@mds ~]# rmdir /.snap/new-snaps
```
