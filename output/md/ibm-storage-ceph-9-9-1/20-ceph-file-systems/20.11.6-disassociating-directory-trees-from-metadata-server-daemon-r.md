## Disassociating directory trees from Metadata Server daemon ranks

Last Updated
: 2026-06-25

Disassociate a directory from a particular active Metadata Server (MDS) rank.

### Before you begin

Before disassociating directory trees, be sure that you have user access to the Ceph File
System (CephFS) client node.

Also, ensure that the `attr` package is installed on
the client node with a mounted CephFS.

### Procedure

Set the
`ceph.dir.pin`
extended attribute to
`-1`
on a
directory:

```plaintext-ibm
setfattr -n ceph.dir.pin -v -1 DIRECTORY
```

Copy to clipboard

For
example:

```
[user@client ~]$ setfattr -n ceph.dir.pin -v -1 /home/ceph-user
```

> 📝 **Note:** Note:
Any separately mapped subdirectories of
`/home/ceph-user/`
are not
affected.

### What to do next

- Syntax

```plaintext-ibm
setfattr -n ceph.dir.pin -v -1 DIRECTORY
```

Copy to clipboard

Example

```
[user@client ~]$ setfattr -n ceph.dir.pin -v -1 /home/ceph-user
```
