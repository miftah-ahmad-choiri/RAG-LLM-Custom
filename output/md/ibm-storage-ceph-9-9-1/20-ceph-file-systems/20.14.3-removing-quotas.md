## Removing quotas

Last Updated
: 2026-06-25

Learn how to use the setfattr command and the
`ceph.quota` extended attributes to remove a quota from a directory.

### About this task

For more information, see the
`setfattr(1)`
manual page.

### Procedure

Remove CephFS quotes in one of the following ways.

- Using a byte-limit quota.
```plaintext-ibm
setfattr -n ceph.quota.max_bytes -v 0 DIRECTORY
```

Copy to clipboard
For
example:

```
[root@client ~]# setfattr -n ceph.quota.max_bytes -v 0 /mnt/cephfs/
```
In
this example,
`100000000`
equals 100 MB.
- Using a file-limit quota.
```plaintext-ibm
setfattr -n ceph.quota.max_files -v 0 DIRECTORY
```

Copy to clipboard
For
example:

```
[root@client ~]# setfattr -n ceph.quota.max_files -v 0 /mnt/cephfs/
```
