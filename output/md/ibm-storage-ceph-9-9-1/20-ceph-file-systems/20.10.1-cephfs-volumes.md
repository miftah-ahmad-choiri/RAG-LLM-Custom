## CephFS volumes

Last Updated
: 2026-06-25

You can create, list, and remove Ceph File System (CephFS) volumes. CephFS volumes are an
abstraction for Ceph File Systems.

Before working with  CephFS volume be sure that you have:

- A working IBM Storage Ceph cluster with Ceph File System deployed.
- A minimum read access on the Ceph Monitor.
- Read and write capability on the Ceph Manager nodes.
