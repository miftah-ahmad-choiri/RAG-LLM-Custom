## Listing CephFS volumes

Last Updated
: 2026-06-25

Learn how to list Ceph File System volumes.

### Before you begin

Be sure that you have a CephFS volume.

### Procedure

List the CephFS volume.

```plaintext-ibm
[ceph: root@host01 /]# ceph fs volume ls
```

Copy to clipboard
