## Removing snapshot schedule retention policy for a CephFS

Last Updated
: 2026-06-25

Learn how to remove the retention policy of the scheduled snapshots for a Ceph File
System (CephFS).

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A working IBM Storage Ceph cluster with a Ceph File System
(CephFS) deployed.
- Minimum of read access on the Ceph Monitor.
- Read and write capability on the Ceph Manager nodes.
- A snapshot schedule that is created for a CephFS volume path.

### Procedure

Remove a retention policy on a CephFS path.

```plaintext-ibm
ceph fs snap-schedule retention remove FILE_SYSTEM_VOLUME_PATH [COUNT_TIME_PERIOD_PAIR] TIME_PERIOD COUNT
```

Copy to clipboard

For example,

```
[ceph: root@host02 ~]# ceph fs snap-schedule retention remove /cephfs h 4 (1)
[ceph: root@host02 ~]# ceph fs snap-schedule retention remove /cephfs 14d4w (2)
```

- **(1)** This example removes 4 hourly snapshots.
- **(2)** This example removes 14 daily and 4 weekly snapshots.

### What to do next

Verify the retention policy, by using the snap-schedule status command. For
more information, see Checking status of CephFS snapshot schedules.
