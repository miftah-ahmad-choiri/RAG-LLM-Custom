## Removing custom metadata from the file system subvolume

Last Updated
: 2026-06-25

Learn how to remove the custom metadata, the key-value pairs, of a Ceph File System
(CephFS) in a volume, and optionally, in a specific subvolume group.

### Procedure

1. Remove the custom metadata on the CephFS subvolume.
```plaintext-ibm
ceph fs subvolume metadata rm VOLUME_NAME SUBVOLUME_NAME KEY_NAME [--group_name SUBVOLUME_GROUP_NAME]
```

Copy to clipboard
For
example:

```
[ceph: root@host01 /]# ceph fs subvolume metadata rm cephfs01 sub0 test_meta --group_name subgroup0
```
2. List the metadata.For
example:

```
[ceph: root@host01 /]# ceph fs subvolume metadata ls cephfs01 sub0 --group_name subgroup0

{}
```
