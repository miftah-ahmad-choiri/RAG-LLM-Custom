## Managing the MDS service using the Ceph Orchestrator

Last Updated
: 2026-06-25

Use the Ceph Orchestrator with `cephadm` in the backend to deploy the MDS
service.

By default, a Ceph File System (CephFS) uses only one active MDS daemon. However, systems with
many clients benefit from multiple active MDS daemons.

When managing the MDS service by using the Ceph Orchestrator, be sure to have:

- A running IBM Storage Ceph cluster.
- Root-level access to all the nodes.
- Hosts added to the cluster.
- All manager, monitor, and OSD daemons deployed.
