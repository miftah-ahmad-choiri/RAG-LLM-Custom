## Recalculating a CRUSH tree bucket weight

Last Updated
: 2026-06-25

When manually editing CRUSH map weights, recalculate the CRUSH bucket tree
weight.

CRUSH tree buckets should be the sum of their leaf weights. If you manually edit the CRUSH map
weights, you should run the following to ensure that the CRUSH bucket tree accurately reflects the
sum of the leaf OSDs under the bucket.

Syntax

```plaintext-ibm
osd crush reweight-all
```
