## Fetching details for an erasure-code-profile

Last Updated
: 2026-06-25

Learn how to display an erasure code profile.

To display an erasure code profile:

Syntax

```plaintext-ibm
ceph osd erasure-code-profile get NAME
```

Copy to clipboard

where NAME is the name of the profile.
