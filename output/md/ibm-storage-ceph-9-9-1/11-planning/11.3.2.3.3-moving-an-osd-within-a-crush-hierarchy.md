## Moving an OSD within a CRUSH Hierarchy

Last Updated
: 2026-06-25

If the storage cluster topology changes, you can move an OSD in the CRUSH hierarchy to
reflect its actual location.

> 📝 **Note:** Important:
Moving an OSD in the CRUSH hierarchy means that Ceph will recompute which
placement groups get assigned to the OSD, potentially resulting in significant redistribution of
data

To move an OSD within the CRUSH hierarchy:

Syntax

```plaintext-ibm
ceph osd crush set ID_OR_NAME WEIGHT root=POOL_NAME  [BUCKET_TYPE=BUCKET_NAME...]
```

Copy to clipboard

> 📝 **Note:** Note:
You can also use
`ceph osd crush create-or-move`
to move an OSD within the CRUSH
hierarchy.
