## Scrubbing placement groups

Last Updated
: 2026-06-25

Learn how to scrub a placement group.

To scrub a placement group, run the following:

Syntax

```plaintext-ibm
ceph pg scrub PG_ID
```

Copy to clipboard

Ceph checks the primary and any replica nodes, generates a catalog of all objects in the
placement group and compares them to ensure that no objects are missing or mismatched, and their
contents are consistent. Assuming the replicas all match, a final semantic sweep ensures that all of
the snapshot-related object metadata is consistent. Errors are reported via logs.
