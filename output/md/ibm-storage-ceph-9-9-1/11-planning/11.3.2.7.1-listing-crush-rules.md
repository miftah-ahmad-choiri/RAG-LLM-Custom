## Listing CRUSH rules

Last Updated
: 2026-06-25

Use this information to list CRUSH rules from the command-line.

To list CRUSH rules from the command line, run the following:

Syntax

```plaintext-ibm
ceph osd crush rule list
ceph osd crush rule ls
```
