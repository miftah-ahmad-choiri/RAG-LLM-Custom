## Updating noautoscale flag

Last Updated
: 2026-06-25

If you want to enable or disable the autoscaler for all the pools at same time, you can
use the `noautoscale` global flag. This global flag is useful during upgradation of
the storage cluster when some OSDs are bounced or when the cluster is under maintenance. You can set
the flag before any activity and unset it once the activity is complete.

By default, the `noautoscale` flag is set to `off`. When this flag
is set, then all the pools have `pg_autoscale_mode` as `off` and all
the pools have the autoscaler disabled.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to all the nodes.

### Procedure

1. Get the value of the `noautoscale` flag:

Example

```plaintext-ibm
 [ceph: root@host01 /]# ceph osd pool get noautoscale
```

Copy to clipboard
2. Set the `noautoscale` flag before any activity:

Example

```plaintext-ibm
 [ceph: root@host01 /]# ceph osd pool set noautoscale
```

Copy to clipboard
3. Unset the `noautoscale` flag on completion of the activity:

Example

```plaintext-ibm
 [ceph: root@host01 /]# ceph osd pool unset noautoscale
```
