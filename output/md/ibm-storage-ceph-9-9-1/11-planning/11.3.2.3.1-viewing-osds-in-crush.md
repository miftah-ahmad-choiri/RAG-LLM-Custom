## Viewing OSDs in CRUSH

Last Updated
: 2026-06-25

The ceph osd crush tree command outputs CRUSH buckets and items in a
tree view. Use this command to determine a list of OSDs in a particular bucket. It gives output
similar to the ceph osd tree command.

To return additional details, run the following:

```plaintext-ibm
# ceph osd crush tree -f json-pretty
```

Copy to clipboard
