## Getting the number of object replicas

Last Updated
: 2026-06-25

Learn how to get the number of object replicas.

To get the number of object replicas, run the following command:

```plaintext-ibm
ceph osd dump | grep 'replicated size'
```

Copy to clipboard

Ceph will list the pools, with the `replicated size` attribute highlighted. By
default, Ceph creates two replicas of an object, that is a total of three copies, or a size of
`3`.
