## Getting pool values

Last Updated
: 2026-06-25

Get a value from a pool.

To get a value from a pool, run the following command:

```plaintext-ibm
ceph osd pool get POOL_NAME KEY
```

Copy to clipboard

For more information about the available key-value pairs, see Pool values.
