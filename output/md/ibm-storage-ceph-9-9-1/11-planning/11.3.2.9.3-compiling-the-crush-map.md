## Compiling the CRUSH map

Last Updated
: 2026-06-25

To compile a CRUSH map, run the following:

Syntax

```plaintext-ibm
crushtool -c DECOMPILED_CRUSHMAP_FILENAME -o COMPILED_CRUSHMAP_FILENAME
```

Copy to clipboard

Ceph will store a compiled CRUSH map to the file name you specified.
