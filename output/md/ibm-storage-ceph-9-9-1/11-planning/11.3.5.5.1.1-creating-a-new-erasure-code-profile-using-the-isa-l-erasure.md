## Creating a new erasure code profile using the ISA-L erasure code plugin

Last Updated
: 2026-06-25

The ISA-L plugin provides high-performance Reed-Solomon erasure coding using the Intel® Intelligent Storage Acceleration Library. Starting with IBM Storage Ceph 9.9.0, new clusters created on this release use ISA-L as the default erasure code plugin. Clusters upgrading to IBM Storage Ceph 9.9.0 continue using their existing Jerasure-based default profile, but they may create new ISA-L or Jerasure profiles as needed.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- The cluster is running IBM Storage Ceph 9.9.0 or later.
- You have administrator privileges.
- All OSD nodes have ISA-L support installed.

### Procedure

1. To create an ISA-L–based erasure code profile, run the following commands:

```plaintext-ibm
ceph osd erasure-code-profile set <NAME> \
     plugin=isa \
     k=DATA_CHUNKS \
     m=CODING_CHUNKS \
     technique=TECHNIQUE \
     [crush-root=ROOT] \
     [crush-failure-domain=BUCKET_TYPE] \
     [directory=DIRECTORY] \
     [--force]
```

Copy to clipboard

The following example creates a 4+2 ISA-L profile:

```
ceph osd erasure-code-profile set isal_4_2 \
     plugin=isa \
     k=4 \
     m=2 \
     technique=reed_sol_van \
     crush-failure-domain=host
```
2. Create a pool using the profile:

```plaintext-ibm
ceph osd pool create ecpool 12 12 erasure isal_4_2
```

Copy to clipboard

### Results

The ISA-L erasure code profile is created and available for use. You can verify the profile by running the following command:

```plaintext-ibm
ceph osd erasure-code-profile get <NAME>
```
