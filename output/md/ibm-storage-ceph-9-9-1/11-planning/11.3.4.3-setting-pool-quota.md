## Setting pool quota

Last Updated
: 2026-06-25

You can set pool quotas for the maximum number of bytes or the maximum number of objects
per pool or for both.

Syntax

```plaintext-ibm
ceph osd pool set-quota POOL_NAME [max_objects OBJECT_COUNT>] [max_bytes BYTES]
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph osd pool set-quota data max_objects 10000
```

Copy to clipboard

To remove a quota, set its value to
`0`
.

> 📝 **Note:** Note:
In-flight write operations might
overrun pool quotas for a short time until Ceph propagates the pool usage across the cluster. This
is normal behavior. Enforcing pool quotas on in-flight write operations would impose significant
performance penalties.
