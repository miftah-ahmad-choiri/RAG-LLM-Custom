## Configuring OpenStack to use Ceph Block Devices

Last Updated
: 2026-06-25

Configure OpenStack services to use Ceph block devices as a scalable and resilient storage backend after the Ceph cluster is prepared.

As a storage administrator, you must configure OpenStack services to use Ceph Block Devices after installing and preparing the Ceph cluster. This configuration enables OpenStack components to consume Ceph storage for images, volumes, backups, and virtual machine disks.

This section describes the tasks required to configure OpenStack components to integrate with Ceph block storage. Complete all tasks in this section only after Ceph is fully installed and configured for OpenStack.

Before you begin, make sure that you have the following prerequisites in place:

- IBM Storage Ceph is installed and configured for use with OpenStack.
- Ceph storage pools required for OpenStack service integration are created.
- Ceph client authentication is configured.
- A running OpenStack environment is available.
