## Configuring Cinder Backup to use Ceph Block Devices

Last Updated
: 2026-06-25

Configure OpenStack Cinder Backup to store volume backup data in Ceph Block Storage.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Root access to the Cinder node.
- A Ceph pool is created for storing backup data.

### About this task

Cinder Backup enables backup and restore of Cinder volumes. When configured to use Ceph, backup data is stored as RADOS objects in a designated Ceph pool.

### Procedure

1. Edit the Cinder configuration file.

For example, to open the configuration file on the Cinder node:

```plaintext-ibm
vi /etc/cinder/cinder.conf
```

Copy to clipboard
2. Add the Cinder Backup configuration to the
`[ceph]`
section of the configuration file.

```plaintext-ibm
backup_driver = cinder.backup.drivers.ceph
backup_ceph_conf = /etc/ceph/ceph.conf
backup_ceph_pool = backups
backup_ceph_user = cinder-backup
backup_ceph_chunk_size = 134217728
backup_ceph_stripe_unit = 0
backup_ceph_stripe_count = 0
restore_discard_excess_bytes = true
```

Copy to clipboard
3. Verify that the Cinder Backup service is enabled in the OpenStack dashboard configuration.

### Results

Cinder Backup is configured to use Ceph Block Devices for storing backup data. Volume backups can now be created and managed by using the Ceph backend.

### What to do next

Restart the OpenStack service to complete the configuration. For more information, see
Restarting the OpenStack services
.
