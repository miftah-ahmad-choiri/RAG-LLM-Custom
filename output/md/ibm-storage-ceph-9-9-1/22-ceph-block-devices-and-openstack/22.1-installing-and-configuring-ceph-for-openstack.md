## Installing and configuring Ceph for OpenStack

Last Updated
: 2026-06-25

Install and configure IBM Storage Ceph so that OpenStack can use Ceph Block Devices as a storage backend.

Before you begin, make sure that you have the following prerequisites in place:

- A new or existing IBM Storage Ceph cluster is installed and operational.
- Administrative access to the Ceph cluster.
- Access to the OpenStack environment that will use Ceph storage.

Complete all tasks in this section before proceeding to coßnfigure OpenStack services to use Ceph Block Devices. The following is a high-level workflow of the tasks required:

1. Install IBM Storage Ceph and verify that the cluster reports a healthy status.

For more information, see Installing the Ceph client on OpenStack.
2. Create and configure Ceph storage pools for OpenStack services.
3. Configure authentication and access for OpenStack.
4. Validate connectivity between OpenStack and the Ceph cluster.
