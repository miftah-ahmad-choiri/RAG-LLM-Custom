## Deleting NFS shares from the Ceph Dashboard

Last Updated
: 2026-06-25

You can delete the NFS service daemons on the IBM Storage Ceph dashboard.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- A minimum `ganesha-manager` level of access on the Ceph dashboard.
- NFS service daemon configured on the dashboard.

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### Procedure

1. Go to the NFS page.

- To create an Object Gateway NFS share, go to Object
>
NFS and click Create.
- To create a CephFS NFS share, go to File
>
NFS and click Create.

  - To create an Object Gateway NFS share, go to Object
  >
  NFS and click Create.
  - To create a CephFS NFS share, go to File
  >
  NFS and click Create.
2. Click
Delete
from the NFS share row menu.
3. In the
Delete NFS export
dialog, select
Yes, I am sure
and click
Delete NFS export
.
The selected row is no longer shows in the NFS table.
