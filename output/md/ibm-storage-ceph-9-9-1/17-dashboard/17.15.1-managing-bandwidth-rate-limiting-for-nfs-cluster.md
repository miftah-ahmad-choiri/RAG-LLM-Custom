## Managing bandwidth rate-limiting for NFS cluster

Last Updated
: 2026-06-25

Learn to set, edit, and disable the bandwidth rate-limiting by using the Ceph dashboard.

### Before you begin

Before you begin, make sure that you have an NFS cluster configured.

### About this task

Rate-limiting is also known as quality of service (QoS). Defining bandwidth limits helps ensure a balanced workload distribution across the cluster.

> 📝 **Note:** Note:
The bandwidth rate limiting for NFS clusters ranges from a minimum of 1 MiB to a maximum of 100 GiB.

For more information, see Rate-limiting in NFS.

### Setting bandwidth rate-limiting

Learn to set the bandwidth rate-limiting for an NFS cluster by using the dashboard.

1. From the Dashboard navigation, go to
File

NFS

The

3. Complete the form, per your requirements.

is prepopulated with the selected cluster name.

Individual

Bandwidth QOS type
based on your requirements.

### Editing bandwidth rate-limiting

Edit bandwidth rate-limiting information, changing the existing rate-limiting values, as required.

#### Before you begin

- You must have QoS already set for the selected NFS cluster. For more information, see Setting bandwidth rate-limiting.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Select the NFS cluster for which you want to edit QoS and click
Set QOS
.
The
Edit NFS cluster
form displays.
3. In the
Edit NFS cluster
form, edit the required information and click
Edit Cluster
.
A notification is displayed that the cluster is updated successfully.

### Disabling bandwidth rate-limiting

You can disable bandwidth rate-limit for the NFS cluster at any time through the Ceph dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Select the NFS cluster for which you want to disable QoS.
3. Click
Set QOS
.
The
Edit NFS cluster
form displays.
4. In the
Edit NFS cluster
form, clear the
Enable Bandwidth QOS
checkbox.
A notification is displayed that the cluster is updated successfully.
