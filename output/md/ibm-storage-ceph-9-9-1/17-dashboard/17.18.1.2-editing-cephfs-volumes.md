## Editing CephFS volumes

Last Updated
: 2026-06-25

You can edit Ceph File System (CephFS) volumes on the IBM Storage Ceph dashboard.

### Before you begin

- A working IBM Storage Ceph cluster with Ceph File System
deployed.

### Procedure

1. From the dashboard navigation, go to
File
>
File
Systems
.
2. From the listed volumes, select the volume to be edited and click
Edit
.
3. In the
Edit File System
window, rename the volume as required and
click
Edit File System
.A notification displays that the
volume was edited successfully.
