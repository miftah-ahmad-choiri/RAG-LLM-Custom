## Configuring a Grafana certificate

Last Updated
: 2026-09-06

Configure a custom SSL/TLS certificate for Grafana by using the certmgr certificate manager.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- A valid SSL/TLS certificate.
- A corresponding private key.
- Access to the cephadm shell.

### About this task

cephadm deploys Grafana by using certificates managed by the certmgr certificate manager. Grafana certificates are configured per host.

If you do not configure a custom certificate, cephadm generates and signs a certificate for each host where Grafana runs.

To use your own certificate, configure the Grafana service to use `certificate_source: reference` and upload the certificate and private key to certmgr.

### Procedure

1. Log in to the
cephadm
shell.
For example,

```
[root@host01 ~]# cephadm shell
```
2. Configure the Grafana service specification to reference certificates managed by
certmgr
.

```plaintext-ibm
service_type: grafana
placement:
  hosts:
  - ceph-node-hostname
spec:
  ssl: true
  certificate_source: reference
```

Copy to clipboard
3. Upload the SSL/TLS certificate to
certmgr
.

```plaintext-ibm
ceph orch certmgr cert set \
--cert-name GRAFANA_CERTIFICATE \
--hostname CEPH_HOSTNAME \
-i $PWD/certificate.pem
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch certmgr cert set \
--cert-name grafana_ssl_cert \
--hostname ceph-node-hostname \
-i $PWD/certificate.pem
```
4. Upload the private key to
certmgr
.

```plaintext-ibm
ceph orch certmgr key set \
--key-name GRAFANA_KEY \
--hostname CEPH_HOSTNAME \
-i $PWD/key.pem
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch certmgr key set \
--key-name grafana_ssl_key \
--hostname ceph-node-hostname \
-i $PWD/key.pem
```
5. Apply the updated certificate configuration.

```plaintext-ibm
ceph orch reconfig grafana
```

Copy to clipboard

### Results

Grafana uses the user-provided SSL/TLS certificate and private key stored in
certmgr
for the specified host.

### What to do next

Verify that the Ceph Dashboard and Grafana interface load successfully using the updated SSL/TLS certificate.
