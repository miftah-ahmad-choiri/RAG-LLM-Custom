## Managing the Ceph NVMe-oF gateway

Last Updated
: 2026-07-23

Manage Ceph NVMe-oF gateway resources directly from the Ceph Dashboard.

To manage the NVMe over Fabrics (NVMe-oF) gateway and related actions through the dashboard, go to
Block
>
NVMe/TCP
.

> 📝 **Note:** Important:
Ceph Block Device (
`rbd`
) enabled pools are necessary for using the Ceph NVMe-oF gateway.

The basic workflow for configuring NVMe-oF resources from the dashboard is as follows:

1. Create a gateway group.
2. Add gateway nodes to the gateway group.
3. Create a subsystem.
4. Configure host access and authentication.
5. Add initiators as needed.
6. Create one or more namespaces.
7. Expand or delete resources as needed.

> 📝 **Note:** Note:
The pool created with the nvmeof service is specifically for managing the gateway group metadata. Other pools can be created for managing the images with the namespaces.

The NVMe/TCP page contains the following tabs: Gateways, Subsystems, and Namespaces.

Gateways
Manage gateway groups and gateway nodes. Use the
Gateways
tab to create gateway groups, add gateway nodes, view gateway group details, and delete gateway groups.

For more information, see Managing gateway groups.

Subsystems
Manage NVMe-oF subsystems and host access. Use the
Subsystems
tab to create and delete subsystems, configure host access and authentication settings, and view subsystem details, including associated initiators, namespaces, listeners, and performance information.

For more information, see Managing NVMe-oF subsystems.

Namespaces
Manage storage that is exposed through NVMe-oF subsystems. Use the
Namespaces
tab to create, expand, view, and delete namespaces.

For more information, see Managing NVMe-oF namespaces.

For more information about the Ceph NVMe-oF gateway, including information about setup and best practices, see Ceph NVMe-oF gateway.
