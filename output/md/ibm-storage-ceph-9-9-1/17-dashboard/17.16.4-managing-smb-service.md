## Managing SMB service

Last Updated
: 2026-06-25

Learn to create and list the SMB services by using the Ceph dashboard.

### About this task

You can provide CephFS access to clients by using the SMB service and samba-container images, managed by IBM Storage Ceph.

### Creating SMB service

Learn to create a SMB service. Complete the steps in order listed.

#### Procedure

1. Create a CephFS volume. See
Creating CephFS volumes
.
2. Create a CephFS subvolume group. See
Creating CephFS subvolume groups
.
3. Create a CephFS subvolume. See
Creating CephFS subvolume
.
4. Create a Ceph SMB cluster. See
Managing SMB clusters
.
5. Create SMB shares. See
Managing SMB shares
.
6. Verify SMB service status.

1. Check cluster status is "Running".
2. Verify shares are "Active".
3. Test connectivity from SMB client.

> 📝 **Note:** Note:
The SMB service becomes operational only after all these steps are completed.

  1. Check cluster status is "Running".
  2. Verify shares are "Active".
  3. Test connectivity from SMB client.

### Listing SMB service

Learn to view the SMB services by using the Ceph dashboard.

#### Procedure

1. Navigate to the dashboard, click
Administration
.
2. Click
Services
.
A list of all the services created is displayed.
