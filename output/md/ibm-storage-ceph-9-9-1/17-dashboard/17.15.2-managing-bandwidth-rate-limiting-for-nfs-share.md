## Managing bandwidth rate-limiting for NFS share

Last Updated
: 2026-06-25

Learn to set, edit, and disable the bandwidth rate-limiting by using the Ceph dashboard.

### About this task

Enabling bandwidth rate limiting for NFS shares helps control network traffic by restricting the data transfer rate for NFS clients. This prevents network congestion, ensures fair bandwidth distribution, and optimizes system performance.

To enable share-level bandwidth control, you must enable cluster-level bandwidth control with Bandwidth QOS type as either PerShare or Pershare_PerClient.

> 📝 **Note:** Note:
You cannot enable share-level bandwidth control if the cluster-level
Bandwidth QOS type
is
PerClient
.

For more information, see Rate-limiting in NFS.

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### Setting bandwidth rate-limiting

Learn to set the bandwidth rate-limiting for an NFS share by using the dashboard.

#### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- An NFS cluster.
- NFS shares.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Click the
arrow
next to the NFS cluster for which share you want to set the QoS.
A list of shares that are associated with the selected cluster is displayed.
3. If no shares are available, click
Create
to create the share.
The
Create NFS export
form displays.
4. Complete the form, per your requirements.
5. Enable rate-limiting by selecting
Enable bandwidth QOS
.
6. Select the
Bandwidth QOS type
based on your requirements.
Based on your selection further options to set the limits are given. Add the required information.
7. Click
Create NFS Export
to save the QoS settings.
A notification is displayed that the QoS is set successfully.

### Editing bandwidth rate-limiting

Edit bandwidth rate-limiting information, changing the existing rate-limiting values, as required.

#### Before you begin

You must have QoS already set for the selected NFS share. For more information, see
Setting bandwidth rate-limiting
.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Click the
arrow
next to the NFS cluster for which share you want to set the QoS.
A list of shares that are associated with the selected cluster is displayed.
3. Select the NFS share for which you want to edit QoS and click the
action menu
.
The
Edit
option displays.
4. Click
Edit
.
The
Edit NFS export
form displays.
5. In the
Edit NFS export
form, edit the required information and click
Edit export
.
A notification is displayed that the share is updated successfully.

### Disabling bandwidth rate-limiting

You can disable bandwidth rate-limit for the NFS share at any time through the Ceph Dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Click the
arrow
next to the NFS cluster for which share you want to set the QoS.
A list of shares that are associated with the selected cluster is displayed.
3. Select the NFS share for which you want to disable QoS and click the
action menu
.
The
Edit
option displays.
4. Click
Edit
.
The
Edit NFS export
form displays.
5. In the
Edit NFS export
form, clear the
Enable Bandwidth QOS
checkbox.
A notification is displayed that the export is updated successfully.
