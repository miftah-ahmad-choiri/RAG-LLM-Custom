## Cloning roles

Last Updated
: 2026-06-25

When you want to assign additional permissions to existing roles, you can clone the
system roles and edit it on the IBM Storage Ceph Dashboard.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Dashboard is installed.
- Admin-level of access to the dashboard.
- Roles are created on the dashboard.

### Procedure

1. From the dashboard menu, click the Dashboard Settings icon and then click
User management.
2. On Roles tab, click the role you want to clone.
3. Select Clone from action drop-down.
4. In the Clone Role dialog box, enter the details for the role, and then
click Clone Role.

Once you clone the role, you can customize the permissions as per the requirements.
