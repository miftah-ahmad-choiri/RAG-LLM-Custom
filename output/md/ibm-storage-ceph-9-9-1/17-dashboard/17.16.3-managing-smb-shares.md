## Managing SMB shares

Last Updated
: 2026-06-25

The IBM Storage Ceph dashboard provides an interface
for managing SMB shares. You can create, edit, and delete the SMB shares by using the
dashboard.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:
Follow the sections to create, edit, and
delete the SMB shares:

- Creating an SMB share.
- Editing SMB share.
- Deleting SMB share.
- Listing SMB shares.

### Creating an SMB share

Learn to create SMB shares by using the Caph dashboard.

#### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running SMB cluster.
- A file system (volume), subvolume group.
- A subvolume not earmarked by NFS.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Go to the
Clusters
tab, and a list of all the available SMB
clusters is displayed.
3. Click the
^
next to the SMB cluster for which you want to create a
share.The
Create Share
form displays.
4. Complete the
Create Share
form, per your
requirements.
5. **Optional:**Select the
Browseable
checkbox if you want
the share to be visible to clients.
6. **Optional:**Select the
Readonly
checkbox to restrict the
share to read-only access without write permissions.
7. Click
Create Share
.A notification is displayed
that the share is created successfully.

### Editing SMB share

Learn to edit SMB shares by using the Ceph dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Go to the
Clusters
tab, and a list of all the available SMB
clusters is displayed.
3. Click
^
next to the SMB cluster for which you want to edit the
share.
4. Click the action button next to the share that you want to edit.
5. Click
Edit
.The
Edit Share
form displays.
6. In the
Edit Share
form, edit the required information and click
Edit Share
.A notification is displayed that the share is
edited successfully.

> 📝 **Note:** Note:
The
Share name
field cannot be edited as it serves
as a unique identifier for the share within the system. Renaming it might disrupt configurations,
access paths, and dependent services.

### Deleting SMB share

Learn to delete SMB share by using the Ceph dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Go to the
Clusters
tab, and a list of all the available SMB
clusters is displayed.
3. Click
^
next to the SMB cluster for which you want to edit the
share.
4. Click the action button next to the share that you want to delete.
5. Click
Delete
.
6. Confirm that you want to delete the SMB share.A notification is
displayed that the share is deleted successfully.

### Listing SMB shares

Learn to list the SMB shares by using the Ceph dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Go to the
Clusters
.A list of all the available
SMB clusters is displayed
3. Click
^
next to the SMB cluster for which you want to list the
shares.A list of shares that are associated with the selected cluster is
displayed.
