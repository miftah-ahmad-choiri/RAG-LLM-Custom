## Managing bandwidth and IOPS rate-limiting for SMB shares

Last Updated
: 2026-06-25

Learn to set, edit, and disable the bandwidth rate-limiting by using the Ceph dashboard.

### Before you begin

Before you begin, make sure that you have an SMB cluster configured.

### About this task

Rate-limiting is also known as quality of service (QoS). Defining bandwidth limits helps ensure a balanced workload distribution across the cluster.

> 📝 **Note:** Note:
The bandwidth rate limiting for SMB clusters ranges from a minimum of 1 MiB to a maximum of 100 GiB.

For more information, see Rate-limiting in SMB.

### Setting bandwidth rate-limiting

Learn to set the bandwidth rate-limiting for an SMB cluster by using the dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Select the SMB cluster for which you want to set the QoS.
The selected cluster row expands to display the list of shares.
3. Select the share where you want to set the QoS and click on
Edit
.
4. On the Edit Share page, scroll down to Rate limiting section and enter the
IOPS
and
bandwidth limits
as per your requirements.
5. Click
Edit Share
to save the settings.
A notification is displayed that the QoS is set successfully.
