## Managing gateway groups

Last Updated
: 2026-07-23

Create, view, and delete gateway groups with the Ceph Dashboard.

### About this task

To manage gateway groups, from the dashboard navigation, go to Block
>
NVMe/TCP. Click the Gateways tab.

Gateway groups provide a logical grouping of NVMe-oF gateway nodes. Gateway groups are used to organize gateway resources and manage associated subsystems.

Click a gateway group name to view gateway nodes and associated subsystems.

### Viewing gateway groups

View configured gateway groups from the Ceph Dashboard.

#### Procedure

View configured NVMe-oF gateway groups from the
Gateways
tab.
The
Gateways
table displays the gateway group name, number of gateways, number of subsystems, creation date, and available management actions for each gateway group.

### Creating gateway groups

Create gateway groups with the Ceph Dashboard.

#### Procedure

1. On the
Gateways
tab, click
Create
.
2. Complete the required fields and click
Create
.
The gateway group is added to the
Gateways
table.

### Viewing gateway group details

View gateway nodes and associated subsystems for a gateway group.

#### About this task

Gateway group details provide information about the gateway nodes that belong to the gateway group and the subsystems that are associated with it.

From the Gateways tab, click the gateway group name. The gateway group details page opens and provides access to the Gateway nodes and Subsystems pages.

#### Procedure

- From the
Gateway nodes
page, view the gateway nodes that belong to the gateway group, including the hostname, IP address, status, and labels for each gateway node.
- From the
Subsystems
page, view the subsystems that are associated with the gateway group, including the subsystem NQN, authentication settings, and associated hosts and initiators.

### Adding gateway nodes

Add gateway nodes to a gateway group.

#### About this task

Gateway nodes provide hosts that are used by the gateway group for NVMe-oF operations.

A gateway group can contain one or more gateway nodes. The available hosts in the cluster can be added to a gateway group as needed.

#### Procedure

1. From the
Gateways
tab, click the gateway group name.
2. On the
Gateway nodes
page, click
Add
.
3. Select one or more hosts and click
Add
.
The selected hosts are added to the gateway group and are displayed in the
Gateway nodes
table.

### Deleting gateway groups

Delete gateway groups that are no longer required.

#### About this task

Gateway groups can be deleted at any time from the Gateways tab.

> 📝 **Note:** Important:
Deleting a gateway group removes all associated subsystems and can disrupt active traffic.

#### Procedure

1. From the action menu for the gateway group, select
Delete
.
2. In the
Delete gateway group
dialog, review the warning message and click
Delete gateway group
.
The selected gateway group is removed from the
Gateways
table.
