## Managing input/output operations rate-limiting for NFS shares

Last Updated
: 2026-06-25

Learn to set, edit, and disable the input/output operations (IOPS) rate-limiting by using the Ceph dashboard.

### About this task

Enabling input/output operations (IOPS) rate limiting for NFS shares helps control network traffic by restricting the data transfer rate for NFS clients. This prevents network congestion, ensures fair bandwidth distribution, and optimizes system performance.

To enable share-level bandwidth control, you must enable cluster-level bandwidth control with IOPS QOS type as either PerShare or Pershare_PerClient.

> 📝 **Note:** Note:
You cannot enable share-level bandwidth control if the cluster-level
IOPS QOS type
is
PerClient
.

For more information, see Rate-limiting in NFS.

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### Setting input/output operations rate-limiting

Learn to set the input/output operations (IOPS) rate-limiting for an NFS shares by using the dashboard.

#### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- An NFS cluster.
- NFS shares.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Click the
arrow
next to the NFS cluster for which export you want to set the QoS.
A list of shares that are associated with the selected cluster is displayed.
3. If no shares are available, click
Create
to create the share.
The
Create NFS export
form displays.
4. Complete the form, per your requirements.
5. Enable rate-limiting by selecting
Enable IOPS QOS
.
6. Select the
IOPS QOS type
based on your requirements.
Based on your selection further options to set the limits are given. Add the required information.
7. Click
Create NFS Export
to save the QoS settings.
A notification is displayed that the QoS is set successfully.

### Editing input/output operations rate-limiting

Edit input/output operations (IOPS) rate-limiting information, changing the existing rate-limiting values, as required.

#### Before you begin

You must have QoS already set for the selected NFS share. For more information, see
Setting input/output operations rate-limiting
.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Click the
arrow
next to the NFS cluster for which export you want to set the QoS.
A list of shares that are associated with the selected cluster is displayed.
3. Select the NFS share for which you want to edit QoS and click the
action menu
.
The
Edit
option displays.
4. Click
Edit
.
The
Edit NFS export
form displays.
5. In the
Edit NFS export
form, edit the required information and click
Edit export
.
A notification is displayed that the share is updated successfully.

### Disabling input/output operations rate-limiting

You can disable input/output operations (IOPS) rate-limit for the NFS share at any time through the Ceph Dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
NFS
.
2. Click the
arrow
next to the NFS cluster for which share you want to set the QoS.
A list of shares that are associated with the selected cluster is displayed.
3. Select the NFS share for which you want to disable QoS and click the
action menu
.
The
Edit
option displays.
4. Click
Edit
.
The
Edit NFS export
form displays.
5. In the
Edit NFS export
form, clear the
Enable IOPS QOS
checkbox.
A notification is displayed that the export is updated successfully.
