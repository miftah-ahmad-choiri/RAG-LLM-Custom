## Adding peer in mirroring

Last Updated
: 2026-06-25

Add storage cluster peer for the `rbd-daemon` mirror to discover its peer
storage cluster on the IBM Storage Ceph Dashboard.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Two healthy running IBM Storage Ceph clusters.
- The dashboard is installed on both the clusters.
- Pools created with the same name.
- `rbd` application enabled on both the clusters.

> 📝 **Note:** Note:
Ensure that mirroring is enabled for the pool in which images are
created.

### About this task

For more information, see
Configuring two-way mirroring
.
