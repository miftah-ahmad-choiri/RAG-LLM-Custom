## Managing S3 bucket lifecycle policies

Last Updated
: 2026-06-25

As
a storage administrator, the IBM Storage Ceph Dashboard allows you
to view and manage Ceph Object Gateway bucket lifecycle policies.

- A running IBM Storage Ceph cluster.
- At least one Ceph Object Gateway user is created.
- Ceph Object Gateway login credentials are added to the dashboard.
- At
least one Ceph Object Gateway bucket. For information about creating a bucket,
see Creating Ceph Object Gateway buckets.
