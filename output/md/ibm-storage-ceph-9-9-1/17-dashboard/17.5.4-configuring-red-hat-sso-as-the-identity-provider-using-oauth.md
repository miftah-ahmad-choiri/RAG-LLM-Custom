## Configuring Red Hat SSO as the identity provider using OAuth2 Protocol

Last Updated
: 2026-06-25

You can enable single sign-on (SSO) for the IBM Storage Ceph Dashboard by configuring Red
Hat SSO as the Identity Provider (IdP).

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Installation of the Ceph Dashboard.
- Enable the Ceph Management gateway (`mgmt-gateway`) service. For more
information, see Enabling the Ceph Management gateway.
- Enable the OAuth2 Proxy service (`oauth2-proxy`). For more information, see Enabling the OAuth2 Proxy service.

Ensure that oauth2 proxy and identity provider are configured before you can configure the
Identity Provider.

  - Enable the Ceph Management gateway (`mgmt-gateway`) service. For more
  information, see Enabling the Ceph Management gateway.
  - Enable the OAuth2 Proxy service (`oauth2-proxy`). For more information, see Enabling the OAuth2 Proxy service.

SSO is now enabled for the Ceph management stack. When users access the
dashboard, they are redirected to the Red Hat SSO login page. After successful authentication, users
are granted access across all monitoring stacks, including dashboard, Grafana, and Prometheus, based
on the roles assigned in Red Hat SSO.
