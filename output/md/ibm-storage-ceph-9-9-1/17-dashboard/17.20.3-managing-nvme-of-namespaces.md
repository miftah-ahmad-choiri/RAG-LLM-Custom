## Managing NVMe-oF namespaces

Last Updated
: 2026-09-06

View, create, expand, and delete NVMe-oF namespaces with the Ceph Dashboard.

### About this task

To manage NVMe-oF namespaces, open a subsystem from the Subsystems tab and click Namespaces.

Namespaces are storage volumes that are mapped to subsystems for host access.

### Viewing namespaces

View namespaces that are associated with a subsystem.

#### Procedure

View namespaces from the
Namespaces
page.
The
Namespaces
table displays the namespace ID, pool, image, image size, block size, and IOPS configuration for each namespace.

### Creating namespaces

Create namespaces for a subsystem.

#### About this task

Create namespaces to provision storage volumes within a subsystem.

#### Procedure

1. From the
Namespaces
page, click
Create
.
2. Select the subsystem and specify the number of namespaces to create.

You can create between 1 and 5 namespaces in a single operation.
3. Specify the image size and host access configuration.
4. Select the Ceph Block Device (
`rbd`
) image pool and image creation method.

- Select Gateway-provisioned image to create new Ceph Block Device images for the namespace.
- Select Externally managed image to use an existing Ceph Block Device image.

  - Select Gateway-provisioned image to create new Ceph Block Device images for the namespace.
  - Select Externally managed image to use an existing Ceph Block Device image.
5. Specify the namespace block size and click
Create Namespace
.
The namespace is added to the
Namespaces
table.

### Expanding namespaces

Increase the size of an existing namespace.

#### About this task

Namespace capacity can be increased at any time from the Namespaces page.

> 📝 **Note:** Important:
Namespace size can be increased but cannot be reduced.

#### Procedure

1. From the action menu for the namespace, select
Expand
.
2. Specify the new namespace size and click
Expand
.
The dashboard emits the
Updated namespace
ID
for subsystem
NQN
message.

### Deleting namespaces

Delete namespaces that are no longer required.

#### About this task

Namespaces can be deleted at any time from the Namespaces page.

#### Procedure

1. From the action menu for the namespace, select
Delete
.
2. Confirm the deletion.
The namespace is removed from the
Namespaces
table.
