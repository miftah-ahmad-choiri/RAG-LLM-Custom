## Managing SMB clusters

Last Updated
: 2026-06-25

The IBM Storage Ceph dashboard provides an interface
for managing SMB clusters. You can create, edit, and delete the SMB clusters by using the Ceph
dashboard.

### About this task

You can opt to create the SMB cluster with 2 different authentication modes:
Standalone
This mode allows you to manually define and manage user accounts and groups within Ceph. It is
suitable for setups where external authentication services are not required. To create an SMB
cluster with
Standlone
as the authentication mode, see
Creating users and groups access resources
.
Active Directory (AD)
This mode integrates with an existing Active Directory domain, enabling centralized
authentication and access control. Users and groups are managed in AD, providing seamless
integration with enterprise environments. To create an SMB cluster with
AD
as
the authentication mode, see
Creating Active Directory access resources
.
Follow the section to create, edit, list, and delete the SMB clusters:

- Creating SMB cluster.
- Editing SMB cluster.
- Listing SMB clusters.
- Deleting SMB cluster.

### Editing SMB cluster

Learn to edit SMB clusters by using the Ceph dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Go to the
Clusters
tab.A list of all the
available SMB clusters is displayed.
3. Click the action button next to the share that you want to edit.
4. Click
Edit
.The
Edit
Cluster
form displays.
5. In the
Edit Cluster
form, edit the required information and click
Edit Cluster
.A notification is displayed that the share is
edited successfully.

> 📝 **Note:** Note:
The
Cluster name
,
Authentication
mode
,
Clustering
, and
Count
fields are
fixed at the time of SMB cluster creation to ensure system stability and configuration integrity.
These settings define core aspects of the cluster’s identity, security, and architecture, and cannot
be edited.

### Deleting SMB cluster

Learn to delete SMB clusters by using the Ceph dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Go to the
Clusters
tab.A list of all the
available SMB clusters is displayed.
3. Click the action button next to the share that you want to delete.
4. Click
Delete
.
5. Confirm that you want to delete the SMB cluster.A notification is
displayed that the share is deleted successfully.

### Listing SMB clusters

Learn to list the SMB cluster by using the Ceph dashboard.

#### Procedure

1. From the Dashboard navigation, go to
File
>
SMB
.
2. Click the
Clusters
tab.A list of the clusters
that are created for SMB service is displayed. It also shows the authentication mode of the SMB
cluster.
