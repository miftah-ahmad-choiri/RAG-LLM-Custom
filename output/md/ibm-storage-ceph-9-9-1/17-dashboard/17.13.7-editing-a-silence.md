## Editing a silence

Last Updated
: 2026-06-25

You can edit an active silence, for example, to extend the time it is active on the IBM Storage Ceph Dashboard. If the silence has expired, you can either
recreate a silence or create a new silence for the alert.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Dashboard is installed.
- An alert fired.
- A silence created for the alert.

### Procedure

1. From the dashboard navigation, go to
Observability
>
Alerts
.
2. On the
Silences
tab, select the row with the alert that you want
ot edit, and click
Edit
from the action drop-down.
> 📝 **Note:** Note:
To edit a
matcher, click the
Edit
icon.

A notification displays indicating that
the silence was edited successfully.
