## Viewing Ceph Object Gateway per-user and per-bucket performance counters

Last Updated
: 2026-06-25

You can view the Ceph Object Gateway performance counters per user per bucket in the Grafana dashboard.

### Procedure

1. Log in to the Grafana URL.

```plaintext-ibm
https://DASHBOARD_URL:3000
```

Copy to clipboard

Example

```
https://dashboard_url:3000
```
2. Go to the
Dashboard
tab and search for
RGW S3 Analytics
.
3. To view per-bucket Ceph Object gateway operations, select the 'Bucket' window:
Figure 1.
Bucket operations counter
form
4. To view per-user Ceph Object gateway operations, select the 'User' window:
Figure 2.
User operations counter
form

> 📝 **Note:** Note:
The output of per-bucket and per-user
`get operation count`
command increases by two for each
`get`
operation that is run from client: s3cmd. This behaviour is a known issue.
