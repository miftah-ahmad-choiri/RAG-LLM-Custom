## Removing CephFS volumes

Last Updated
: 2026-06-25

You can remove Ceph File System (CephFS) volumes on the IBM Storage Ceph dashboard.

### Before you begin

- A working IBM Storage Ceph cluster with Ceph File System
deployed.

### Procedure

1. From the dashboard navigation, go to
File
>
File
Systems
.
2. From the listed volumes, select the volume to be removed and click
Remove
from the action drop-down.
3. In the
Remove File System
window, select
Yes, I am
sure
and click
Remove File System
.A
notification displays that the volume was removed successfully.
