## Syncing users from Red Hat Sign-On to the Ceph dashboard

Last Updated
: 2026-06-25

You can use Red Hat Single Sign-on (SSO) with Lightweight Directory Access Protocol
(LDAP) integration to synchronize users to the IBM Storage Ceph
Dashboard.

### Before you begin

- A running IBM Storage Ceph cluster.
- Ceph Dashboard installed.
- Admin-level access to the dashboard.
- Users added to the dashboard. See Creating users.
- Root-level access on all the hosts.
- Admin account created for syncing users. See Creating an admin account for syncing users to the Ceph dashboard.

### About this task

The users are added to specific realms in which they can access the dashboard through SSO without
any additional requirements of a password.
