## Configuring Ansible inventory location

Last Updated
: 2026-06-25

You can configure inventory location files for the `cephadm-ansible`
staging and production environments. The Ansible inventory hosts file contains all the hosts that
are part of the storage cluster.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- An Ansible administration node.
- Root-level access to the Ansible administration node.
- The `cephadm-ansible` package is installed on the node.

### About this task

You can list nodes individually in the inventory hosts file or you can create groups such as
`[mons]`,`[osds]`, and `[rgws]` to provide clarity to
your inventory and ease the usage of the `--limit` option to target a group or node
when running a playbook.

> 📝 **Note:** Note:
If deploying clients, client nodes must be defined in a dedicated
`[clients]`
group.

### Procedure

1. Navigate to the
/usr/share/cephadm-ansible/
directory.
```plaintext-ibm
cd /usr/share/cephadm-ansible
```

Copy to clipboard
For
example,

```
[root@admin ~]# cd /usr/share/cephadm-ansible
```
2. **Optional:**Create subdirectories for staging and production.
```plaintext-ibm
mkdir -p inventory/staging inventory/production
```

Copy to clipboard
For
example,

```
[root@admin cephadm-ansible]# mkdir -p inventory/staging inventory/production
```
3. **Optional:**Edit the
ansible.cfg
file and add the
following line to assign a default inventory location.
```plaintext-ibm
[defaults]
inventory = ./inventory/staging
```

Copy to clipboard
4. **Optional:**Create an inventory
`hosts`
file for each
environment.
```plaintext-ibm
touch inventory/staging/hosts
touch inventory/production/hosts
```

Copy to clipboard
For
example,

```
[root@admin cephadm-ansible]# touch inventory/staging/hosts
[root@admin cephadm-ansible]# touch inventory/production/hosts
```
5. Open and edit each
hosts
file and add the nodes and
`[admin]`
group.
```plaintext-ibm
NODE_NAME_1
NODE_NAME_2

[admin]
ADMIN_NODE_NAME_1
```

Copy to clipboard

- Replace NODE_NAME_1 and NODE_NAME_2 with the Ceph nodes
such as monitors, OSDs, MDSs, and gateway nodes.
- Replace ADMIN_NODE_NAME_1 with the name of the node where the admin keyring
is stored.
For example,

```
host02
host03
host04

[admin]
host01
```

> 📝 **Note:** Note:
If you set the inventory location in the
`ansible.cfg`
file to staging, you
need to run the playbooks in the staging environment as
follows:

```plaintext-ibm
ansible-playbook -i inventory/staging/hosts PLAYBOOK.yml
```

Copy to clipboard

To
run the playbooks in the production
environment:

```plaintext-ibm
ansible-playbook -i inventory/production/hosts PLAYBOOK.yml
```

Copy to clipboard

  - Replace NODE_NAME_1 and NODE_NAME_2 with the Ceph nodes
  such as monitors, OSDs, MDSs, and gateway nodes.
  - Replace ADMIN_NODE_NAME_1 with the name of the node where the admin keyring
  is stored.
