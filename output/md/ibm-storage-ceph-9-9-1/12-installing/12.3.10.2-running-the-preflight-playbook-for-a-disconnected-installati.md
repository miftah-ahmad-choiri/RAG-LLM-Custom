## Running the preflight playbook for a disconnected installation

Last Updated
: 2026-06-25

Use the cephadm-preflight.yml Ansible playbook to configure the Ceph repository and prepare the storage cluster for bootstrapping in an air-gapped environment. It also installs some prerequisites, such as `podman`, `lvm2`, `chrony`, and `cephadm`.

### About this task

> 📝 **Note:** Important:
Run the preflight playbook before you bootstrap the initial host.

The preflight playbook uses the `cephadm-ansible` inventory `hosts` file to identify all the nodes in the storage cluster. The default location for `cephadm-ansible`, cephadm-preflight.yml, and the inventory `hosts` file is /usr/share/cephadm-ansible/.

The following example shows the structure of a typical inventory file:

```plaintext-ibm
host02
host03
host04

[admin]
host01
```

Copy to clipboard

The `[admin]` group in the inventory file contains the name of the node where the admin keyring is stored.

The Ansible Preflight performs a check to detect whether swap space is configured on the host. This check is informational only and does not block deployment. Operational practices vary across environments:

- Some deployments disable swap on OSD nodes to avoid increased latency under memory pressure.
- Other deployments keep swap enabled but configure a very low `vm.swappiness` value (for example, 0 or 1) to minimize swapping activity.

> 📝 **Note:** Note:
Specific swap configurations are not enforced. Follow the appropriate guidance for your specific environment.

### Procedure

1. Navigate to the
/usr/share/cephadm-ansible
directory on the Ansible administration node.
2. Open and edit the
hosts
file and add your nodes.
3. Add license to install IBM Storage Ceph and click
Accept
on all nodes.

```plaintext-ibm
dnf install ibm-storage-ceph-license
```

Copy to clipboard

For example,

```
[root@admin ~]# dnf install ibm-storage-ceph-license
```
4. Accept the provisions.

```plaintext-ibm
sudo touch /usr/share/ibm-storage-ceph-license/accept
```

Copy to clipboard

For example,

```
[root@admin ~]# sudo touch /usr/share/ibm-storage-ceph-license/accept
```
5. Run the preflight playbook.

> 📝 **Note:** Note:
When running the preflight playbook,
`cephadm-ansible`
automatically installs
`chrony`
and
`ceph-common`
on the client nodes.

Use one of the following options:

- Use ceph_origin parameter set to custom to use a local YUM repository.

```plaintext-ibm
ansible-playbook -i INVENTORY_FILE cephadm-preflight.yml --extra-vars "ceph_origin=custom" -e "custom_repo_url=CUSTOM_REPO_URL"
```

Copy to clipboard

            For example,


```
[ansible@admin cephadm-ansible]$ ansible-playbook -i hosts cephadm-preflight.yml --extra-vars "ceph_origin=custom" -e "custom_repo_url=http://mycustomrepo.lab.ibm.com/x86_64/os/"
```

            After installation is complete, `cephadm` resides in the /usr/sbin/ directory.
- Use the --limit option to run the preflight playbook on a selected set of hosts in the storage cluster.

```plaintext-ibm
ansible-playbook -i INVENTORY_FILE cephadm-preflight.yml --extra-vars "ceph_origin=custom" -e "custom_repo_url=CUSTOM_REPO_URL" --limit GROUP_NAME|NODE_NAME
```

Copy to clipboard

            Replace GROUP_NAME with a group name from your inventory file and NODE_NAME with a specific node name from your inventory file.
            For example,

```
[ansible@admin cephadm-ansible]$ ansible-playbook -i hosts cephadm-preflight.yml --extra-vars "ceph_origin=custom" -e "custom_repo_url=http://mycustomrepo.lab.ibm.com/x86_64/os/" --limit clients
[ansible@admin cephadm-ansible]$ ansible-playbook -i hosts cephadm-preflight.yml --extra-vars "ceph_origin=custom" -e "custom_repo_url=http://mycustomrepo.lab.ibm.com/x86_64/os/" --limit host02
```
