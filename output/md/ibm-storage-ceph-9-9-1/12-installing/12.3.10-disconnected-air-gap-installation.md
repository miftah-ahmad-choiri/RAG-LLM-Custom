## Disconnected (air gap) installation

Last Updated
: 2026-06-25

As a storage administrator, you can install IBM Storage Ceph in a disconnected, also known as
air-gapped environment, to install `cephadm` and bootstrap your storage
cluster on a private network. A disconnected installation uses a private registry for
installation.

Before starting to install IBM Storage Ceph, see Installation and upgrade requirements.
