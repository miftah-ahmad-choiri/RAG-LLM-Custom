## Managing Ceph daemon states using the ceph_orch_daemon module

Last Updated
: 2026-06-25

Start, stop, and restart Ceph daemons on hosts using the
`ceph_orch_daemon` module in your Ansible playbooks.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Ansible user with sudo and passwordless SSH access to all nodes in the storage cluster.
- Installation of the `cephadm-ansible` package on the Ansible administration
node.
- The Ansible inventory file contains the cluster and admin hosts. For more information about
adding hosts to your storage cluster, see Adding or removing hosts using the ceph_orch_host module.

### Procedure

1. Log in to the Ansible administration node.
2. Navigate to the `/usr/share/cephadm-ansible` directory on the Ansible
administration node:

Example

```plaintext-ibm
[ansible@admin ~]$ cd /usr/share/cephadm-ansible
```

Copy to clipboard
3. Create a playbook with daemon state changes:

Syntax

```plaintext-ibm
sudo vi PLAYBOOK_FILENAME.yml

---
- name: PLAY_NAME
  hosts: ADMIN_HOST
  become: USE_ELEVATED_PRIVILEGES
  gather_facts: GATHER_FACTS_ABOUT_REMOTE_HOSTS
  tasks:
    - name: NAME_OF_TASK
      ceph_orch_daemon:
        state: STATE_OF_SERVICE
        daemon_id: DAEMON_ID
        daemon_type: TYPE_OF_SERVICE
```

Copy to clipboard

Example

```plaintext-ibm
[ansible@admin cephadm-ansible]$ sudo vi restart_services.yml

---
- name: start and stop services
  hosts: host01
  become: true
  gather_facts: false
  tasks:
    - name: start osd.0
      ceph_orch_daemon:
        state: started
        daemon_id: 0
        daemon_type: osd

    - name: stop mon.host02
      ceph_orch_daemon:
        state: stopped
        daemon_id: host02
        daemon_type: mon
```

Copy to clipboard

In this example, the playbook starts the OSD with an ID of `0` and stops a Ceph
Monitor with an id of `host02`.
4. Run the playbook:

Syntax

```plaintext-ibm
ansible-playbook -i INVENTORY_FILE _PLAYBOOK_FILENAME.yml
```

Copy to clipboard

Example

```plaintext-ibm
[ansible@admin cephadm-ansible]$ ansible-playbook -i hosts restart_services.yml
```

Copy to clipboard

### Verification

- Review the output from the playbook tasks.
