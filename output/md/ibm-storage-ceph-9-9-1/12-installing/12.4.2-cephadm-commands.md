## cephadm commands

Last Updated
: 2026-06-25

The `cephadm` is a command line tool to manage the local host for the `cephadm` Orchestrator. It provides commands to investigate and modify the state of the current host.

Some of the commands are generally used for debugging.

> 📝 **Note:** Note:
`cephadm`
is not required on all hosts, however, it is useful when investigating a particular daemon. The
`cephadm-ansible-preflight`
playbook installs
`cephadm`
on all hosts and the
`cephadm-ansible purge`
playbook requires
`cephadm`
be installed on all hosts to work properly.
