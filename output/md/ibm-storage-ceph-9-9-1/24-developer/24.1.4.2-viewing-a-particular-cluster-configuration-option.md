## Viewing a particular cluster configuration option

Last Updated
: 2026-09-06

Understand how to view a particular cluster option and its value.

On the command line, run the following
command.

```plaintext-ibm
curl --silent --user USER 'https://CEPH_MANAGER:8080/api/cluster_conf/ARGUMENT'
```

Copy to clipboard

Replace:

- USER with the username.
- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- ARGUMENT with the configuration option you want to view.

Enter the user’s password when prompted.

> 📝 **Note:** Note:
If you used a self-signed certificate, use the
--insecure
option.

```plaintext-ibm
curl --silent --insecure --user USER 'https://CEPH_MANAGER:8080/api/cluster_conf/ARGUMENT'
```

Copy to clipboard

### Viewing a particular cluster configuration option using Python

In the Python interpreter, enter the following:

```plaintext-ibm
$ python
>> import requests
>> result = requests.get('https://CEPH_MANAGER:8080/api/cluster_conf/ARGUMENT', auth=("USER", "PASSWORD"))
>> print(result.json())
```

Copy to clipboard

Replace:

- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- ARGUMENT with the configuration option you want to view.
- USER with the username.
- PASSWORD with the user’s password.

> 📝 **Note:** Note:
If using a self-signed certificate, use
`verify=False`
.

```plaintext-ibm
$ python
>> import requests
>> result = requests.get('https://CEPH_MANAGER:8080/api/cluster_conf/ARGUMENT', auth=("USER", "PASSWORD"), verify=False)
>> print(result.json())
```

Copy to clipboard

### Viewing a particular cluster configuration option using a web browser

In the web browser, go to
https://
CEPH_MANAGER
:8080/api/cluster_conf/
ARGUMENT.

Replace:

- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- ARGUMENT with the configuration option you want to view.

Enter the username and password when prompted.
