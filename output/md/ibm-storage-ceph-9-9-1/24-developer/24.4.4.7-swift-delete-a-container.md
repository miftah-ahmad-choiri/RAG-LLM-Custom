## Swift delete a container

Last Updated
: 2026-06-25

To delete a container, make a `DELETE` request with the API version, account, and
the name of the container. The container must be empty. If you’d like to check if the container is
empty, run a `HEAD` request against the container. Once you’ve successfully removed
the container, you’ll be able to reuse the container name.

Syntax

```plaintext-ibm
DELETE /_AP_VERSION_/_ACCOUNT_/_TENANT_:_CONTAINER_ HTTP/1.1
Host: FULLY_QUALIFIED_DOMAIN_NAME
X-Auth-Token: _AUTH_TOKEN_
```

Copy to clipboard

HTTP Response

`204`

Status Code

`NoContent`

Description

The container was removed.
