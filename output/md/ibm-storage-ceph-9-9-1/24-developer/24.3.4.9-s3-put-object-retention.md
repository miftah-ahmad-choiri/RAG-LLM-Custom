## S3 put object retention

Last Updated
: 2026-06-25

The put object retention API places an object retention configuration on an object. A retention
period protects an object version for a fixed amount of time. There are two modes: GOVERNANCE and
COMPLIANCE. These two retention modes apply different levels of protection to your objects.

> 📝 **Note:** Note:
During this period, your object is Write-Once-Read-Many (WORM-protected) and cannot be
overwritten or deleted. For more information about the WORM model, see
Ceph Object Gateway
.

Syntax

```plaintext-ibm
PUT /BUCKET/OBJECT?retention&versionId= HTTP/1.1
```

Copy to clipboard

Example

```plaintext-ibm
PUT /testbucket/testobject?retention&versionId= HTTP/1.1
```

Copy to clipboard

The `versionId` sub-resource retrieves a particular version of the object.
