## S3 get bucket access control lists

Last Updated
: 2026-06-25

Retrieves the bucket access control list. The user needs to be the bucket owner or to have been
granted `READ_ACP` permission on the bucket.

Add the `acl` subresource to the bucket request.

Syntax

```plaintext-ibm
GET /BUCKET?acl HTTP/1.1
Host: cname.domain.com

Authorization: AWS ACCESS_KEY:HASH_OF_HEADER_AND_SECRET
```
