## S3 get the request payment configuration on a bucket

Last Updated
: 2026-06-25

Uses the `requestPayment` subresource to return the request payment configuration
of a bucket. The user needs to be the bucket owner or to have been granted `READ_ACP`
permission on the bucket.

Add the `requestPayment` subresource to the bucket request.

Syntax

```plaintext-ibm
GET /BUCKET?requestPayment HTTP/1.1
Host: cname.domain.com

Authorization: AWS ACCESS_KEY:HASH_OF_HEADER_AND_SECRET
```
