## S3 get object tagging

Last Updated
: 2026-06-25

The get object tagging API returns the tag of an object. By default, the `GET`
operation returns information on the current version of an object.

> 📝 **Note:** Note:
For a versioned bucket, you can have multiple versions of an object in your bucket. To
retrieve tags of any other version, add the
`versionId`
query parameter in the
request.

Syntax

```plaintext-ibm
GET /BUCKET/OBJECT?tagging&versionId= HTTP/1.1
```

Copy to clipboard

Example

```plaintext-ibm
GET /testbucket/testobject?tagging&versionId= HTTP/1.1
```
