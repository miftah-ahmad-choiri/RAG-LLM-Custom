## Link a bucket

Last Updated
: 2026-06-25

Link a bucket to a specified user, unlinking the bucket from any previous
user.

Capabilities

```plaintext-ibm
`buckets=write`
```

Copy to clipboard

Syntax

```plaintext-ibm
PUT /admin/bucket?format=json HTTP/1.1
Host FULLY_QUALIFIED_DOMAIN_NAME
```

Copy to clipboard

Request Parameters

`bucket`

Description

The bucket to unlink.

Type

String

Example

`foo_bucket`

Required

Yes

`uid`

Description

The user ID to link the bucket to.

Type

String

Example

`foo_user`

Required

Yes
