## Enabling and Securing the Ceph API module

Last Updated
: 2026-06-25

The IBM Storage Ceph Dashboard module offers the RESTful API access to the storage
cluster over an SSL-secured connection.

> 📝 **Note:** Important:
If disabling SSL, then user names and passwords are sent unencrypted to the
IBM Storage Ceph
Dashboard.

### Prerequisites

- Root-level access to a Ceph Monitor node.
- Ensure that you have at least one `ceph-mgr` daemon active.
- If you use a firewall, ensure that TCP port `8443`, for SSL, and TCP port
`8080`, without SSL, are open on the node with the active `ceph-mgr`
daemon.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Enable the RESTful plug-in:

```plaintext-ibm
[ceph: root@host01 /]# ceph mgr module enable dashboard
```

Copy to clipboard
3. Configure an SSL certificate.

1. If your organization’s certificate authority (CA) provides a certificate, then set using the
certificate files:

Syntax

```plaintext-ibm
ceph dashboard set-ssl-certificate HOST_NAME -i CERT_FILE
ceph dashboard set-ssl-certificate-key HOST_NAME -i KEY_FILE
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph dashboard set-ssl-certificate -i dashboard.crt
[ceph: root@host01 /]# ceph dashboard set-ssl-certificate-key -i dashboard.key
```

Copy to clipboard

If you want to set unique node-based certificates, then add a *HOST_NAME* to the
commands:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph dashboard set-ssl-certificate host01 -i dashboard.crt
[ceph: root@host01 /]# ceph dashboard set-ssl-certificate-key host01 -i dashboard.key
```

Copy to clipboard
2. Alternatively, you can generate a self-signed certificate. However, using a self-signed
certificate does not provide full security benefits of the HTTPS protocol:

```plaintext-ibm
[ceph: root@host01 /]# ceph dashboard create-self-signed-cert
```

Copy to clipboard

> 📝 **Note:** Warning:
Most modern web browsers will complain about self-signed certificates, which
require you to confirm before establishing a secure connection.

4. Create a user, set the password, and set the role:

Syntax

```plaintext-ibm
echo -n "PASSWORD" > PATH_TO_FILE/PASSWORDFILE
ceph dashboard ac-user-create USERNAME -i PASSWORDFILE ROLE
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# echo -n "p@ssw0rd" > /root/dash-password.txt
[ceph: root@host01 /]# ceph dashboard ac-user-create user1 -i /root/dash-password.txt administrator
```

Copy to clipboard

This example creates a user named `user1` with the `administrator`
role.
5. Connect to the RESTful plug-in web page. Open a web browser and enter the following URL:

Syntax

```plaintext-ibm
https://HOST_NAME:8443
```

Copy to clipboard

Example

```plaintext-ibm
https://host01:8443
```

Copy to clipboard

If you used a self-signed certificate, confirm a security exception.
