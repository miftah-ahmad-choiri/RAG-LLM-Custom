## Changing an OSD state

Last Updated
: 2026-09-06

Understand how to use the RESTful plug-in to change the state of an OSD.

On the command line, run the following command:

```plaintext-ibm
echo -En '{"=STATE": VALUE}' | curl --request PATCH --data @- --silent --user USER 'https://CEPH_MANAGER:8080/api/osd/ID'
```

Copy to clipboard

Replace:

- STATE with either in or up.
- VALUE with true or false.
- USER with the username.
- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- ID with the ID of the OSD listed in the `osd` field.

Enter the user’s password when prompted.

> 📝 **Note:** Note:
If using a self-signed certificate, use the
--insecure
option.

```plaintext-ibm
echo -En '{"=STATE": VALUE}' | curl --request PATCH --data @- --silent --insecure --user USER 'https://CEPH_MANAGER:8080/api/osd/ID'
```

Copy to clipboard

### Changing the state of an OSD using Python

In the Python interpreter, enter the following:

```plaintext-ibm
$ python
>> import requests
>> result = requests.patch('https://CEPH_MANAGER:8080/api/osd/ID', json={"STATE": VALUE}, auth=("USER", "PASSWORD"))
>> print(result.json())
```

Copy to clipboard

Replace:

- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- STATE with either in or up.
- VALUE with true or false.
- USER with the username.
- PASSWORD with the user’s password.
- ID with the ID of the OSD listed in the `osd` field.

> 📝 **Note:** Note:
If using a self-signed certificate, use
`verify=False`
.

```plaintext-ibm
$ python
>> import requests
>> result = requests.patch('https://CEPH_MANAGER:8080/api/osd/ID', json={"STATE": VALUE}, auth=("USER", "PASSWORD"), verify=False)
>> print(result.json())
```
