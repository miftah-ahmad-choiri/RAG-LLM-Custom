## S3 get bucket website

Last Updated
: 2026-06-25

The get bucket website API retrieves the configuration of the website that is specified in the
`website` subresource.

> 📝 **Note:** Note:
`Get`
operation requires the
`S3:GetBucketWebsite`
permission.
By default, only the bucket owner can read the bucket website configuration.

Syntax

```plaintext-ibm
GET /BUCKET?website-configuration=HTTP/1.1
```

Copy to clipboard

Example

```plaintext-ibm
GET /testbucket?website-configuration=HTTP/1.1
```
