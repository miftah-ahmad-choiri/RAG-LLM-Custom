## Modify a user

Last Updated
: 2026-06-25

Modify an existing user.

Capabilities

```plaintext-ibm
`users=write`
```

Copy to clipboard

Syntax

```plaintext-ibm
POST /admin/user?format=json HTTP/1.1
Host: FULLY_QUALIFIED_DOMAIN_NAME
```

Copy to clipboard

Request Parameters

`uid`

Description

The user ID to be created.

Type

String

Example

`foo_user`

Required

Yes

`display-name`

Description

The display name of the user to be created.

Type

String

Example

`foo_user`

Required

Yes

`email`

Description

The email address associated with the user.

Type

String

Example

`foo@bar.com`

Required

No

`generate-key`

Description

Generate a new key pair and add to the existing keyring.

Type

Boolean

Example

True [False]

No

`access-key`

Description

Type

String

Example

`ABCD0EF12GHIJ2K34LMN`

Required

No

`secret-key`

Description

Type

String

No

No

`user-caps`

Type

String

No
