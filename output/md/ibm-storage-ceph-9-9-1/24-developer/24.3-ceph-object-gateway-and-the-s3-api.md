## Ceph Object Gateway and the S3 API

Last Updated
: 2026-06-25

As a developer, you can use a RESTful application programming interface (API) that is
compatible with the Amazon S3 data access model. You can manage the buckets and objects stored in an
IBM Storage Ceph cluster through the Ceph Object Gateway.

- A running IBM Storage Ceph cluster.
- A RESTful client.
