## S3 put object legal hold

Last Updated
: 2026-06-25

The put object legal hold API applies a legal hold configuration to the selected object. With a
legal hold in place, you cannot overwrite or delete an object version. A legal hold does not have an
associated retention period and remains in place until you explicitly remove it.

Syntax

```plaintext-ibm
PUT /BUCKET/OBJECT?legal-hold&versionId= HTTP/1.1
```

Copy to clipboard

Example

```plaintext-ibm
PUT /testbucket/testobject?legal-hold&versionId= HTTP/1.1
```

Copy to clipboard

The `versionId` subresource retrieves a particular version of the object.

Request Entities

`LegalHold`

Description

A container for the request.

Type

Container

Required

Yes

`Status`

Description

Indicates whether the specified object has a legal hold in place. Valid values: ON/OFF

Type

String

Required

Yes
