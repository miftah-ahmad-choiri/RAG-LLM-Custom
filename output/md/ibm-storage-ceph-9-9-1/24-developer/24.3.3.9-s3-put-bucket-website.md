## S3 put bucket website

Last Updated
: 2026-06-25

The put bucket website API sets the configuration of the website that is specified in the
`website` subresource. To configure a bucket as a website, the
`website` subresource can be added on the bucket.

> 📝 **Note:** Note:
`Put`
operation requires
`S3:PutBucketWebsite`
permission. By
default, only the bucket owner can configure the website attached to a bucket.

Syntax

```plaintext-ibm
PUT /BUCKET?website-configuration=HTTP/1.1
```

Copy to clipboard

Example

```plaintext-ibm
PUT /testbucket?website-configuration=HTTP/1.1
```
