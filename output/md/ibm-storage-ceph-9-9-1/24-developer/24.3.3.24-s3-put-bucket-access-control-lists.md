## S3 put bucket Access Control Lists

Last Updated
: 2026-06-25

Sets an access control to an existing bucket. The user needs to be the bucket owner or to have
been granted `WRITE_ACP` permission on the bucket.

Add the `acl` subresource to the bucket request.

Syntax

```plaintext-ibm
PUT /_BUCKET_?acl HTTP/1.1
```
