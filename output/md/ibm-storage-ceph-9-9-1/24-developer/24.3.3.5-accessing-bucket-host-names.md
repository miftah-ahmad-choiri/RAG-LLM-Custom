## Accessing bucket host names

Last Updated
: 2026-06-25

There are two different modes of accessing the buckets. The first, and preferred method
identifies the bucket as the first level directory in the URL.

Example

```plaintext-ibm
GET /mybucket HTTP/1.1
Host: cname.domain.com
```

Copy to clipboard

The second method identifies the bucket via a virtual bucket host name.

Example

```plaintext-ibm
GET / HTTP/1.1
Host: mybucket.cname.domain.com
```

Copy to clipboard

> 📝 **Note:** Tip:
While both methods are available, it is preferable to use the first method,
because the second method requires expensive domain certification and DNS wild cards.
