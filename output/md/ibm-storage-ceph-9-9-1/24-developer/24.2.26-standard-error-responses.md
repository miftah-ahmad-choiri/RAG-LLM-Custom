## Standard error responses

Last Updated
: 2026-06-25

Get to know the standard error responses and their descriptions.

`AccessDenied`

Description

Access denied.

Code

403 Forbidden

`InternalError`

Description

Internal server error.

Code

500 Internal Server Error

`NoSuchUser`

Description

User does not exist.

Code

404 Not Found

`NoSuchBucket`

Description

Bucket does not exist.

Code

404 Not Found

`NoSuchKey`

Description

No such access key.

Code

404 Not Found
