## S3 get bucket location

Last Updated
: 2026-06-25

Retrieves the bucket’s zone group. The user needs to be the bucket owner to call this. A bucket
can be constrained to a zone group by providing `LocationConstraint` during a PUT
request.

Add the `location` subresource to the bucket resource.

Syntax

```plaintext-ibm
GET /BUCKET?location HTTP/1.1
Host: cname.domain.com

Authorization: AWS ACCESS_KEY:HASH_OF_HEADER_AND_SECRET
```

Copy to clipboard

Response Entities

`LocationConstraint`

Description

The zone group where bucket resides, an empty string for default zone group.

Type

String
