## S3 put bucket versioning

Last Updated
: 2026-06-25

This subresource set the versioning state of an existing bucket. The user needs to be the bucket
owner to set the versioning state. If the versioning state has never been set on a bucket, then it
has no versioning state. Doing a GET versioning request does not return a versioning state
value.

Setting the bucket versioning state:

`Enabled`: Enables versioning for the objects in the bucket. All objects added to
the bucket receive a unique version ID. `Suspended`: Disables versioning for the
objects in the bucket. All objects added to the bucket receive the version ID null.

Syntax

```plaintext-ibm
PUT /BUCKET?versioning HTTP/1.1
```
