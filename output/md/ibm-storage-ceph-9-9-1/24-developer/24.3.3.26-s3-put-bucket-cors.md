## S3 put bucket cors

Last Updated
: 2026-06-25

Sets the cors configuration for the bucket. The user needs to be the bucket owner or to have been
granted `READ_ACP` permission on the bucket.

Add the `cors` subresource to the bucket request.

Syntax

```plaintext-ibm
PUT /BUCKET?cors HTTP/1.1
Host: cname.domain.com

Authorization: AWS ACCESS_KEY:HASH_OF_HEADER_AND_SECRET
```
