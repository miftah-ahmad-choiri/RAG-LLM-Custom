## S3 set the request payment configuration on a bucket

Last Updated
: 2026-06-25

Uses the `requestPayment` subresource to set the request payment configuration of
a bucket. By default, the bucket owner pays for downloads from the bucket. This configuration
parameter enables the bucket owner to specify that the person requesting the download will be
charged for the request and the data download from the bucket.

Add the `requestPayment` subresource to the bucket request.

Syntax

```plaintext-ibm
PUT /BUCKET?requestPayment HTTP/1.1
Host: cname.domain.com
```

Copy to clipboard

`Payer`

Description

Specifies who pays for the download and request fees.
