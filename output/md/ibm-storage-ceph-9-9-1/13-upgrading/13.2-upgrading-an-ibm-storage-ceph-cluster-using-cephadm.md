## Upgrading an IBM Storage Ceph cluster using cephadm

Last Updated
: 2026-09-09

As a storage administrator, you can use the `cephadm` Orchestrator to upgrade to the latest version of IBM Storage Ceph by using the ceph orch upgrade command.

The automated upgrade process follows Ceph best practices.

- The upgrade order starts with Ceph Managers, Ceph Monitors, then other daemons.
- Each daemon is restarted only after Ceph indicates that the cluster will remain available.

For information about upgrade paths, see Supported upgrade and crossgrade paths.

> 📝 **Note:** Upgrade planning:
Upgrades to
IBM Storage Ceph
9.9.1.1
and later versions can take longer to complete, compared to earlier releases. Plan maintenance windows accordingly. For more information, see
Known issues
for
IBM Storage Ceph
9.9.1.1
.

Before starting to upgrade IBM Storage Ceph, see Installation and upgrade requirements.

The storage cluster health status is likely to switch to HEALTH_WARNING during the upgrade. When the upgrade is complete, the health status should switch back to HEALTH_OK.

> 📝 **Note:** Note:
You do not get a message once the upgrade is successful. Run
ceph versions
and
ceph orch ps
commands to verify the new image ID and the version of the storage cluster.
