## New features and enhancements

Last Updated
: 2026-09-10

This section lists all the major updates, and enhancements introduced in this release of IBM Storage Ceph.

`cephadm`
now supports configurable persistent logging levels

Previously, `cephadm` used a fixed logging verbosity level for persistent logs written to /var/log/ceph/cephadm.log and `syslog`, when enabled.

With this enhancement, you can control the verbosity of `cephadm` persistent logging by using the `mgr/cephadm/CEPHADM_BINARY_LOGGING_LEVEL` configuration option. As a result, administrators can adjust `cephadm` logging verbosity to match operational and troubleshooting requirements, while console output for bootstrap and other interactive operations remains unchanged.

Supported CEPHADM_BINARY_LOGGING_LEVEL values are debug, info, warning, and error. The default value is debug.

(IBMCEPH-15698)

### NFS service

Enhanced log messages in the NFS share creation path

This release introduces improved log messages in the `create_export` path. Log messages are standardized, previously missing messages are added, and additional context is included to help administrators identify the cause of NFS share creation failures.

(IBMCEPH-17005)

New NFS cluster authentication key rotation

Previously, rotating authentication keys for an NFS cluster required manual management of individual keyrings and associated services, increasing administrative effort and the risk of configuration inconsistencies.

With this enhancement, the ceph nfs cluster rotate-key command enables administrators to rotate authentication keys for an entire NFS cluster or for specific cluster entities. The command supports custom key types through the --key-type option. It automatically updates associated CephFS share keyrings and redeploys NFS services when daemon keyrings are rotated. This simplifies key management and helps maintain secure NFS deployments.

For more information, see CephX key rotation.

(IBMCEPH-16471)
