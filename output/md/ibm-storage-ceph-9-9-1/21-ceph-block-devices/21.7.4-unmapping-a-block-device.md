## Unmapping a block device

Last Updated
: 2026-06-25

You can unmap a block device image with the rbd command, by using the
unmap option and providing the device name.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.
- An image that is mapped.

### Procedure

1. Get the specification of the
device.Example

```plaintext-ibm
[root@rbd-client ~]# rbd device list
```

Copy to clipboard
2. Unmap the block device image:

Syntax

```plaintext-ibm
rbd device unmap /dev/rbd/POOL_NAME/IMAGE_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[root@rbd-client ~]# rbd device unmap /dev/rbd/pool1/image1
```

Copy to clipboard
