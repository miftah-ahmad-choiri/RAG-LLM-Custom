## Checking status

Last Updated
: 2026-06-25

You can check the status of the Persistent Write Log (PWL) cache. The cache is used when
an exclusive lock is acquired, and when the exclusive-lock is released, the persistent write log
cache is closed. The cache status shows information about the cache size, location, type, and other
cache-related information. Updates to the cache status are done when the cache is opened and
closed.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the monitor node.
- A running process with PWL cache enabled.

### Procedure

- View the PWL cache status:

Syntax

```plaintext-ibm
rbd status POOL_NAME/IMAGE_NAME
```

Copy to clipboard
