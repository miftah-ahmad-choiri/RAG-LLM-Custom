## Creating a Ceph Block Device and using it from a Linux kernel module client

Last Updated
: 2026-06-25

Create a Ceph Block Device for a Linux kernel module client on the IBM Storage Ceph Dashboard. As a system administrator, you can map
that block device on a Linux client, and partition, format, and mount it, using the command line.
After this, you can read and write files to it.

Creating a Ceph Block device for a Linux kernel module client requires:

- A running IBM Storage Ceph cluster.
- A Red Hat Enterprise Linux client.
