## Committing the live migration

Last Updated
: 2026-06-25

You can commit the migration, once the live migration has completed deep-copying all the
data blocks from the source image to the target image.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Two block device pools.
- One block device image, that was used while running the live migration.
- A completed migration block deep-copy process, in the executed
state.

### Procedure

Commit the migration.

```plaintext-ibm
rbd migration commit TARGET_POOL_NAME/SOURCE_IMAGE_NAME
```

Copy to clipboard

For
example,

```
[ceph: root@rbd-client /]# rbd migration commit targetpool1/sourceimage1
Commit image migration: 100% complete...done.
```

Committing the live
migration removes the cross-links between the source and target images and removes the source image
from the source pool.

### What to do next

To see which source images were removed from the source pool, use the
trash
list
command.

```plaintext-ibm
rbd trash list --all SOURCE_POOL_NAME
```

Copy to clipboard

For
example,

```
[ceph: root@rbd-client /]# rbd trash list --all sourcepool1
```
