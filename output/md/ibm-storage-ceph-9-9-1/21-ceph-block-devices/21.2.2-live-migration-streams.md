## Live migration streams

Last Updated
: 2026-06-25

Use `file`, `HTTP`, `S3`, and `NBD` streams for live migration.

You can use the `file` stream to import from a locally accessible POSIX file source.

```plaintext-ibm
{
    <format unique parameters>
    "stream": {
        "type": "file",
        "file_path": "FILE_PATH"
    }
}
```

Copy to clipboard

The following is a
`source-spec`
JSON file that imports a raw-format image from a file located at
`/mnt/image.raw`
.

```
{
    "type": "raw",
    "stream": {
        "type": "file",
        "file_path": "/mnt/image.raw"
    }
}
```

### HTTP stream

You can use the `HTTP` stream to import from a remote HTTP or HTTPS web server.

```plaintext-ibm
{
    <format unique parameters>
    "stream": {
        "type": "http",
        "url": "URL_PATH"
    }
}
```

Copy to clipboard

The following is a
`source-spec`
JSON file that imports a raw-format image from a file located at
`http://download.ceph.com/image.raw`
.

```
{
    "type": "raw",
    "stream": {
        "type": "http",
        "url": "http://download.ceph.com/image.raw"
    }
}
```

### S3 stream

You can use the `s3` stream to import from a remote S3 bucket.

```plaintext-ibm
{
    <format unique parameters>
    "stream": {
        "type": "s3",
        "url": "URL_PATH",
        "access_key": "ACCESS_KEY",
        "secret_key": "SECRET_KEY"
    }
}
```

`source-spec`
JSON file that imports a raw-format image from a file located at
`http://s3.ceph.com/bucket/image.raw`
.

```
{
    "type": "raw",
    "stream": {
        "type": "s3",
        "url": "http://s3.ceph.com/bucket/image.raw",
        "access_key": "NX5QOQKC6BH2IDN8HC7A",
        "secret_key": "LnEsqNNqZIpkzauboDcLXLcYaWwLQ3Kop0zAnKIn"
    }
}
```

### NBD stream

You can use the `NBD` stream to import from a remote NBD export.

`nbd-uri` parameter must follow the NBD URI format. The default NBD port is 10809.

For more information, see [The NBD Uniform Resource Indicator (URI) format](https://www.ibm.com/links?url=https%3A%2F%2Fgithub.com%2FNetworkBlockDevice%2Fnbd%2Fblob%2Fmaster%2Fdoc%2Furi.md).

```plaintext-ibm
{
            <format unique parameters>
            "stream": {
                "type": "nbd",
                "uri": "<nbd-uri>",
            }
        }
```

Copy to clipboard

The following is a `source-spec` JSON file that imports a raw-format image from an NBD export located at `nbd://nbd.ceph.com/image.raw`.

```plaintext-ibm
{
            "type": "raw",
            "stream": {
                "type": "nbd",
                "uri": "nbd://nbd.ceph.com/image.raw",
            }
        }
```
