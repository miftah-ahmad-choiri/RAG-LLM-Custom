## Block-list options

Last Updated
: 2026-06-25

Understand the block-list options for Ceph Block Devices.

Table 1
lists the block-list
configuration options for Ceph Block Devices.

| Option | Description | Type | Default |
| --- | --- | --- | --- |
| rbd_blocklist_on_break_lock | Whether to block-list clients whose lock was broken. | Boolean | true |
| rbd_blocklistexpire_seconds | The number of seconds to block-list - set to 0 for OSD default. | Integer | 0 |
