## Renaming snapshots

Last Updated
: 2026-06-25

Rename a block device snapshot.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### Procedure

1. To rename a snapshot:

Syntax

```plaintext-ibm
rbd snap rename POOL_NAME/IMAGE_NAME@ORIGINAL_SNAPSHOT_NAME POOL_NAME/IMAGE_NAME@NEW_SNAPSHOT_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[root@rbd-client ~]# rbd snap rename data/dataset@snap1 data/dataset@snap2
```

Copy to clipboard

This renames `snap1` snapshot of the `dataset` image on the
`data` pool to `snap2`.
2. Run the `rbd help snap rename` command to display additional details on renaming
snapshots.
