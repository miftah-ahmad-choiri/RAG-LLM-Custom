## Purging snapshots

Last Updated
: 2026-06-25

Purge block device snapshots.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### About this task

> 📝 **Note:** Note:
Purging a snapshot means deleting all snapshots in the image, where deleting a snapshot refers
to removing a specific snapshot from the image.

### Procedure

Specify the
snap purge
option and the image name on a specific
pool.

```plaintext-ibm
rbd --pool POOL_NAME snap purge IMAGE_NAME
rbd snap purge POOL_NAME/IMAGE_NAME
```

Copy to clipboard

For
example,

```
[root@rbd-client ~]# rbd --pool pool1 snap purge image1
[root@rbd-client ~]# rbd snap purge pool1/image1
```
