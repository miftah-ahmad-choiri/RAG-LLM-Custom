## Listing images

Last Updated
: 2026-06-25

List the Ceph Block Device images with the rbd ls command.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the client node.

### Procedure

1. To list block devices in the
`rbd`
pool, run the following
command:

> 📝 **Note:** Note:
`rbd`
is the default pool name.

Example

```plaintext-ibm
[root@rbd-client ~]# rbd ls
```

Copy to clipboard
2. To list block devices in a specific pool:

Syntax

```plaintext-ibm
rbd ls POOL_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[root@rbd-client ~]# rbd ls pool1
```

Copy to clipboard
