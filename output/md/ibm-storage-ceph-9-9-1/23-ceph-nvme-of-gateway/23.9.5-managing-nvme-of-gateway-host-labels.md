## Managing NVMe-oF gateway host labels

Last Updated
: 2026-06-25

Use this information to add and remove NVMe-oF gateway host labels.

### Adding host labels

#### Procedure

1. Add a label to the host.

```plaintext-ibm
ceph orch host label add NODE LABEL
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch host label add host01 nvmeof_label
[ceph: root@host01 /]# ceph orch host label add host02 nvmeof_label
```

In this example, the
NODE
name is
host01
and
host02
and the
LABEL
is
nvmeof_label
.
2. Display the labels associated with the host.

```plaintext-ibm
ceph orch host ls
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch host ls
HOST    ADDR  LABELS                     STATUS
host01        mon,mgr,_admin,nvmeof_label
host02        mon,mgr,_admin,nvmeof_label
```
3. Apply the daemons with the labels added in step
1
.

```plaintext-ibm
ceph orch apply nvmeof NVME-OF_POOL_NAME GW_GROUP --placement="label:LABEL"
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch apply nvmeof nvmeof_pool01 group2 --placement="label:nvmeof_label"
```

### Removing host labels

#### Procedure

1. Remove a node from a host, by using the
ceph orch host label rm
command.

```plaintext-ibm
ceph orch host label rm HOST_NAME LABEL
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch host label rm host02 nvmeof_label
```
2. Apply the daemons with the labels removed.

```plaintext-ibm
ceph orch apply nvmeof NVME-OF_POOL_NAME GW_GROUP --placement="label:LABEL"
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch apply nvmeof nvmeof_pool01 group1 --placement="label:nvmeof_label"
```
