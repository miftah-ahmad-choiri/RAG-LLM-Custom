## Verifying deployment

Last Updated
: 2026-06-25

Verify that the gateway deployment process was completed successfully.

### Procedure

Use one of the following commands to verify NVMe-oF gateway deployment.

- Use the
nvme-gw show
command to list the details of the gateways that
were created during deployment.
For more information about deployment, see
Deploying the NVMe-oF gateway
.

```plaintext-ibm
ceph nvme-gw show NVME-OF_POOL_NAME GATEWAY_GROUP_NAME
```

Copy to clipboard

The following example is for the
`nvmeof_pool01`
pool for gateway group
`group1`
.

> 📝 **Note:** Note:
Until the first subsystem is created the following output displays:

- Availability outputs as "CREATED"
- ana states outputs as STANDBY for both
gateways.

- Verify by using the

command.Make sure that
