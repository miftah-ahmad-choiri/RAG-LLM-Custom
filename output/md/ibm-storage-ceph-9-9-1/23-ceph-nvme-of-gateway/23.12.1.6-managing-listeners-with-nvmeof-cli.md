## Managing listeners with nvmeof-cli

Last Updated
: 2026-06-25

As a system administrator, you can add, list, and delete NVMe-oF subsystem listeners by using the command-line interface (CLI).

### Before you begin

Managing NVMe-oF subsystem listeners with the CLI requires the
`nvmeof-cli`
alias setup. For more information about defining the alias, see step
1
of
Defining an NVMe-oF subsystem with nvmeof-cli
.

### About this task

At any point, you can use the
-h
or
--help
parameters for command help.
The following parameters are interchangeable:

- --subsystem and -n
- --host-name and -t
- --serial-number and -s
- --traddr and -a
- --trsvcid and -s
- --adrfam and -f

Use the commands listed here to manage your listeners.

- Adding a listener
- Listing listeners
- Deleting listeners

> 📝 **Note:** Note:
The commands here show the
SUBSYSTEM_NQN
with the subsystem NQN and group name, assuming that the
--no-group-append
was not added when adding the subsystem. For more information, see
Managing subsystems with nvmeof-cli
.

### Adding a listener

Starting from IBM Storage Ceph 8.1, you can add listeners for any of the gateways through any of the gateways in the gateway group. Adding listeners through a gateway group is useful in cases that you plan to add more gateways to a gateway group but the new gateways are still not up and running. It is sufficient to know what the IP address of the new gateways will be and then add the listeners to the IP address. This way, when the gateway joins the group, the gateway automatically begins participating in I/O activity.

Use the
listener add
command to add a listener to an NVMe-oF subsystem.

```plaintext-ibm
nvmeof-cli --server-address GATEWAY_IP --server-port SERVER_PORT listener add --subsystem SUBSYSTEM_NQN --host-name HOST_NAME --traddr GATEWAY_IP
```

Copy to clipboard

For example,

```
[root@host01 ~]# nvmeof-cli --server-address 10.172.19.01 --server-port 5500 listener add --subsystem nqn.2016-06.io.spdk:cnode1.group1 --host-name host02 --traddr 10.172.19.01
```

Add a listener for each NVMe-oF gateway.

To define the IP port on the gateway, be sure to include the --host-name and --traddr parameters.

The following parameters can optionally be added to the command:
--trsvcid
Enter the port number. The default port is 4420.
--adrfam
Enter the
IP_TYPE
. The supported value is IPv4 and the input can be written as either
ipv4
or
IPV4
.
--server-port
Enter the
SERVER_PORT
number. The default port is 5500.

### Listing listeners

Use the
listener list
command to list listeners of an NVMe-oF subsystem.

> 📝 **Note:** Note:
Run this command for each subsystem.

```plaintext-ibm
nvmeof-cli --server-address GATEWAY_IP --server-port SERVER_PORT listener list --subsystem SUBSYSTEM_NQN
```

Copy to clipboard

See the following example output for two gateways on a subsystem.

```
[root@host01 ~]# nvmeof-cli --server-address 10.172.19.01 --server-port 5500 listener list --subsystem nqn.2016-06.io.spdk:cnode1.group1

Listeners for nqn.2016-06.io.spdk:cnode1.group1:
Host   | Transport | Address | Address
       |           | Family  |
=================================================
host03 | TCP       | IPv4    | 10.8.128.223:4420
-------------------------------------------------
host04 | TCP       | IPv4    | 10.8.128.223:4420
```

### Getting listener information

Use the
gw listener_info
command to get listener information of an NVMe-oF subsystem on a specific gateway. The output includes on which load balancing group this listener is optimized.

> 📝 **Note:** Note:
Run this command for each subsystem.

```plaintext-ibm
nvmeof-cli --server-address GATEWAY_IP --server-port SERVER_PORT gw listener_info --subsystem SUBSYSTEM_NQN
```

Copy to clipboard

See the following example output for two gateways on a subsystem.

```
[root@host01 ~]# nvmeof-cli --server-address 10.172.19.01 --server-port 5500 gw listener_info --subsystem nqn.2016-06.io.spdk:cnode1.group1

Gateway listeners for nqn.2016-06.io.spdk:cnode1.group1:
Host   | Transport | Address | Address          | Secure | Load Balancing Group ID/State
       |           | Family  |                  |        |
==========================================================================================
host03 | TCP       | IPv4    | 10.8.128.223:4420| Yes    | 1: Optimized
------------------------------------------------------------------------------------------
host04 | TCP       | IPv4    | 10.8.128.223:4420| Yes    | 2: Optimized
```

### Deleting listeners

Use the
listener del
command to delete a listener from an NVMe-oF subsystem.

```plaintext-ibm
nvmeof-cli --server-address GATEWAY_IP --server-port SERVER_PORT listener del --subsystem SUBSYSTEM_NQN --host-name HOST_NAME --traddr GATEWAY_IP --trsvcid PORT_NUMBER
```

Copy to clipboard

Use the optional --force parameter to force the listener deletion, even if active connections for the address exist, or if the name does not match.

Use the optional --adrfam to provide the IP_TYPE. The supported value is IPv4 and the input can be written as either ipv4 or IPV4.

Use the following information to properly complete the parameters for your subsystem.
--trsvcid
Enter the
PORT_NUMBER
. The default port is 4420.
--adrfam
Enter the
IP_TYPE
. The supported value is IPv4 and the input can be written as either
ipv4
or
IPV4
.
--server-port
Enter the
SERVER_PORT
number. The default port is 5500.
For example,

```
[root@host01 ~]# nvmeof-cli --server-address 10.172.19.01 --server-port 5500 listener del --subsystem nqn.2016-06.io.spdk:cnode1.group1 --host-name host02 --traddr 10.8.128.223 --trsvcid 4420 --adrfam ipv4
```
