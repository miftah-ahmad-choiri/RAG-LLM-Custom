## Using the nvmeof-cli utility for configuring and managing NVMe-oF gateways

Last Updated
: 2026-06-25

Use the command-line interface with the `nvmeof-cli` utility to manage NVMe-oF gateways.

> 📝 **Note:** Important:
As of
IBM Storage Ceph
9.0.0, the
`nvmeof-cli`
utility is deprecated and should only be used if the Ceph Dashboard is not installed and configured.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- NVMe-oF gateway deployment.

For more information, see Installing the NVMe-oF gateway.
- The `nvmeof-cli` alias defined.

For more information, see step 1 of Defining an NVMe-oF subsystem with nvmeof-cli.

### Getting nvmeof-cli help

Use the
-h
or
--help
parameters for command help.

```plaintext-ibm
nvmeof-cli --help
```

Copy to clipboard

### General nvmeof-cli parameters

Use the following
`nvmeof-cli`
command parameters for more defined commands.

| Parameter | Description |
| --- | --- |
| --format | View the output for each of these commands in any of the following format options: text, json, yaml, plain, or python. If not specified, the default is text. |
| --output | Use one of the following CLI output methods: log, stdio. If not specified, the default is log. Use stdio if the CLI output needs to be redirected to a file or another program. |
| --server-address | Use to specify the server address. |
| --server-port | Use to specify the server port. |
| --verbose | Use to run the CLI in verbose mode, for extra messages to be displayed. |
| --client-key | Used with mTLS. Use to provide a path to the client key file. |
| --client-cert | Used with mTLS. Use to provide a path to the client certificate file. |
| --server-key | Used with mTLS. Use to provide a path to the server key file. |
| --server-cert | Used with mTLS. Use to provide a path to the server certificate file. |
