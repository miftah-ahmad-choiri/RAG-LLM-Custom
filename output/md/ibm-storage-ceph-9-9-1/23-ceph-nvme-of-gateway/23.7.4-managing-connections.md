## Managing connections

Last Updated
: 2026-06-25

List NVMe-oF connections by using `ceph nvmeof` commands.

### Procedure

Use the
connection list
command to view NVMe-oF subsystem connectivity.

```plaintext-ibm
ceph nvmeof connection list [--nqn NQN] [--gw_group GW_GROUP] [--server-address SERVER_ADDRESS]
```

Copy to clipboard

For example,

```
[root@host01 ~]# ceph nvmeof connection list --nqn nqn.2016-06.io.spdk:cnode1.group1
+------+-------+------+------+---------+------------+-------------+-------+----------+-----------------------------------+-------------------------------------+
|Traddr|Trsvcid|Trtype|Adrfam|Connected|Qpairs Count|Controller Id|Use Psk|Use Dhchap|Subsystem                          |Disconnected Due To Keepalive Timeout|
+------+-------+------+------+---------+------------+-------------+-------+----------+-----------------------------------+-------------------------------------+
|<n/a> |0      |      |ipv4  |False    |-1          |-1           |False  |True      |nqn.2016-06.io.spdk:cnode2.mygroup1|False                                |
+------+-------+------+------+---------+------------+-------------+-------+----------+-----------------------------------+-------------------------------------+
```
