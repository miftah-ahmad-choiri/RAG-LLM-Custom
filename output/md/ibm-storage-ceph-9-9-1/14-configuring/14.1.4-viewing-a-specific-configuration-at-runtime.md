## Viewing a specific configuration at runtime

Last Updated
: 2026-06-25

Configuration settings for IBM Storage Ceph can be viewed at runtime from the Ceph
Monitor node.

- A running IBM Storage Ceph cluster.
- Root-level access to the Ceph Monitor node.

### Procedure

1. Log into a Ceph node and and run the following command.

Syntax

```plaintext-ibm
ceph daemon DAEMON_TYPE.ID config get PARAMETER
```

Copy to clipboard

Example

```plaintext-ibm
[root@mon ~]# ceph daemon osd.0 config get public_addr
```

Copy to clipboard
