## Viewing the Ceph configuration at runtime

Last Updated
: 2026-06-25

The Ceph configuration files can be viewed at boot time and run time.

- Root-level access to the Ceph node.
- Access to admin keyring.

### Procedure

1. To view a runtime configuration, log in to a Ceph node running the daemon and run the following
command.

Syntax

```plaintext-ibm
ceph daemon DAEMON_TYPE.ID config show
```

Copy to clipboard

To see the configuration for `osd.0`, you can log into the node containing
`osd.0` and run this command:

Example

```plaintext-ibm
[root@osd ~]# ceph daemon osd.0 config show
```

Copy to clipboard
2. For additional options, specify a daemon and `help`.

Example

```plaintext-ibm
[root@osd ~]# ceph daemon osd.0 help
```

Copy to clipboard
