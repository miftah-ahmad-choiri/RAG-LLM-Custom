## Ceph Monitor data store

Last Updated
: 2026-06-25

Ceph provides a default path where Ceph monitors store data.

> 📝 **Note:** Important:
For optimal performance in a production
IBM Storage Ceph
cluster, run Ceph monitors on separate drives from
Ceph OSDs.

> 📝 **Note:** Note:
A dedicated
`/var/lib/ceph`
partition should be used for the MON database with
a size between 50 and 100 GB.

Ceph monitors call the `fsync()` function often, which can interfere with Ceph OSD
workloads.

Ceph monitors store their data as key-value pairs. Using a data store prevents recovering Ceph
monitors from running corrupted versions through Paxos, and it enables multiple modification
operations in one single atomic batch, among other advantages.

> 📝 **Note:** Important:
Only change the
default data location if necessary. If you modify the default location, make it uniform across Ceph
monitors by setting it in the
`[mon]`
section of the configuration file.
