## Integrating active directory with SMB by using imperative method

Last Updated
: 2026-06-25

Learn how to integrate SMB and active directory.

### Before you begin

- Gather information about the domain for using active directory (AD).
- Create a domain user to join to AD.
- Determine whether you need to use custom_dns setting.

### About this task

SMB services for
IBM Storage Ceph
can use and connect to an existing Active Directory domain server. Upon SMB cluster creation, an administrator needs to decide whether the SMB cluster uses AD or not. If a cluster is configured with Active Directory, then active directory manages all user information and user authentication for this cluster.

### Procedure

Set the
auth_mode
parameter to
`active-directory`
and ensure to give the cluster ID of the AD.

```plaintext-ibm
auth_mode: active-directory
```

Copy to clipboard

For example,

```
[ceph: root@host01 ~]# ceph smb cluster create smb1 active-directory --domain_realm samba.qe --domain_join_user_pass Administrator%RT@123 --custom_dns 10.71.34.153 --placement label:smb --clustering default
```
