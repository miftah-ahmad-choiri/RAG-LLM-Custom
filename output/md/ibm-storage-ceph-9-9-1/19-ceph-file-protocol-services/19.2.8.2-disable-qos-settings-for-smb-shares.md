## Disable QoS settings for SMB shares

Last Updated
: 2026-06-25

You can disable Quality of Service (QoS) settings for SMB shares in Ceph by setting all QoS limits to 0. This removes any rate limiting applied to the share.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running Ceph cluster with SMB services enabled.
- The share name and share ID for which you want to disable QoS.

### About this task

QoS settings control IOPS, bandwidth, and delay limits for SMB shares. Disabling QoS restores default behavior with unrestricted read and write operations.

### Disable QoS with YAML

Use a YAML configuration file to turn off Quality of Service (QoS) settings for a Ceph SMB share. This method removes limits for IOPS, bandwidth, and latency.

#### Procedure

Update the SMB share resource YAML file by setting all QoS parameters to
0
.

```plaintext-ibm
qos:
  read_iops_limit: 0
  write_iops_limit: 0
  read_bw_limit: 0
  write_bw_limit: 0
  read_delay_max: 0
```

Copy to clipboard

#### Results

QoS settings are removed from the specified SMB share. All IOPS, bandwidth, and delay limits are disabled, and the share operates without any rate limiting.

### Set QoS value with CLI

Use the command-line interface (CLI) to change Quality of Service (QoS) parameters for a Ceph SMB share. You can set limits for IOPS, bandwidth, and latency to optimize performance.

#### Procedure

1. Log in to the
`cephadm`
shell.
For example,

```
[root@host01 ~]# cephadm shell
```
2. Replace all the integer values for QoS settings with
0
.

```plaintext-ibm
ceph smb share update cephfs qos <share_name> <share_id> \
  --read-iops-limit=0 \
  --write-iops-limit=0 \
  --read-bw-limit=0 \
  --write-bw-limit=0 \
  --read-delay-max=0 \
  --write-delay-max=0
```

Copy to clipboard

For example,

```
ceph smb share update cephfs qos foo bar \
  --read-iops-limit=0 \
  --write-iops-limit=0 \
  --read-bw-limit=0 \
  --write-bw-limit=0 \
  --read-delay-max=0 \
  --write-delay-max=0
```
