## Disabling bandwidth rate-limiting for NFS share

Last Updated
: 2026-06-25

Learn how to disable bandwidth rate-limiting for NFS shares by using the command line.

### About this task

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### Procedure

You can disable bandwidth rate-limiting for the NFS shares by using the following command.

```plaintext-ibm
nfs export qos disable bandwidth_control CLUSTER_ID PSEUDO_PATH
```

Copy to clipboard

Where,

- CLUSTER_ID is the NFS cluster ID.
- PSEUDO_PATH is the pseudo-root path. (The path must be an absolute path.)

This command disables QoS bandwidth control for shares, allowing them to use unlimited input/output bandwidth. Once share QoS is disabled, the shares will no longer follow the bandwidth values set at the cluster level.

> 📝 **Note:** Note:
To use cluster level QoS bandwidth control values for share again, you can use the NFS share apply
CLUSTER_ID
command, with the share section not having QOS_BLOCK.
