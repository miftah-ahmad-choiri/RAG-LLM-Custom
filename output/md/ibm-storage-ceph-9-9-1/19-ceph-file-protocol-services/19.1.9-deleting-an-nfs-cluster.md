## Deleting an NFS cluster

Last Updated
: 2026-06-25

Delete an NFS cluster with the nfs cluster rm command. This deletes the deployed cluster. The removal of NFS daemons and the ingress service is asynchronous. Check the status of removal with the ceph orch ls command.

### Before you begin

- A running, and healthy IBM Storage Ceph cluster.
- Root-level access to a Ceph Metadata Server (MDS) node.
- NFS daemons deployed with ceph nfs cluster create command.

### Procedure

1. Log into the `cephadm` shell.

For example,

```plaintext-ibm
[root@mds ~]# cephadm shell
```

Copy to clipboard
2. Remove the NFS cluster.

```plaintext-ibm
ceph nfs cluster rm CLUSTER_NAME
```

Copy to clipboard

For example,

```plaintext-ibm
[ceph: root@host01 /]# ceph nfs cluster rm nfs-cephfs
```

Copy to clipboard
