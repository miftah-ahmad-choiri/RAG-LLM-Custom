## Creating an NFS cluster

Last Updated
: 2026-06-25

Create an NFS cluster with the ceph nfs cluster create command. This creates a common recovery pool for all NFS service daemons, new user based on the cluster name, and a common NFS service configuration RADOS object.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running, and healthy IBM Storage Ceph cluster.
- An existing Ceph File System.
- Root-level access to Ceph Monitor.
- Installation of the `nfs-pool`, `nfs-pool-ceph`, `nfspool-rados-grace`, and `nfs-pool-rados-urls` packages on the Ceph Manager hosts.
- Root-level access to the client.

### Procedure

1. Log into the
`cephadm`
shell.
For example,

```
[root@mds ~]# cephadm shell
```
2. Enable the Ceph Manager NFS module.

```plaintext-ibm
ceph mgr module enable nfs
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph mgr module enable nfs
```
3. Create an NFS service cluster.

```plaintext-ibm
ceph nfs cluster create CLUSTER_NAME [PLACEMENT] [--ingress] [--virtual_ip IP_ADDRESS] [--ingress-mode {default|keepalive-only|haproxy-standard|haproxy-protocol}] [--port PORT]
```

Copy to clipboard

> 📝 **Note:** Important:
IBM
only supports one NFS service daemon running per host.

For example,

```
[ceph: root@host01 /]# ceph nfs cluster create nfs-cephfs "host01 host02"
NFS Cluster Created Successfully
```

In this example, the NFS service cluster name is
`nfs-cephfs`
and the daemon containers are deployed to
`host01`
, and
`host02`
.
4. Verify the NFS service cluster information.

```plaintext-ibm
ceph nfs cluster info [CLUSTER_NAME]
```

Copy to clipboard

> 📝 **Note:** Note:
Specifying the
CLUSTER_NAME
is optional.

For example,

```
[ceph: root@host01 /]# ceph nfs cluster info {
"nfs-cephfs": {
"backend": [
{
"hostname": "host01",
"ip": "10.8.129.4",
"port": 2049
},
{
"hostname": "host02",
"ip": "10.8.129.4",
"port": 2049
}
],
"virtual_ip": null
}
}
```
