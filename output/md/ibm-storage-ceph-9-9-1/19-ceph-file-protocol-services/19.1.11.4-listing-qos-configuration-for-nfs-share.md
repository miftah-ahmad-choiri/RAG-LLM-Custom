## Listing QoS configuration for NFS share

Last Updated
: 2026-06-25

Learn to list the quality of service (QoS) configuration for NFS shares by using the command line.

### About this task

You can list the quality of service (QoS) configuration for the NFS shares.

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### Procedure

Run the
nfs export qos get
command.

```plaintext-ibm
nfs export qos get CLUSTER_ID PSEUDO_PATH [--format VALUE]
```

Copy to clipboard

Where,

- CLUSTER_ID is the NFS cluster ID.
- PSEUDO_PATH is the pseudo-root path. (The path must be an absolute path.)
- VALUE is either JSON or YAML.

Example for QoS listing:
QoS listing with format as JSON

```
[ceph: root@ceph-node-0 /]# ceph nfs cluster qos get clust_nfs --format json
{
"combined_rw_bw_control": false,
"enable_bw_control": false,
"enable_iops_control": true,
"enable_qos": true,
"max_client_iops": 1000,
"qos_type": "PerClient"
}
```

QoS listing with format as YAML

```
[ceph: root@ceph-node-0 /]# ceph nfs cluster qos get clust_nfs --format yaml
combined_rw_bw_control: false
enable_bw_control: false
enable_iops_control: true
enable_qos: true
max_client_iops: 1000
qos_type: PerClient
```

QoS listing for a share

```
[ceph: root@ceph-node-0 /]# ceph nfs export qos get clust_nfs /export1
{
"cluster_enable_bw_control": true,
"cluster_enable_iops_control": true,
"cluster_enable_qos": true,
"combined_rw_bw_control": false,
"enable_bw_control": true,
"enable_iops_control": true,
"enable_qos": true,
"max_client_iops": 1000,
"max_client_read_bw": "100.0MB",
"max_client_write_bw": "100.0MB",
"max_export_iops": 2000,
"max_export_read_bw": "200.0MB",
"max_export_write_bw": "100.0MB"
}
```

The share will not have any bandwidth restriction in this case; that is, it will not have any cluster level bandwidth restrictions.
