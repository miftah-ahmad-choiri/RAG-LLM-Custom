## Remove customized NFS configurations

Last Updated
: 2026-06-25

Remove previously applied user‑defined NFS configuration overrides and restore the NFS cluster to its default configuration blocks.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running and healthy IBM Storage Ceph cluster.
- The NFS cluster name.
- You have administrative access to run Ceph CLI commands.

### About this task

The reset commands removes all user‑defined parameters that were previously applied with the ceph nfs cluster config set command. The reset operation reverts the NFS service to its default cephadm‑managed configuration and removes the related user configuration object from the `.nfs` pool.

### Procedure

1. Remove the user-defined configuration.

```plaintext-ibm
ceph nfs cluster config reset CLUSTER_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph nfs cluster config reset nfs-cephfs
```
2. **Optional:**
Verify that the configuration was removed.

```plaintext-ibm
ceph nfs cluster config get CLUSTER_NAME
```

Copy to clipboard

> 📝 **Note:** Note:
If no user configuration is present, the command returns either an empty result or only the default values managed by cephadm.

### Results

The user‑defined NFS configuration is removed, and the cluster reverts to the default cephadm‑generated settings. The verification command confirm that no custom configuration remains, and the service operates using only the default configuration blocks.
