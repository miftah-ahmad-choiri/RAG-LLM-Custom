## TLS security in NFS

Last Updated
: 2026-06-25

Transport Layer Security (TLS), when used with Network File System (NFS), enables secure, encrypted communication for NFS traffic between the client and server.

TLS is a cryptographic protocol that provides confidentiality, integrity, and authentication for network communications. When used with NFS, TLS encrypts all traffic between the client and server. This ensures that data is not visible to intermediaries and cannot be altered in transit without detection.

TLS runs above Transmission Control Protocol (TCP) at the transport layer and establishes a secure channel between the client and server before any application data is exchanged.

A TLS handshake is the connection establishment phase. During the TLS handshake:

- The client validates the server's identity using its certificate.
- The server may optionally request a certificate from the client.

> 📝 **Note:** Note:
When NFS is configured to use TLS-based transport security, the mount negotiation and all subsequent Remote Procedure Call (RPC) operations occur over this encrypted channel.

### TLS versus mTLS

The authentication models supported by TLS are TLS and mTLS.

TLS (one-way authentication)
In TLS authentication, only the server is authenticated. The client verifies the server's certificate against a trusted Certificate Authority (CA). The server does not verify the client's identity beyond network address and application-level authentication.
mTLS (mutual authentication)
In mTLS authentication, both endpoints present certificates during the TLS handshake. The client validates the server's certificate, and the server validates the client's certificate against its trusted CA list. This ensures only authorized clients can connect.

### Use Cases

This feature is essential in scenarios where secure and compliant NFS communication is required, such as:

- SAP workloads requiring secure NFS communication.
- Migration from NetApp file services to Ceph-based NFS Regional File Services.
- Environments where compliance mandates encrypted data in transit.
