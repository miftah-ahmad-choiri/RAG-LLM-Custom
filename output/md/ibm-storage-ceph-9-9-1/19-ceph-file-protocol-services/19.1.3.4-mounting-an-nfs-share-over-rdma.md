## Mounting an NFS share over RDMA

Last Updated
: 2026-06-25

Mount an NFS share by using RDMA transport.

### Procedure

1. Identify the RDMA interface IP address to mount on the client side.

```plaintext-ibm
rdma link show
```

Copy to clipboard
2. If needed, create a mount point.

```plaintext-ibm
mkdir -p
```

Copy to clipboard
3. Mount the export by using RDMA command.

```plaintext-ibm
mount -t nfs -o rdma,port=20049 SERVER_IP:EXPORT_PATH MOUNT_POINT
```

Copy to clipboard

For example,

```
mount -t nfs -o rdma, port=20049 10.64.4.115:/nfs_export /mnt/rdma_mnt
```

### What to do next

Verify that the mount is successful.

```plaintext-ibm
mount | grep
```

Copy to clipboard

For example,

```
mount -t nfs -o rdma, port=20049 10.64.4.115:/nfs_export /mnt/rdma_mnt
```

### Verify the NFS RDMA port

#### Procedure

Confirm that NFS is listening on RDMA port 20049, either through the command line or by looking within the logs.

- Confirm that NFS is listening from the command line.

```plaintext-ibm
rdma resource show cm_id
```

Copy to clipboard

For example,

```
[root@ceph61:/home/ceph_up/ceph/build]# rdma resource show cm_id
link bnxt_re0/- cm-idn 4 state LISTEN ps TCP pid 334500 comm ganesha.nfsd src-addr 0.0.0.0:20049
```
- Confirm that NFS is listening from the
ganesha.log
file.
Search for the following message within the log file:

```
Create_RDMA :RDMA :EVENT :RDMA: NFS Ganesha is now LISTENING for RPC/RDMA connections on port 20049
```
