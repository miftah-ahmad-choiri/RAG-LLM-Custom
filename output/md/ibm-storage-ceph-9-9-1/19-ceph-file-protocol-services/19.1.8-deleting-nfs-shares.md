## Deleting NFS shares from the CLI

Last Updated
: 2026-06-25

You can delete the Ceph File System (CephFS) NFS shares with the ceph export rm command.

### Procedure

Delete an NFS share.

```plaintext-ibm
ceph nfs export rm CLUSTER_NAME BINDING
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph nfs export rm nfs-cephfs /ceph
```
