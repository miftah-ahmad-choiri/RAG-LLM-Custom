## Configuring case folding in CephFS

Last Updated
: 2026-06-25

Learn how to configure case sensitivity for directory entry names in CephFS using the
`ceph.dir.casesensitive` and `ceph.dir.charmap` virtual attributes. By
default, CephFS treats directory names as case-sensitive, following POSIX behavior. You can disable
case sensitivity (enable case folding) to allow case-insensitive comparisons for a directory and its
sub-directories.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Directory must be empty.
- Directory must not be part of a snapshot.
- The client has `p` (path) MDS capabilities to modify virtual extended attributes.
This applies to all `ceph.dir.charmap` attributes, including normalization.

### Procedure

1. Set the directory to be case-insensitive.
```plaintext-ibm
setfattr -n ceph.dir.casesensitive -v <bool <directory>
```

Copy to clipboard
For example,

```
setfattr -n ceph.dir.casesensitive -v 0 foo/
```

> 📝 **Note:** Note:
Setting case sensitivity automatically enables the default normalization form
`nfd`
.
2. Verify the case sensitivity setting.
```plaintext-ibm
getfattr -n ceph.dir.casesensitive foo/

# file: foo/

ceph.dir.casesensitive="0"
```

Copy to clipboard
For example,

```
# file: foo/
ceph.dir.casesensitive="0"
```
3. Verify the updated character map.
```plaintext-ibm
getfattr -n ceph.dir.charmap <directory>/
```

Copy to clipboard

```plaintext-ibm
getfattr -n ceph.dir.charmap foo/

# file: foo/

ceph.dir.charmap="{\"casesensitive\":false,\"normalization\":\"nfd\",\"encoding\":\"utf8\"}"
```

Copy to clipboard
