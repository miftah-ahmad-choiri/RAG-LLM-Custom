## Getting started with block storage

Last Updated
: 2026-06-25

Get to know the relevant tasks and most common commands that are required for working
with Ceph Block Devices.

Manage Ceph Block Devices by using the IBM Storage Ceph dashboard. As a storage administrator,
you can manage and monitor block device images on the IBM Storage Ceph dashboard. The functionality
is divided between generic image functions and mirroring functions. For example, you can create new
images, view the state of images that are mirrored across clusters, and set IOPS limits on an
image.

For detailed information, see Managing block devices.

### Common block image CLI commands

This information is for a quick reference of basic block image CLI commands. For a full list and
more detailed information about each command, see
Ceph Block Devices
.
Creating images

```plaintext-ibm
rbd create IMAGE_NAME --size MEGABYTES --pool POOL_NAME
```

Copy to clipboard

> 📝 **Note:** Important:
A pool must be created before creating a block image. For details, see
Creating block device pools
.

Listing images

```plaintext-ibm
rbd ls POOL_NAME
```

Copy to clipboard

Retrieving image information from a particular image in the default pool

```plaintext-ibm
rbd --image IMAGE_NAME info
```

Copy to clipboard

Retrieving information from an image within a pool

```plaintext-ibm
rbd --image IMAGE_NAME -p POOL_NAME info
```
