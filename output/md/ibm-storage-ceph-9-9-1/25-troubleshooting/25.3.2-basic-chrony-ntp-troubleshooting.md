## Basic chrony NTP troubleshooting

Last Updated
: 2026-06-25

Use this information to run basic chrony NTP troubleshooting steps.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Root-level access to the Ceph Monitor node.

### About this task

For more information, see the following:

- Clock skew
- [Checking if chrony is synchronized](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2Fred_hat_enterprise_linux%2F9%2Fhtml%2Fconfiguring_basic_system_settings%2Fconfiguring-time-synchronization_configuring-basic-system-settings%23checking-if-chrony-is-synchronized_using-chrony) on [Red Hat Documentation](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2F).
- [How to troubleshoot chrony issues](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2Fsolutions%2F1259943) solution on the [Red Hat Customer Portal](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2F) for advanced chrony NTP troubleshooting steps.

### Procedure

1. Verify that the
`chrony`
daemon is running on the Ceph Monitor hosts:
For example,

```
[root@mon ~]# systemctl status chrony
```

1. If
`chrony`
is not running, enable and start it.
For example,

```
[root@mon ~]# systemctl enable chrony
[root@mon ~]# systemctl start chrony
```

  1. If
  `chrony`
  is not running, enable and start it.
  For example,

  ```
  [root@mon ~]# systemctl enable chrony
  [root@mon ~]# systemctl start chrony
  ```
2. Ensure that
`chrony`
is synchronizing the clocks correctly.
For example,

```
[root@mon ~]# chronyc sources
[root@mon ~]# chronyc sourcestats
[root@mon ~]# chronyc tracking
```
3. To configure NTP. see NTP section in
[Installation Guide for RHEL (x86_64)](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2Fred_hat_ceph_storage%2F1.2.3%2Fhtml%2Finstallation_guide_for_rhel_x86_64%2F)
4. To configure using chrony, open the NTP configuration file
/etc/chrony.con
in a text editor such as vi or nano, or create a new one if it does not already exist.
5. Add the NTP server entry details
`server <NTP_Server> iburst`
6. Restart the chrony service
`systemctl restart chrony`
.
7. Repeat the same steps on all nodes to configure NTP and to sync time across all nodes.
