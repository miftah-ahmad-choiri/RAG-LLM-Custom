## Configuring the gateway to run without huge pages

Last Updated
: 2026-09-06

Configure an NVMe-oF gateway to run without Linux huge pages by updating the service specification.

### Before you begin

Before you begin, be sure that you have the minimum hardware requirements for running Ceph NVMe-oF gateway. For more information, see
Minimum hardware considerations
.

### About this task

By default, the NVMe-oF gateway uses Linux huge pages. If huge pages are not available or your environment requires a non–huge-page configuration, update the gateway specification to define a fixed memory size.

### Procedure

1. Export the current gateway service specification.

```plaintext-ibm
ceph orch export NVME_SERVICE > file.yaml
```

Copy to clipboard

Replace
NVME_SERVICE
with the name of your NVMe-oF gateway service.
2. Add the memory configuration parameter to the specification file.
Add the following line and replace
SIZE
with the amount of memory (in MB) that the gateway should use.

```plaintext-ibm
spdk_mem_size: SIZE
```

Copy to clipboard

In the following example, the gateway is being configured to use 4 GB (4096 MB).

```
spdk_mem_size: 4096
```
3. Apply the updated service specification.

```plaintext-ibm
ceph orch apply -i file.yaml
```

Copy to clipboard
4. Redeploy the gateway service.

```plaintext-ibm
ceph orch redeploy NVME_SERVICE
```

Copy to clipboard

### Results

After the service redeploys, the gateway runs without using Linux huge pages.
