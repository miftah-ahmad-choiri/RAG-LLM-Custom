## Troubleshooting high-level object operations

Last Updated
: 2026-06-25

Use the `ceph-objectstore-tool` utility to run high-level object operations.

> 📝 **Note:** Important:
Manipulating objects can cause unrecoverable data loss. Before using the
`ceph-objectstore-tool`
utility, contact
[IBM Support](https://www.ibm.com/mysupport/)
.

The
`ceph-objectstore-tool`
utility supports the following high-level object operations:

- List objects
- List lost objects
- Fix lost objects

Before troubleshooting high-level object operations be sure to have root-level access to the Ceph OSD nodes.
