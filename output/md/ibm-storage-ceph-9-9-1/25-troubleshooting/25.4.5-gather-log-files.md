## Gather log files

Last Updated
: 2026-06-25

Gather log files to help troubleshoot `cephadm`.

> 📝 **Note:** Note:

- Be sure to run all log file commands outside the `cephadm` shell.
- By default, `cephadm` stores logs in journald.

| Action needed | Command | Example | Notes |
| --- | --- | --- | --- |
| Gather log files for all daemons | journalctl |  |  |
| Read the log file of a specific daemon | cephadm logs --name DAEMON_NAMECopy to clipboard | [root@host01 ~]# cephadm logs --name cephfs.hostname.ppdhszCopy to clipboard | This command works when run on the same hosts where the daemon is running. |
| Read the log file of a specific daemon running on a different host | cephadm logs --fsid FSID --name DAEMON_NAMECopy to clipboard | [root@host01 ~]# cephadm logs --fsid 2d2fd136-6df1-11ea-ae74-002590e526e8 --name cephfs.hostname.ppdhszCopy to clipboard | FSID is the cluster ID provided by the ceph status command. |
| Fetch all log files of all the daemons on a given host | for name in $(cephadm ls | python3 -c "import sys, json; [print(i[name]) for i in json.load(sys.stdin)]") ; do cephadm logs --fsid FSID_OF_CLUSTER --name "$name" > $name; doneCopy to clipboard | [root@host01 ~]# for name in $(cephadm ls | python3 -c "import sys, json; [print(i['name']) for i in json.load(sys.stdin)]") ; do cephadm logs --fsid 57bddb48-ee04-11eb-9962-001a4a000672 --name "$name" > $name; doneCopy to clipboard |  |
