## CIDR network error

Last Updated
: 2026-06-25

Classless inter domain routing (CIDR) also known as supernetting, is a method of
assigning Internet Protocol (IP) addresses, the `cephadm` log entries shows the current state that
improves the efficiency of address distribution and replaces the previous system based on Class A,
Class B and Class C networks.

If you see one of the following errors:

`ERROR: Failed to infer CIDR network for mon ip ***; pass --skip-mon-network to configure it
later`

Or

`Must set public_network config option or specify a CIDR network, ceph addrvec, or plain
IP`

You need to run the following command:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config set host public_network hostnetwork
```
