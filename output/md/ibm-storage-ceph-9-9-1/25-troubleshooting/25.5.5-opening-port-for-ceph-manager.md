## Opening port for Ceph Manager

Last Updated
: 2026-06-25

Understand how to open ports for Ceph Manager. The ports must be open to keep the
clusters working correctly.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Root-level access to Ceph Manager.

### About this task

The `ceph-mgr` daemons receive placement group information from OSDs on the same
range of ports as the `ceph-osd` daemons. If these ports are not open, a cluster
devolves from HEALTH_OK to HEALTH_WARN and
indicates that placement groups (PGs) are unknown with a percentage count of the PGs
unknown.

### Procedure

Use this procedure to open ports.

1. For each host running
`ceph-mgr`
daemons, open ports
6800-7300.For
example,

```
[root@ceph-mgr] # firewall-cmd --add-port 6800-7300/tcp
[root@ceph-mgr] # firewall-cmd --add-port 6800-7300/tcp --permanent
```
2. Restart the
`ceph-mgr`
daemons.
