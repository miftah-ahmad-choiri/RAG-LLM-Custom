## Critical events that trigger support tickets

Last Updated
: 2026-06-25

Some critical Ceph cluster events automatically trigger IBM Storage Ceph support cases.

When critical issues are encountered, a support case automatically opens for the IBM Storage Ceph support team. The case includes the required troubleshooting data, such as the `sosreport` and other relevant information.

> 📝 **Note:** Important:
IBM
Call Home is enabled by default. Support cases for critical events are opened automatically only when service events are enabled. If Call Home is disabled on
IBM Storage Ceph
, support cases are not created automatically.

- For enabling service events, see Enabling service events.
- For enabling Call Home using CLI, see Enabling Call Home.

IBM
Support cases are triggered by the following critical events.

> 📝 **Note:** Note:
This list is subject to change.

- CephMonDiskspaceCritical
- CephOSDFull
- CephFilesystemOffline
- CephFilesystemDamaged
- CephPGsInactive
- CephObjectMissing

For more information about these events, see
IBM Call Home events
.
