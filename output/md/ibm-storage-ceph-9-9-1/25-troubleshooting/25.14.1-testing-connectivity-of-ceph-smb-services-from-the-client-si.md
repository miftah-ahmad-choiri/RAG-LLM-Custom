## Testing connectivity of Ceph SMB services from the client side (Windows)

Last Updated
: 2026-06-25

Learn about the SMB file system share access right and control management.

Clients can connect to the servers after a cluster and its component containers are deployed and the shares are configured. Microsoft Windows systems have SMB support that is built in and using Windows Explorer a share can be specified as:
\\<hostname>\<sharename>
. For example,
\\ceph0.mycluster.sink.test\Staff Pics
.

> 📝 **Note:** Note:
IP addresses must be added in the DNS to use the hostnames.

The Windows node automatically attempts to log in to the share. If the cluster and Windows client are configured for the same AD Domain, a password-less single sign-on login is automatically performed. A username and password prompt appears if the cluster is configured for user authentication. Enter one username and password combination that was specified in the cluster or the
`ceph.smb.usersgroups`
resource.

MacOS X systems and many Linux based systems also support connecting to SMB shares.
