## Deleting data from a full storage cluster

Last Updated
: 2026-06-25

Ceph automatically prevents any I/O operations on OSDs that reached the capacity that is
specified by the mon_osd_full_ratio parameter and returns the full
osds error message. To fix this error, delete any unnecessary data.

### Before you begin

Before you begin, be sure that you have root-level access to the Ceph Monitor node.

### About this task

> 📝 **Note:** Note:
The
mon_osd_full_ratio
parameter sets the value of the
full_ratio
parameter when creating a cluster. You cannot change the value of
mon_osd_full_ratio
afterward. To temporarily increase the
full_ratio
value, increase the
`set-full-ratio`
instead.

### Procedure

1. Log in to the
`cephadm`
shell.
```
[root@host01 ~]# cephadm shell
```
2. Determine the current value of
full_ratio
.By default,
the
full_ratio
value is set to
`0.95`
.

```plaintext-ibm
ceph osd dump | grep -i full
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph osd dump | grep -i full
full_ratio 0.95
```
3. Temporarily change the value of
`set-full-ratio`
to
`0.97`
.
> 📝 **Note:** Important:
Do not set the
set-full-ratio
to a value higher than
0.97. Setting this parameter to a higher value makes the recovery process harder. As a result, you
might not be able to recover full OSDs at all.

```plaintext-ibm
ceph osd set-full-ratio 0.97
```

Copy to clipboard
4. Check that the parameter was successfully changed to
`0.97`
.For
example

```
[ceph: root@host01 /]# ceph osd dump | grep -i full
full_ratio 0.97
```
5. Monitor the cluster state, by using the
ceph -w
command.As
soon as the cluster changes its state from
full
to
nearfull
, delete any
unnecessary data.

For more information about these states, see Full OSDs and Nearfull OSDs.
6. After any unnecessary data is deleted, change the
`full_ratio`
value back
to
`0.95`
.
```plaintext-ibm
ceph osd set-full-ratio 0.95
```

Copy to clipboard
7. Check that the parameter was successfully changed to
`0.95`
.For
example,

```
[ceph: root@host01 /]# ceph osd dump | grep -i full
full_ratio 0.95
```
