## Pause or disable cephadm

Last Updated
: 2026-06-25

If `cephadm` does not behave as expected, you can pause most of the background activity or
disable it completely.

Pause `cephadm` with the following commands:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch pause
```

Copy to clipboard

This stops any changes, but `cephadm` periodically checks hosts to refresh it’s inventory of
daemons and devices.

If you want to disable `cephadm` completely, run the following commands:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch set backend ''
[ceph: root@host01 /]# ceph mgr module disable cephadm
```

Copy to clipboard

Note that previously deployed daemon containers continue to exist and start as they did
before.

To re-enable `cephadm` in the cluster, run the following commands:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph mgr module enable cephadm
[ceph: root@host01 /]# ceph orch set backend cephadm
```

Copy to clipboard
