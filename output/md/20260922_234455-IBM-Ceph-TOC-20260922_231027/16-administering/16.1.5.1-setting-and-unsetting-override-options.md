## Setting and unsetting override options

Last Updated
: 2026-06-25

You can set and unset Ceph options to override Ceph’s default behavior.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### Procedure

1. To override Ceph’s default behavior, use the `ceph osd set` command and the
behavior you wish to override:

Syntax

```plaintext-ibm
ceph osd set FLAG
```

Copy to clipboard

Once you set the behavior, `ceph health` will reflect the override(s) that you
have set for the cluster.

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph osd set noout
```

Copy to clipboard
2. To cease overriding Ceph’s default behavior, use the `ceph osd unset` command and
the override you wish to cease.

Syntax

```plaintext-ibm
ceph osd unset FLAG
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph osd unset noout
```

Copy to clipboard

| Flag | Description |
| --- | --- |
| noin | Prevents OSDs from being treated as in the cluster. |
| noout | Prevents OSDs from being treated as out of the cluster. |
| noup | Prevents OSDs from being treated as up and running. |
| nodown | Prevents OSDs from being treated as down. |
| full | Makes a cluster appear to have reached its full_ratio, and thereby prevents write operations. |
| pause | Ceph stops processing read and write operations, but will not affect OSD in, out, up or down statuses. |
| nobackfill | Ceph prevents new backfill operations. |
| norebalance | Ceph prevents new rebalancing operations. |
| norecover | Ceph prevents new recovery operations. |
| noscrub | Ceph prevents new scrubbing operations. |
| nodeep-scrub | Ceph prevents new deep scrubbing operations. |
| notieragent | Ceph disables the process that is looking for cold/dirty objects to flush and evict. |
