## Deploying the monitor daemons on specific network

Last Updated
: 2026-06-25

The Ceph Orchestrator deploys one monitor daemon by default. You can explicitly specify
the IP address or CIDR network for each monitor and control where each monitor is
placed.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Disable automated monitor deployment:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mon --unmanaged
```

Copy to clipboard
3. Deploy monitors on hosts on specific network:

Syntax

```plaintext-ibm
ceph orch daemon add mon _HOST_NAME_1_:_IP_OR_NETWORK_
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch daemon add mon host03:10.1.2.123
```

Copy to clipboard

### Verification

- List the service:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ls
```

Copy to clipboard
- List the hosts, daemons, and processes:

Syntax

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps --daemon_type=mon
```

Copy to clipboard
