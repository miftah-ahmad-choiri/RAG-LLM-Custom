## Crimson metrics

Last Updated
: 2026-06-25

Learn about the different ways Crimson reports statistics and metrics.

Crimson reports statistics and metrics in the following ways:
Placement group (PG) statistics reported to manager
Crimson collects the
`per-pg`
,
`per-pool`
, and
`per-osd`
stats from the
`MPGStats`
message, which is sent to the Ceph
Managers.
Admin socket commands
An admin socket (
asock
) command is offered to dump
metrics.

reactor_utilization is an optional string to filter the dumped
metrics by prefix.

```plaintext-ibm
ceph tell OSD_ID dump_metrics
ceph tell OSD_ID dump_metrics reactor_utilization
```

Copy to clipboard

For
example,

```
[ceph: root@host01 /]# ceph tell osd.0 dump_metrics

[ceph: root@host01 /]# ceph tell osd.0 dump_metrics reactor_utilization
```

Prometheus text protocol
Configure the listening port and address by using the
--prometheus-port
command-line option.
