## Managing the NFS service gateway using the Ceph orchestrator

Last Updated
: 2026-06-25

As a storage administrator, you can use the Orchestrator with `cephadm` in the backend to deploy the NFS service gateway. `cephadm` deploys NFS service using a predefined RADOS pool and optional namespace.

> 📝 **Note:** Note:
IBM supports CephFS shares only over the NFS v4.0+ protocol.

NFS service is an open source user-space NFS (Network File System) server that allows the sharing of file systems with the NFS protocol.

For information on all the supported Ceph configurations, see [IBM Storage Ceph Supported configurations](https://www.ibm.com/support/pages/node/7236061).

### Prerequisites

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Root-level access to all the nodes.
- Hosts are added to the cluster.
- All manager, monitor, and OSD daemons are deployed.
