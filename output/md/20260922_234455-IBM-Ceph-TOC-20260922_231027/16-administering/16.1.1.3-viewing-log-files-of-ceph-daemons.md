## Viewing log files of Ceph daemons

Last Updated
: 2026-06-25

Use the `journald` daemon from the container host to view a log file of a
Ceph daemon from a container.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### Procedure

1. To view the entire Ceph log file, run a `journalctl` command as
`root` composed in the following format:

Syntax

```plaintext-ibm
journalctl -u ceph SERVICE_ID
```

Copy to clipboard

Example

```plaintext-ibm
[root@host01 ~]# journalctl -u ceph-499829b4-832f-11eb-8d6d-001a4a000635@osd.8.service
```

Copy to clipboard

In the example, you can view the entire log for the OSD with ID `osd.8`.
2. To show only the recent journal entries, use the `-f` option.

Syntax

```plaintext-ibm
journalctl -fu SERVICE_ID
```

Copy to clipboard

Example

```plaintext-ibm
[root@host01 ~]# journalctl -fu ceph-499829b4-832f-11eb-8d6d-001a4a000635@osd.8.service
```

Copy to clipboard
