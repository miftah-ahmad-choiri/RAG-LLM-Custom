## Placement group clean state

Last Updated
: 2026-06-25

When a placement group is in the `clean` state, the primary OSD and the
replica OSDs have successfully peered and there are no stray replicas for the placement
group.

The `clean` state indicates that Ceph replicated all objects in the placement
group the correct number of times.
