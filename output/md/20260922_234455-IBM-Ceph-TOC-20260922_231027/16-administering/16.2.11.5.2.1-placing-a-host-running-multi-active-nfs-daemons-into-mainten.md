## Placing a host running multi-active NFS daemons into maintenance mode

Last Updated
: 2026-06-25

Move NFS daemons from a host to other nodes before placing the host into maintenance mode to prevent service disruption.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- The Ceph cluster is deployed and healthy.
- Replacement hosts are available to run NFS daemons.
- You have administrative access to run Ceph orchestrator commands.

### About this task

In a multi-active NFS deployment, multiple NFS daemons serve client requests. Before placing a host into maintenance mode, you must relocate any running NFS daemons to other hosts.

This ensures continuous availability of the NFS service and prevents client disruption. If a host is placed into maintenance mode without relocating the daemon, clients connected through that node might experience connection hangs or service interruptions.

Choose one of the following approaches based on your NFS placement configuration:

- NFS configured with explicit host placement
- NFS configured with placement labels

### NFS configured with explicit host placement

#### Procedure

1. Identify the host that you want to place into maintenance mode.
2. Update the NFS service specification:

- Remove the host from the `placement.hosts` list.
- Add another available host to maintain the required daemon count.

For example,

```
placement:
  count: 2
  hosts:
    - ceph-node-1
    - ceph-node-2
```

  - Remove the host from the `placement.hosts` list.
  - Add another available host to maintain the required daemon count.
3. Apply the updated NFS specification:

```
ceph orch apply -i nfs.yaml
```
4. Verify the changes:

- Confirm that the NFS daemon is removed from the original host.
- Confirm that a new NFS daemon is deployed on the replacement host.

  - Confirm that the NFS daemon is removed from the original host.
  - Confirm that a new NFS daemon is deployed on the replacement host.
5. Place the host into maintenance mode:

```
ceph orch host maintenance enter <hostname>
```

### NFS configured with placement labels

#### Procedure

1. Identify the host that you want to place into maintenance mode.
2. Add the NFS placement label to another eligible host:

```
ceph orch host label add <hostname label>
```
3. Remove the label from the host that will enter maintenance mode:

```
ceph orch host label rm <hostname label>
```
4. Wait for the orchestrator to complete the following actions:

- Remove the NFS daemon from the original host
- Deploy a new NFS daemon on the newly labeled host

  - Remove the NFS daemon from the original host
  - Deploy a new NFS daemon on the newly labeled host
5. Verify that the required number of NFS daemons are running and healthy.
6. Place the host into maintenance mode:

```
ceph orch host maintenance enter <hostname>
```

> 📝 **Note:** Note:
Do not place a host running an active NFS daemon into maintenance mode without first relocating the daemon. Otherwise, clients might experience connection hangs or service disruption.
