## Removing labels from a host

Last Updated
: 2026-06-25

Use the Ceph Orchestrator to remove a label from a host.

### Before you begin

- An IBM Storage Ceph cluster is installed and bootstrapped.
- Root-level access to all nodes in the storage cluster.
- Hosts are added to the storage cluster.

### Procedure

1. Log into the
`cephadm`
shell.

```
[root@host01 ~]# cephadm shell
```
2. Remove the label.

```plaintext-ibm
ceph orch host label rm HOST_NAME LABEL_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch host label rm host02 mon
```

### What to do next

Verify that the label is moved from the host, by using the
ceph orch host ls
command.
