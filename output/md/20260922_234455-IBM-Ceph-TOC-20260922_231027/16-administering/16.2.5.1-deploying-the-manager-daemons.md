## Deploying the manager daemons

Last Updated
: 2026-06-25

The Ceph Orchestrator deploys two Manager daemons by default. You can deploy additional
manager daemons using the `placement` specification in the command line interface. To
deploy a different number of Manager daemons, specify a different number. If you do not specify the
hosts where the Manager daemons should be deployed, the Ceph Orchestrator randomly selects the hosts
and deploys the Manager daemons to them.

### Prerequisites

> 📝 **Note:** Note:
Ensure your deployment has at least three Ceph Managers in each deployment.

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.

### Procedure

1. Log into the `cephadm` shell.

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. You can deploy manager daemons in two different ways:

Method 1

- Deploy manager daemons using placement specification on specific set of hosts:

> 📝 **Note:** Note:
Use the
`--placement`
option to deploy on specific hosts.

Syntax

```plaintext-ibm
ceph orch apply mgr --placement="HOST_NAME_1 HOST_NAME_2 HOST_NAME_3"
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mgr --placement="host01 host02 host03"
```

Copy to clipboard

Method 2

- Deploy manager daemons randomly on the hosts in the storage cluster.

Syntax

```plaintext-ibm
ceph orch apply mgr NUMBER_OF_DAEMONS
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch apply mgr 3
```

Copy to clipboard

### Verification

- List the service.

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ls
```

Copy to clipboard
- List the hosts, daemons, and processes.

Syntax

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps --daemon_type=mgr
```

Copy to clipboard
