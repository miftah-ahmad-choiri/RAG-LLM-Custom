## Supervised optimization

Last Updated
: 2026-06-25

Break down the balancer operations in a phased manner.

### About this task

The balancer operation is broken into a few distinct phases.

### Procedure

1. Build a
`plan`
.
2. Evaluate the quality of the data distribution, either for the current PG distribution, or
the PG distribution that might result after running a
`plan`
.
3. Run the
`plan`
.
1. Evaluate and score the current distribution.

```plaintext-ibm
ceph balancer eval
```

Copy to clipboard
2. Evaluate the distribution for a single
pool.

```plaintext-ibm
ceph balancer eval POOL_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph balancer eval rbd
```
3. See a greater detail for the evaluation.

```plaintext-ibm
ceph balancer eval-verbose ...
```

Copy to clipboard
4. Generate a plan using the currently configured
mode.

```plaintext-ibm
ceph balancer optimize PLAN_NAME
```

Copy to clipboard

Replace
PLAN_NAME with a custom plan name.
For
example,
```
[ceph: root@host01 /]# ceph balancer optimize rbd_123
```
5. See the contents of a
plan.

```plaintext-ibm
ceph balancer show PLAN_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph balancer show rbd_123
```
6. Discard old plans.

```plaintext-ibm
ceph balancer rm PLAN_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph balancer rm rbd_123
```
7. See currently recorded plans use the status
command.

```plaintext-ibm
ceph balancer status
```

Copy to clipboard
8. Calculate the quality of the distribution that would result after executing a
plan.

```plaintext-ibm
ceph balancer eval PLAN_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph balancer eval rbd_123
```
9. Run the plan.

```plaintext-ibm
ceph balancer execute PLAN_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph balancer execute rbd_123
```

> 📝 **Note:** Note:
Only run the plan if it is expected to improve the distribution. After execution, the plan is
discarded.
