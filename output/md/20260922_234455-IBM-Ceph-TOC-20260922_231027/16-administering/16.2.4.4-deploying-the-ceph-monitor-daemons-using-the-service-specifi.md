## Deploying the Ceph monitor daemons using the service specification

Last Updated
: 2026-06-25

The Ceph Orchestrator deploys one monitor daemon by default. You can deploy additional
monitor daemons by using the service specification, like a YAML format file.

### Prerequisites

- A running IBM Storage Ceph .
- Hosts are added to the cluster.

### Procedure

1. Create the `mon.yaml` file:

Example

```plaintext-ibm
[root@host01 ~]# touch mon.yaml
```

Copy to clipboard
2. Edit the `mon.yaml` file to include the following details:

Syntax

```plaintext-ibm
service_type: mon
placement:
  hosts:
    - HOST_NAME_1
    - HOST_NAME_2
```

Copy to clipboard

Example

```plaintext-ibm
service_type: mon
placement:
  hosts:
    - host01
    - host02
```

Copy to clipboard
3. Mount the YAML file under a directory in the container:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell --mount mon.yaml:/var/lib/ceph/mon/mon.yaml
```

Copy to clipboard
4. Navigate to the directory:

Example

```plaintext-ibm
[ceph: root@host01 /]# cd /var/lib/ceph/mon/
```

Copy to clipboard
5. Deploy the monitor daemons:

Syntax

```plaintext-ibm
ceph orch apply -i FILE_NAME.yaml
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 mon]# ceph orch apply -i mon.yaml
```

Copy to clipboard

### Verification

- List the service:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ls
```

Copy to clipboard
- List the hosts, daemons, and processes:

Syntax

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps --daemon_type=mon
```

Copy to clipboard
