## Dump Ceph performance counters

Last Updated
: 2026-06-25

The `ceph daemon .. perf dump` command outputs the current values and
groups the metrics under the collection name for each subsystem.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### Procedure

1. To view the current metric data:

Syntax

```plaintext-ibm
ceph daemon DAEMON_NAME perf dump
```

Copy to clipboard

> 📝 **Note:** Note:
run the
ceph daemon
command from the node running the daemon.
2. Executing `ceph daemon .. perf dump` command from the Monitor node:

```plaintext-ibm
[ceph: root@host01 /]# ceph daemon mon.host01 perf dump
```

Copy to clipboard
3. Executing the `ceph daemon .. perf dump` command from the OSD node:

```plaintext-ibm
[ceph: root@host01 /]# ceph daemon osd.11 perf dump
```

Copy to clipboard

### Reference

- To view a short description of each Monitor metric available, see Ceph Monitor metrics.
