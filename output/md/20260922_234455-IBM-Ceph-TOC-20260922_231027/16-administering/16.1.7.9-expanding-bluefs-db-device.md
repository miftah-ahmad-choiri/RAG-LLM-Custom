## Expanding BlueFS DB device

Last Updated
: 2026-06-25

Expand the storage of BlueStore File System.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Ceph OSDs are prepared by the `ceph-volume` utility.
- Volume groups and Logical volumes are created.

> 📝 **Note:** Note:
Run these steps on the host where the OSD is deployed.

### About this task

You can expand the storage of the BlueStore file system (BlueFS) data that is the RocksDB
data of
`ceph-volume`
created OSDs with the
`ceph-bluestore`
tool.

### Procedure

`cephadm`
shell, list the devices in the
IBM Storage Ceph
cluster.

```plaintext-ibm
ceph-volume lvm list
```

4. Resize, shrink, and expand the logical volumes.
```plaintext-ibm
lvresize -l 100%FREE PATH_OF_DB_DEVICE
```

Copy to clipboard

5. Launch the
`cephadm`
shell.
```plaintext-ibm
cephadm shell -m /var/lib/ceph/CLUSTER_FSID/osd.OSD_ID:/var/lib/ceph/osd/ceph-OSD_ID:z
```

Copy to clipboard
For
example,

```
[root@host01 ~]# cephadm shell -m /var/lib/ceph/1a6112da-ed05-11ee-bacd-525400565cda/osd.3:/var/lib/ceph/osd/ceph-3:z
```

The `ceph-bluestore-tool` needs to access the BlueStore data from within the
`cephadm` shell container, so it must be bind-mounted. Use the `-m`
option to make the BlueStore data available.
