## Deploying the NFS service gateway using the command line interface

Last Updated
: 2026-07-23

You can use the Ceph Orchestrator with `cephadm` in the backend to deploy the NFS service gateway using the placement specification. In this case, you have to create a RADOS pool and create a namespace before deploying the gateway.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Hosts are added to the cluster.
- All manager, monitor and OSD daemons are deployed.

### About this task

> 📝 **Note:** Note:
IBM
supports CephFS exports only over the NFS v4.0+ protocol.

> 📝 **Note:** Note:
Deploying the NFS service gateway with persistent idmap configuration must be done through the service specification file. To get the specification file, use the following command:

```plaintext-ibm
ceph orch ls --service-type nfs --export
```

Copy to clipboard

After exporting the file, follow the procedure in
Deploying NFS with idmap settings
.

### Procedure

1. Log into the
`cephadm`
shell.
For example,

```
[root@host01 ~]# cephadm shell
```
2. Create the RADOS pool namespace, and enable the application.
For Ceph Block Device (
`rbd`
) pools, enable
`rbd`
.

```plaintext-ibm
ceph osd pool create POOL_NAME
ceph osd pool application enable POOL_NAME freeform/rgw/rbd/cephfs/nfs
rbd pool init -p POOL_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph osd pool create nfs-pool
[ceph: root@host01 /]# ceph osd pool application enable nfs-pool nfs
[ceph: root@host01 /]# rbd pool init -p nfs-service
```
3. Deploy NFS service gateway using placement specification in the command line interface.

```plaintext-ibm
ceph orch apply nfs SERVICE_ID --placement="NUMBER_OF_DAEMONS HOST_NAME_1 HOST_NAME_2 HOST_NAME_3"
```

Copy to clipboard

The following example deploys an NFS service cluster
`nfsservice`
with one daemon on
`host01`
and
`host02`
.

```
[ceph: root@host01 /]# ceph orch apply nfs foo --placement="2 host01 host02"
```

### What to do next

- List the service.
          For example,

```
[ceph: root@host01 /]# ceph orch ls
```
- List the hosts, daemons, and processes.

```plaintext-ibm
ceph orch ps --daemon_type=DAEMON_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch ps --daemon_type=nfs
```
