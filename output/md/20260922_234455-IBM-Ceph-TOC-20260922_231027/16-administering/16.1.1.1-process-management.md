## Process management

Last Updated
: 2026-06-25

In IBM Storage Ceph, all process management is done
through the systemd service. Each time you want to `start`, `restart`,
and `stop` the Ceph daemons, you must specify the daemon type or the daemon
instance.

For more information on using systemd, see the Introduction to systemd and
Managing system services with systemctl chapters within the *Configuring basic system settings* guide within the Product Documentation for Red Hat Enterprise Linux for
your OS version, on the [Managing system services with systemctl](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2Fdocumentation%2Fen-us%2Fred_hat_enterprise_linux%2F9%2Fhtml%2Fconfiguring_basic_system_settings%2Fmanaging-system-services-with-systemctl_configuring-basic-system-settings).
