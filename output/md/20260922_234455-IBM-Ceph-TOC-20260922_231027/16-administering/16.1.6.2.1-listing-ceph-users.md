## Listing Ceph users

Last Updated
: 2026-06-25

You can list the users in the storage cluster using the command-line
interface.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the node.

### Procedure

- To list the users in the storage cluster, run the following:

> 📝 **Note:** Note:
The
`TYPE.ID`
notation for users applies such that
`osd.0`
is a
user of type
`osd`
and its ID is
`0`
.
`client.admin`
is
a user of type
`client`
and its ID is
`admin`
, that is, the default
`client.admin`
user. Note also that each entry has a
`key: VALUE`
entry, and one or more
`caps:`
entries.

You may use the `-o FILE_NAME` option with `ceph auth list` to save
the output to a file.
