## Managing Ceph users

Last Updated
: 2026-06-25

As a storage administrator, you can manage Ceph users by creating, modifying, deleting, and importing users.

A Ceph client user can be either individuals or applications, which use Ceph clients to interact with the IBM Storage Ceph cluster daemons.
