## Removing the NFS service gateway

Last Updated
: 2026-06-25

You can remove the NFS service gateway using the ceph orch rm
command.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to all the nodes.
- Hosts are added to the cluster.
- At least one NFS service gateway deployed on the hosts.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. List the service:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ls
```

Copy to clipboard
3. Remove the service:

Syntax

```plaintext-ibm
ceph orch rm SERVICE_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch rm nfs.foo
```

Copy to clipboard

### Verification

- List the hosts, daemons, and processes:

Syntax

```plaintext-ibm
ceph orch ps
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch ps
```

Copy to clipboard
