## Modifying backfills and recovery options

Last Updated
: 2026-06-25

Modify the `backfills` and `recovery` options with the
ceph config set command.

The backfill or recovery options that can be modified are listed in mClock profile types.

> 📝 **Note:** Warning:
This section is for advanced users or for experimental testing. Do not use
these commands on a running storage cluster as it could have unexpected outcomes.

Modify the
values only for experimental testing, or if the cluster is unable to handle the values or it shows
poor performance with the default settings.

> 📝 **Note:** Important:
The modification of the mClock default backfill or recovery options is
restricted by the
`osd_mclock_override_recovery_settings`
option, which is set to
`false`
by default.

If you attempt to modify any default backfill or recovery
options without setting `osd_mclock_override_recovery_settings` to
`true`, it resets the options back to the mClock defaults along with a warning
message logged in the cluster log.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the Ceph Monitor host.

### Procedure

1. Log into the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Set the `osd_mclock_override_recovery_settings` configuration option to
`true` on all Ceph OSDs:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config set osd osd_mclock_override_recovery_settings true
```

Copy to clipboard
3. Set the desired `backfills` or `recovery` option:

Syntax

```plaintext-ibm
ceph config set osd OPTION VALUE
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config set osd osd_max_backfills 5
```

Copy to clipboard
4. Wait a few seconds and verify the configuration for the specific OSD:

Syntax

```plaintext-ibm
ceph config show osd.OSD_ID | grep OPTION
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config show osd.0 | grep osd_max_backfills
```

Copy to clipboard
5. Reset the `osd_mclock_override_recovery_settings` configuration option to
`false` on all OSDs:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config set osd osd_mclock_override_recovery_settings false
```

Copy to clipboard
