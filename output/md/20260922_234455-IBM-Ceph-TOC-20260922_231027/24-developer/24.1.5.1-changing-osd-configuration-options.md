## Changing OSD configuration options

Last Updated
: 2026-09-06

Understand how to use the RESTful plug-in to change OSD configuration
options.

On the command line, run the following command:

```plaintext-ibm
echo -En '{"=OPTION": VALUE}' | curl --request PATCH --data @- --silent --user USER 'https://CEPH_MANAGER:8080/api/osd/flags'
```

Copy to clipboard

Replace:

- OPTION with one of the modifying options: pause,
noup, nodown, noout, noin,
nobackfill, norecover, noscrub, or
nodeep-scrub.
- VALUE with true or false.
- USER with the username.
- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.

Enter the user’s password when prompted.

> 📝 **Note:** Note:
If using a self-signed certificate, use the
--insecure
option.

```plaintext-ibm
echo -En '{"=OPTION": VALUE}' | curl --request PATCH --data @- --silent --insecure --user USER 'https://CEPH_MANAGER:8080/api/osd/flags'
```

Copy to clipboard

### Changing OSD configuration options using Python

In the Python interpreter, enter the following:

```plaintext-ibm
$ python
>> import requests
>> result = requests.patch('https://CEPH_MANAGER:8080/api/osd/flags', json={"OPTION": VALUE}, auth=("USER", "PASSWORD"))
>> print(result.json())
```

Copy to clipboard

Replace:

- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- OPTION with one of the modifying options: pause,
noup, nodown, noout, noin,
nobackfill, norecover, noscrub, or
nodeep-scrub.
- VALUE with true or false.
- USER with the username.
- PASSWORD with the user’s password.

> 📝 **Note:** Note:
If using a self-signed certificate, use
`verify=False`
.

```plaintext-ibm
$ python
>> import requests
>> result = requests.patch('https://CEPH_MANAGER:8080/api/osd/flags', json={"OPTION": VALUE}, auth=("USER", "PASSWORD"), verify=False)
>> print(result.json())
```
