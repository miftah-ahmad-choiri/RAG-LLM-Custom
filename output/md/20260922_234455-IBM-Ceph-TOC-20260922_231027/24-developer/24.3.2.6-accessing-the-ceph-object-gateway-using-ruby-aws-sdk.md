## Accessing the Ceph Object Gateway using Ruby AWS SDK

Last Updated
: 2026-06-25

Use the Ruby programming language along with `aws-sdk` gem for
`S3` access. Run the steps on the node used for accessing the Ceph Object Gateway
server with `Ruby AWS::SDK`.

### Prerequisites

- User-level access to Ceph Object Gateway.
- Root-level access to the node accessing the Ceph Object Gateway.
- Internet access.

### Procedure

1. Install the `ruby` package:

```plaintext-ibm
[root@dev ~]# yum install ruby
```

Copy to clipboard

> 📝 **Note:** Note:
This command installs
`ruby`
and its essential dependencies like
`rubygems`
and
`ruby-libs`
. If somehow the command does not install
all the dependencies, install them separately.
2. Install the `aws-sdk` Ruby package:

```plaintext-ibm
[root@dev ~]# gem install aws-sdk
```

Copy to clipboard
3. Create a project directory:

```plaintext-ibm
[user@dev ~]$ mkdir ruby_aws_sdk
[user@dev ~]$ cd ruby_aws_sdk
```

Copy to clipboard
4. Create the connection file:

```plaintext-ibm
[user@dev ~]$ vim conn.rb
```

Copy to clipboard
5. Paste the following contents into the `conn.rb` file:

Syntax

```plaintext-ibm
#!/usr/bin/env ruby

require aws-sdk
require resolv-replace

Aws.config.update(
        endpoint: http://FQDN_OF_GATEWAY_NODE:8080,
        access_key_id: MY_ACCESS_KEY,
        secret_access_key: MY_SECRET_KEY,
        force_path_style: true,
        region: us-east-1
)
```

Copy to clipboard

Replace `FQDN_OF_GATEWAY_NODE` with the FQDN of the Ceph Object Gateway node.
Replace `MY_ACCESS_KEY` and `MY_SECRET_KEY` with the
`access_key` and `secret_key` that were generated when you created the
`radosgw` user for `S3` access as mentioned in the Create an S3 user section.

Example

```plaintext-ibm
#!/usr/bin/env ruby

require 'aws-sdk'
require 'resolv-replace'

Aws.config.update(
        endpoint: 'http://testclient.englab.pnq.redhat.com:8080',
        access_key_id: '98J4R9P22P5CDL65HKP8',
        secret_access_key: '6C+jcaP0dp0+FZfrRNgyGA9EzRy25pURldwje049',
        force_path_style: true,
        region: 'us-east-1'
)
```

Copy to clipboard

Save the file and exit the editor.
6. Make the file executable:

```plaintext-ibm
[user@dev ~]$ chmod +x conn.rb
```

Copy to clipboard
7. Run the file:

```plaintext-ibm
[user@dev ~]$ ./conn.rb | echo $?
```

Copy to clipboard

If you have provided the values correctly in the file, the output of the command will be
`0`.
8. Create a file for creating a bucket:

```plaintext-ibm
[user@dev ~]$ vim create_bucket.rb
```

Copy to clipboard

Paste the following contents into the file:

Syntax

```plaintext-ibm
#!/usr/bin/env ruby

load 'conn.rb'

s3_client = Aws::S3::Client.new
s3_client.create_bucket(bucket: 'my-new-bucket2')
```

Copy to clipboard

Save the file and exit the editor.
9. Make the file executable:

```plaintext-ibm
[user@dev ~]$ chmod +x create_bucket.rb
```

Copy to clipboard
10. Run the file:

```plaintext-ibm
[user@dev ~]$ ./create_bucket.rb
```

Copy to clipboard

If the output of the command is `true`, this means that bucket
`my-new-bucket2` was created successfully.
