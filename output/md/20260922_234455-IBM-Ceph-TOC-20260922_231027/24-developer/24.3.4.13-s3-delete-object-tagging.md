## S3 delete object tagging

Last Updated
: 2026-06-25
The delete object tagging API removes the entire tag set from the specified object. You must have
permission to perform the
`s3:DeleteObjectTagging`
action, to use this
operation.

> 📝 **Note:** Note:
To delete tags of a specific object version, add the
`versionId`
query parameter in the request.

Syntax

```plaintext-ibm
DELETE /_BUCKET_/_OBJECT_?tagging&versionId= HTTP/1.1
```

Copy to clipboard

Example

```plaintext-ibm
DELETE /testbucket/testobject?tagging&versionId= HTTP/1.1
```
