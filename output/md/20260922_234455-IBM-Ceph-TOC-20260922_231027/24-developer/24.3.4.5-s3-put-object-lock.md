## S3 put object lock

Last Updated
: 2026-06-25

The put object lock API places a lock configuration on the selected bucket. With object lock, you
can store objects using a Write-Once-Read-Many (WORM) model. Object lock ensures an object is
not deleted or overwritten, for a fixed amount of time or indefinitely. The rule specified in the
object lock configuration is applied by default to every new object placed in the selected
bucket.

For more information about the WORM model, see Ceph Object Gateway.

> 📝 **Note:** Note:
Enable the object lock when creating a bucket otherwise, the operation fails.

Syntax

```plaintext-ibm
PUT /BUCKET?object-lock HTTP/1.1
```
