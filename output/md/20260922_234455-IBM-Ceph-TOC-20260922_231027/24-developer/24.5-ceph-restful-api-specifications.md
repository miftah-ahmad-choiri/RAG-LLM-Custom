## Ceph RESTful API specifications

Last Updated
: 2026-06-25

As a storage administrator, you can access the various Ceph sub-systems through the Ceph
RESTful API endpoints. This is a reference section for the available Ceph RESTful API
methods.

Before you begin, make sure that you have the following prerequisites in place:

- An understanding of how to use a RESTful API.
- A healthy running IBM Storage Ceph cluster.
- The Ceph Manager `dashboard` module is enabled.
