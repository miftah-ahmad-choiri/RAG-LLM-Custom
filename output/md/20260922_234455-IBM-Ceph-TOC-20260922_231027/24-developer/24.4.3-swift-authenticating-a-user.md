## Swift authenticating a user

Last Updated
: 2026-06-25

To authenticate a user, make a request containing an `X-Auth-User` and a
`X-Auth-Key` in the header.

Syntax

```plaintext-ibm
GET /auth HTTP/1.1
Host: swift.example.com
X-Auth-User: johndoe
X-Auth-Key: R7UUOLFDI2ZI9PRCQ53K
```

Copy to clipboard

Example Response

```plaintext-ibm
HTTP/1.1 204 No Content
Date: Mon, 16 Jul 2012 11:05:33 GMT
Server: swift
X-Storage-Url: https://swift.example.com
X-Storage-Token: UOlCCC8TahFKlWuv9DB09TWHF0nDjpPElha0kAa
Content-Length: 0
Content-Type: text/plain; charset=UTF-8
```

Copy to clipboard

> 📝 **Note:** Note:
You can retrieve data about Ceph’s Swift-compatible service by executing
`GET`
requests using the
`X-Storage-Url`
value during authentication.
