## S3 delete a bucket

Last Updated
: 2026-06-25

Deletes a bucket. You can reuse bucket names following a successful bucket removal.

Syntax

```plaintext-ibm
DELETE /_BUCKET_ HTTP/1.1
Host: cname.domain.com

Authorization: AWS _ACCESS_KEY_:_HASH_OF_HEADER_AND_SECRET_
```

Copy to clipboard

HTTP Response

`204`

Status Code

`No Content`

Description

Bucket removed.
