## Viewing all configuration options for OSDs

Last Updated
: 2026-09-06

Understand how to view all configuration options and their values for OSDs.

On the command line, run the following command.

```plaintext-ibm
curl --silent --user USER 'https://CEPH_MANAGER:8080/api/osd/flags'
```

Copy to clipboard

Replace:

- USER with the username.
- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.

Enter the user’s password when prompted.

> 📝 **Note:** Note:
If you used a self-signed certificate, use the
--insecure
option.

```plaintext-ibm
curl --silent --insecure --user USER 'https://CEPH_MANAGER:8080/api/osd/flags'
```

Copy to clipboard

### Viewing all configuration options for OSDs using Python

In the Python interpreter, enter the following:

```plaintext-ibm
$ python
>> import requests
>> result = requests.get('https://CEPH_MANAGER:8080/api/osd/flags', auth=("USER", "PASSWORD"))
>> print(result.json())
```

Copy to clipboard

Replace:

- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- USER with the username.
- PASSWORD with the user’s password.

If you used a self-signed certificate, use the
`verify=False`
option.

> 📝 **Note:** Note:
If
using a self-signed certificate, use
`verify=False`
.

```plaintext-ibm
$ python
>> import requests
>> result = requests.get('https://CEPH_MANAGER:8080/api/osd/flags', auth=("USER", "PASSWORD"), verify=False))
>> print(result.json())
```

Copy to clipboard

### Viewing all configuration options for OSDs using a web browser

In the web browser, go to
userhttps://
CEPH_MANAGER
:8080/api/osd/flags.

Replace CEPH_MANAGER with the IP address or short hostname of the node with
the active `ceph-mgr` instance.

Enter the username and password when prompted.
