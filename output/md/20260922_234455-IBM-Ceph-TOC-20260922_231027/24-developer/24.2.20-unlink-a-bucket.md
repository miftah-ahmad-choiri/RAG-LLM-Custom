## Unlink a bucket

Last Updated
: 2026-06-25

Unlink a bucket from a specified user. Unlinking is primarily useful for changing bucket
ownership.

Capabilities

```plaintext-ibm
`buckets=write`
```

Copy to clipboard

Syntax

```plaintext-ibm
POST /admin/bucket?format=json HTTP/1.1
Host FULLY_QUALIFIED_DOMAIN_NAME
```

Copy to clipboard

`bucket`

Description

The bucket to unlink.

Type

String

Example

`foo_bucket`

Required

Yes

`uid`

Description

The user ID to link the bucket to.

Type

String

Example

`foo_user`

Required

Yes

Response Entities None.

`BucketUnlinkFailed`

Description

Unable to unlink bucket from specified user.

Type

409 Conflict
