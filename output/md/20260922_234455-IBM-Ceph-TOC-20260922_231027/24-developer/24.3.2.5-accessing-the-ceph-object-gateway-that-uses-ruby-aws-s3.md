## Accessing the Ceph Object Gateway that uses Ruby AWS S3

Last Updated
: 2026-06-25

Use Ruby programming language along with `aws-s3` gem for
`S3` access. Run the steps that are described on the node that is used for accessing
the Ceph Object Gateway server with `Ruby AWS::S3`.

### Prerequisites

- User-level access to Ceph Object Gateway.
- Root-level access to the node that can access the Ceph Object Gateway.
- Internet access.

### Procedure

1. Install the `ruby` package:

```plaintext-ibm
[root@dev ~]# yum install ruby
```

Copy to clipboard

> 📝 **Note:** Note:
The command installs
`ruby`
and its essential dependencies like
`rubygems`
and
`ruby-libs`
. If somehow the command does not install
all the dependencies, install them separately.
2. Install the `aws-s3` Ruby package:

```plaintext-ibm
[root@dev ~]# gem install aws-s3
```

Copy to clipboard
3. Create a project directory:

```plaintext-ibm
[user@dev ~]$ mkdir ruby_aws_s3
[user@dev ~]$ cd ruby_aws_s3
```

Copy to clipboard
4. Create the connection file:

```plaintext-ibm
[user@dev ~]$ vim conn.rb
```

Copy to clipboard
5. Paste the following contents into the `conn.rb` file:

Syntax

```plaintext-ibm
#!/usr/bin/env ruby

require aws/s3
require resolv-replace

AWS::S3::Base.establish_connection!(
        :server            => FQDN_OF_GATEWAY_NODE,
        :port           => 8080,
        :access_key_id     => MY_ACCESS_KEY,
        :secret_access_key => MY_SECRET_KEY
)
```

Copy to clipboard

Replace `FQDN_OF_GATEWAY_NODE` with the FQDN of the Ceph Object Gateway node.

Example

```plaintext-ibm
#!/usr/bin/env ruby

require 'aws/s3'
require 'resolv-replace'

AWS::S3::Base.establish_connection!(
        :server            => 'testclient.englab.pnq.redhat.com',
        :port           => '8080',
        :access_key_id     => '98J4R9P22P5CDL65HKP8',
        :secret_access_key => '6C+jcaP0dp0+FZfrRNgyGA9EzRy25pURldwje049'
)
```

Copy to clipboard

Save the file and exit the editor.
6. Make the file executable:

```plaintext-ibm
[user@dev ~]$ chmod +x conn.rb
```

Copy to clipboard
7. Run the file:

```plaintext-ibm
[user@dev ~]$ ./conn.rb | echo $?
```

Copy to clipboard

If you have provided the values correctly in the file, the output of the command is
`0`.
8. Create a file for creating a bucket:

```plaintext-ibm
[user@dev ~]$ vim create_bucket.rb
```

Copy to clipboard

Paste the following contents into the file:

```plaintext-ibm
#!/usr/bin/env ruby

load 'conn.rb'

AWS::S3::Bucket.create('my-new-bucket1')
```

Copy to clipboard

Save the file and exit the editor.
9. Make the file executable:

```plaintext-ibm
[user@dev ~]$ chmod +x create_bucket.rb
```

Copy to clipboard
10. Run the file:

```plaintext-ibm
[user@dev ~]$ ./create_bucket.rb
```

Copy to clipboard

If the output of the command is `true` it would mean that a bucket
`my-new-bucket1` was created successfully.

```plaintext-ibm

AWS::S3::Service.buckets.each do |bucket|
        puts "{bucket.name}\t{bucket.creation_date}"
end
```

Copy to clipboard

Save the file and exit the editor.
12. Make the file executable:

```plaintext-ibm
[user@dev ~]$ chmod +x list_owned_buckets.rb
```

Copy to clipboard
13. Run the file:

```plaintext-ibm
[user@dev ~]$ ./list_owned_buckets.rb
```

Copy to clipboard

The output should look something like this:

```plaintext-ibm

```

Copy to clipboard
14. Create a file for creating an object:

```plaintext-ibm
[user@dev ~]$ vim create_object.rb
```

Copy to clipboard

Paste the following contents into the file:

```plaintext-ibm
#!/usr/bin/env ruby

AWS::S3::S3Object.store(
        'hello.txt',
        'Hello World!',
        'my-new-bucket1',
        :content_type => 'text/plain'

```

Copy to clipboard

Save the file and exit the editor.
15. Make the file executable:

```plaintext-ibm
[user@dev ~]$ chmod +x create_object.rb
```

Copy to clipboard
16. Run the file:

```plaintext-ibm
[user@dev ~]$ ./create_object.rb
```

Copy to clipboard

This command creates a file `hello.txt` with the string `Hello
World!`.

```plaintext-ibm

```

Copy to clipboard

```plaintext-ibm
end
```

Copy to clipboard

Save the file and exit the editor.

```plaintext-ibm

[user@dev ~]$ ./list_bucket_content.rb
```

Copy to clipboard

The output looks something like this:


Copy to clipboard
