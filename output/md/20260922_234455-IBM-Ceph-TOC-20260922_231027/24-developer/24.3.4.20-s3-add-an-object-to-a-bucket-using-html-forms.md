## S3 add an object to a bucket using HTML forms

Last Updated
: 2026-06-25

Adds an object to a bucket using HTML forms. You must have write permissions on the bucket to
perform this operation.

Syntax

```plaintext-ibm
POST _BUCKET_/_OBJECT_ HTTP/1.1
```
