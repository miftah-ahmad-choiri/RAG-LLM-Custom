## Running a scheduled process on an OSD

Last Updated
: 2026-09-06

Understand how to use the RESTful plug-in to run a scheduled process on an OSD, such as
scrubbing or deep scrubbing.

On the command line, run the following command:

```plaintext-ibm
echo -En '{"command": "COMMAND"}' | curl --request POST --data @- --silent --user USER 'https://CEPH_MANAGER:8080/api/osd/ID/command'
```

Copy to clipboard

Replace:

- COMMAND with the process you want to start. The options are
scrub, deep-scrub, or repair. Verify if the
process is supported on the OSD. For more information, see Determining processes that can be scheduled on an OSD.
- USER with the username.
- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- ID with the ID of the OSD listed in the `osd` field

Enter the user’s password when prompted.

> 📝 **Note:** Note:
If using a self-signed certificate, use the
--insecure
option.

```plaintext-ibm
echo -En '{"command": "COMMAND"}' | curl --request POST --data @- --silent --insecure --user USER 'https://CEPH_MANAGER:8080/api/osd/ID/command'
```

### Running a scheduled process on an OSD using Python

In the Python interpreter, enter the following:

```plaintext-ibm
$ python
>> import requests
>> result = requests.post('https://CEPH_MANAGER:8080/api/osd/ID/command', json={"command": "COMMAND"}, auth=("USER", "PASSWORD"))
>> print(result.json())
```

Copy to clipboard

Replace:

- CEPH_MANAGER with the IP address or short hostname of the node with the
active `ceph-mgr` instance.
- ID with the ID of the OSD listed in the `osd` field
- COMMAND with the process you want to start. The options are
scrub, deep-scrub, or repair. Verify if the
process is supported on the OSD. For more information, see Determining processes that can be scheduled on an OSD.
- USER with the username.
- PASSWORD with the user’s password.

> 📝 **Note:** Note:
If using a self-signed certificate, use
`verify=False`
.

```plaintext-ibm
$ python
>> import requests
>> result = requests.post('https://CEPH_MANAGER:8080/api/osd/ID/command', json={"command": "COMMAND"}, auth=("USER", "PASSWORD"), verify=False)
>> print(result.json())
```
