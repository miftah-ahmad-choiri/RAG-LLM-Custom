## S3 delete PublicAccessBlock

Last Updated
: 2026-06-25

Use this to delete the
`PublicAccessBlock`
configuration for an account.

For information about the S3 Public Access Block feature used with IBM Storage Ceph, see S3 Block Public Access.

```plaintext-ibm
DELETE /v20180820/configuration/publicAccessBlock HTTP/1.1
Host: s3-control.amazonaws.com
x-amz-account-id: AccountId
```

Copy to clipboard

### Request Headers

For information about common request headers, see S3 common request headers.

### Response

The response is an HTTP 200 response and is returned with an empty HTTP body.
