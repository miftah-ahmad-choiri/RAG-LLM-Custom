## Swift response headers

Last Updated
: 2026-06-25

The response from the server should include an `X-Auth-Token` value. The response
might also contain a `X-Storage-Url` that provides the
`API_VERSION_/_ACCOUNT` prefix that is specified in other requests throughout the API
documentation.

| Name | Description | Type |
| --- | --- | --- |
| X-Storage-Token | The authorization token for the X-Auth-User specified in the request. | String |
| X-Storage-Url | The URL and _API_VERSION_/_ACCOUNT_ path for the user. | String |
