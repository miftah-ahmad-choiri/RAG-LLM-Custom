## Set a bucket quota

Last Updated
: 2026-06-25

To set a quota, the user must have `users` capability set with
`write` permission.

Syntax

```plaintext-ibm
PUT /admin/user?quota&uid=UID&quota-type=bucket
```

Copy to clipboard

The content must include a JSON representation of the quota settings as encoded in the
corresponding read operation.
