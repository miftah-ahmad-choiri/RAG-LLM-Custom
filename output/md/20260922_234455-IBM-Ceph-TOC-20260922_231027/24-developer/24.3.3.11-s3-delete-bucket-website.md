## S3 delete bucket website

Last Updated
: 2026-06-25

The delete bucket website API removes the website configuration for a bucket.

Syntax

```plaintext-ibm
DELETE /BUCKET?website-configuration=HTTP/1.1
```

Copy to clipboard

Example

```plaintext-ibm
DELETE /testbucket?website-configuration=HTTP/1.1
```

Copy to clipboard
