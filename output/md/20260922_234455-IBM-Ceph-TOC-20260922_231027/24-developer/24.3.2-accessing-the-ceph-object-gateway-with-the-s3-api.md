## Accessing the Ceph Object Gateway with the S3 API

Last Updated
: 2026-06-25

As a developer, you must configure access to the Ceph Object Gateway and the Secure Token
Service (STS) before you can start using the Amazon S3 API.

- A running IBM Storage Ceph cluster.
- A running Ceph Object Gateway.
- A RESTful client.
