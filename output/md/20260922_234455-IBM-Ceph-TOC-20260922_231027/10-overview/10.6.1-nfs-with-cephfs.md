## NFS with CephFS

Last Updated
: 2026-09-06

Ceph File System (CephFS) is a distributed file system designed to provide reliable and scalable storage for large-scale deployments. It is part of the IBM Storage Ceph software-defined storage platform and offers features like data replication, fault tolerance, and scalability. When the Ceph NFS service gateway is used with CephFS, it helps enables clients to access CephFS file systems using the NFS protocol.

Ceph NFS service gateway shows how the NFS service integrates with IBM Storage Ceph and CephFS.

Figure 1.
Ceph NFS service gateway

CephFS namespaces can be exported over the NFS protocol using the NFS service NFS server with `ceph nfs` commands.

For more information, see Sharing Ceph File System namespaces over the NFS protocol.

For more information about using the Ceph orchestrator with `cephadm` in the backend to deploy the NFS service gateway, see Managing the NFS service gateway using the Ceph orchestrator.
