## NFS file services

Last Updated
: 2026-09-06

NFS file services enable you to share files across systems in a distributed environment by using the NFS protocol with either Ceph File System (CephFS) or Ceph Object Storage as the backend.

NFS can be used with either Ceph File System (CephFS) or Ceph Object Storage.

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.
