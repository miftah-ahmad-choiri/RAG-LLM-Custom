## Federal Information Processing Standard (FIPS)

Last Updated
: 2026-06-25

IBM Storage Ceph uses FIPS validated cryptography
modules when run on the latest certified Red Hat Enterprise Linux version.

Enable FIPS mode on Red Hat Enterprise Linux either during system installation or after the
installation process.

For container deployments, follow the instructions in the [Red Hat Enterprise Linux 9 Security Hardening Guide](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2Fred_hat_enterprise_linux%2F9%2Fhtml%2Fsecurity_hardening%2Fusing-the-system-wide-cryptographic-policies_security-hardening%23enabling-fips-mode-in-a-container_using-the-system-wide-cryptographic-policies) on [Red Hat Documentation](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2F).
