## Updating Ceph Object Gateway to use cephadm self-signed certificates in a multi-site deployment

Last Updated
: 2026-06-25

Starting from IBM Storage Ceph 8.1, IBM Storage Ceph introduced a new root certificate authority (CA) format. As a result, when updating the Ceph Object Gateway in multi-site deployments from IBM Storage Ceph versions 8.0 or earlier, you must complete additional steps to enable `cephadm` self-signed certificates.

### Before you begin

Before you begin, make sure that your
IBM Storage Ceph
9.9.1
storage system is using the earlier old-style root CA.

```plaintext-ibm
ceph orch certmgr cert ls
```

Copy to clipboard

- If the root CA `commonName` has the `cephadm-root` format, it is in the old style. Continue with the procedure documented here.
- If the root CA `commonName` has the `cephadm-root-FSID` format, your cluster has already been upgraded to the new format and no further actions are required.

### About this task

Use this procedure in any of the following scenarios:

- You are upgrading from IBM Storage Ceph versions 8.0 or earlier and are planning on using `cephadm` self-signed certificates.
- `cephadm` self-signed certificates are expired.

If you do not plan on using `cephadm` self-signed certificates or the root CA `commonName` has the `cephadm-root-FSID` format and the certificates are valid, this procedure is not required.

### Procedure

1. Remove the previous root CA.

```plaintext-ibm
ceph orch certmgr rm cephadm_root_ca_cert
```

2. Reload the
`certmgr`

```plaintext-ibm

```

3. Verify that the
`certmgr`
has been loaded correctly.

```plaintext-ibm
ceph orch certmgr cert ls
```

`cephadm_root_ca_cert`

`cephadm-root-FSID`

9. Upgrade the Ceph Dashboard certificates.

1. Generate the
`cephadm`
-signed certificates for the dashboard.
From the
`cephadm`
command-line interface (CLI), run the following commands:

```plaintext-ibm
json="$(ceph orch certmgr generate-certificates dashboard)"
printf '%s' "$json" | jq -r '.cert' > dashboard.crt
printf '%s' "$json" | jq -r '.key'  > dashboard.key
```
