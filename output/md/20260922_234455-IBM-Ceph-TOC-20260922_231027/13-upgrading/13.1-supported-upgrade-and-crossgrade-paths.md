## Supported upgrade and crossgrade paths

Last Updated
: 2026-09-06

Upgrade to IBM Storage Ceph based on the support that is provided by IBM.

Supported upgrade paths
details the upgrade paths that are supported to upgrade from older
IBM Storage Ceph
versions to
IBM Storage Ceph
9.9.1
.

| Pre-upgrade | Post-upgrade |
| --- | --- |
| IBM Storage Ceph 7.11, 2 | IBM Storage Ceph 9.9.1 |
| IBM Storage Ceph 8.1 | IBM Storage Ceph 9.9.1 |
| IBM Storage Ceph 9.9.0 | IBM Storage Ceph 9.9.1 |

1To define a group name for the NVMe-oF service that was upgraded from IBM Storage Ceph 7.1, see Updating an NVMe-oF service with a gateway group name.

2To upgrade Ceph Object Gateway (RGW) with multi-site to use`cephadm` self-signed certificates from IBM Storage Ceph 7.1, see Updating Ceph Object Gateway to use cephadm self-signed certificates in a multi-site deployment.

For more information and the latest supported configurations, see [IBM Storage Ceph Supported configurations](https://www.ibm.com/support/pages/node/7236061).

### Crossgrade paths

Crossgrade paths detail supported upgrade paths from Red Hat Ceph Storage to IBM Storage Ceph.

> 📝 **Note:** Note:
For customers currently using Red Hat Ceph Storage with iSCSI gateway who want to migrate to
IBM Storage Ceph
with NVMe-oF gateway support, contact
[IBM Support](https://www.ibm.com/mysupport/)
.
