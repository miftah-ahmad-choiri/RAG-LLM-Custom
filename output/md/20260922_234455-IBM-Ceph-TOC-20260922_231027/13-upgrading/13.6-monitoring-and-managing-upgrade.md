## Monitoring and managing upgrade

Last Updated
: 2026-09-09

You can monitor and manage the upgrade of the storage cluster during the upgrade process.

After running the ceph orch upgrade start command to upgrade the IBM Storage Ceph cluster, you can check the status, pause, resume, or stop the upgrade process. The health of the cluster changes to HEALTH_WARNING during an upgrade.

> 📝 **Note:** Note:
Call Home status is automatically enabled after license acceptance and might generate a health warning until it is acknowledged or disabled.
Use Ceph Orchestrator commands to clear the health warning emitted by Call Home.

- Clear the health warning and allow the module to remain active.

```plaintext-ibm
ceph orch accept call-home-enabled
```

Copy to clipboard
- Clear the health warning and turn off the Call Home module.

```plaintext-ibm
ceph orch deny call-home-enabled
```

Copy to clipboard

Automatic service events are not enabled automatically. To enable service events, see
Enabling service events
.

> 📝 **Note:** Note:
Upgrade one daemon type after the other.

The upgrade is paused in the following situations:

- The host of the cluster is offline.
- A daemon cannot be upgraded.
- An invalid CRUSH bucket name or type is specified during an OSD upgrade.

> 📝 **Note:** Note:
If a cluster is or becomes unavailable the upgrade will be paused until it is restored.

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph supported existing.
- Root-level access to all the nodes.
- At least two Ceph Manager nodes in the storage cluster: one active and one standby.
- Upgrade for the storage cluster initiated.

Use the
ceph orch upgrade
command to take you through the upgrade process.
Table 1
provides the different options that can be used to help manage and monitor during the upgrade process.

| Command option | Syntax | Notes |
| --- | --- | --- |
| status | ceph orch upgrade statusCopy to clipboard | Use the status option to determine whether an upgrade is in progress and the version to which the cluster is upgrading. You do not get a message when the upgrade is successful. Run ceph versions and ceph orch ps commands to verify the new image ID and the version of the storage cluster. |
| pause | ceph orch upgrade pauseCopy to clipboard | None |
| resume | ceph orch upgrade resumeCopy to clipboard | None |
| stop | ceph orch upgrade stopCopy to clipboard | None |
