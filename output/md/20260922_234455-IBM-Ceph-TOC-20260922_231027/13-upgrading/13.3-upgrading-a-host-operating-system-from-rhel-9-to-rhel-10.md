## Upgrading a host operating system from RHEL 9 to RHEL 10

Last Updated
: 2026-06-25

You can perform an IBM Storage Ceph host operating system upgrade from Red Hat Enterprise Linux (RHEL) 9 to Red Hat Enterprise Linux 10 using the Leapp utility.

### Before you begin

Be sure that you have a running
IBM Storage Ceph
cluster that is supported for upgrade. For more information, see
Supported upgrade and crossgrade paths
.

### About this task

> 📝 **Note:** Important:
This host operating system upgrade
*must*
be performed before upgrading the
IBM Storage Ceph
cluster.

The following are the supported combinations of containerized Ceph daemons. For more information, see
Colocation
.

- Ceph Metadata Server (`ceph-mds`), Ceph OSD (`ceph-osd`), and Ceph Object Gateway (`radosgw`)
- Ceph Monitor (`ceph-mon`) *or* Ceph Manager (`ceph-mgr`), Ceph OSD (`ceph-osd`), and Ceph Object Gateway (`radosgw`)
- Ceph Monitor (`ceph-mon`), Ceph Manager (`ceph-mgr`), Ceph OSD (`ceph-osd`), and Ceph Object Gateway (`radosgw`)

### Procedure

1. Deploy your existing
IBM Storage Ceph
on the latest Red Hat Enterprise Linux 9 supported version with service.

> 📝 **Note:** Note:
Verify that the cluster contains two admin nodes, so that while performing host upgrade in one admin node (with
`_admin`
label), the second admin node can be used for managing clusters.

For full instructions, see
Initial installation
and
Deploying the Ceph daemons using the service specification
.
2. Set the
`noout`
flag on the Ceph OSD.
For example,

```plaintext-ibm
[ceph: root@host01 /]# ceph osd set noout
```

Copy to clipboard
3. Run the host upgrade one node at a time using the Leapp utility.

1. Put the respective node in maintenance mode before performing host upgrade using Leapp.

```plaintext-ibm
ceph orch host maintenance enter HOST
```

Copy to clipboard

For example,

```plaintext-ibm
ceph orch host maintenance enter host01
```

Copy to clipboard
2. Enable the Ceph tools repo manually when executing the Leapp command with the
`--enablerepo`
parameter.
For example,

```plaintext-ibm
leapp upgrade --enablerepo https://public.dhe.ibm.com/ibmdl/export/pub/storage/ceph/ibm-storage-ceph-9-rhel-10.repo
```

Copy to clipboard
3. Upgrade Red Hat Enterprise Linux from version 9 to 10.
For full instructions, follow the instructions provided within the
[Upgrading from RHEL 9 to RHEL 10](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2Fred_hat_enterprise_linux%2F10%2Fhtml%2Fupgrading_from_rhel_9_to_rhel_10)
guide within the Red Hat Enterprise Linux product documentation on the
[Red Hat Customer Portal](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2F)
.

> 📝 **Note:** Important:
After performing an in-place upgrade from Red Hat Enterprise Linux 9 to Red Hat Enterprise Linux 10, manually enable and start the
`logrotate.timer`
service.

```plaintext-ibm
systemctl start logrotate.timer
systemctl enable logrotate.timer
```

### What to do next

Continue with the existing
IBM Storage Ceph
version to
IBM Storage Ceph

upgrade, by following
