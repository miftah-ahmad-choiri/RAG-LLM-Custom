## Updating an NVMe-oF service with a gateway group name

Last Updated
: 2026-09-06

Starting from IBM Storage Ceph 8.0, NVMe-oF gateway group names are now mandatory. For uniformity, it is recommended to set an NVMe-oF gateway group name for any empty group name that is being updated from IBM Storage Ceph 7.1.

### About this task

Setting NVMe-oF gateway group names is not necessary but helps ensure uniformity across all clusters in the upgraded IBM Storage Ceph system.

Updating the group name can be done before or after upgrading the cluster procedure defined in Upgrading the IBM Storage Ceph cluster.

> 📝 **Note:** Important:
If you are upgrading from
IBM Storage Ceph
7.1
, gateways with an empty group name may remain after completing this procedure. Follow the final step to remove them.

### Procedure

1. From the
`cephadm`
shell command-line, copy the gateway group configuration OMAP file.

```plaintext-ibm
rados -p NVME-OF_POOL_NAME cp nvmeof.state nvmeof.NVME-OF_GROUP_NAME.state
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# rados -p nvmeof_pool01 cp nvmeof.state nvmeof.nvmeof_group01.state
```
2. Export the service specification file into a YAML file.

```plaintext-ibm
ceph orch ls nvmeof --export nvmeof.NVME-OF_POOL_NAME > SPEC_COPY.yaml
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch ls nvmeof --export nvmeof.nvmeof_pool01 > spec1.yaml
```
3. Edit the YAML file and add the group name.

```plaintext-ibm
group: NVME-OF_GROUP_NAME
```

Copy to clipboard

For example,

```
[root@host01 ~]# cat file.yaml
service_type: nvmeof
service_id: nvmeof_pool01
service_name: nvmeof.nvmeof_pool01
placement:
  hosts:
    - host01
    - host02
spec:
  pool: nvmeof_pool01
  group: nvmeof_group01
```
4. Apply the new specification file.

```plaintext-ibm
ceph orch apply -i SPEC_COPY.yaml
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch apply -i spec1.yaml
```
5. Reconfigure the NVMe-oF service.

```plaintext-ibm
ceph orch reconfig SERVICE_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch reconfig nvmeof
```
6. Delete any remaining NVMe-oF gateways that still have an empty group name.

After reconfiguring the service, gateways with a blank group name may remain. Verify and remove them to complete the update.

1. List the gateways with an empty group name:

```plaintext-ibm
ceph nvme-gw show NVME-OF_POOL_NAME ''
```

Copy to clipboard
2. For each gateway listed, delete it:

```plaintext-ibm
ceph nvme-gw delete GATEWAY_ID NVME-OF_POOL_NAME ''
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph nvme-gw show nvmeof_pool01 ''
[
  {
    "gw-id": "client.nvmeof.nvmeof_pool01.host01.asdfk"
  }
]

[ceph: root@host01 /]# ceph nvme-gw delete client.nvmeof.nvmeof_pool01.host01.asdfk nvmeof_pool01 ''
```
