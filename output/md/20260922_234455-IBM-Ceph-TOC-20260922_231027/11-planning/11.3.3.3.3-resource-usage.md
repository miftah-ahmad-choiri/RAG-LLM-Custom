## Resource usage

Last Updated
: 2026-06-25

For each placement group, OSDs and Ceph monitors need memory, network, and CPU at all
times, and even more during recovery. Sharing this overhead by clustering objects within a placement
group is one of the main reasons placement groups exist.

Minimize the number of placement groups to save significant amounts of resources.
