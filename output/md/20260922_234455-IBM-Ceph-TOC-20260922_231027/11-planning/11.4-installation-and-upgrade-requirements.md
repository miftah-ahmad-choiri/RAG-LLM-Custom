## Installation and upgrade requirements

Last Updated
: 2026-06-25

Use this IBM Storage Ceph software container and version information to learn how to obtain the correct container versions and tags during installation and upgrade procedures. Get to know how to log in to the IBM Container Registry (ICR) and get the needed container version and tags during installation and upgrades.

### About this task

Use this information for general installation and upgrade requirements and information.
For information about disconnected installations and upgrades, see the following:

- Disconnected installation
- Upgrading cluster in a disconnected environment

### Finding the latest available supported container images

#### Procedure

Find the latest available supported container images on the IBM Container Registry.
The following examples for obtaining the most recent images use skopeo.

```plaintext-ibm
skopeo login -u "cp" -p \ MY_KEY cp.icr.io
```

Copy to clipboard

For example,

```plaintext-ibm
skopeo list-tags docker://cp.icr.io/cp/ibm-ceph/ceph-9-rhel9
```

Copy to clipboard

### Upgrading with the default image tags

#### Procedure

Upgrade the storage cluster in a disconnected environment by using the
--image
tag.
By default, the monitoring stack components are deployed based on the primary Ceph image.
For disconnected environment of the storage cluster, you have to use the latest available monitoring stack component images. For more information, see
Upgrading cluster in a disconnected environment
.

### Upgrading with specific image tags

#### Procedure

Use the
ceph orch upgrade
command to start and check an upgrade to a specific tagged version.
For example,

```plaintext-ibm
ceph orch upgrade check cp.icr.io/cp/ibm-ceph/ceph-9-rhel9:7-59
```

Copy to clipboard

```plaintext-ibm
ceph orch upgrade start cp.icr.io/cp/ibm-ceph/ceph-9-rhel9:7-59
```
