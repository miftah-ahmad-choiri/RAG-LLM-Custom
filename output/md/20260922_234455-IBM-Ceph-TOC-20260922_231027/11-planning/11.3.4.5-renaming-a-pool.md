## Renaming a pool

Last Updated
: 2026-06-25

Learn how to rename a pool.

To rename a pool, run:

Syntax

```plaintext-ibm
ceph osd pool rename CURRENT_POOL_NAME NEW_POOL_NAME
```

Copy to clipboard

If you rename a pool and you have per-pool capabilities for an authenticated user, you must
update the user’s capabilities (that is, caps) with the new pool name.
