## Specifying target size using the absolute size of the pool

Last Updated
: 2026-06-25

Specify the target size of a pool by using the absolute size of the pool.

1. Set the `target size` using the absolute size of the pool in bytes:

```plaintext-ibm
 ceph osd pool set pool-name target_size_bytes value
```

Copy to clipboard

For example, to instruct the system that `mypool` is expected to consume 100T of
space:

```plaintext-ibm
 $ ceph osd pool set mypool target_size_bytes 100T
```

Copy to clipboard

You can also set the target size of a pool at creation time by adding the optional
`--target-size-bytes <bytes>` argument to the ceph osd pool
create command.
