## Removing CRUSH rules

Last Updated
: 2026-06-25

Use this information to remove a CRUSH rule from the command-line.

To remove a rule, run the following and specify the CRUSH rule name:

Syntax

```plaintext-ibm
ceph osd crush rule rm NAME
```
