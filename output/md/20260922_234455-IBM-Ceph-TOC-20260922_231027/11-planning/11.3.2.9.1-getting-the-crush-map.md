## Getting the CRUSH map

Last Updated
: 2026-06-25

Getting the CRUSH map is the necessary first step in editing the map.

To get the CRUSH map for your cluster, run the following:

Syntax

```plaintext-ibm
ceph osd getcrushmap -o COMPILED_CRUSHMAP_FILENAME
```

Copy to clipboard

Ceph will output (-o) a compiled CRUSH map to the file name you specified. Since the CRUSH map is
in a compiled form, you must decompile it first before you can edit it.
