## Dumping CRUSH rules

Last Updated
: 2026-06-25

Use this information to ldump the contents of a specific CRUSH rule from the
command-line.

To dump the contents of a specific CRUSH rule, run the following:

Syntax

```plaintext-ibm
ceph osd crush rule dump NAME
```
