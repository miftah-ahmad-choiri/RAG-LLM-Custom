## Removing an existing erasure-code-profile

Last Updated
: 2026-06-25

Learn how to remove an erasure code profile.

### Procedure

Remove an erasure code profile.

```plaintext-ibm
ceph osd erasure-code-profile rm NAME
```

Copy to clipboard

where NAME is the name of the profile.

> 📝 **Note:** Important:
If the profile is referenced by a pool, the deletion fails.

> 📝 **Note:** Warning:
Removing an erasure code profile using
osd erasure-code-profile rm
command does not automatically delete the associated CRUSH rule that is associated with the erasure code profile. Manually remove the associated CRUSH rule using
ceph osd crush rule remove RULE_NAME
command to avoid unexpected behavior.
