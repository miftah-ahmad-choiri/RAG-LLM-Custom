## General principles for selecting hardware

Last Updated
: 2026-06-25

As a storage administrator, you must select the appropriate hardware for running a production IBM Storage Ceph cluster. When selecting hardware for IBM Storage Ceph, review these following general principles. These principles will help save time, avoid common mistakes, save money and achieve a more effective solution.

For a list of supported configurations, see [IBM Storage Ceph Supported configurations](https://www.ibm.com/support/pages/node/7236061).

### Prerequisites

- A planned use for IBM Storage Ceph.
- Linux System Administration Advance level with Red Hat Enterprise Linux certification.
- Storage administrator with Ceph Certification.
