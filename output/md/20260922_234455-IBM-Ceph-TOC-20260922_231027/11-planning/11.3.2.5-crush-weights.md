## CRUSH weights

Last Updated
: 2026-06-25

The CRUSH algorithm assigns a weight value in terabytes (by convention) per OSD device.
The assigned weight is done with the objective of approximating a uniform probability distribution
for write requests that assign new data objects to placement groups (PGs) and PGs to
OSDs.

As a result, it is best practice to create CRUSH hierarchies with devices of the same type and
size, and to assign the same weight. In addition, use devices with the same I/O and throughput
characteristics so that you will also have uniform performance characteristics in your CRUSH
hierarchy, even though performance characteristics do not affect data distribution.

Since using uniform hardware is not always practical, you might incorporate OSD devices of
different sizes and use a relative weight so that Ceph will distribute more data to larger devices
and less data to smaller devices.
