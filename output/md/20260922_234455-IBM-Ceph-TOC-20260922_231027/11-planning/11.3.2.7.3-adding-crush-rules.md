## Adding CRUSH rules

Last Updated
: 2026-06-25

Use this information to add CRUSH rules from the command-line.

To add a CRUSH rule, you must specify a rule name, the root node of the hierarchy you wish to
use, the type of bucket you want to replicate across (for example, *rack*, *row*, and so
on and the mode for choosing the bucket.

Syntax

```plaintext-ibm
ceph osd crush rule create-simple RULENAME ROOT BUCKET_NAME FIRSTN_OR_INDEP
```

Copy to clipboard

Ceph creates a rule with `chooseleaf` and one bucket of the type you specify.

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph osd crush rule create-simple deleteme default host firstn
```

Copy to clipboard

Create the following rule:

```plaintext-ibm
{ "id": 1,
  "rule_name": "deleteme",
  "type": 1,
  "min_size": 1,
  "max_size": 10,
  "steps": [
        { "op": "take",
          "item": -1,
          "item_name": "default"},
        { "op": "chooseleaf_firstn",
          "num": 0,
          "type": "host"},
        { "op": "emit"}]}
```

Copy to clipboard
