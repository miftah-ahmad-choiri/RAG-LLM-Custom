## Setting a CRUSH map

Last Updated
: 2026-06-25

To set the CRUSH map for your cluster, run the following:

Syntax

```plaintext-ibm
ceph osd setcrushmap -i COMPILED_CRUSHMAP_FILENAME
```

Copy to clipboard

Ceph inputs the compiled CRUSH map of the file name you specified as the CRUSH map for the
cluster.
