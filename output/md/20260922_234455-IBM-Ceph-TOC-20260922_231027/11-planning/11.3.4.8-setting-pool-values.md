## Setting pool values

Last Updated
: 2026-06-25

Set pool values.

To set a value to a pool, run the following command:

```plaintext-ibm
ceph osd pool set POOL_NAME KEY VALUE
```

Copy to clipboard

For more information about the available key-value pairs, see Pool values.
