## Marking unfound objects

Last Updated
: 2026-06-25

If the cluster has lost one or more objects, and you have decided to abandon the search
for the lost data, you must mark the unfound objects as `lost`.

If all possible locations have been queried and objects are still lost, you might have to give up
on the lost objects. This is possible given unusual combinations of failures that allow the cluster
to learn about writes that were performed before the writes themselves are recovered.

Currently the only supported option is "revert", which will either roll back to a previous
version of the object or (if it was a new object) forget about it entirely. To mark the "unfound"
objects as "lost", run the following:

Syntax

```plaintext-ibm
ceph pg PG_ID mark_unfound_lost revert|delete
```

Copy to clipboard

> 📝 **Note:** Important:
Use this feature with caution, because it might confuse applications that
expect the object(s) to exist.
