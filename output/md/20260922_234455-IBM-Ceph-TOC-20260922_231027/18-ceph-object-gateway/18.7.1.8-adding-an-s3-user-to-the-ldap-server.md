## Adding an S3 user to the LDAP server

Last Updated
: 2026-06-25

Create at least one S3 user so that an S3 client can use the LDAP user
credentials.

In the administrative console on the LDAP server, create at least one S3 user so that an S3
client can use the LDAP user credentials. Make a note of the user name and secret for use when
passing the credentials to the S3 client.
