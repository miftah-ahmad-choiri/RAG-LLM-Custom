## Deploying NFS service with Ceph Object Storage backend

Last Updated
: 2026-06-25

Using the Ceph Orchestrator, you can deploy the NFS service in Ceph Object
Gateway.

### Before you begin

- A running IBM Storage Ceph cluster.
- Root-level access to all the nodes.
- Hosts are added to the cluster.
- All Manager, Monitor, RGW, and OSD daemons are deployed.

### Procedure

1. Log into the
`cephadm`
shell.
```plaintext-ibm
cephadm shell
```

Copy to clipboard
2. Create a NFS specification file with the relevant data, including
the host on which the NFS service needs to be installed.
```plaintext-ibm
cat nfs-conf.yml

service_type: nfs
service_id: nfs-rgw-service
placement:
  hosts: ['host1']
spec:
  port: 2049
```

Copy to clipboard
3. Apply the NFS service via the specification file created in step
2
.
```plaintext-ibm
ceph orch apply -i nfs-conf.yml
```

Copy to clipboard
4. Verify if the NFS service has been created successfully.
```plaintext-ibm
ceph orch ls --service_name nfs.nfs-rgw-service --service_type nfs
```

Copy to clipboard
