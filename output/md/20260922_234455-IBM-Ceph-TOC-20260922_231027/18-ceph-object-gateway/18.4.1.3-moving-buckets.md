## Moving buckets

Last Updated
: 2026-06-25

The `radosgw-admin bucket` utility provides the ability to move buckets
between users. To do so, link the bucket to a new user and change the ownership of the bucket to the
new user.

You can move buckets:

- Between two non-tenanted users
- Between two tenanted users
- Between a non-tenanted user to a tenanted user

### Prerequisites

- A running IBM Storage Ceph cluster.
- Ceph Object Gateway is installed.
- An S3 bucket.
- Various tenanted and non-tenanted users.
