## Listing zones

Last Updated
: 2026-06-25

Use the zone list command to list zones in a cluster.

As `root`, to list the zones in a cluster, run the following command:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin zone list
```

Copy to clipboard
