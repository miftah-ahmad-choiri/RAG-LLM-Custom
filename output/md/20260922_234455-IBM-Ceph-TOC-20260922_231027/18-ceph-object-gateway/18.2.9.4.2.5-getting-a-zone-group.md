## Getting a zone group

Last Updated
: 2026-06-25

Use the zonegroup get command to retrieve a zone group
configuration.

To view the configuration of a zone group, run the following command:

Syntax

```plaintext-ibm
radosgw-admin zonegroup get [--rgw-zonegroup=ZONE_GROUP_NAME]
```
