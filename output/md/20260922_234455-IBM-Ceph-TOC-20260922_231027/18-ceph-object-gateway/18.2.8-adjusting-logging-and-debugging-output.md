## Adjusting logging and debugging output

Last Updated
: 2026-06-25

Debug output can be changed and log output can be adjusted to save as files.

After finishing the setup procedure, check your logging output to ensure it meets your needs. By
default, the Ceph daemons log to `journald`, and you can view the logs using the
`journalctl` command. Alternatively, you can also have the Ceph daemons log to files,
which are located under the `/var/log/ceph/CEPH_CLUSTER_ID/` directory.

> 📝 **Note:** Important:
Verbose logging can generate over 1 GB of data per hour. This type of logging
can potentially fill up the operating system’s disk, causing the operating system to stop
functioning.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Installation of the Ceph Object Gateway software.

### Procedure

1. Set the following parameter to increase the Ceph Object Gateway logging output:

Syntax

```plaintext-ibm
ceph config set client.rgw debug_rgw VALUE
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config set client.rgw debug_rgw 20
```

Copy to clipboard

1. You can also modify these settings at runtime:

Syntax

```plaintext-ibm
ceph --admin-daemon /var/run/ceph/CEPH_CLUSTER_ID/ceph-client.rgw.NAME.asok config set debug_rgw VALUE
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph --admin-daemon /var/run/ceph/62a081a6-88aa-11eb-a367-001a4a000672/ceph-client.rgw.rgw.asok config set debug_rgw 20
```

2. Optionally, you can configure the Ceph daemons to log their output to files. Set the
`log_to_file`, and `mon_cluster_log_to_file` options to
`true`:

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph config set global log_to_file true
[ceph: root@host01 /]# ceph config set global mon_cluster_log_to_file true
```
