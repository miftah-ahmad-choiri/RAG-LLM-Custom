## Restarting the Ceph Object Gateway daemon

Last Updated
: 2026-06-25

Restarting the Ceph Object Gateway must be done to active configuration
changes.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Access to the Ceph software repository.
- `admin` privileges to the production environment.

### Procedure

- Once you have saved the Ceph configuration file and distributed it to each Ceph node, restart the
Ceph Object Gateway instances:

> 📝 **Note:** Note:
Use the output from the
`ceph orch ps`
command, under the
`NAME`
column, to get the
*SERVICE_TYPE*
.
*ID*
information.

1. To restart the Ceph Object Gateway on an individual node in the storage cluster:

Syntax

```plaintext-ibm
systemctl restart ceph-CLUSTER_ID@SERVICE_TYPE.ID.service
```

Copy to clipboard

Example

```plaintext-ibm
[root@host01 ~]# systemctl restart ceph-c4b34c6f-8365-11ba-dc31-529020a7702d@rgw.realm.zone.host01.gwasto.service
```

Copy to clipboard
2. To restart the Ceph Object Gateways on all nodes in the storage cluster:

Syntax

```plaintext-ibm
ceph orch restart SERVICE_TYPE
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch restart rgw
```

Copy to clipboard
