## D3N Data Cache

Last Updated
: 2026-06-25

Datacenter-Data-Delivery Network (D3N) uses high-speed storage, such as
`NVMe`, to cache datasets on the access side. Such caching allows big data jobs to
use the compute and fast-storage resources available on each Ceph Object Gateway node at the edge.
The Ceph Object Gateways act as cache servers for the back-end object store (OSDs), storing data
locally for reuse.

> 📝 **Note:** Note:
Each time the Ceph Object Gateway is restarted the content of the cache directory is
purged.
