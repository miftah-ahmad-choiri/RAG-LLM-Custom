## Adjusting backfill and recovery settings

Last Updated
: 2026-06-25

Backfill and recovery operations can affect client I/O performance during cluster expansion or recovery. Adjust the backfill and recovery configuration values to help balance recovery operations and client workload performance.

> 📝 **Note:** Note:
When using the mClock scheduler, enable recovery setting overrides before modifying backfill and recovery value.

1. Enable recovery setting overrides:

```plaintext-ibm
ceph config set osd osd_mclock_override_recovery_settings true
```

Copy to clipboard
2. Set the recovery and backfill configuration values:

```plaintext-ibm
ceph config set osd osd_max_backfills VALUE
ceph config set osd osd_recovery_max_active VALUE
ceph config set osd osd_recovery_op_priority VALUE
```
