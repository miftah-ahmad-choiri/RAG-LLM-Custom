## Configuration

Last Updated
: 2026-06-25

As a storage administrator, learning the basics of configuring the Ceph Object Gateway is
important. You can learn about the defaults and the embedded web server called Beast.

For troubleshooting issues with the Ceph Object Gateway, you can adjust the logging and debugging
output generated by the Ceph Object Gateway. Also, you can provide a High-Availability proxy for
storage cluster access using the Ceph Object Gateway.
