## Obtaining information about sync operations

Last Updated
: 2026-06-25

The sync info command enables you to get information about the
expected sync sources and targets, as defined by the sync policy.

When you create a sync policy for a bucket, that policy defines how data moves from that bucket
toward a different bucket in a different zone. Creating the policy also creates a list of bucket
dependencies that are used as hints whenever that bucket syncs with another bucket. Note that a
bucket can refer to another bucket without actually syncing to it, since syncing depends on whether
the data flow allows the sync to take place.

Both the `--bucket` and `effective-zone-name` parameters are
optional. If you invoke the `sync info` command without specifying any options, the
Ceph Object Gateway returns all of the sync operations defined by the sync policy in all zones.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root or `sudo` access.
- The Ceph Object Gateway is installed.
- A group sync policy is defined.

### Procedure

- Get information about sync operations for buckets.

Syntax

```plaintext-ibm
radosgw-admin sync info --bucket=BUCKET_NAME --effective-zone-name=ZONE_NAME
```

Copy to clipboard
- Get information about sync operations at the zonegroup level.

Syntax

```plaintext-ibm
radosgw-admin sync info
```

Copy to clipboard
