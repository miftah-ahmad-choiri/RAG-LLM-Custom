## Listing zone groups

Last Updated
: 2026-06-25

Use the zonegroup list command to list zone groups within a Ceph
cluster.

To list the zone groups, run the following command:

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin zonegroup list
```

Copy to clipboard

The `radosgw-admin` returns a JSON formatted list of zone groups.

```plaintext-ibm
{
    "default_info": "90b28698-e7c3-462c-a42d-4aa780d24eda",
    "zonegroups": [
        "us"
    ]
}
```
