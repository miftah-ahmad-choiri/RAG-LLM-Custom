## Getting a sync policy group

Last Updated
: 2026-06-25

You can use the group get command to show the current sync policy
group by group ID, or to show a specific bucket policy.

If the `--bucket` option is not provided, the groups created at zonegroup level is
retrieved and not the groups at the bucket-level.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root or `sudo` access.
- The Ceph Object Gateway is installed.

### Procedure

- Show the current sync policy group or bucket policy. To show a specific bucket policy, use the
`--bucket` option:

Syntax

```plaintext-ibm
radosgw-admin sync group get --bucket=BUCKET_NAME --group-id=GROUP_ID
```

Example

```plaintext-ibm

```
