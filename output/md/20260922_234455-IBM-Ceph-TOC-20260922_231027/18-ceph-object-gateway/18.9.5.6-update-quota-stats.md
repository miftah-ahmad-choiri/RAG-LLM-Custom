## Update quota stats

Last Updated
: 2026-06-25

Quota stats get updated asynchronously. You can update quota statistics for all users and
all buckets manually to retrieve the latest quota stats.

Syntax

```plaintext-ibm
radosgw-admin user stats --uid=USER_ID --sync-stats
```
