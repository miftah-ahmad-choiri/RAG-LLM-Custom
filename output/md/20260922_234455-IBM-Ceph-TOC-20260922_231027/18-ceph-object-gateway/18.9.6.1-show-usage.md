## Show usage

Last Updated
: 2026-06-25

To show usage statistics, specify the `usage show`.

To show usage for a particular user, you must specify a user ID. You may also specify a start
date, end date, and whether or not to show log entries.

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin usage show
                --uid=johndoe --start-date=2022-06-01
                --end-date=2022-07-01
```

Copy to clipboard

You may also show a summary of usage information for all users by omitting a user ID.

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin usage show --show-log-entries=false
```
