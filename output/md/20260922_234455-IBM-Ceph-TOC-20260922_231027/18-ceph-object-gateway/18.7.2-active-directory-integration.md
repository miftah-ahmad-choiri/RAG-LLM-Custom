## Active Directory integration

Last Updated
: 2026-06-25

Configuring Active Directory (AD) for LDAPS is important  to enable secure LDAP
communication between the Ceph Object Gateway (RGW) and the LDAP server

To configure an Active Directory server to authenticate Ceph Object Gateway users, perform the
following steps:

1. Using Microsoft Active Directory
2. Configuring Active Directory for LDAPS
3. Adding a gateway user
4. Configuring the gateway to use Active Directory
5. Add an S3 user to the LDAP server
6. Export an LDAP token
7. Test the configuration with an S3 client
