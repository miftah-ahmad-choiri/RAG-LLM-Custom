## Deleting a realm

Last Updated
: 2026-06-25

Use this information to delete a Ceph Object Gateway realm.

### Procedure

1. Delete a realm, by using the
realm rm
command.

```plaintext-ibm
radosgw-admin realm rm --rgw-realm=REALM_NAME
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# radosgw-admin realm rm --rgw-realm=test_realm
```

> 📝 **Note:** Important:
If the deleted realm was configured as the default realm, continue to step
2
. If the deleted realm was not configured as default, no further steps are required.
2. Remove the default realm ID from the
`default_info`
in the realm list.
This step is required for realms that were configured as the default.

```plaintext-ibm
radosgw-admin realm default rm
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# radosgw-admin realm default rm
```

### What to do next

Verify that the realm and the realm ID are no longer listed.

```plaintext-ibm
radosgw-admin realm list
```

Copy to clipboard
