## Reading and writing global quotas

Last Updated
: 2026-06-25

You can read and write quota settings in a zonegroup map.

To get a zonegroup map:

```plaintext-ibm
[root@host01 ~]# radosgw-admin global quota get
```

Copy to clipboard

The global quota settings can be manipulated with the `global quota` counterparts
of the `quota set`, `quota enable`, and `quota disable`
commands, for example:

```plaintext-ibm
[root@host01 ~]# radosgw-admin global quota set --quota-scope bucket --max-objects 1024
[root@host01 ~]# radosgw-admin global quota enable --quota-scope bucket
```

Copy to clipboard

> 📝 **Note:** Note:
In a multi-site configuration, where there is a realm and period present, changes to the
global quotas must be committed using
`period update --commit`
. If there is no period
present, the Ceph Object Gateways must be restarted for the changes to take effect.
