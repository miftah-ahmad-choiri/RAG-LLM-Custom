## Delete an account

Last Updated
: 2026-06-25

Use the `radosgw-admin account rm` command to delete an IAM
user.

Removing a user removes the user from the
system..

```plaintext-ibm
radosgw-admin account rm --account-id={accountid}
```

Copy to clipboard

Example

```
radosgw-admin account rm --account-id=account123
```
