## Deleting a zone

Last Updated
: 2026-06-25

Learn how to delete a zone.

### Procedure

To delete a zone, start by removing it from the zonegroup.

1. Remove the zone from the zonegroup.
> 📝 **Note:** Important:
Do not delete a zone without removing it from a zone group first. Otherwise,
updating the period fails.

```plaintext-ibm
radosgw-admin zonegroup remove --rgw-zonegroup=ZONE_GROUP_NAME
                                 --rgw-zone=ZONE_NAME
```

Copy to clipboard
2. Update the period.
```plaintext-ibm
radosgw-admin period update --commit
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# radosgw-admin period update --commit
```
3. Delete the zone.
> 📝 **Note:** Important:
This procedure must be used on a host within the zone.

```plaintext-ibm
radosgw-admin zone delete --rgw-zone=ZONE_NAME
```

Copy to clipboard
4. Update the period.
```plaintext-ibm
radosgw-admin period update --commit
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# radosgw-admin period update --commit
```
5. Delete the pools.If the pools for the deleted zone will not be used anywhere
else, consider deleting the pools. Replace
DELETED_ZONE_NAME
in the following
example with the deleted zone’s name.

> 📝 **Note:** Important:

- Once Ceph deletes the zone pools, it deletes all of the data within them in an unrecoverable
manner. Only delete the zone pools if Ceph clients no longer need the pool contents.
- In a multi-realm cluster, deleting the `.rgw.root` pool along with the zone pools
removes ALL the realm information for the cluster. Ensure that `.rgw.root` does not
contain other active realms before deleting the `.rgw.root` pool.

```plaintext-ibm
ceph osd pool delete DELETED_ZONE_NAME.rgw.control DELETED_ZONE_NAME.rgw.control --yes-i-really-really-mean-it
ceph osd pool delete DELETED_ZONE_NAME.rgw.data.root DELETED_ZONE_NAME.rgw.data.root --yes-i-really-really-mean-it
ceph osd pool delete DELETED_ZONE_NAME.rgw.log DELETED_ZONE_NAME.rgw.log --yes-i-really-really-mean-it
ceph osd pool delete DELETED_ZONE_NAME.rgw.users.uid DELETED_ZONE_NAME.rgw.users.uid --yes-i-really-really-mean-it
```

Copy to clipboard

6. **Required:**Restart the Ceph Object Gateway process.
