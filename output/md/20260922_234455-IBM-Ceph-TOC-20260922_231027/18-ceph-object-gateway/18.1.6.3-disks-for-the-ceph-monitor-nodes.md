## Disks for the Ceph Monitor nodes

Last Updated
: 2026-06-25

Ceph Monitors use `rocksdb`, which is sensitive to synchronous write
latency. IBM strongly recommends using SSD disks to store the Ceph Monitor data. Choose SSD disks
that have sufficient sequential write and throughput characteristics.
