## Adding a zone to a zone group

Last Updated
: 2026-06-25

Use the zonegroup add command to add a zone to a zone
group.

This command must be run on a host that will be in the zone. To add a zone to a zonegroup, run
the following command:

Syntax

```plaintext-ibm
radosgw-admin zonegroup add --rgw-zonegroup=ZONE_GROUP_NAME --rgw-zone=ZONE_NAME
```

Copy to clipboard

Then, update the period:

Example

```plaintext-ibm
[ceph: root@host01 /]# radosgw-admin period update --commit
```

Copy to clipboard
