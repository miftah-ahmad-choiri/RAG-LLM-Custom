## Managing account statistics and quotas

Last Updated
: 2026-06-25

Retrieve detailed statistics for accounts, including storage usage and object counts. Configure storage quotas at the account level and bucket level to control resource usage.

Before you begin, make sure that you have administrative access to the Ceph Object Gateway (`radoswg`) cluster.

### Viewing account statistics

To retrieve current usage statistics for an account, run the following command:

```plaintext-ibm
radosgw-admin account stats --account-id=ACCOUNT_ID --sync-stats
```

Copy to clipboard

The command returns statistics in JSON format:

```
{
  "account": "account123",
  "data_size": 3145728000,
  "num_objects": 12000,
  "num_buckets": 5,
  "usage": {
    "total_size": 3145728000,
    "num_objects": 12000
  }
}
```

The response includes the following fields:

- `data_size` - Total storage size in bytes
- `num_objects` - Total number of objects stored
- `num_buckets` - Total number of buckets in the account

### Setting and enabling account quotas

Account quotas limit the total storage size or number of objects across all buckets in an account.

1. Set the quota limit.

```plaintext-ibm
radosgw-admin quota set --quota-scope=account --account-id=ACCOUNT_ID --max-size=SIZE
```

Copy to clipboard

Replace SIZE with a value like `10G`, `500M`, or `1T`.
2. Enable the quota.

```plaintext-ibm
radosgw-admin quota enable --quota-scope=account --account-id=ACCOUNT_ID
```

Copy to clipboard

### Setting and enabling bucket quotas

Bucket quotas limit the number of objects that can be stored in individual buckets within an account.

1. Set the bucket quota:

```plaintext-ibm
radosgw-admin quota set --quota-scope=bucket --account-id=ACCOUNT_ID --max-objects=NUMBER
```

Copy to clipboard
2. Enable the bucket quota:

```plaintext-ibm
radosgw-admin quota enable --quota-scope=bucket --account-id=ACCOUNT_ID
```

Copy to clipboard

### Modifying account resource limits

You can set limits on the maximum number of buckets, users, roles, and other resources within an account.

```plaintext-ibm
radosgw-admin quota set --quota-scope=account --account-id=ACCOUNT_ID --max-buckets=VALUE
```

Copy to clipboard

Available limit parameters:

- `--max-buckets`
- `--max-users`
- `--max-roles`
- `--max-groups`
- `--max-access-keys`

### Example: Setting a bucket limit

The following example sets the maximum number of buckets to 10000 for account `RGW12345678901234568`:


To verify the current quota configuration for an account:

```plaintext-ibm
radosgw-admin account get --account-id=ACCOUNT_ID
```
