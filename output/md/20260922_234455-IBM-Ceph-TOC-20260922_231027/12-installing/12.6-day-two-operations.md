## Day Two operations

Last Updated
: 2026-06-25

As a storage administrator after installing and configuring the IBM Storage Ceph, you can begin performing "Day Two" operations for your storage cluster. These tasks include adding metadata servers (MDS) and Ceph Object Gateways (RGW), and configuring other services to optimize and manage your cluster's performance and capabilities.

For more information about how to use the `cephadm` orchestrator to run "Day Two" operations, see Operations.

To deploy, configure, and administer the Ceph Object Gateway on "Day Two" operations, see Ceph Object Gateway.

Use the Ceph Dashboard to monitor clusters. For more information, see Monitor IBM Storage Ceph clusters.
