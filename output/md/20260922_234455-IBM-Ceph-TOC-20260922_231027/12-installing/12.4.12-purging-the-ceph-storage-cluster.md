## Purging the Ceph storage cluster

Last Updated
: 2026-06-25

Purging the Ceph storage cluster clears any data or connections that remain from previous deployments on your server.

### Before you begin

Before you begin, be sure that you have a running
IBM Storage Ceph
.

### About this task

For Red Hat Enterprise Linux 9, use the
cephadm rm-cluster
command, since Ansible is not supported.

### Procedure

1. Disable
`cephadm`
to stop all the orchestration operations to avoid deploying new daemons.

```plaintext-ibm
ceph mgr module disable cephadm
```

Copy to clipboard

For example,

```
[ceph: root#host01 /]# ceph mgr module disable cephadm
```
2. Get the FSID of the cluster.

```plaintext-ibm
ceph fsid
```

Copy to clipboard

For example,

```
[ceph: root#host01 /]# ceph fsid
```
3. Exit the
`cephadm`
shell.
For example,

```
[ceph: root@host01 /]# exit
```
4. Purge the Ceph daemons from all hosts in the cluster.

```plaintext-ibm
cephadm rm-cluster --force --zap-osds --fsid FSID
```

Copy to clipboard

For example,

```
[root@host01 ~]# cephadm rm-cluster --force --zap-osds  --fsid 2d2fd136-6df1-11ea-ae74-002590e526e8
```
