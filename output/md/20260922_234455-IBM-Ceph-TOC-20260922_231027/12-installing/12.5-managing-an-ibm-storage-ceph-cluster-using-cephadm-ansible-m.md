## Managing an IBM Storage Ceph cluster using cephadm-ansible modules

Last Updated
: 2026-06-25

Use the `cephadm-ansible` modules in Ansible playbooks to manage your IBM Storage Ceph cluster. The `cephadm-ansible` package includes several modules that wrap `cephadm` commands, allowing you to create custom Ansible playbooks to administer your cluster. These modules help ensure consistent configuration and automate tasks across your Ceph deployment.

> 📝 **Note:** Note:
`cephadm-ansible`
modules do not cover all tasks. Any operation that is not covered by
`cephadm-ansible`
modules must be completed by using either the
`command`
or
`shell`
Ansible modules in your playbooks.
