## Registering the IBM Storage Ceph nodes

Last Updated
: 2026-09-09

Register the IBM Storage Ceph nodes on Red Hat Enterprise Linux.

### Before you begin

Before registering the
IBM Storage Ceph
nodes, be sure that you have:

- At least one running virtual machine (VM) or bare-metal server with an active internet connection.
- Red Hat Enterprise Linux
9.8 or 10.2
with
`ansible-core`
2.16.18 bundled into AppStream.
- A valid IBM subscription with the appropriate entitlements.

> 📝 **Note:** Note:
If you purchased an
IBM Storage Ceph
Premium license, complete the Red Hat entitlement activation process before beginning deployment.

For more information, see Accessing Red Hat entitlements from IBM Storage Ceph.
- Root-level access to all nodes.

> 📝 **Note:** Note:
Red Hat now supports only Simple Content Access (SCA). As a result, customers no longer need to attach any subscription to a system. Registering the system and enabling the required repositories is now sufficient for registration use. For more information, see
[How to register and subscribe a RHEL system to the Red Hat Customer Portal using Red Hat Subscription-Manager?](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2Fsolutions%2F253273)
on the
[Red Hat Customer Portal](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2F)
.

For the latest supported Red Hat Enterprise Linux versions, see
Compatibility matrix
.

### Procedure

1. Register the system, and when prompted, enter your Red Hat customer portal credentials.

```plaintext-ibm
subscription-manager register
```

Copy to clipboard

For example,

```
[root@admin ~]# subscription-manager register

Registering to: subscription.rhsm.redhat.com:443/subscription
Username: USERNAME
Password: PASSWORD
The system has been registered with ID: ID
The registered system name is: SYSTEM_NAME
```
2. Pull the latest subscription.

```plaintext-ibm
subscription-manager refresh
```

Copy to clipboard

For example,

```
[root@admin ~]# subscription-manager refresh
All local data refreshed
```
3. Disable the software repositories.

```plaintext-ibm
subscription-manager repos --disable=*
```

Copy to clipboard

For example,

```
[root@admin ~]# subscription-manager repos --disable=*
```
4. Enable the Red Hat Enterprise Linux BaseOS and appstream repositories.

- Enabling repositories with Red Hat Enterprise Linux 9.x:

```plaintext-ibm
subscription-manager repos --enable=rhel-9-for-x86_64-baseos-rpms
```

Copy to clipboard

```plaintext-ibm
subscription-manager repos --enable=rhel-9-for-x86_64-appstream-rpms
```

Copy to clipboard
- Enabling repositories with Red Hat Enterprise Linux 10.x:

```plaintext-ibm
subscription-manager repos --enable=rhel-10-for-x86_64-baseos-rpms
```

Copy to clipboard

```plaintext-ibm
subscription-manager repos --enable=rhel-10-for-x86_64-appstream-rpms
```

Copy to clipboard

  - Enabling repositories with Red Hat Enterprise Linux 9.x:

  ```plaintext-ibm
  subscription-manager repos --enable=rhel-9-for-x86_64-baseos-rpms
  ```



  Copy to clipboard


  ```plaintext-ibm
  subscription-manager repos --enable=rhel-9-for-x86_64-appstream-rpms
  ```



  Copy to clipboard
  - Enabling repositories with Red Hat Enterprise Linux 10.x:

  ```plaintext-ibm
  subscription-manager repos --enable=rhel-10-for-x86_64-baseos-rpms
  ```



  Copy to clipboard


  ```plaintext-ibm
  subscription-manager repos --enable=rhel-10-for-x86_64-appstream-rpms
  ```



  Copy to clipboard
5. Update the system to receive the latest packages for Red Hat Enterprise Linux.

```plaintext-ibm
dnf update
```

Copy to clipboard

For example,

```plaintext-ibm
[root@admin ~]# dnf update
```

Copy to clipboard
6. Enable the
`ceph-tools`
repository.

- Enabling repositories with Red Hat Enterprise Linux 9.x:


```plaintext-ibm
curl https://public.dhe.ibm.com/ibmdl/export/pub/storage/ceph/ibm-storage-ceph-9-rhel-9.repo | sudo tee /etc/yum.repos.d/ibm-storage-ceph-9-rhel-9.repo
```

Copy to clipboard
- Enabling repositories with Red Hat Enterprise Linux 10.x:


```plaintext-ibm
curl https://public.dhe.ibm.com/ibmdl/export/pub/storage/ceph/ibm-storage-ceph-9-rhel-10.repo | sudo tee /etc/yum.repos.d/ibm-storage-ceph-9-rhel-10.repo
```

Copy to clipboard

  - Enabling repositories with Red Hat Enterprise Linux 9.x:


  ```plaintext-ibm
  curl https://public.dhe.ibm.com/ibmdl/export/pub/storage/ceph/ibm-storage-ceph-9-rhel-9.repo | sudo tee /etc/yum.repos.d/ibm-storage-ceph-9-rhel-9.repo
  ```



  Copy to clipboard
  - Enabling repositories with Red Hat Enterprise Linux 10.x:


  ```plaintext-ibm
  curl https://public.dhe.ibm.com/ibmdl/export/pub/storage/ceph/ibm-storage-ceph-9-rhel-10.repo | sudo tee /etc/yum.repos.d/ibm-storage-ceph-9-rhel-10.repo
  ```



  Copy to clipboard
7. Add the license to install
IBM Storage Ceph
and click
Accept
.

```plaintext-ibm
dnf install ibm-storage-ceph-license
```

Copy to clipboard
8. Accept the provisions.

```plaintext-ibm
touch /usr/share/ibm-storage-ceph-license/accept
```

Copy to clipboard

> 📝 **Note:** Important:
Starting from
IBM Storage Ceph
9.9.1
,
Call Home is enabled by default. When you accept the license, the Call Home feature is automatically enabled.

By using Call Home, you agree to allow IBM and its subsidiaries to store and use your contact information and certain system information anywhere you do business worldwide as described in the Program license agreement and documentation. For more information, refer to the Program license agreement and documentation.

For more information about Call Home and disabling after installation, see Call Home.
9. Repeat steps
1
through
8
on all the nodes of the storage cluster.
10. Install
`cephadm-ansible`
.

```plaintext-ibm
dnf install cephadm-ansible
```

Copy to clipboard
