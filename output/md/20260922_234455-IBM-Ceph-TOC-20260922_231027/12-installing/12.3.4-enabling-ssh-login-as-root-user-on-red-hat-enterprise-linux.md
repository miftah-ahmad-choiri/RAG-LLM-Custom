## Enabling SSH login as root user on Red Hat Enterprise Linux 9 and 10

Last Updated
: 2026-06-25

Enable the SSH login as root user on Red Hat Enterprise Linux 9and 10, as it is not automatically supported.

### Before you begin

Before you begin, make sure that you have root-level access to all nodes.

### About this task

Red Hat Enterprise Linux 9
and 10 do not
support SSH login as a root user even if
`PermitRootLogin`
parameter is set to
`yes`
in the
/etc/ssh/sshd_config file
. See the following error example for using SSH login with RHEL 9.

```
[root@host01 ~]# ssh root@myhostname
root@myhostname password:
Permission denied, please try again.
```

You can run one of the following methods to enable login as a root user:

- Use the Allow root SSH login with password flag while setting the root password during installation of Red Hat Enterprise Linux 9.
- Manually set the `PermitRootLogin` parameter after Red Hat Enterprise Linux 9 installation.

This section describes manual setting of the `PermitRootLogin` parameter.

For more information, see [Not able to login as root user via ssh in RHEL 9 server](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2Fsolutions%2F6695971) on the [Red Hat Customer Portal](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2F).

### Procedure

1. Open the
`etc/ssh/sshd_config`
file and set the
`PermitRootLogin`
to
`yes`
.
For example,

```
[root@admin ~]# echo 'PermitRootLogin yes' >> /etc/ssh/sshd_config.d/01-permitrootlogin.conf
```
2. Restart the
`SSH`
service.
For example,

```
[root@admin ~]# systemctl restart sshd.service
```
3. Login to the node as the
`root`
user.

```plaintext-ibm
ssh root@HOST_NAME
```

Copy to clipboard

Replace HOST_NAME with the host name of the Ceph node.

For example,

```
[root@admin ~]# ssh root@host01
```
4. When prompted, enter the
`root`
password.
