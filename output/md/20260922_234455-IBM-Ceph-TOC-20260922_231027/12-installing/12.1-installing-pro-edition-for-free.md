## Installing Pro Edition for free

Last Updated
: 2026-09-06

Install IBM Storage Ceph Pro Edition for a free 60-day trial.

### About this task

Install an IBM Storage Ceph trial version by following the steps provided. For the latest supported Red Hat Enterprise Linux versions, see
Compatibility matrix
.

### Procedure

1. Download and install Red Hat Enterprise Linux (RHEL).

1. If needed, create a Red Hat account.
Create an account on
[Create a Red Hat Login](https://www.ibm.com/links?url=https%3A%2F%2Fwww.redhat.com%2Fwapps%2Fugc%2Fregister.html%3F_flowId%3Dregister-flow%26amp%3B_flowExecutionKey%3De1s1)
on redhat.com.
2. Log in to your Red Hat account.
3. Get a free Red Hat Enterprise Linux subscription from Red Hat.
For more information, see
[Red Hat product trial center](https://www.ibm.com/links?url=https%3A%2F%2Fwww.redhat.com%2Fen%2Fproducts%2Ftrials%3Fproducts%3Drhel%23trial-details)

> 📝 **Note:** Note:
Confirm that your version meets the operating system requirements for
IBM Storage Ceph
9.9.1
or later. For more information, see
Operating system requirements
.
4. Install Red Hat Enterprise Linux on your storage nodes or hosts.
For information about installing Red Hat Enterprise Linux, see
Installing RHEL

[Red Hat Documentation](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2F)

IBM Storage Ceph

`cephadm`

Bootstrapping a new storage cluster
