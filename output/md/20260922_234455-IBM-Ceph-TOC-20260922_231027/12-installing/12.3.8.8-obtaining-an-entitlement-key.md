## Obtaining an entitlement key

Last Updated
: 2026-06-25

Entitlement keys determine whether IBM Storage Ceph can automatically pull the required container default images. During installation, image pull failures can occur due to an invalid entitlement key or a key that belongs to an account that does not have entitlement to IBM Storage Ceph.

### Procedure

1. Log in to the IBM container software library with the IBMid and password that is associated with the entitled
IBM Storage Ceph
software.
[IBM container software library](https://myibm.ibm.com/products-services/containerlibrary)
2. Click
Get entitlement key
.
3. On the
Entitlement keys
page, access your container software page, click
Copy key
to copy the generated entitlement key.

> 📝 **Note:** Important:
When connecting to the IBM
`cp.io`
registry, use the entitlement key with the IBM Container Registry’s default user,
`cp`
.
4. Save the key to a secure location for future use.
