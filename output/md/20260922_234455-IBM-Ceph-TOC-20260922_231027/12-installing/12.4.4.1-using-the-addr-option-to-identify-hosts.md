## Using the addr option to identify hosts

Last Updated
: 2026-06-25

The `addr` option offers an additional way to contact a host. Add the IP
address of the host to the `addr` option. If `ssh` cannot connect to
the host by its hostname, then it uses the value stored in `addr` to reach the host
by its IP address.

### Prerequisites

Before you begin, make sure that you have the following prerequisites in place:

- A storage cluster is installed and bootstrapped.
- Root-level access to all nodes in the storage cluster.

### Procedure

1. Log in to the `cephadm` shell:

Example

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard
2. Add the IP address:

Syntax

```plaintext-ibm
ceph orch host add HOSTNAME IP_ADDR
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# ceph orch host add host02 10.10.128.68
```

Copy to clipboard

> 📝 **Note:** Note:
If adding a host by hostname results in that host being added with an IPv6 address instead of
an IPv4 address, use the
ceph orch host
command to specify the IP address of
that host:

Syntax

```plaintext-ibm
ceph orch host set-addr HOSTNAME IP_ADDR
```

Copy to clipboard

To
convert the IP address from IPv6 format to IPv4 format for a host you have added, use the following
command:

```plaintext-ibm
ceph orch host set-addr HOSTNAME IPV4_ADDRESS
```

Copy to clipboard
