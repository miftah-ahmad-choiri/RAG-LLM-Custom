## New features and enhancements

Last Updated
: 2026-09-10

This section lists all the major updates, and enhancements introduced in this release of IBM Storage Ceph.

New support for CephX key type

Ceph now supports CephX aes256k keys. `cephadm` automatically rotates the keys of the service daemons with CephX aes256k key type.

For more information, see CephX key rotation.
