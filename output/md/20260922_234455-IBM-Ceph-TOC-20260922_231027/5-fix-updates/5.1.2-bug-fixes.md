## Bug fixes

Last Updated
: 2026-07-23

This section describes bugs with significant user impact, which were fixed in this release of IBM Storage Ceph. In addition, the section includes descriptions of fixed known issues found in previous versions.

Dashboard no longer displays a 500 error when retrieving upgrade image information

Previously, the Dashboard Upgrade API could fail to retrieve image information. As a result, users encountered a `500 - Internal Server Error` with the message, The server encountered an unexpected condition which prevented it from fulfilling the request, when logging in to the dashboard and accessing the Overview page.

With this fix, the Upgrade API retrieves upgrade image information correctly and no longer fails during dashboard operations. As a result, users can access the Overview page without encountering the 500 error.

(IBMCEPH-14087)
