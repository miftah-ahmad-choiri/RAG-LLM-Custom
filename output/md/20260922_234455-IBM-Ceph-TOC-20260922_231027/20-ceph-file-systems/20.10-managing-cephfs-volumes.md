## Managing CephFS volumes

Last Updated
: 2026-06-25

Use the
IBM Storage Ceph
CSI driver
(CSI) to manage Ceph File System (CephFS) exports. This also allows you to use other services, such as OpenStack’s file system service (Manila) by having a common command-line interface to interact with.

The `volumes` module for the Ceph Manager daemon (`ceph-mgr`) implements the ability to export Ceph File Systems (CephFS).

The Ceph Manager volumes module implements the following file system export abstractions:

- CephFS volumes
- CephFS subvolumes
- CephFS subvolume groups

For more information, see
Managing Ceph users
and
[IBM Storage Ceph CSI driver documentation](https://www.ibm.com/docs/ceph-csi-driver)
.
