## Removing the MDS service using the Ceph Orchestrator

Last Updated
: 2026-06-25

Remove the service either by using the ceph orch rm command or by
removing the file system and the associated pools.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Hosts added to the cluster.
- Root-level access to all the nodes.
- At least one MDS daemon deployed on the hosts.

### About this task

To remove the MDS service with the command-line interface, log in to the
`cephadm`
shell.

```plaintext-ibm
[root@host01 ~]# cephadm shell
```

Copy to clipboard

Use one of the following options to
remove MDS daemons.

### Removing the MDS service from the entire cluster through the command line

#### Procedure

Use the
ceph orch rm
command to remove the MDS service from the
entire cluster.

1. List the service.
```plaintext-ibm
ceph orch ls
```

Copy to clipboard
For example,

```
[ceph: root@host01 /]# ceph orch ls
```
2. Remove the service.
```plaintext-ibm
ceph orch rm SERVICE_NAME
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph orch rm mds.test
```

### Removing the CephFS volume, associated pools, and the services

#### Procedure

1. Set the configuration parameter
mon_allow_pool_delete
to
`true`
.
```plaintext-ibm
ceph config set mon mon_allow_pool_delete true
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph config set mon mon_allow_pool_delete true
```
2. Remove the file system, its data, and metadata pools.
```plaintext-ibm
ceph fs volume rm FILESYSTEM_NAME --yes-i-really-mean-it
```

Copy to clipboard

This command also tries to remove the MDS using the enabled `ceph-mgr`
Orchestrator module.

```plaintext-ibm
ceph fs volume rm cephfs-new --yes-i-really-mean-it
```

Copy to clipboard

For
example,

```
[ceph: root@host01 /]# ceph fs volume rm cephfs-new --yes-i-really-mean-it
```

### Verifying the MDS service removal

#### Procedure

List the hosts, daemons, and processes, by using the
ceph orch ps
command.
For
example,

```
[ceph: root@host01 /]# ceph orch ps
```
