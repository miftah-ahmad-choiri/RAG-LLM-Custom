## Manually evicting a CephFS client

Last Updated
: 2026-06-25

You might want to manually evict a Ceph File System (CephFS) client if the client is
misbehaving and you do not have access to the client node, or if a client dies and you do not want
to wait for the client session to time out.

### Before you begin

Before evicting a Ceph File System client, be sure that you have root-level access to the
Ceph Monitor node.

### Procedure

1. Review the client list.
```plaintext-ibm
ceph tell DAEMON_NAME client ls
```
