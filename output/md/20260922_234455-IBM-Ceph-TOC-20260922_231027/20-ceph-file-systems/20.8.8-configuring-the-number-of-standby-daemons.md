## Configuring the number of standby daemons

Last Updated
: 2026-06-25

Each Ceph File System (CephFS) can specify the required number of standby daemons to be
considered healthy. This number also includes the standby-replay daemon waiting for a rank
failure.

### Before you begin

Be sure that you have root-level access to a Ceph Monitor node.

### Procedure

Set the expected number of standby daemons for a particular CephFS.

```plaintext-ibm
ceph fs set FS_NAME standby_count_wanted NUMBER
```

Copy to clipboard

> 📝 **Note:** Note:
Setting the
NUMBER
to zero disables the daemon health check.

For example, to set the expected standby daemon count to
two:

```
[root@mon ~]# ceph fs set cephfs standby_count_wanted 2
```
