## CephFS subvolume groups

Last Updated
: 2026-06-25

You can create, list, fetch absolute path, and remove Ceph File System (CephFS) subvolume
groups. subvolume groups are abstractions at a directory level that effects policies. For example,
file layouts, across a set of subvolumes.

> 📝 **Note:** Note:
The subvolume group snapshot feature is not supported. You can only list and remove the
existing snapshots of these subvolume groups.

Before working with Ceph File System subvolume groups be sure that you have:

- A working IBM Storage Ceph cluster with  CephFS  deployed.
- A minimum read access on the Ceph Monitor.
- Read and write capability on the Ceph Manager nodes.
