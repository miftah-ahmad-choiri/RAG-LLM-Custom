## Disable snapshot visibility on a subvolume

Last Updated
: 2026-06-25

Disable snapshot visibility for a specific CephFS subvolume so that clients respecting visibility settings cannot view .snap or perform snapshot operations.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- CephFS cluster with snapshots enabled.
- Ceph CLI access and administrative privileges.
- If upgraded to Ceph 9.0, remount NFS mountpoints before toggling visibility.

### About this task

Disabling snapshot visibility hides the .snap directory for all clients that respect the visibility configuration. Clients that do not enforce the rule continue to see .snap.

### Procedure

1. Disable visibility for the subvolume.

```plaintext-ibm
ceph fs subvolume snap snapshot visibility set <fs_name> <subvolume_name> <subvolume_group> false
```

Copy to clipboard

For example,

```
ceph fs subvolume snap snapshot visibility set cephfs sv1 appgrp false
```
2. (Optional) use extended attributes to disable visibility.

```plaintext-ibm
setfattr -n ceph.subvolume.snaps.visible -v 0 /cephfs/path/to/subvolume
```

Copy to clipboard
3. Ensure visibility parameters are respected.

```plaintext-ibm
ceph config set client.<cephx_entity> client_respect_subvolume_snapshot_visibility true
```

Copy to clipboard

> 📝 **Note:** Note:
Clients that do not respect this flag will continue to see .snap.
4. (Optional) verify from a client.

```plaintext-ibm
ls /mnt/sv1/.snap
```

Copy to clipboard

After the subvolume is disabled, the following is the expected outcome.

```
EPERM
```

### Results

Snapshot visibility is disabled for the selected subvolume. Clients respecting visibility no longer see .snap and cannot perform snapshot operations.
