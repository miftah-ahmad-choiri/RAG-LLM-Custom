## Creating a CephFS volume

Last Updated
: 2026-06-25

Ceph Orchestrator is a module for Ceph Manager that creates a Metadata Server (MDS) for
the Ceph File System (CephFS). This section describes how to create a CephFS volume.

### About this task

Creating a  CephFS  volume creates the Ceph File system along with the data and metadata
pools.

### Procedure

Create a CephFS volume on the monitor node.

```plaintext-ibm
ceph fs volume create VOLUME_NAME
```

Copy to clipboard

For
example,

```
[ceph: root@host01 /]# ceph fs volume create cephfs
```
