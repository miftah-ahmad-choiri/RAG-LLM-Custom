## Removing a CephFS volume

Last Updated
: 2026-06-25

Ceph Orchestrator is a module for Ceph Manager that removes the Metadata Server (MDS) for
the Ceph File System (CephFS). Learn how to remove the Ceph File System (CephFS) volume.

### Before you begin

Be sure that you have a CephFS volume.

### Procedure

1. If the
`mon_allow_pool_delete`
option is not set to
`true`
,
then set it to
`true`
before removing the CephFS volume.
```plaintext-ibm
[ceph: root@host01 /]# ceph config set mon mon_allow_pool_delete true
```

Copy to clipboard
2. Remove the CephFS volume.
```plaintext-ibm
ceph fs volume rm VOLUME_NAME [--yes-i-really-mean-it]
```

Copy to clipboard
For
example:

```
[ceph: root@host01 /]# ceph fs volume rm cephfs --yes-i-really-mean-it
```
