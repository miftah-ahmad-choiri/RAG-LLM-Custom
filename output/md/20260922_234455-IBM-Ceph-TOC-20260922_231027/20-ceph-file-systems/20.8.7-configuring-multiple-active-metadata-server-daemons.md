## Configuring multiple active Metadata Server daemons

Last Updated
: 2026-06-25

Configure multiple active Metadata Server (MDS) daemons to scale metadata performance for
large systems.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Ceph administration capabilities on the MDS node.
- Root-level access to a Ceph Monitor node.

### About this task

> 📝 **Note:** Important:
Do not convert all standby MDS daemons to active ones. A Ceph File System
(CephFS) requires at least one standby MDS daemon to remain highly available.

### Procedure

1. Set the
`max_mds`
parameter to the desired number of active MDS
daemons.
```plaintext-ibm
ceph fs set NAME max_mds NUMBER
```

Copy to clipboard
For example, to increase the number of active MDS daemons to two in the CephFS
called
`cephfs`
:

```
[root@mon ~]# ceph fs set cephfs max_mds 2
```

> 📝 **Note:** Note:
Ceph only increases the actual number of ranks in the CephFS if a spare MDS daemon
is available to take the new rank.
2. Verify the number of active MDS daemons.
```plaintext-ibm
ceph fs status NAME
```

Copy to clipboard
For example:

```
[root@mon ~]# ceph fs status cephfs
```
