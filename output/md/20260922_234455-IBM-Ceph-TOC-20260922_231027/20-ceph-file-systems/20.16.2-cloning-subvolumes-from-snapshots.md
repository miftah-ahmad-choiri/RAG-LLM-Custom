## Cloning subvolumes from snapshots

Last Updated
: 2026-06-25

Subvolumes are created by cloning subvolume snapshots. It is an asynchronous operation
involving copying data from a snapshot to a subvolume.

### Before you begin

Be sure that you have a CephFS subvolume.

In addition to read (`r`) and
write (`w`) capabilities, clients also require `s` flag on a directory
path within the file system.

Verify that the
`s`
flag is set on the
directory.

```plaintext-ibm
ceph auth get CLIENT_NAME
```

Copy to clipboard

Output
example:

```plaintext-ibm
CLIENT_NAME
    key = AQAz7EVWygILFRAAdIcuJ12opU/JKyfFmxhuaw==
    caps mds = allow rw, allow rws path=DIRECTORY_PATH
    caps mon = allow r
    caps osd = allow rw tag cephfs01 data=DIRECTORY_NAME
```

Copy to clipboard

In the
following example,
`client.0`
can create or delete snapshots in the
`bar`
directory of file system
`cephfs_a`
.

```
[root@mon ~]# ceph auth get client.0
[client.0]
    key = AQAz7EVWygILFRAAdIcuJ12opU/JKyfFmxhuaw==
    caps mds = "allow rw, allow rws path=/bar"
    caps mon = "allow r"
    caps osd = "allow rw tag cephfs data=cephfs_a"
```

### About this task

For more information, see
Managing Ceph users
.

> 📝 **Note:** Note:
Cloning is inefficient for very large data sets.

### Procedure

1. Create a Ceph File System (CephFS) volume.This creates the CephFS file
system, its data, and metadata pools.

> 📝 **Note:** Note:
The
`--group_name`
parameter is optional.
If the subvolume needs to be created in a subvolume group, then
`--group_name`
needs
to be passed in the
command.

```plaintext-ibm
ceph fs volume create VOLUME_NAME
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs volume create cephfs01
```
2. Create a subvolume group.By default, the subvolume group is created with an
octal file mode '755', and data pool layout of its parent
directory.

```plaintext-ibm
ceph fs subvolumegroup create VOLUME_NAME GROUP_NAME [--pool_layout DATA_POOL_NAME --uid UID --gid GID --mode OCTAL_MODE]
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs subvolumegroup create cephfs01 subgroup0
```
3. Create a subvolume.By default, a subvolume is created within the default
subvolume group, and with an octal file mode ‘755’, uid of its subvolume group, gid of its subvolume
group, data pool layout of its parent directory, and no size
limit.

```plaintext-ibm
ceph fs subvolume create VOLUME_NAME SUBVOLUME_NAME [--size SIZE_IN_BYTES --group_name SUBVOLUME_GROUP_NAME --pool_layout DATA_POOL_NAME --uid UID --gid GID --mode OCTAL_MODE]
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs subvolume create cephfs01 sub0 subgroup0
```
4. Create a snapshot of a subvolume.
```plaintext-ibm
ceph fs subvolume snapshot create VOLUME_NAME SUBVOLUME_NAME SNAP_NAME [--group_name SUBVOLUME_GROUP_NAME]
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs subvolume snapshot create cephfs01 sub0 snap0  --group_name subgroup0
```
5. Initiate a clone operation.
> 📝 **Note:** Note:
By default, cloned subvolumes are created in the default group.

1. If the source subvolume and the target clone are in the default group, run the
following command.
```plaintext-ibm
ceph fs subvolume snapshot clone VOLUME_NAME SUBVOLUME_NAME SNAP_NAME TARGET_CLONE_NAME
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs subvolume snapshot clone cephfs01 sub0 snap0 clone0
```
2. If the source subvolume is in the non-default group, then specify the source subvolume
group in the following command.
```plaintext-ibm
ceph fs subvolume snapshot clone VOLUME_NAME SUBVOLUME_NAME SNAP_NAME TARGET_CLONE_NAME --group_name SUBVOLUME_GROUP_NAME
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs subvolume snapshot clone cephfs01 sub0 snap0 clone0 --group_name subgroup0
```
3. If the target clone is to a non-default group, then specify the target group in the
following command.
```plaintext-ibm
ceph fs subvolume snapshot clone VOLUME_NAME SUBVOLUME_NAME SNAP_NAME TARGET_CLONE_NAME --target_group_name SUBVOLUME_GROUP_NAME
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs subvolume snapshot clone cephfs01 sub0 snap0 clone0 --target_group_name subgroup1
```

6. Check the status of the clone operation.
```plaintext-ibm
ceph fs clone status VOLUME_NAME CLONE_NAME [--group_name TARGET_GROUP_NAME]
```

Copy to clipboard
For
example,

```
[root@mon ~]# ceph fs clone status cephfs01 clone0 --group_name subgroup1

{
  "status": {
    "state": "complete"
  }
}
```
