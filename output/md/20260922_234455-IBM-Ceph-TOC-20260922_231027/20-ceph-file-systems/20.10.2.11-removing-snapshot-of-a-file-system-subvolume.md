## Removing snapshot of a file system subvolume

Last Updated
: 2026-06-25

Learn how to remove snapshots of a Ceph File System (CephFS) subvolume group.

### Before you begin

Be sure that you have a CephFS subvolume and a snapshot of the subvolume group.

### About this task

Using the
`--force`
flag allows the command to succeed that would otherwise
fail if the snapshot did not exist.

### Procedure

Remove the snapshot of the CephFS subvolume.

> 📝 **Note:** Note:
The
`--group_name`
parameter is optional. If the subvolume is present within a
subvolume group, then
`--group_name`
needs to be passed in the command.

```plaintext-ibm
ceph fs subvolume snapshot rm VOLUME_NAME SUBVOLUME_NAME SNAP_NAME [--group_name GROUP_NAME --force]
```

Copy to clipboard

For
example:

```
[root@mon ~]# ceph fs subvolume snapshot rm cephfs01 sub0 snap0 --group_name subgroup0 --force

[]
```
