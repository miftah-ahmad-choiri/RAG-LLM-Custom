## Earmarking a file system subvolume

Last Updated
: 2026-06-25

Learn how to earmark a Ceph files system (CephFS) subvolume.

You can also assign an `earmark` to a subvolume by using the `--earmark` option. The earmark is a unique identifier that tags the subvolume for specific purposes, such as NFS or SMB services. By default, no earmark is set, allowing for flexible assignment based on administrative needs. Use an empty string (“”) to remove any existing earmark from a subvolume.

The earmarking mechanism helps ensure that subvolumes are correctly tagged and managed. It helps to avoid conflicts and ensure that each subvolume is associated with the intended service or use case.

Following are the valid earmarks for NFS and SMB:
NFS valid earmarks
The valid earmark format is the top-level scope:
`nfs`
.
SMB
The following are valid SMB earmark formats:

- The top-level scope: `smb`.

Example without intra-module scope: `smb`
- The top-level scope with an intra-module level scope: `smb.cluster.{cluster_id}`, where `cluster_id` is a short string uniquely identifying the cluster.

Example with intra-module scope: `smb.cluster.cluster_1`

### Setting earmark of file system subvolume

Set the earmark of a subvolume.

```plaintext-ibm
ceph fs subvolume earmark set VOLUME_NAME SUBVOLUME_NAME [--group_name SUBVOLUME_GROUP_NAME] --earmark EARMARK
```

Copy to clipboard

Based on your requirement, set EARMARK to either `smb` or `nfs`.

For example,

```
ceph fs subvolume earmark set cephfs01 sub0 --group_name subgroup0 --earmark nfs
```

### Getting earmark of a file system subvolume

Get the earmark of a subvolume.

```plaintext-ibm
ceph fs subvolume earmark get VOLUME_NAME SUBVOLUME_NAME [--group_name SUBVOLUME_GROUP_NAME]
```

Copy to clipboard

For example,

```
ceph fs subvolume earmark get cephfs01 sub0 --group_name subgroup0

nfs
```

### Removing earmark of file system subvolume

Remove the earmark of a subvolume.

```plaintext-ibm
ceph fs subvolume earmark rm VOLUME_NAME SUBVOLUME_NAME [--group_name SUBVOLUME_GROUP_NAME]
```

Copy to clipboard

For example,

```
ceph fs subvolume earmark rm cephfs01 sub0 --group_name subgroup0
```
