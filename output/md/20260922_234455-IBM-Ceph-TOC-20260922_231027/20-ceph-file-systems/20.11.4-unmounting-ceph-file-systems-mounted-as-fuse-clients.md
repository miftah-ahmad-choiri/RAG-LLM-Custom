## Unmounting Ceph File Systems mounted as FUSE clients

Last Updated
: 2026-06-25

Learn how to unmount a Ceph File System that is mounted as a File System in User Space
(FUSE) client.

### Before you begin

Before beginning this task, be sure that you have root-level access to the FUSE client
node.

### About this task

For more information, see the
`ceph-fuse(8)`
manual page.

### Procedure

Unmount a Ceph File System mounted in FUSE.

```plaintext-ibm
fusermount -u MOUNT_POINT
```

Copy to clipboard

For
example,

```
[root@client ~]# fusermount -u /mnt/cephfs
```
