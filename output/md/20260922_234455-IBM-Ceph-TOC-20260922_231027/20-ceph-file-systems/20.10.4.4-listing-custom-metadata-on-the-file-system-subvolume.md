## Listing custom metadata on the file system subvolume

Last Updated
: 2026-06-25

Learn how to list the custom metadata associated with the key of a Ceph File System
(CephFS) in a volume, and optionally, in a specific subvolume group.

List the metadata on the CephFS
subvolume.

```plaintext-ibm
ceph fs subvolume metadata ls VOLUME_NAME SUBVOLUME_NAME [--group_name SUBVOLUME_GROUP_NAME]
```

Copy to clipboard

For
example:

```
[ceph: root@host01 /]# ceph fs subvolume metadata ls cephfs01 sub0
{
    "test_meta": "cluster"
}
```
