## Creating and collecting operation logs for Ceph Object Gateway

Last Updated
: 2026-06-25

Track user identities reliably by S3 request in all versions of the Ceph Object Gateway
operation log.

### About this task

User identity information is added to the operation log output. This is used to enable customers
to access this information for auditing of S3 access.

### Procedure

1. Find where the logs are located.
```plaintext-ibm
logrotate -f
```

Copy to clipboard
For example,

```
[root@host01 ~]# logrotate -f
 /etc/logrotate.d/ceph-12ab345c-1a2b-11ed-b736-fa163e4f6220
```
2. List the logs within the specified location.
```plaintext-ibm
ll LOG_LOCATION
```

Copy to clipboard
For
example,

```
[root@host01 ~]# ll /var/log/ceph/12ab345c-1a2b-11ed-b736-fa163e4f6220
 -rw-r--r--. 1 ceph ceph    412 Sep 28 09:26 opslog.log.1.gz
```
3. Create a bucket.
```plaintext-ibm
/usr/local/bin/s3cmd mb s3://NEW_BUCKET_NAME
```

Copy to clipboard
For example,

```
[root@host01 ~]# /usr/local/bin/s3cmd mb s3://bucket1
 Bucket `s3://bucket1` created
```
4. Collect the logs.
```plaintext-ibm
tail -f LOG_LOCATION/opslog.log
```

Copy to clipboard
