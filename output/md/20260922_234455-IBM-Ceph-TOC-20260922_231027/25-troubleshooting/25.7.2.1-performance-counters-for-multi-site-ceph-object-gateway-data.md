## Performance counters for multi-site Ceph Object Gateway data sync

Last Updated
: 2026-06-25

Use performance counters to measure data sync for multi-site configurations of the Ceph
Object Gateway.

### About this task

The following performance counters are available for multi-site configurations of the Ceph Object
Gateway to measure data sync:

- `poll_latency` measures the latency of requests for remote replication logs.
- `fetch_bytes` measures the number of objects and bytes fetched by data sync.

For more information about performance encounters, see Ceph performance counters.

### Procedure

Use the
ceph --admin-daemon
command to view the current metric data
for the performance counters.

> 📝 **Note:** Note:
Run the
ceph --admin-daemon
command from the node running the
daemon.

```plaintext-ibm
ceph --admin-daemon /var/run/ceph/cluster-id/ceph-client.rgw.RGW_ID.asok perf dump data-sync-from-ZONE_NAME
```
