## Diagnosing health

Last Updated
: 2026-06-25

Learn how to run a basic diagnostic of the health of an IBM Storage Ceph cluster.

### Before you begin

- A running IBM Storage Ceph cluster.

### Procedure

1. Log in to the
`cephadm`
shell.
```plaintext-ibm
cephadm shell
```

Copy to clipboard
2. Check the overall status of the storage cluster.For
example,

```
[ceph: root@host01 /]# ceph health detail
```
If the command
returns a
HEALTH_WARN
or
HEALTH_ERR
message, see
Understanding Ceph health
.
3. Monitor the logs of the storage cluster.For
example,

```
[ceph: root@host01 /]# ceph -w cephadm
```
4. Run the following commands to capture the logs of the cluster to a
file.
```plaintext-ibm
ceph config set global log_to_file true
```

Copy to clipboard

```plaintext-ibm
ceph config set global mon_cluster_log_to_file true
```

Copy to clipboard

By
default, the logs are located in the
/var/log/ceph/
directory.
5. Check the Ceph logs for any error messages that are listed in
Understanding Ceph logs
.
6. If the logs do not include enough information, increase the debugging level and try to
reproduce the action that failed.For more information, see
Configuring logging at runtime
.
