## Configuring logging at runtime

Last Updated
: 2026-06-25

Configure the logging of Ceph subsystems at system runtime to help troubleshoot any
issues that might occur.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- Access to Ceph debugger.

### About this task

For more information, see:

- Ceph subsystems
- Configuring logging in configuration file
- Debugging and logging configuration options

### Procedure

Activate the Ceph debugging output
`dout()`
, at
runtime.

```plaintext-ibm
ceph tell TYPE.ID injectargs --debug-SUBSYSTEM VALUE [--NAME VALUE]
```

Copy to clipboard

Replace
as follows:

- TYPE with the type of Ceph daemons (`osd`,
`mon`, or `mds`).
- ID with a specific ID of the Ceph daemon. Alternatively, use
`*` to apply the runtime setting to all daemons of a particular type.
- SUBSYSTEM with a specific subsystem.
- VALUE with a number from `1` to `20`, where
`1` is terse and `20` is verbose.

The following example shows setting the log level for the OSD subsystem on the
OSD name
`osd.0`
to 0 and the memory level to
5.

```
# ceph tell osd.0 injectargs --debug-osd 0/5
```

### Seeing the configuration settings at runtime

#### Procedure

1. Log in to the host with a running Ceph daemon.For example,
`ceph-osd`
or
`ceph-mon`
.
2. Display the configuration.
```plaintext-ibm
ceph daemon NAME config show | less
```

Copy to clipboard
For
example,

```
[ceph: root@host01 /]# ceph daemon osd.0 config show | less
```
