## Manually configuring TLS settings for NFS

Last Updated
: 2026-06-25

Diagnose and resolve issues that occur when enabling or using TLS or mutual TLS (mTLS) for NFS.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- The NFS configuration file (`ganesha.conf`) is accessible for editing.
- You have administrative privileges to restart NFS services.

### About this task

TLS settings in NFS define how encrypted communication is established between clients and the server. These parameters allow administrators to enable TLS, specify certificates, choose cipher suites, and configure advanced options such as Kernel TLS (KTLS) and debugging. This topic explains each configuration option and provides examples for OpenSSL backends.

> 📝 **Note:** Note:
The certificates required by the nfs service should be created by the user.

TLS configuration parameters and their default values are listed in Table 1.

| Parameter | Default | Description |
| --- | --- | --- |
| Enable_TLS | false | Enable or disable TLS support. |
| TLS_CA_File | "" | Path to CA certificate file. |
| TLS_Cert_File | "" | Path to server certificate file. |
| TLS_Key_File | "" | Path to private key file. |
| TLS_Ciphers | NULL | Specify cipher suites for TLS. |
| TLS_Min_Version | TLSv1.3 | Minimum TLS protocol version. |
| Enable_KTLS | false | Enable Kernel TLS (OpenSSL only). |
| Enable_debug | false | Enable detailed TLS debugging logs. |

### Procedure

1. Enable TLS support in the
`TLS_CONFIG{}`
block.

```plaintext-ibm
Enable_TLS = true
```

Copy to clipboard
2. Specify certificate file paths.

```plaintext-ibm
TLS_CA_File = "/etc/ganesha/tls/ca.crt"
TLS_Cert_File = "/etc/ganesha/tls/ganesha.crt"
TLS_Key_File = "/etc/ganesha/tls/ganesha.key"
```

Copy to clipboard
3. Configure the cipher suites, for OpenSSL.

```plaintext-ibm
TLS_Ciphers = "TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384"
```

Copy to clipboard
4. Set the minimum TLS version.

```
TLS_Min_Version = "TLSv1.3"
```
5. Enable Kernel TLS (KTLS) for OpenSSL.

```plaintext-ibm
Enable_KTLS = true
```

Copy to clipboard
6. Enable debugging for detailed TLS logs.

```plaintext-ibm
Enable_debug = true
```

Copy to clipboard
