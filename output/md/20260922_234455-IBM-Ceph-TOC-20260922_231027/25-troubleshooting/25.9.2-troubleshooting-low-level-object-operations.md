## Troubleshooting low-level object operations

Last Updated
: 2026-09-06

Use the `ceph-objectstore-tool` utility to run low-level object operations.

> 📝 **Note:** Important:
Manipulating objects can cause unrecoverable data loss. Before using the
`ceph-objectstore-tool`
utility, contact
[IBM Support](https://www.ibm.com/mysupport/)
.

Before using the
`ceph-objectstore-tool`
utility, verify that you have root-level access to the Ceph OSD nodes.
