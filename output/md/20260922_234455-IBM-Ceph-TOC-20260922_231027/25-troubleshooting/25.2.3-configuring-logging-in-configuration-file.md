## Configuring logging in configuration file

Last Updated
: 2026-06-25

Configure Ceph subsystems to log information, warning, and error messages to the log
file.

### About this task

You can specify the debugging level in the Ceph configuration file, which is found by default in
/etc/ceph/ceph.conf.

For more information, see:

- Ceph subsystems
- Configuring logging at runtime
- Debugging and logging configuration options

### Procedure

To activate the Ceph debugging output
`dout()`
at boot time, add the
debugging settings to the Ceph configuration file.

1. For subsystems common to each daemon, add the settings under the
`[global]`
section.
2. For subsystems for particular daemons, add the settings under a daemon section, such as
`[mon]`
,
`[osd]`
, or
`[mds]`
.For
example,

```
[global]
            debug_ms = 1/5

    [mon]
            debug_mon = 20
            debug_paxos = 1/5
            debug_auth = 2

    [osd]
            debug_osd = 1/5
            debug_monc = 5/20

    [mds]
            debug_mds = 1
```
