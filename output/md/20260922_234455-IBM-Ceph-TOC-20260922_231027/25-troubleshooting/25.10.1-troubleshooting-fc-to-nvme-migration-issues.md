## Resolving FC to NVMe migration issues

Last Updated
: 2025-11-12

Understand different FC to NVMe migration issues that may occur and how to resolve them.

### About this task

Use this information to specifically troubleshoot FC to NVMe step issues.

### Finding a host NQN

A host NVMe Qualified Name (NQN) is a unique identifier. The NQN identifies a host system by using FC-NVMe connections, allowing the storage system to recognize and interact with the host.

#### Before you begin

Before you begin, verify that
`nvme-cli`
is installed and running.

#### Procedure

Fetch the NQN from the
/etc/nvme/hostnqn
file.

```plaintext-ibm
cat /etc/nvme/hostnqn
```

Copy to clipboard

For example,

```
[root@host] cat /etc/nvme/hostnqn
nqn.2014-08.org.nvmexpress:uuid:9ed5b327-b9fc-4cf5-97b3-1b5d986345d1
```

### Troubleshooting migration abort command issues

If watchers were not removed before running the migration abort command, the process fails

#### About this task

Aborting the migration deletes the target Ceph Block Device image. As a result, the abort process fails if the target device is still mounted on the host, as watchers are still present on the Ceph Block Device (RBD) image.

If the target device is still mounted on the host, use the following steps and then retry stopping the migration process, removing the watchers from the Ceph Block Device image.

#### Procedure

1. Unmount the target device.
2. Get the namespace ID (NSID).

```plaintext-ibm
ceph nvmeof namespace list --nqn=NQN
```

Copy to clipboard
3. Delete the namespace.

```plaintext-ibm
nvmeof-cli --server-address GATEWAY_IP --server-port 5500 namespace del --subsystem SUBSYSTEM_NQN --nsid NSID
```

Copy to clipboard

For more information, see
[Deleting a namespace](https://www.ibm.com/docs/en/storage-ceph/8.1.0?topic=target-managing-namespaces)
within
Ceph NVMe-oF gateway
>
Configuring the NVMe-oF gateway target
>
Managing namespaces
.
For example,

```
[root@host01 ~]# nvmeof-cli --server-address 10.172.19.01 --server-port 5500 namespace del --subsystem nqn.2016-06.io.spdk:cnode1.group1 --nsid 1
Deleting namespace 1 from nqn.2016-06.io.spdk:cnode1: Successful
```

#### What to do next

Retry stopping the migration. For more information, see Manually migrating FC to NVMe.
