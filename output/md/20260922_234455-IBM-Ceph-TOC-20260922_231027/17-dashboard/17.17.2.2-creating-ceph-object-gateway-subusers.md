## Creating Ceph Object Gateway subusers

Last Updated
: 2026-06-25

A subuser is associated with a user of the S3 interface. You can create a subuser for a
specific Ceph Object Gateway user on the IBM Storage Ceph
dashboard.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Dashboard is installed.
- The Ceph Object Gateway is installed.
- Ceph Object Gateway login credentials are added to the dashboard.
- Ceph Object Gateway user is created.

### Procedure

1. From the dashboard navigation, go to
Object
>
Users.
2. On the Users tab, select a user and click Edit.
3. In the Edit User form, from the  Subusers section,
click Create Subuser.
4. In the Create Subuser dialog, enter the Subuser and
select the appropriate permissions.
5. Select
Auto-generate secret
and click
Create
Subuser
.

> 📝 **Note:** Note:
Selecting
Auto-generate-secret
automatically
generates the Ceph Object Gateway secret key.

Figure 1.
Create Subuser form
6. In the Edit User form, save your changes by clicking Edit
user.

A notification displays that the Object Gateway user was updated successfully.
