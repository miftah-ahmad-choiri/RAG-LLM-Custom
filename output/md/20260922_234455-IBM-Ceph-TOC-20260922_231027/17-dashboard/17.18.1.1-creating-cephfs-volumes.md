## Creating CephFS volumes

Last Updated
: 2026-06-25

You can create Ceph File System (CephFS) volumes on the IBM Storage Ceph Dashboard.

### Before you begin

Before you begin, make sure that you have a working
IBM Storage Ceph
cluster with MDS deployed.

### Procedure

1. From the dashboard navigation, go to
File
>
File Systems
.
2. Click
Create
.
3. In the
Create Volume
window, set the following parameters:

1. **Name**: Set the name of the volume.
2. **Placement (Optional)**: Select the placement of the volume. You can set it as either *Hosts* or *Label*.
3. **Hosts/Label (Optional)**: If placement is selected as *Hosts* in the previous option, then select the appropriate host from the list. If placement is selected as *Label* in the previous option, then enter the label.

> 📝 **Note:** Important:
To identify the label that has been created for the hosts while using it as a placement, you can run the following command from the CLI:

```
[ceph: root@ceph-hk-ds-uoayxl-node1-installer /]# ceph orch host ls

HOST ADDR LABELS STATUS

host01 10.0.210.182 _admin,installer,mon,mgr
host02 10.0.96.72 mon,mgr
host03 10.0.99.37 mon,mds
host04 10.0.99.244 osd,mds
host05 10.0.98.118 osd,mds
host06 10.0.98.66 osd,nfs,mds
host07 10.0.98.23 nfs,mds
7 hosts in cluster
```

  1. **Name**: Set the name of the volume.
  2. **Placement (Optional)**: Select the placement of the volume. You can set it as either *Hosts* or *Label*.
  3. **Hosts/Label (Optional)**: If placement is selected as *Hosts* in the previous option, then select the appropriate host from the list. If placement is selected as *Label* in the previous option, then enter the label.
4. Click
Create Volume
.
A notification displays that the volume was created successfully.
