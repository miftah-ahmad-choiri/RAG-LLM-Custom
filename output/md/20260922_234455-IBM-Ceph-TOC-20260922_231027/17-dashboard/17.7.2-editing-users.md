## Editing users

Last Updated
: 2026-06-25

You can edit the users on the IBM Storage Ceph
dashboard. You can modify the user’s password and roles based on the requirements.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Dashboard is installed.
- Admin-level of access to the Dashboard.
- User created on the dashboard.

### Procedure

1. Log in to the Dashboard.
2. Click the Dashboard Settings icon and then click User
management.
3. To edit the user, from the Users tab, select the user row and click
Edit.
4. In the Edit User form, edit parameters like password and roles, and then
click Edit User.

> 📝 **Note:** Note:
If you want to disable any user’s access to the Ceph dashboard, you can clear the
Enabled
option.

A notification displays that the user was created successfully.
