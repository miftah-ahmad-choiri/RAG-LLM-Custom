## Toggling Ceph dashboard features

Last Updated
: 2026-06-25

You can customize the IBM Storage Ceph dashboard components by enabling or disabling features on demand. All features are enabled by default.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Installation and configuration of the IBM Storage Ceph Dashboard software.
- User access to the Ceph Manager host or the dashboard web interface.
- Root level access to the Ceph Manager host.

### About this task

When disabling a feature, the web-interface elements become hidden and the associated REST API end-points reject any further requests for that feature. Enabling and disabling dashboard features can be done from the command-line interface or the web interface.
Available features:

- Ceph Block Devices:

- Image management, `rbd`
- Mirroring, `mirroring`

  - Image management, `rbd`
  - Mirroring, `mirroring`
- Ceph File System, `cephfs`
- Ceph Object Gateway, `rgw`
- NFS service gateway, `nfs`

> 📝 **Note:** Note:

- By default, the Ceph Manager is collocated with the Ceph Monitor.
- You can disable multiple features at once.

> 📝 **Note:** Important:
Once a feature is disabled, it can take up to 20 seconds to reflect the change in the web interface.

### Toggling the dashboard features from the web interface

#### Procedure

1. From the dashboard navigation, go to

>
Administration
>
Manager Modules
.
2. Click
Edit
.
3. In the
Edit Manager module
form, you can enable or disable the dashboard features by selecting or clearing the check boxes next to the different feature names.
Figure 1.
Editing manager modules
4. After the selections are made, click
Update
.

#### Toggling the dashboard features from the command-line interface

##### Procedure

1. Login to
`cephadm`
shell.

```plaintext-ibm
cephadm shell
```

Copy to clipboard
2. List the feature status.

```plaintext-ibm
ceph dashboard feature status
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph dashboard feature status
```
3. Disable a feature.

```plaintext-ibm
ceph dashboard feature disable FEATURE
```

Copy to clipboard

The following example disables the Ceph Object Gateway feature.

```
[ceph: root@host01 /]# ceph dashboard feature disable rgw
```
4. Enable a feature.

```plaintext-ibm
ceph dashboard feature enable FEATURE
```

Copy to clipboard

The following example enables the Ceph File System feature.

```
[ceph: root@host01 /]# ceph dashboard feature enable cephfs
```
