## Changing the dashboard password

Last Updated
: 2026-06-25

By default, the password for accessing dashboard is randomly generated by the system
while bootstrapping the cluster. You have to change the password the first time you log in to the
IBM Storage Ceph dashboard. You can change the password for the
`admin` user using the dashboard.

### Prerequisites

- A running IBM Storage Ceph cluster.

### Procedure

1. Log in to the dashboard:

```plaintext-ibm
https://HOST_NAME:8443
```

Copy to clipboard
2. Click the *Dashboard Settings* icon and then click *User management*.
3. To change the password of **admin**, click it’s row.
4. From the *Edit* drop-down menu, select *Edit*.
5. In the *Edit User* window, enter the new password, and change the other parameters, and then
Click *Edit User*.

You will be logged out and redirected to the log-in screen. A notification appears confirming the
password change.
