## Managing input/output operations rate-limiting for NFS cluster

Last Updated
: 2026-06-25

Learn to set, edit, and disable the input/output operations (IOPS) rate-limiting by using
the Ceph dashboard.

### About this task

Rate-limiting is also known as quality of service (QoS). Defining IOPS limits helps
ensure a balanced workload distribution across the cluster.

> 📝 **Note:** Note:
The IOPS rate limiting for NFS clusters ranges from a minimum of 10 IOPS to a maximum of
409600 IOPS.

For more information, see Rate-limiting in NFS.

Edit input/output operations (IOPS) rate-limiting information, changing the existing
rate-limiting values, as required.

#### Before you begin

- You must have QoS already set for the selected NFS cluster. For more information, see Setting input/output operations rate-limiting.

#### Procedure

1. From the Dashboard navigation, go to
