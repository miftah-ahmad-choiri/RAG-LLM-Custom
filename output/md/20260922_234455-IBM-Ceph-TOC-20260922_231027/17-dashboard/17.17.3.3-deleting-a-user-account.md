## Deleting a user account

Last Updated
: 2026-06-25

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Ensure that the user does not own any buckets.
- You must have administrator permission to delete user accounts.

> 📝 **Note:** Note:
An Account cannot be deleted until all user linked the accounts are deleted.

### Procedure

1. Go to
Object > User management > Accounts
.
2. In the accounts list, open the
⋮ (three-dot)
menu for the account that you want to remove.
3. Select
Delete
and confirm the action.

### Results

The user account is deleted from the system. All associated credentials are deleted, and the user no longer appears in the Users list.
