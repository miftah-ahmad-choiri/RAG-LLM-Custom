## Copying snapshots of images

Last Updated
: 2026-06-25

Copy the snapshots of images on the IBM Storage Ceph
Dashboard.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Dashboard is installed.
- A pool with the `rbd` application enabled is created.
- An image is created.
- A snapshot of the image is created.

### Procedure

1. From the dashboard navigation, go to
Block
>
Images.
2. To protect the snapshot of the image, from the Images tab, select the row
and then go to the Snapshots tab.
3. Click Copy from the action drop-down.
4. In the Copy RBD form, enter the parameters and click Copy
RBD.

A notification displays that the snapshot was copied successfully. You can search for the copied
image in the *Images* tab.

### Reference

For more information, see the following:

- Creating pools.
- Creating images.
