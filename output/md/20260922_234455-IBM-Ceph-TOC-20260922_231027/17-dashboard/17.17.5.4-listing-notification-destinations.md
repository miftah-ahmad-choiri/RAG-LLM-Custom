## Listing notification destinations

Last Updated
: 2026-06-25

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- The Dashboard service is running.
- You are signed in with a user ID that has permission to view notification destinations.

### Procedure

1. In the Dashboard navigation pane, select
Object Gateway > Bucket notifications
and select the
Destinations
tab
2. Review the list of configured notification destinations.
3. Optional. Use the search box or filters to refine the list.

### Results

All available notification destinations are displayed..
