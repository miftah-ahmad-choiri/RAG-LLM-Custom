## Managing block device images

Last Updated
: 2026-06-25

As a storage administrator, you can create, edit, copy, purge, and delete images using
the IBM Storage Ceph dashboard. In addition, you can also create,
clone, copy, rollback, and delete snapshots of the images using the Ceph dashboard.

> 📝 **Note:** Note:
The Block Device images table is paginated for use with 10000+ image storage clusters to
reduce Block Device information retrieval costs.
