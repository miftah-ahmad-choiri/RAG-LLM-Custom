## Removing CephFS subvolume

Last Updated
: 2026-06-25

You can remove Ceph File System (CephFS) subvolume on the IBM Storage Ceph dashboard.

### Before you begin

- A working IBM Storage Ceph cluster with Ceph File System
deployed.
- A subvolume created.

### Procedure

1. From the dashboard navigation, go to
File
>
File
Systems
.
2. From the listed volumes, select the row.
3. Navigate to
Subvolume
tab, select the subvolume you want to
remove, and click
Remove
.
4. In the
Remove Subvolume
window, confirm whether you want to remove
the selected subvolume and click
Remove Subvolume
.A
notification that the subvolume was removed successfully is displayed.
