## Setting admin user password for Grafana

Last Updated
: 2026-06-25

By default, `cephadm` does not create an admin user for Grafana. With the Ceph Orchestrator, you can create an admin user and set the password. With these credentials, you can log in to the storage cluster’s Grafana URL with the given password for the admin user.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster with the monitoring stack installed.
- Root-level access to the `cephadm` host.
- The `dashboard` module enabled.

### Procedure

1. As a root user, create a
`grafana.yml`
file.
Provide the following details:

```plaintext-ibm
service_type: grafana
spec:
  initial_admin_password: PASSWORD
```

Copy to clipboard
2. Mount the
`grafana.yml`
file under a directory in the container.
For example,

```
[root@host01 ~]# cephadm shell --mount grafana.yml:/var/lib/ceph/grafana.yml
```

> 📝 **Note:** Note:
Every time you exit the shell, you have to mount the file in the container before deploying the daemon.
3. **Optional:**
Verify and enable that the
`dashboard`
Ceph Manager module is enabled.

1. Check that the
`dashboard`
module is enabled.

```plaintext-ibm
ceph mgr module ls
```

Copy to clipboard
2. Enable the
`dashboard`
module.

```plaintext-ibm
ceph mgr enable dashboard
```

Copy to clipboard

  1. Check that the
  `dashboard`
  module is enabled.

  ```plaintext-ibm
  ceph mgr module ls
  ```



  Copy to clipboard
  2. Enable the
  `dashboard`
  module.

  ```plaintext-ibm
  ceph mgr enable dashboard
  ```



  Copy to clipboard
4. Apply the specification file.

```plaintext-ibm
ceph orch apply -i FILE_NAME.yml
```

Copy to clipboard

For example,

```
[ceph: root@host01 /]# ceph orch apply -i /var/lib/ceph/grafana.yml
```
5. Redeploy the
`grafana`
service.
This creates an admin user called
`admin`
with the given password and the user can log in to the Grafana URL with these credentials.

```plaintext-ibm
ceph orch redeploy grafana
```

Copy to clipboard

### What to do next

Log into Grafana with the proper credentials.

```plaintext-ibm
https://HOST_NAME:PORT
```

Copy to clipboard

For example,

```
https://host01:3000/
```
