## Editing a user account

Last Updated
: 2026-06-25

Update a user account’s attributes, permissions, or access settings.

### Before you begin

Before you begin, make sure that you have administrator permission to edit user accounts.

> 📝 **Note:** Note:
Account-linked users cannot be removed at the account level. To modify their attributes or policies, use the
User
page.

### Procedure

1. Go to
Object
>
User management
>
Accounts
.
2. In the accounts list, open the
⋮
(three-dot) menu for the account that you want to modify.
3. Select
Edit
and update the required identity details, limits, or managed policies.
4. Save the changes.

### Results

The user account is updated with the new configuration. The changes take effect immediately and appear in the User Details panel.
