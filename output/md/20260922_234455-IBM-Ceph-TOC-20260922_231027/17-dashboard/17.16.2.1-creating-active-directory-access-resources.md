## Creating Active Directory access resources

Last Updated
: 2026-06-25

Learn to create Active Directory resources by using the Ceph dashboard if you want to
create an SMB cluster with the authentication mode as Active
Directory.

### About this task

SMB services for IBM Storage Ceph can integrate with an
existing Active Directory (AD) domain server. When the administrator creates an SMB cluster, they
can decide whether to use Active Directory. If the cluster is configured to use AD, then Active
Directory handles all user information and authentication for the cluster.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
