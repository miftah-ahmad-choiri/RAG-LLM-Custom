## Managing NVMe-oF subsystems

Last Updated
: 2026-07-23

Create, view, and delete NVMe-oF subsystems with the Ceph Dashboard.

### About this task

To manage NVMe-oF subsystems, from the dashboard navigation, go to Block
>
NVMe/TCP.

The Subsystems tab displays the subsystems associated with the selected gateway group.

Subsystems group NVMe namespaces and manage host access.

### Viewing subsystems

View NVMe-oF subsystems from the Ceph Dashboard.

#### Procedure

View subsystems from the
Subsystems
tab.
The
Subsystems
table displays the subsystem NQN, gateway group, initiators, namespaces, and authentication configuration for each subsystem.

### Creating subsystems

Create NVMe-oF subsystems with the Ceph Dashboard.

#### About this task

Subsystems group NVMe namespaces and manage host access. Create a subsystem to start mapping NVMe volumes to hosts.

#### Procedure

1. On the
Subsystems
tab, click
Create
.
2. In the
Subsystem details
step, enter the subsystem NQN, select the gateway group, select one or more listeners, and click
Next
.
3. In the
Host access control
step, select either
Allow all hosts
or
Restrict to specific hosts
.

> 📝 **Note:** Important:
Allowing all hosts grants access to every initiator on the network. Authentication is not supported in this mode and might expose the subsystem to unauthorized access.

1. If you selected
Restrict to specific hosts
add one or more host NQNs and click
Next
.

  Next

4. In the
Authentication
step, select either
Unidirectional
or
Bidirectional

Bidirectional authentication requires authentication keys for both the subsystem and the host.

### Viewing subsystem details

View subsystem configuration and associated resources.

#### About this task

Subsystem details provide information about the subsystem configuration, associated initiators, namespaces, listeners, and performance metrics.

From the Subsystems tab, click the subsystem NQN. The subsystem details page opens and provides access to the Overview, Initiators, Namespaces, Listeners, and Performance pages.

#### Procedure

- From the
Overview
page, view subsystem configuration details, including the serial number, subsystem type, model number, gateway group, controller identifiers, namespace limits, host access configuration, and HA status.
- From the
Initiators
page, view the initiators that are associated with the subsystem, including the host NQN and configured authentication settings.
- From the
Namespaces
page, view the namespaces that are associated with the subsystem, including the namespace ID, pool, image, image size, block size, and IOPS configuration.
- From the
Listeners
page, view the listeners that are associated with the subsystem, including the transport, address, and listener name.
- From the
Performance
page, view performance information for the subsystem.

### Managing listeners

Add and remove listeners for an NVMe-oF subsystem.

#### About this task

Listeners define the network endpoints that hosts use to connect to a subsystem.

From the Subsystems tab, click the subsystem NQN. The subsystem details page opens.

#### Procedure

- To view listeners, click
Listeners
in the subsystem details sidebar.
The
Listeners
page displays the configured listeners for the subsystem.
- To add a listener, click
Add
.
- To remove a listener, select
Delete
from the listener action menu.

### Deleting subsystems

Delete NVMe-oF subsystems that are no longer required.

#### About this task

Subsystems can be deleted at any time from the Subsystems tab.

> 📝 **Note:** Important:
Deleting a subsystem might remove resources that are still attached to the subsystem.

#### Procedure

1. From the action menu for the subsystem, select
Delete
.
2. In the
Delete Subsystem
dialog, copy and paste the subsystem name.
3. Select
I understand this may remove resources still attached to this subsystem
.
4. Click
Delete Subsystem
.
The dashboard emits the
Deleted subsystem
NQN
message and removes the subsystem from the
Subsystems
table.
