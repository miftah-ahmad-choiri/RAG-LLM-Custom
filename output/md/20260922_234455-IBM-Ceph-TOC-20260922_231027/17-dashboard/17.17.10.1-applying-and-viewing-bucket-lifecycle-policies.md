## Applying and viewing bucket lifecycle policies

Last Updated
: 2026-06-25

Use
the dashboard to apply and manage a Ceph Object Gateway bucket lifecycle policy on
the IBM Storage Ceph dashboard.

### Procedure

1. From the dashboard, go to
Object
>
Buckets
.
2. Select the bucket for which the lifecycle policy needs to be applied and click
Edit

> 📝 **Note:** Note:
Bucket lifecycle policy cannot be applied during the creation of the bucket. They can be
applied only after a bucket is created.
3. In the
Edit Bucket
form, go to
Policies
and
apply the lifecycle rule in the
Lifecycle
field in JSON format.
4. To save the bucket lifecycle policy, click
Edit Bucket
.Figure 1.
Apply bucket LC rule
5. After the bucket lifecycle policy is applied, it can viewed in the bucket listing screen
by expanding the relevant bucket entry.Figure 2.
View bucket LC rule
