## Viewing Performance Metrics for Multi-Site Sync Deltas in Ceph Object Gateway

Last Updated
: 2026-06-25

You can view the replication performance of each shard between zones in the Grafana
dashboard.

### Before you begin

- A running IBM Storage Ceph cluster.
- ceph-exporter, Grafana, and Prometheus are installed.
- Ceph Object Gateway is installed.
- Object gateway login credentials are added to the dashboard.
- Object gateway users and buckets are created and not suspended.

### Procedure

1. Log in to the Grafana URL.
```plaintext-ibm
https://<ip-where-grafana-deployed>:3000
```

Copy to clipboard

Example

```
https://<ip-where-grafana-deployed>:3000
```
2. Go to the
Dashboard
tab and search for
RGW Sync
Overview
.
3. To view the performance metrics of the multi-site sync deltas, see the
Replication(Time) Delta per shard
panelFigure 1.
Replication (Time) Delta per
shard

The panel displays the time taken for each shard in the cluster to replicate.
