## Managing NVMe-oF initiators

Last Updated
: 2026-07-23

View and add NVMe-oF initiators with the Ceph Dashboard.

### About this task

To manage NVMe-oF initiators, open a subsystem from the Subsystems tab and click Initiators.

Initiators define the hosts that are allowed to access a subsystem.

### Viewing initiators

View initiators that are associated with a subsystem.

#### Procedure

View initiators from the
Initiators
page.
The
Initiators
table displays the host NQN and configured authentication information for each initiator.

### Adding initiators

Add initiators to a subsystem.

#### About this task

Add initiators to control which hosts can access a subsystem.

#### Procedure

1. From the
Initiators
page, click
Add
.
2. In the
Host access control
step, specify the host NQN and click
Next
.
3. Configure authentication settings.

If authentication is enabled, configure the required DHCHAP authentication keys and click Next.
4. Click
Add initiator
.
The initiator is added to the
Initiators
table.
