## Editing NFS shares

Last Updated
: 2026-06-25

You can edit the NFS service daemons on the IBM Storage Ceph dashboard.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
- A minimum `ganesha-manager` level of access on the Ceph dashboard.
- NFS service daemon configured on the dashboard.

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### Procedure

1. Go to the NFS page.

- To edit an Object Gateway NFS share, go to Object
>
NFS.
- To edit a CephFS NFS share, go to File
>
NFS.

  - To edit an Object Gateway NFS share, go to Object
  >
  NFS.
  - To edit a CephFS NFS share, go to File
  >
  NFS.
2. Click
Edit
from the NFS shares row menu.
3. In the
Edit NFS export
form, edit the required parameters, and click
Edit NFS export
.
A notification displays that NFS service has been updated successfully.
