## Deleting buckets of a multi-site Ceph Object Gateway configuration

Last Updated
: 2026-06-25

You can delete buckets of secondary sites in primary sites on the IBM Storage Ceph
Dashboard in a multi-site Ceph Object Gateway configuration.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Minimum of one running IBM Storage Ceph cluster deployed on
both sites.
- Dashboard is installed.
- The multi-site Ceph Object Gateway is configured on the primary and secondary sites.
- Ceph Object Gateway login credentials of the primary and secondary sites are added to the
dashboard.
- Ceph Object Gateway users are created on the primary site.
- Ceph Object Gateway buckets are created on the primary site.
- Minimum of `rgw-manager` level of access on the Ceph dashboard.

### About this task

> 📝 **Note:** Important:
Do not delete buckets of primary site from secondary sites.

### Procedure

1. From the dashboard navigation of the primary site, go to
Object
>
Buckets
.
2. Select the bucket of the secondary site to be deleted, and click
Delete
from the action drop-down.
3. In the
Delete Bucket
notification, select
Yes, I am
sure
and click
Delete bucket
.The bucket is deleted
from the
Buckets
table.
