## Managing users

Last Updated
: 2026-06-25

As a storage administrator, you can create, edit, and delete users with specific roles on
the IBM Storage Ceph Dashboard. Role-based access control is given
to each user based on their roles and requirements.

You can also create, edit, import, export, and delete Ceph client authentication keys on the
dashboard. Once you create the authentication keys, you can rotate keys using command-line interface
(CLI). Key rotation meets the current industry and security compliance requirements.
