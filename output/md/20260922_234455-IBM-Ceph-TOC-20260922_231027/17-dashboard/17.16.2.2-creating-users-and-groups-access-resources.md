## Creating users and groups access resources

Last Updated
: 2026-06-25

Learn to create users and groups access resources by using the Ceph dashboard if you want
to create an SMB cluster by using authentication mode as
standalone.

### About this task

User and group access resources are required to create an SMB cluster in a standalone
environment. A standalone cluster is ideal for environments that require simple, direct-access
control by using local user accounts. It ensures secure and controlled access to shared resources by
defining user permissions and group policies.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster.
