## Deleting Ceph Object Gateway users

Last Updated
: 2026-06-25

Delete Ceph Object Gateway users on the IBM Storage Ceph, after the credentials are set-up using the CLI.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Dashboard is installed.
- The Ceph Object Gateway is installed.
- Ceph Object Gateway login credentials are added to the dashboard.
- A Ceph Object Gateway user is created.

### Procedure

1. From the dashboard navigation, go to
Object
>
Users.
2. Select the Username to delete, and click Delete
from the action drop-down.
3. In the Delete user notification, select Yes, I am
sure and click Delete User.
The user is removed from the
Users table.
