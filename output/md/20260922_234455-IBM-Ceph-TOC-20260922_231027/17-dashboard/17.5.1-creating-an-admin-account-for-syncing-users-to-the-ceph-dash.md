## Creating an admin account for syncing users to the Ceph dashboard

Last Updated
: 2026-06-25

Create an admin account to synchronize users to the Ceph dashboard.

### Before you begin

- A running IBM Storage Ceph cluster.
- Dashboard is installed.
- Admin-level access to the dashboard.
- Users are added to the dashboard.
- Root-level access on all the hosts.
- Java OpenJDK installed. For more information, see the [Installing a JRE on RHEL by using yum](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2Fred_hat_build_of_openjdk%2F8%2Fhtml%2Finstalling_and_using_red_hat_build_of_openjdk_8_for_rhel%2Fassembly_installing-openjdk-8-on-red-hat-enterprise-linux_openjdk%23installing-jre-on-rhel-using-yum) section of the
Installing and using OpenJDK 8 for RHEL guide for OpenJDK on [Red Hat Documentation](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2F).
- Red Hat Single Sign-On installed from a ZIP file. For more information, see the [Installing RH-SSO from a ZIP File](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2Fred_hat_single_sign-on%2F7.4%2Fhtml-single%2Fserver_installation_and_configuration_guide%2Findex%23installing_rh_sso_from_a_zip_file) section of the Server
Installation and Configuration Guide for Red Hat Single Sign-On on [Red Hat Documentation](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2F).

### About this task

After creating the account, use Red Hat Single Sign-on (SSO) to synchronize users to the Ceph
dashboard. See Syncing users to the Ceph dashboard using Red Hat Single Sign-On.

For more information, see the following:

- Creating roles.
- Creating users.

### Procedure

1. Download the
Red Hat Single Sign-On 7.4.0 Server
on the system where
IBM Storage Ceph
is installed.For download package and information, see
[Software Details](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2Fjbossnetwork%2Frestricted%2FsoftwareDetail.html%3FsoftwareId%3D80791%26product%3Dcore.service.rhsso%26version%3D7.4%26downloadType%3Ddistributions)
for
Red Hat Single Sign-On 7.4.0
Server
on the
[Red Hat Customer Portal](https://www.ibm.com/links?url=https%3A%2F%2Faccess.redhat.com%2F)
.
2. Extract the folder.
```plaintext-ibm
unzip rhsso-7.4.0.zip
```

Copy to clipboard
For example,

```
[root@host01 ~]# unzip rhsso-7.4.0.zip
```
3. Go to the
standalone/configuration
directory and open the
standalone.xml
file for editing.For
example,

```
[root@host01 ~]# cd standalone/configuration
[root@host01 configuration]# vi standalone.xml
```
4. From the
bin
directory of the newly created
rhsso-7.4.0
folder, run the
`add-user-keycloak`
script to add
the initial administrator user.
```plaintext-ibm
./add-user-keycloak.sh -u admin
```

Copy to clipboard
For
example,

```
[root@host01 bin]# add-user-keycloak.sh -u admin
```
5. Replace the
localhost
and
127.0.0.1
with the
IP address of the server where the Red Hat SSO is installed.
6. Start the server.From the
`bin`
directory of
`rh-sso-7.4`
folder, run the
`standalone`
boot
script.

```plaintext-ibm
./standalone.sh
```

Copy to clipboard
For
example,

```
[root@host01 bin]# ./standalone.sh
```
7. Create the admin account in
`https: IP_ADDRESS
:8080/auth`
with a username and password.
> 📝 **Note:** Note:
You must create an admin account only the first time that you log into the console.
8. Log in to the admin console with the credentials created.
