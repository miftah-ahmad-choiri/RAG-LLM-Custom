## Managing the NVMe-oF service

Last Updated
: 2026-07-23

Create, configure, and delete an NVMe service and gateways with the Ceph Dashboard. The
NVMe-oF service includes managing NVMe-oF gateways and gateway groups, and
configuring mutual TLS (mTLS) authentication.

### Before you begin

If you are
enabling mTLS authentication
, ensure that you have the
following for each NVMe-oF gateway Ceph node.

- Server certificate and key files.
> 📝 **Note:** Important:
When creating the server certificates,
use the
subjectAltName
parameter to specify the IP addresses of all gateways in
the group. For
example,

```
openssl req -x509 -newkey rsa:4096 -nodes -keyout server.key -out server.crt -days 3650 -subj /CN=my.server -addext "subjectAltName=IP:10.243.64.15,IP:10.243.64.17,IP:10.243.64.13,IP:10.243.64.4"
```

For
more information about creating server certificates, see Creating and managing TLS keys
and certificates within [Securing networks](https://www.ibm.com/links?url=https%3A%2F%2Fdocs.redhat.com%2Fen%2Fdocumentation%2Fred_hat_enterprise_linux%2F9%2Fhtml%2Fsecuring_networks%2Findex) in the Red Hat Enterprise Linux
documentation.
- Client certificate and key files.
- A running IBM Storage Ceph cluster.
- Ceph NVMe-oF gateway installed. For more information about deploying the NVMe-oF service through
the dashboard, see Managing the NVMe-oF service.

### About this task

NVMe-oF service actions are done from the Services page of the Ceph
dashboard. From Services, you can create or delete the NVMe-oF service and
modify the service at any time. Modifying includes changing pools, and changing hosts.

Creating an NVMe-oF service through the Ceph Dashboard creates gateway groups with the hosts as
the gateways. With this setup, you can seamlessly manage your gateways and gateway groups from
within the NVMe-oF service.

### Creating an NVMe-oF service and gateway group

Create services through the Ceph Dashboard. Creating the NVMe-oF
service through the dashboard creates NVMe-oF gateway groups. Use this procedure to create the
`nvmeof` service.

#### About this task

> 📝 **Note:** Note:
If the service is not created, the
Block
>
NVMe/TCP
page shows a
notification that the service must be configured. Click
Configure NVMe/TCP
to
go directly to the
Create Service
form.

#### Before you begin

To create a service, you must have the following configured:

- An RBD application-enabled pool.
- A host with Ceph Block Devices.

#### Procedure

1. From the dashboard navigation, go to
Administration
>
Services
and
click
Create
.
2. In the
Create Service
form, from the
Type
drop-down list, select
nvmeof
.The
Block Pool
and
Service Name
automatically
display the default
`rbd`
.

> 📝 **Note:** Note:
If the default
`rbd`
pool not present,
the first block device application-based pool in the cluster is selected.
3. **Optional:**Select
Encryption
to enable mTLS encryption
and complete the necessary encryption key fields.
> 📝 **Note:** Note:
mTLS encryption can be disabled at any time, by editing the NVMe-oF service. For more
information, see
Editing the NVMe-oF service
.
4. Complete or modify any other needed fields, and click
Create
Service
.The dashboard emits the
Created Service
'nvmeof'
message.

### Editing the NVMe-oF service

Modify the NVMe-oF service at any time.

#### Procedure

1. Edit the service by selecting the
`nvmeof`
service row from the
Services
table and clicking
Edit
.
2. In the
Edit Service
form, change the needed service
information.Use the
Edit Service
form to
scale-up
and
scale-down NVMe-oF gateways
and
change
mTLS encryption
settings.

To disable mTLS encyrption, clear the
Encryption box.
3. Click
Edit Service
.The dashboard emits the
Updated Service 'nvmeof'
message.

### Deleting the NVMe-oF service

Remove the NVMe-oF service if no longer using the NVMe-oF gateway or before running a
fresh installation.

#### Procedure

1. Delete the service by selecting the
`nvmeof`
service row from the
Services
table and selecting
Delete
from the action
drop-down.
2. In the
Delete Service
dialog, select
Yes, I am
sure
and click
Delete Service
.The dashboard
emits the
Deleted Service 'nvmeof'
message and the
`nvmeof`
row is removed from the
Services
table.
