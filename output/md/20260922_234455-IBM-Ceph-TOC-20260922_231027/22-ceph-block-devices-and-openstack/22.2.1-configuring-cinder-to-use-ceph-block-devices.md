## Configuring Cinder to use Ceph Block Devices

Last Updated
: 2026-06-25

Configure OpenStack Cinder to use Ceph Block Devices as the backend for volume storage.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

1. Prerequisites defined in Installing and configuring Ceph for OpenStack.
2. Root access to the Cinder node.
3. A Ceph pool is created for storing Cinder volumes.
4. The Ceph user and UUID secret required for Cinder are configured.

### About this task

Cinder uses a backend driver to provision and manage block storage volumes. When configured to use Ceph, Cinder stores volumes as Ceph Block Devices (RBDs) in a designated Ceph pool.

### Procedure

1. Edit the Cinder configuration file.

For example, to open the configuration file on the Cinder node:

```plaintext-ibm
vi /etc/cinder/cinder.conf
```

Copy to clipboard
2. In the
`[DEFAULT]`
section, enable Ceph as the backend.

Add or update the following configuration options, as required.

```plaintext-ibm
enabled_backends = ceph
glance_api_version = 2
```

Copy to clipboard
3. Create a
`[ceph]`
section and configure the Ceph volume driver.

```plaintext-ibm
[ceph]
volume_driver = cinder.volume.drivers.rbd.RBDDriver
rbd_cluster_name = ceph
rbd_pool = volumes
rbd_user = cinder
rbd_ceph_conf = /etc/ceph/ceph.conf
rbd_secret_uuid = UUID
rbd_flatten_volume_from_snapshot = false
rbd_max_clone_depth = 5
rbd_store_chunk_size = 4
rados_connect_timeout = -1
```

Copy to clipboard

Replace UUID with the UUID of the libvirt secret configured for the Cinder service.
4. Save the file and exit the editor.

### Results

Cinder is configured to use Ceph Block Devices as its volume backend. Volumes can now be created and managed by using Ceph storage.

### What to do next

Restart the OpenStack service to complete the configuration. For more information, see
Restarting the OpenStack services
.
