## Displaying command help

Last Updated
: 2026-06-25

Display command, and sub-command online help from the command-line interface.

> 📝 **Note:** Note:
The
`-h`
option still displays help for all available commands.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the client node.

### Procedure

1. Use the `rbd help` command to display help for a particular `rbd`
command and its subcommand:

Syntax

```plaintext-ibm
rbd help COMMAND SUBCOMMAND
```

Copy to clipboard
2. To display help for the `snap list` command:

```plaintext-ibm
[root@rbd-client ~]# rbd help snap list
```

Copy to clipboard
