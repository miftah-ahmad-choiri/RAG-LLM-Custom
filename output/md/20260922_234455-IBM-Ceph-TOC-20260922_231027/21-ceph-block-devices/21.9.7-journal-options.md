## Journal options

Last Updated
: 2026-06-25

Understand the journal options for Ceph Block Devices.

Table 1
lists the journal
configuration options for Ceph Block Devices.

| Option | Description | Type | Default |
| --- | --- | --- | --- |
| rbd_journal_order | The number of bits to shift to compute the journal object maximum size. The value is between 12 and 64. | 32-bit unsigned integer | 24 |
| rbd_journal_splay_width | The number of active journal objects. | 32-bit unsigned integer | 4 |
| rbd_journal_commit_age | The commit time interval in seconds. | Double Precision Floating Point Number | 5 |
| rbd_journal_object_flush_interval | The maximum number of pending commits per a journal object. | Integer | 0 |
| rbd_journal_object_flush_bytes | The maximum number of pending bytes per a journal object. | Integer | 0 |
| rbd_journal_object_flush_age | The maximum time interval in seconds for pending commits. | Double Precision Floating Point Number | 0 |
| rbd_journal_pool | Specifies a pool for journal objects. | String | "" |
