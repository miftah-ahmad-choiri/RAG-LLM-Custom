## Managing mirroring on images

Last Updated
: 2026-06-25

Learn to enable and disable mirroring on Ceph Block Device images by using the
command-line interface. You can also get the mirroring status for an image. Also, learn to promote,
demote, and resynchronize an image.

### Before you begin

Before you begin, make sure that you have root-level access to the node.

### Enabling mirroring on an image

#### About this task

Enable mirroring on an image by using the command in the procedure.

#### Procedure

Enable mirroring for a specific image within the pool, by using the
mirror image
enable
command.
Syntax

```plaintext-ibm
rbd mirror image enable POOL_NAME/IMAGE_NAME
```

Copy to clipboard

The
following example enables mirroring for the
`image2`
image in the
`data`
pool.

```
[root@rbd-client ~]# rbd mirror image enable data/image2
```

### Disabling mirroring on an image

#### About this task

Disable mirroring on an image by using the command in the procedure.

#### Procedure

Disable mirroring for a specific image, by using the
mirror image
disable
command.
Syntax

```plaintext-ibm
rbd mirror image disable POOL_NAME/IMAGE_NAME
```

Copy to clipboard

The
following example disables mirroring of the
`image2`
image in the
`data`
pool.

```
[root@rbd-client ~]# rbd mirror image disable data/image2
```

### Getting mirroring status for an image

#### About this task

Get the mirroring status for an image by using the command in the procedure.

#### Procedure

Get the mirror status for an image, by running the
mirror image status
command.
Syntax

```plaintext-ibm
rbd mirror image status POOL_NAME/IMAGE_NAME
```

Copy to clipboard

The
following example gets the status of the
`image2`
image in the
`data`
pool.

```
[root@site-a ~]# rbd mirror image status data/image2
image2:
  global_id:   1e3422a2-433e-4316-9e43-1827f8dbe0ef
  state:       up+unknown
  description: remote image is non-primary
  service:     pluto008.yuoosv on pluto008
  last_update: 2025-05-01 09:37:58
```

### Promoting an image

#### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A running IBM Storage Ceph cluster with snapshot-based
mirroring is configured.
- Root-level access to the node.

#### About this task

Promote an image by using the command in the procedure.

> 📝 **Note:** Warning:
Do not force promote non-primary images that are still syncing as the images
are not valid after the promotion.

#### Procedure

- Promote an image to primary, by using the
mirror image promote
command.Syntax

```plaintext-ibm
rbd mirror image promote POOL_NAME/IMAGE_NAME
```

Copy to clipboard
The
following example promotes
`image2`
in the
`data`
pool.

```
[root@rbd-client ~]# rbd mirror image promote data/image2
```
- Use forced promotion when the demotion cannot be propagated to the peer Ceph storage
cluster because of cluster failure or communication
outage.Syntax

```plaintext-ibm
rbd mirror image promote --force POOL_NAME/IMAGE_NAME
```

Copy to clipboard

```
[root@rbd-client ~]# rbd mirror image promote --force data/image2
```

### Demoting an image

#### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

#### About this task

Demote an image by using the command in the procedure.

> 📝 **Note:** Warning:
Do not force promote non-primary images that are still syncing as the images
are not valid after the promotion.

#### Procedure

Demote an image to non-primary, by using the
mirror image demote
command.
Syntax

```plaintext-ibm

```

Copy to clipboard

The
following example demotes the
`image2`
image in the
`data`
pool.

```
[root@rbd-client ~]# rbd mirror image demote data/image2
```

### Resynchronizing an image

#### About this task

You can resynchronize an image if an inconsistency occurs between the two peer clusters. When an
image enters an inconsistent state, the `rbd-mirror` daemon skips mirroring for that
image until the issue is resolved.

#### Procedure

Resynchronize to the primary image, by using the
mirror image resync
command.
Syntax

```plaintext-ibm
rbd mirror image resync POOL_NAME/IMAGE_NAME
```

Copy to clipboard

The
following example requests resynchronization of
`image2`
in the
`data`
pool.

```
[root@rbd-client ~]# rbd mirror image resync data/image2
```
