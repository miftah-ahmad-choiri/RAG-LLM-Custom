## Moving images to trash

Last Updated
: 2026-06-25

RADOS Block Device (RBD) images can be moved to the trash using the rbd
trash command.

The rbd trash command provides more options than the rbd rm
command.

Once an image is moved to the trash, it can be removed from the trash at a later time. This helps
to avoid accidental deletion.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the client node.

### Procedure

1. Move an image to the trash:

Syntax

```plaintext-ibm
rbd trash mv POOL_NAME/IMAGE_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[root@rbd-client ~]# rbd trash mv pool1/image1
```

Copy to clipboard

Once an image is in the trash, a unique image ID is assigned.

> 📝 **Note:** Note:
You need this image ID to
specify the image later if you need to use any of the trash options.
2. Run the `rbd trash list POOL_NAME` for a list of IDs of the images in the trash.
This command also returns the image’s pre-deletion name. In addition, there is an optional
`--image-id` argument that can be used with `rbd info` and `rbd
snap` commands. Use `--image-id` with the `rbd info` command
to see the properties of an image in the trash, and with `rbd snap` to remove an
image’s snapshots from the trash.
3. To remove an image from the trash run the following:

Syntax

```plaintext-ibm
rbd trash rm POOL_NAME/IMAGE_ID
```

Copy to clipboard

Example

```plaintext-ibm
[root@rbd-client ~]# rbd trash rm pool1/d35ed01706a0
```

Copy to clipboard

> 📝 **Note:** Important:
Once an image is removed from the trash, it cannot be restored.
4. Run the `rbd trash restore` command to restore the image:

Syntax

```plaintext-ibm
rbd trash restore POOL_NAME/IMAGE_ID
```

Copy to clipboard

Example

```plaintext-ibm
[root@rbd-client ~]# rbd trash restore pool1/d35ed01706a0
```

Copy to clipboard
5. To remove all expired images from trash:

Syntax

```plaintext-ibm
rbd trash purge POOL_NAME
```

Copy to clipboard

Example

```plaintext-ibm
[root@rbd-client ~]# rbd trash purge pool1
Removing images: 100% complete...done.
```

Copy to clipboard
