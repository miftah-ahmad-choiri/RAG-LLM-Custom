## Using Ceph Block Devices

Last Updated
: 2026-09-06

As a storage administrator, being familiar with Ceph Block Device commands can help you effectively manage the IBM Storage Ceph. You can create and manage block devices pools and images, along with enabling and disabling the various features of Ceph Block Devices.

> 📝 **Note:** Important:
Do not attempt any block device commands on block device images which are used as NVMe-oF gateway namespaces. For more information about NVMe-oF gateway image operations, see
Ceph NVMe-oF gateway
.
