## Enabling and disabling image features

Last Updated
: 2026-06-25

The Ceph Block Device image features, such as `fast-diff`,
`exclusive-lock`, `object-map`, or `deep-flatten`, are
enabled by default. You can enable or disable these image features on already existing
images.

> 📝 **Note:** Note:
The
`deep flatten`
feature can be only disabled on already existing images but
not enabled. To use
`deep flatten`
, enable it when creating images.

### Prerequisites

- A running IBM Storage Ceph cluster.
- Root-level access to the client node.

### Procedure

1. Retrieve information from a particular image in a pool:

Syntax

```plaintext-ibm
rbd --image POOL_NAME/IMAGE_NAME info
```

Copy to clipboard

Example

```plaintext-ibm
[ceph: root@host01 /]# rbd --image pool1/image1 info
```

Copy to clipboard
2. Enable a feature:

Syntax

```plaintext-ibm
rbd feature enable POOL_NAME/IMAGE_NAME FEATURE_NAME
```

Copy to clipboard

- To enable the `exclusive-lock` feature on the `image1` image in
the `pool1` pool:Example

```plaintext-ibm
    [ceph: root@host01 /]# rbd feature enable pool1/image1 exclusive-lock
```

Copy to clipboard

> 📝 **Note:** Important:
If you enable the
`fast-diff`
and
`object-map`
features, then rebuild the object
map:

```plaintext-ibm
rbd object-map rebuild POOL_NAME/IMAGE_NAME
```

Copy to clipboard

  - To enable the `exclusive-lock` feature on the `image1` image in
  the `pool1` pool:Example

  ```plaintext-ibm
      [ceph: root@host01 /]# rbd feature enable pool1/image1 exclusive-lock
  ```



  Copy to clipboard




  Copy to clipboard
3. Disable a feature:

Syntax

```plaintext-ibm
rbd feature disable POOL_NAME/IMAGE_NAME FEATURE_NAME
```

Copy to clipboard

- To disable the `fast-diff` feature on the `image1` image in the
`pool1` pool:Example

```plaintext-ibm
    [ceph: root@host01 /]# rbd feature disable pool1/image1 fast-diff
```

Copy to clipboard

  - To disable the `fast-diff` feature on the `image1` image in the
  `pool1` pool:Example

  ```plaintext-ibm

  ```
