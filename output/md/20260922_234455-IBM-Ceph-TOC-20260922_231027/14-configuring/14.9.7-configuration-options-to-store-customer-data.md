## Configuration options to store customer data

Last Updated
: 2026-06-25

Set the configuration options to store customer data using Ceph commands. It cannot be
set using the environment variable syntax.

> 📝 **Note:** Important:
All contact information should be for business contact information. This
includes names, emails, and phone numbers.

Example of using the `ceph config set mgr` command for setting the customer first
name.

```
ceph config set mgr mgr/call_home_agent/customer_first_name John
```

### Configuration options for IBM Call Home customer data

Table 1 lists the different types of customer data that must be configured for IBM Call Home
using Ceph commands.

| Customer data | Syntax |
| --- | --- |
| Contact address | mgr/call_home_agent/customer_addressCopy to clipboard |
| Company name | mgr/call_home_agent/customer_company_nameCopy to clipboard |
| IBM customer number (ICN). It is 7 alpha-numeric characters long. | mgr/call_home_agent/icn ICNCopy to clipboard |
| Country code | mgr/call_home_agent/customer_country_codeCopy to clipboard |
| Customer email | mgr/call_home_agent/customer_emailCopy to clipboard |
| Customer contact first name | mgr/call_home_agent/customer_first_nameCopy to clipboard |
| Customer contact last name | mgr/call_home_agent/customer_last_nameCopy to clipboard |
| Customer contact phone number | mgr/call_home_agent/customer_phoneCopy to clipboard |

### Configuration options for IBM Storage Insights customer data

Set the IBM Storage Insights customer data using the Ceph configuration commands, or the
`callhome set tenant` commands.

| IBM customer data | Syntax |
| --- | --- |
| Company name | mgr/call_home_agent/owner_company_nameCopy to clipboard |
| Company email | mgr/call_home_agent/owner_emailCopy to clipboard |
| Customer contact first name | mgr/call_home_agent/owner_first_nameCopy to clipboard |
| Customer contact last name | mgr/call_home_agent/owner_last_nameCopy to clipboard |
| Customer IBM ID | mgr/call_home_agent/owner_ibm_idCopy to clipboard |
| Customer tenant ID | mgr/call_home_agent/owner_tenant_idCopy to clipboard |
