## Unique identifier for Ceph

Last Updated
: 2026-06-25

Each IBM Storage Ceph cluster has a unique identifier
(`fsid`).

If specified, the unique identifier usually appears under the `[global]` section
of the configuration file. Deployment tools usually generate the `fsid` and store it
in the monitor map, so the value may not appear in a configuration file. The `fsid`
makes it possible to run daemons for multiple clusters on the same hardware.

> 📝 **Note:** Important:
Do not set the
`fsid`
value if you use a deployment tool that
does this automatically.
