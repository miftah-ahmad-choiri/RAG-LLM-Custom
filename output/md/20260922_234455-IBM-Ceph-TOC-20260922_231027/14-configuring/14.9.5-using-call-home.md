## Using Call Home

Last Updated
: 2026-06-25

The Call Home agent uses the `ceph callhome` set of commands for
configuring and receiving reports.

The `ceph callhome` commands are all used through the `cephadm` shell.

| Command | Description | Syntax |
| --- | --- | --- |
| show | Prints the selected report. Available report parameters: inventory status last_contact performance | ceph callhome show inventoryCopy to clipboard |
| send | Immediately sends the selected report. Available report parameters: inventory status last_contact performance | ceph callhome send inventoryCopy to clipboard |
| list-tenants | Provides information about IBM tenant IDs owned by a specific user. Note: The OWNER_IBM_ID is IBM w3id email. | ceph callhome list-tenants owner_ibm_id, owner_company_name, owner_first_name, owner_last_name, owner_emailCopy to clipboard |
| set tenant | Sets the IBM tenant ID to be included in reports that are sent to IBM Storage Insights. | ceph callhome list-tenants owner_tenant_id, owner_ibm_id, owner_company_name, owner_first_name, owner_last_name, owner_emailCopy to clipboard |
| callhome get user info | Shows the customer information that is included in reports that are sent to IBM Call Home and IBM Storage Insights systems. | ceph callhome get user infoCopy to clipboard |
