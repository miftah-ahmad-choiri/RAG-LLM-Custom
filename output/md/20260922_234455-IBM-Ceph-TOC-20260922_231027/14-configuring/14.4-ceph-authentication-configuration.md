## Ceph authentication configuration

Last Updated
: 2026-09-06

Authenticating users and services is important to the security of the IBM Storage Ceph cluster. IBM Storage Ceph includes the Cephx protocol, as the default, for cryptographic authentication, and the tools to manage authentication in the storage cluster.

Be sure to have an IBM Storage Ceph cluster installed before configuring user authentication.

For more information, see Cephx configuration options.
