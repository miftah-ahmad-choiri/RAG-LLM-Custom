## Ceph OSD configuration

Last Updated
: 2026-06-25

All Ceph clusters have a configuration. A deployment tool, such as
`cephadm`, will typically create an initial Ceph configuration file for you. However,
you can create one yourself if you prefer to bootstrap a cluster without using a deployment
tool.

All Ceph clusters have a configuration, which defines:

- Cluster identity
- Authentication settings
- Ceph daemon membership in the cluster
- Network configuration
- Host names and addresses
- Paths to keyrings
- Paths to OSD log files
- Other runtime options

For your convenience, each daemon has a series of default values. Many are set by the
`ceph/src/common/config_opts.h`
script. You can override these settings with a Ceph
configuration file or at runtime by using the monitor
`tell`
command or connecting
directly to a daemon socket on a Ceph node.

> 📝 **Note:** Important:
Changing the default paths makes
it more difficult to troubleshoot Ceph later.
