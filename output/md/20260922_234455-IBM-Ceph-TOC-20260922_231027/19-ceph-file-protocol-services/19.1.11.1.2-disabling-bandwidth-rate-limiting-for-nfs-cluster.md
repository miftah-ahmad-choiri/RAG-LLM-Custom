## Disabling bandwidth rate-limiting for NFS cluster

Last Updated
: 2026-06-25

You can disable bandwidth rate-limiting by using the command line.

### Procedure

Run the following command to disable bandwidth-rate limiting.

```plaintext-ibm
ceph nfs cluster qos disable bandwidth_control CLUSTER_ID
```

Copy to clipboard

Where,

CLUSTER_ID is the NFS cluster ID.

This command disables the bandwidth control in the cluster. If cluster-level QoS is disabled, then share-level QoS is not applicable, even if it is enabled.
