## Enabling bandwidth rate-limiting for NFS cluster

Last Updated
: 2026-06-25

Learn to enable the bandwidth rate-limiting feature by using the command line.

### About this task

You can define bandwidth limits per client or share (per share) to ensure a balanced workload distribution across the cluster.

> 📝 **Note:** Note:
The bandwidth rate-limiting, the limit ranges from a minimum of 1 Mbps to a maximum of 4 Gbps.

**Understanding cluster-wide enforcement of bandwidth and IOPS limits**

When you enable bandwidth or input/output operations (IOPS) control on an NFS cluster, the configured limits apply cumulatively across all hosts in the cluster, rather than per individual host.

To enforce these cumulative limits, NFS services coordinate with NFS daemons running on other hosts in the cluster. This coordination ensures that bandwidth and IOPS limits are enforced consistently, even when multiple NFS servers handle client requests at the same time.

> 📝 **Note:** Note:
You can configure the port used for this inter-node communication by using the cluster_qos_port field in the NFS specification. The default port is 31311.

You can control how frequently NFS daemons exchange coordination messages by using the cqos_msg_interval field in the NFS specification. The default interval is 100 ms.

Alternatively, you can update the message interval by using the command-line interface.

```plaintext-ibm
ceph nfs cluster qos set <cluster_id> <msg_interval>
```

This inter-node coordination ensures accurate enforcement of bandwidth and IOPS limits across the NFS cluster.

**Cluster QoS TCP keepalive configuration**

Cluster QoS uses TCP connections between NFS nodes. To keep these TCP connections open, configure TCP keepalive parameters in the `NFS_CORE_PARAMS` section of the nfs-ganesha.conf file on all NFS nodes.

Configure the following parameters:

```plaintext-ibm
TCP_KEEPCNT = 5;
TCP_KEEPIDLE = 30;
TCP_KEEPINTVL = 2;
```

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A healthy and running IBM Storage Ceph cluster.
- An NFS cluster.

### Procedure

Run the following command to enable bandwidth rate-limiting for an NFS cluster.

```plaintext-ibm
ceph nfs cluster qos enable bandwidth_control CLUSTER ID qos_type:PerShare|PerClient|PerShare_PerClient [--combined-rw-bw-ctrl] [--max_export_write_bw VALUE] [--max_export_read_bw VALUE] [--max_client_write_bw VALUE] [--max_client_read_bw VALUE] [--max_export_combined_bw VALUE] [--max_client_combined_bw VALUE]
```

Copy to clipboard

Where,

- CLUSTER_ID is the NFS cluster ID.
- qos_type is the type of bandwidth control. You can select either PerShare (per share), PerClient or PerShare_PerClient based on your requirement.

- If the PerShare qos_type is selected, the cluster-level quality of service (QoS) configuration applies to all shares created on that NFS cluster. If combined-rw-bw-ctrl is set to false, you must specify both the max_export_write_bw and max_export_read_bw parameters. Otherwise, only the max_export_combined_bw parameter is required.
- If the PerClient qos_type is selected, the cluster-level QoS configuration applies to all clients accessing shares on that cluster. If combined-rw-bw-ctrl is set to false, you must specify both the max_client_write_bw and max_client_read_bw parameters. Otherwise, only the max_client_combined_bw parameter is required
- If the PerShare_PerClient qos_type is selected, the cluster-level configuration applies to all shares and all clients of that NFS cluster. If combined-rw-bw-ctrl is set to false, you must specify the max_export_write_bw, max_export_read_bw, max_client_write_bw, and max_client_read_bw parameters. Otherwise, only the max_export_combined_bw and max_client_combined_bw parameters are required.

  - If the PerShare qos_type is selected, the cluster-level quality of service (QoS) configuration applies to all shares created on that NFS cluster. If combined-rw-bw-ctrl is set to false, you must specify both the max_export_write_bw and max_export_read_bw parameters. Otherwise, only the max_export_combined_bw parameter is required.
  - If the PerClient qos_type is selected, the cluster-level QoS configuration applies to all clients accessing shares on that cluster. If combined-rw-bw-ctrl is set to false, you must specify both the max_client_write_bw and max_client_read_bw parameters. Otherwise, only the max_client_combined_bw parameter is required
  - If the PerShare_PerClient qos_type is selected, the cluster-level configuration applies to all shares and all clients of that NFS cluster. If combined-rw-bw-ctrl is set to false, you must specify the max_export_write_bw, max_export_read_bw, max_client_write_bw, and max_client_read_bw parameters. Otherwise, only the max_export_combined_bw and max_client_combined_bw parameters are required.
- combined-rw-bw-ctrl This parameter enables combined read and write bandwidth. If combined-rw-bw-ctrl is set to true, then only max_export_combined_bw and max_client_combined_bw parameters are allowed based on QoS type.
- max_export_write_bw is the maximum bandwidth for share write per second.
- max_export_read_bw is the maximum bandwidth for share that is read per second.
- max_client_write_bw is the maximum bandwidth that the client can use for writing per second.
- max_client_read_bw is the maximum bandwidth that the client can use for reading per second.
- max_export_combined_bw is the maximum combined read/write bandwidth for share per second.
- max_client_combined_bw is the maximum combined read/write bandwidth for client per second.

> 📝 **Note:** Note:
You can specify the value as 10, 10 MB, 10 MiB, or 10 GB.

PerShare
,
clust_nfs
is the NFS cluster ID

```
[ceph: root@ceph-node-0 /]# ceph nfs cluster qos enable bandwidth_control clust_nfs PerShare --max_export_write_bw 100MB --max_export_read_bw 200MB
[ceph: root@ceph-node-0 /]# ceph nfs cluster qos get clust_nfs
{
  "combined_rw_bw_control": false,
  "enable_bw_control": true,
  "enable_iops_control": false,
  "enable_qos": true,
  "max_export_read_bw": "200.0MB",
  "max_export_write_bw": "100.0MB",
  "qos_type": "PerShare"
}
```
