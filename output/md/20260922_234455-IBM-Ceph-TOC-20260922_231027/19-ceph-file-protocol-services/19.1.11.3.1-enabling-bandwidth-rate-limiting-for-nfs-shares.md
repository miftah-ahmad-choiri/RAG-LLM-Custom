## Enabling bandwidth rate-limiting for NFS shares

Last Updated
: 2026-06-25

Learn how to enable bandwidth rate-limiting for NFS shares by using the command line.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A healthy and running IBM Storage Ceph cluster.
- NFS shares.

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### About this task

Enabling bandwidth rate-limiting for NFS shares helps control network traffic by restricting data transfer rate for NFS clients. Bandwidth rate-limiting prevents network congestion, ensures fair bandwidth distribution, and optimizes system performance.

> 📝 **Note:** Note:

- When you set NFS QoS bandwidth control to a very low limit, other operations on the same file may experience delays. For example, if the QoS bandwidth is limited to 10 MB/sec and you execute the du -h FILE command while the file is under active write I/O, the command may take longer to complete.
- This behavior is expected because the file is servicing throttled write operations, which can delay concurrent access.
- You cannot enable share-level bandwidth control if the cluster-level qos_type is PerClient.

### Procedure

The following command enables and updates QoS bandwidth control for shares.

To enable share-level bandwidth control, you must enable cluster-level bandwidth control with qos_type PerShare or Pershare_PerClient. This command creates QOS_BLOCK in the share block.

```plaintext-ibm
nfs export qos enable bandwidth_control CLUSTER_ID <pseudo_path> [--combined-rw-bw-ctrl] [--max_export_write_bw VALUE] [--max_export_read_bw VALUE] [--max_client_write_bw VALUE] [--max_client_read_bw VALUE] [--max_export_combined_bw VALUE] [--max_client_combined_bw VALUE]
```

Copy to clipboard

Where,

- CLUSTER_ID is the NFS cluster ID.
- pseudo_path is the pseudo-root path. (The path must be an absolute path.)
- combined-rw-bw-ctrl enables combined read and write bandwidth control. When set to True, only the max_export_combined_bw and max_client_combined_bw parameters are allowed, depending on the qos_type.
- max_export_write_bw is the maximum bandwidth that can be used for share write per second.
- max_export_read_bw is the maximum bandwidth that can be used for share that is read per second.
- max_client_write_bw is the maximum bandwidth that the client can use for writing per second.
- max_client_read_bw is the maximum bandwidth that the client can use for reading per second.
- max_export_combined_bw is the maximum combined read/write bandwidth for share per second.
- max_client_combined_bw is the maximum combined read/write bandwidth for client per second.

Example for bandwidth rate-limiting for QoS type
Pershare_PerClient

```
[ceph: root@ceph-node-0 /]# ceph nfs export qos enable bandwidth_control clust_nfs /export1 --max_export_write_bw 100MB --max_export_read_bw 200MB --max_client_write_bw 300MB --max_client_read_bw 100MB
[ceph: root@ceph-node-0 /]# ceph nfs export qos get clust_nfs /export1
{
  "cluster_enable_bw_control": true,
  "cluster_enable_iops_control": false,
  "cluster_enable_qos": true,
  "combined_rw_bw_control": false,
  "enable_bw_control": true,
  "enable_qos": true,
  "max_client_read_bw": "100.0MB",
  "max_client_write_bw": "300.0MB",
  "max_export_read_bw": "200.0MB",
  "max_export_write_bw": "100.0MB"
}
```
