## Listing QoS configuration for NFS cluster

Last Updated
: 2026-06-25

Learn how to list the quality of service (QoS) configuration for the NFS cluster by using
the command line.

### About this task

You can list the QoS configuration for the NFS clusters.

### Procedure

Run the following command to list the QoS
configuration:

```plaintext-ibm
ceph nfs cluster qos get CLUSTER_ID [--format VALUE]
```

Copy to clipboard

Where,

- CLUSTER_ID is the NFS cluster ID.
- VALUE is either YAML or JSON.

> 📝 **Note:** Note:
This command displays all the QoS global default configurations for a given
cluster.

Example of listing QoS settings with JSON format

```
[ceph: root@ceph-node-0 /]# ceph nfs cluster qos get clust_nfs --format json
{
"combined_rw_bw_control": false,
"enable_bw_control": false,
"enable_iops_control": true,
"enable_qos": true,
"max_client_iops": 1000,
"qos_type": "PerClient"
}
```

Example of listing QoS settings with YAML format

```
[ceph: root@ceph-node-0 /]# ceph nfs cluster qos get clust_nfs --format yaml
combined_rw_bw_control: false
enable_bw_control: false
enable_iops_control: true
enable_qos: true
max_client_iops: 1000
qos_type: PerClient
```
