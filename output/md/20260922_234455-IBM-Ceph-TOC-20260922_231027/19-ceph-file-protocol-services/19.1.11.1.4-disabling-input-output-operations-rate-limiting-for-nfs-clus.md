## Disabling input/output operations rate-limiting for NFS cluster

Last Updated
: 2026-06-25

Learn to disable input/output operations (IOPS) rate-limiting for NFS clusters by using
the command line.

### Procedure

You can disable IOPS rate-limiting for the NFS cluster by using the following
command.

```plaintext-ibm
nfs cluster qos disable ops_control CLUSTER_ID
```

Copy to clipboard

Where,

CLUSTER_ID is the NFS cluster ID.
