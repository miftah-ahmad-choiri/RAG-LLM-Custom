## NFS RDMA support (Technology Preview)

Last Updated
: 2026-06-25

NFS supports NFS over Remote Direct Memory Access (RDMA), which enables high-performance data transfer by bypassing the traditional TCP/IP networking stack.

NFS supports NFS over RDMA, which enables high-performance data transfer by bypassing the traditional TCP/IP networking stack. This transport improves efficiency by allowing direct memory-to-memory communication between the client and server.

RDMA support is implemented alongside standard TCP transport, allowing both transport methods to coexist in the same deployment.

### Benefits

NFS over RDMA provides the following advantages:

- Reduced latency through kernel bypass
- Improved throughput for large data transfers
- Lower CPU utilization on client and server systems
- Support for mixed transport environments (TCP and RDMA)

### Transport and protocols

RDMA support in NFS uses the following protocols:

- `nfsrdma`
- `rpcrdma`

> 📝 **Note:** Note:
The RDMA service listens on a dedicated port. You can configure the port during NFS cluster creation based on your environment and workload requirements.

### Supported hardware

NFS RDMA support is validated on RoCEv2-capable network adapters, including:

- Mellanox ConnectX series adapters
- Broadcom NetXtreme

### RDMA communication workflow

An RDMA-based NFS operation follows this high-level workflow:

1. RDMA adapters and kernel modules (xprtrdma, svcrdma, NIC drivers) are initialized on both client and server; memory pinning limits are configured.
2. RoCE network connectivity is established between RDMA interfaces (L2 adjacency, PFC/ECN, MTU, GID table).
3. NFS-Ganesha starts with RDMA transport enabled, listening on the configured RDMA port.
4. Client mounts using proto=rdma,port=<rdma_port>, which creates RPC-over-RDMA sessions backed by RDMA Queue Pairs, Completion Queues, and registered Memory Regions.
5. Data is transferred via zero-copy DMA directly between registered memory buffers, bypassing the TCP/IP stack.
6. On unmount or disconnect, RDMA resources (QPs, CQs, MRs) are drained and released.
