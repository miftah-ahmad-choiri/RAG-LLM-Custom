## Configuring Volume Shadow Copy Service

Last Updated
: 2026-06-25

Learn about integrating Volume Shadow Snapshots with SMB service to enable interoperability between Linux and Windows operating systems.

Ceph File Systems (CephFS) supports point-in-time snapshots through its native snapshot mechanism. For more information about Ceph snapshots, see [CephFS snapshots](https://www.ibm.com/docs/en/storage-ceph/8.0?topic=cfs-cephfs-snapshots). You can expose these snapshots to Windows clients as Volume Shadow Copy Service (VSS) shadow copies by integrating with SMB protocol. This integration enables seamless interoperability between Linux and Windows operating systems.

When you create CephFS shares by using `cephadm`, SMB service is automatically configured to support VSS snapshots. This simplifies the setup process and helps ensure consistent snapshot access across platforms.

To view the default configuration, access one of the SMB containers and run the following command:

Example SMB configuration:

```plaintext-ibm
# testparm -s

[share1]
    path = /volumes/smb/sv1/fe9b27d0-75a5-405e-82f2-c14b1a7aceea/
    vfs objects = acl_xattr ceph_snapshots ceph_new
    acl_xattr:security_acl_name = user.NTACL
    ceph_new:config_file = /etc/ceph/ceph.conf
    ceph_new:filesystem = cephfs
    ceph_new:user_id = smb.fs.cluster.smb1
    read only = No
    browseable = Yes
    kernel share modes = no
    x:ceph:id = smb1.share1
    ceph_new:proxy = yes
```

Copy to clipboard

Make sure that the Ceph snapshots are available. You can create snapshots by using the Ceph Dashboard or the `cephadm` shell if they are not already present. For more information about creating Ceph snapshots, see [Creating CephFS snapshots using the Ceph dashboard](https://www.ibm.com/docs/en/storage-ceph/8.0?topic=cephfs-managing-snapshots) and [Creating CephFS snapshots using cephadm](https://www.ibm.com/docs/en/storage-ceph/7?topic=subvolumes-creating-snapshot-file-system-subvolume).
