## Integrating active directory with SMB by using declarative method

Last Updated
: 2026-06-25

Learn how to integrate SMB and active directory.

### Before you begin

- Gather information about the domain for using active directory (AD).
- Create a domain user to join to AD.
- Determine whether you need to use `custom_dns` setting.

### About this task

SMB services for IBM Storage Ceph can use and connect to an existing Active Directory domain server. Upon SMB cluster creation, an administrator needs to decide whether the SMB cluster uses AD or not. If a cluster is configured with Active Directory, then active directory manages all user information and user authentication for this cluster.

### Procedure

In the resources specification file, add the
authentication mode
as
active-directory
.

```plaintext-ibm
auth_mode: active-directory
```

Copy to clipboard

For example,

```plaintext-ibm
resource_type: ceph.smb.cluster
cluster_id: tango
auth_mode: active-directory
domain_settings:
  realm: DOMAIN1.SINK.TEST
  join_sources:
    # this join source refers to a join auth resource with id "join1-admin"
    - source_type: resource
      ref: join1-admin
custom_dns:
  - "192.168.76.204"
placement:
  count: 1
```
