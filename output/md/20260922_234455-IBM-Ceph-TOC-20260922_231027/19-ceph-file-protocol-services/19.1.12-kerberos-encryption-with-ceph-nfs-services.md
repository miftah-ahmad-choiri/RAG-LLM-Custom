## Kerberos encryption with Ceph NFS services

Last Updated
: 2026-06-25

Learn how Kerberos encryption works with Ceph NFS services.

Ceph NFS services supports secure authentication and data integrity through Kerberos, a network
authentication protocol that uses symmetric encryption and trusted third-party verification. When
Kerberos is enabled, Ceph NFS services clients and the server authenticate each other using tickets
that are issued by the Key Distribution Centre (KDC), eliminating the need for password-based
authentication over the network.

Kerberos integration with Ceph NFS services is typically configured through GSS-API (Generic
Security Services API), which allows RPCSEC_GSS (Remote Procedure Call Security by using GSS) to
handle the authentication and encryption layers. This setup supports various levels of security,
including:

- `AUTH_SYS`: Standard UNIX authentication (nonencrypted, used for
compatibility).
- `AUTH_GSS/KRB5`: Kerberos-based authentication.
- `krb5i`: Kerberos with integrity protection.
- `krb5p`: Kerberos with both integrity and privacy (encryption).

When clients mount an NFS share by using Kerberos (for example, sec=krb5, krb5i, or krb5p), all
communication is secured according to the specified level. Encryption helps ensure secure access
control and data-in-transit protection, making Ceph NFS services a viable choice for enterprise
environments requiring strong authentication and encrypted communication.
