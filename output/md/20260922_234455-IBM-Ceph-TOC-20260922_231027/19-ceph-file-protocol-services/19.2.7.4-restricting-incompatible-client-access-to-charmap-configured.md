## Restricting incompatible client access to charmap-configured directories

Last Updated
: 2026-06-25

Learn how to ensure that only clients that support the `charmap` feature
can access directories with character mapping in CephFS. The Metadata Server (MDS) uses a client
feature bit to restrict access. Clients that do not support `charmap` cannot modify
directories with a charmap configuration, except to unlink files or remove subdirectories.

### Before you begin

> 📝 **Note:** Note:
The kernel driver does not understand the
`charmap`
feature and
probably will not because existing kernel libraries have opinionated case folding and normalization
forms. For this reason, adding
`charmap`
to the required client features is not
recommended.

Before you begin, make sure that you have the following prerequisites in place:

- Ensure all clients accessing the file system are capable of understanding the charmap feature.

### Procedure

Enforce client compatibility. You can require that all clients accessing the file system
understand the charmap feature by adding it to the list of required client features.

```plaintext-ibm
 ceph fs required_client_features fs_name add charmap
```

Copy to clipboard

For
example,

```
 ceph fs required_client_features cephfs_data add charmap
```
