## Disabling input/output operations rate-limiting for NFS share

Last Updated
: 2026-06-25

Learn to disable input/output operations (IOPS) rate-limiting for NFS shares by using command line.

### About this task

> 📝 **Note:** Note:
This documentation uses
*NFS share*
instead of the earlier term
*NFS export*
. In the Ceph Dashboard, labels and controls may still refer to NFS export.

### Procedure

The following command disables QoS operations control for sharing, removing any limits on the operations for shares. As a result, shares will not be subject to any cluster-level operation restrictions.

```plaintext-ibm
nfs export qos disable ops_control CLUSTER_ID PSEUDO_PATH
```

Copy to clipboard

Where,

- CLUSTER_ID is the NFS cluster ID.
- PSEUDO_PATH is the pseudo-root path. The path must be an absolute path.
