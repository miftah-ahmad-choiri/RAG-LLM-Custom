## Windows 11 desktop client side mount options for NFSv3 fileshare

Last Updated
: 2026-06-25

Use this information to understand the client side mount options for NFSv3
fileshare.

NFSv3 (version 3) is supported and enabled for clients that do not yet support NFSv4.2 mounts for
CephFS file shares.

> 📝 **Note:** Note:
Mount a file share with NFSv3 Windows 11 desktop only when NFSv4.2 is not
supported on the client or server side. For more information about configuring NFS, see
Configuring NFS Service daemons.

Use the following mount client-side options to mount a file share with NFSv3 Windows 11
desktop:

```plaintext-ibm
Usage:  mount [-o options] [-u:username] [-p:<password | *>] <\\computername\sharename> <devicename | *>
```

Copy to clipboard

| Mount options | Description |
| --- | --- |
| -o rsize=size | Set the size of the read buffer in kilobytes. |
| -o wsize=size | Set the size of the write buffer in kilobytes. |
| -o timeout=time | Set the timeout value in seconds for an RPC call. |
| -o retry=number | Set the number of retries for a soft mount. |
| -o mtype=soft|hard | Set the mount type. |
| -o lang=euc-jp|euc-tw|euc-kr|shift-jis|big5|ksc5601|gb2312-80|ansi | Specify the encoding used for file and directory names. |
| -o fileaccess=mode | Specify the permission mode of the file. These are used for new files created on NFS servers. Specified using UNIX style mode bits. |
| -o nolock | Disable locking. |
| -o anon | Mount as an anonymous user. |
| -o casesensitive=yes|no | Specify case sensitivity of file lookup on server. |
| -o sec=sys|krb5|krb5i|krb5p | Specify the security mechanism for mounting an NFS share. This value can include any of the following: sec=sys: No authentication or security checks are performed. Data transfers are not encrypted. sec=krb5: Specifies Kerberos authentication for mounting the NFS share. sec=krb5i: Extends Kerberos security by adding data integrity checks between the client and server hasn't been tampered. sec=krb5p: Enhances Kerberos security by enabling data privacy, which encrypts data exchanged between the client and server. |
