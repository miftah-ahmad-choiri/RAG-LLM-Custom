## Providing information for support

Last Updated
: 2026-09-06

To get help troubleshooting IBM Storage Ceph problems, contact IBM Support and provide enough information for the support engineers to diagnose the issue.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- Root-level access to the node.
- IBM Support account.

### Procedure

1. Open a support ticket with
[IBM Support](https://www.ibm.com/mysupport/)
.
2. Attach an
`sos report`
to the ticket.
For more information, see
Generating an sos report
.
3. **Optional:**
Generate a readable core dump file.
If the Ceph daemons fail with a segmentation fault, a core dump file can help diagnose the problem. For more information, see
Generating readable core dump files
.
