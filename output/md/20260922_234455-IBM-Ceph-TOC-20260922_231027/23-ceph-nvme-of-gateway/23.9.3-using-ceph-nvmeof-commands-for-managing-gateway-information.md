## Using ceph nvmeof commands for managing gateway information

Last Updated
: 2026-09-06

Get NVMe-oF gateway information and set log levels by using ceph nvmeof commands.

### Getting the gateway version

Use the
gateway version
command to retrieve the NVMe-oF gateway version.

```plaintext-ibm
ceph nvmeof gateway version [--format FORMAT] [--output log] [gw_group GW_GROUP] [--server-address SERVER_ADDRESS]
```

Copy to clipboard

For example,

```
[root@host01 ~]# ceph nvmeof gw version
+-------+
|Version|
+-------+
|1.6.0  |
+-------+
```

### Getting gateway information

Use the
gateway info
command to get information about the NVMe-oF gateway.

```plaintext-ibm
ceph nvmeof gateway info [gw_group GW_GROUP] [--server-address SERVER_ADDRESS]
```

Copy to clipboard

For example,

```
[root@host01 ~]# ceph nvmeof gateway info
+-------------+-------+--------------------------------------------------+--------+------------+----+--------+------------+
|Hostname     |Version|Name                                              |Group   |Addr        |Port|Lb Group|Spdk Version|
+-------------+-------+--------------------------------------------------+--------+------------+----+--------+------------+
|cephnvme-vm29|1.6.0  |client.nvmeof.mypool.mygroup1.cephnvme-vm29.jgxogm|mygroup1|10.242.64.51|5500|1       |SPDK v25.05 |
+-------------+-------+--------------------------------------------------+--------+------------+----+--------+------------+
```

### Getting the gateway log level

Use the
gateway get_log_level
command to get the log level for the NVMe-oF gateway.

```plaintext-ibm
ceph nvmeof gateway get_log_level [gw_group GW_GROUP] [--server-address SERVER_ADDRESS]
```

Copy to clipboard

For example,

```
[root@host01 ~]# ceph nvmeof gateway get_log_level
+---------+
|Log Level|
+---------+
|info     |
+---------+
```

### Setting the gateway log level

Use the
gw set_log_level
command to set the log level for the NVMe-oF gateway output.

The available log levels for input are: debug, info, warning, error, and critical.

```plaintext-ibm
ceph nvmeof gateway set_log_level --level LEVEL [gw_group GW_GROUP] [--server-address SERVER_ADDRESS]
```

Copy to clipboard

The following example sets the log level to
`INFO`
.

```
[root@host01 ~]# ceph nvmeof gateway set_log_level --level warning
Success
```
