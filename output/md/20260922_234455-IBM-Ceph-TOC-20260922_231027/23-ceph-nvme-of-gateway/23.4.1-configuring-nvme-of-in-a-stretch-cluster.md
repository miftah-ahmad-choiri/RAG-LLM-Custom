## Configuring NVMe-oF in a stretch cluster

Last Updated
: 2026-06-25

Configure NVMe-oF services in a stretch cluster to provide continuous block storage access across two sites during failures and planned maintenance.

### Before you begin

Before you begin, make sure that you have the following prerequisites in place:

- A deployed and operational IBM Storage Ceph stretch cluster spanning two sites.

For more information, see Stretch clusters for Ceph storage
- At least four Ceph nodes per site.
- NVMe-oF gateways deployed in both sites.

For more information, see Deploying the NVMe-oF gateway.
- NVMe-oF initiator hosts, such as VMware ESXi systems.
- Network connectivity between sites with controlled latency, typically in the range of 2–10 milliseconds.

### About this task

NVMe-oF stretch clustering extends IBM Storage Ceph across a minimum of two sites and requires site-aware deployment of storage, gateways, and initiators.

Use this information for initial NVMe-oF stretch cluster configuration. For NVMe-oF stretch cluster management information, see Managing NVMe‑oF stretch cluster behavior.

### Procedure

1. Set the location of each NVMe-oF gateway.
The NVMe-oF gateway location defines the physical site of each gateway and do not need to match the Ceph CRUSH roles.

Run the following command for each gateway:

```plaintext-ibm
ceph nvme-gw set-location GW_ID POOL_NAME GROUP_NAME LOCATION
```

Copy to clipboard

Gateways are assigned to their respective locations.
2. Configure NVMe-oF subsystems and listeners.

For more information, see:

- Defining an NVMe-oF subsystem
- Managing listeners

NVMe-oF targets are configured and accessible.

  - Defining an NVMe-oF subsystem
  - Managing listeners
3. Create namespaces with a defined location.
Use the
--location
parameter in the
ceph nvmeof namespace add
command.

This ensures namespaces are placed on gateways in the same location, when possible.

```plaintext-ibm
ceph nvmeof namespace add --nqn NQN --location LOCATION
```

Copy to clipboard

For more information, see Managing namespaces.

For example,

```
[root@host01 ~]# ceph nvmeof namespace add --nqn nqn.2016-06.io.spdk:cnode1.group1 --location DC2
Success
```

Namespaces are created with location-aware placement.
