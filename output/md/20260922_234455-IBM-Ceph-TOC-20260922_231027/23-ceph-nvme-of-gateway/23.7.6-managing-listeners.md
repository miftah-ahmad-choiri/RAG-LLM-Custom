## Managing listeners

Last Updated
: 2026-09-06

As a system administrator, you can add, list, and delete NVMe-oF subsystem listeners by using `ceph nvmeof` commands.

### About this task

### Adding a listener

> 📝 **Note:** Important:

If a subsystem is already enabled with automatic listeners, do not manually add a listener. For more information, see Managing subsystems.

Configure NVMe‑oF listeners automatically by using the --network-mask parameter. This approach simplifies listener management and ensures that listeners are automatically added or removed during scale‑up and scale‑down operations.

When required, manually add listeners for gateways in the gateway group. Adding listeners through a gateway group is useful in cases that you plan to add more gateways to a gateway group but the new gateways are still not up and running. It is sufficient to know what the IP address of the new gateways will be and then add the listeners to the IP address. This way, when the gateway joins the group, the gateway automatically begins participating in I/O activity.

Use the
listener add
command to add a listener to an NVMe-oF subsystem.

```plaintext-ibm
ceph nvmeof listener add --nqn NQN --host_name HOST_NAME [--traddr LISTENER_ADDRESS] [--server-address SERVER_ADDRESS] [--trsvcid PORT] [--adrfam:int IPV_TYPE] [--gw_group GW_GROUP] [--secure]
```

Copy to clipboard

For example,

```
[root@host01 ~]# ceph nvmeof listener add --nqn nqn.2016-06.io.spdk:cnode1.group1 --host_name host02
```

Add a listener for each NVMe-oF gateway.

To define the IP port on the gateway, be sure to include the --host_name and --traddr parameters.

The following optional parameters are available:

--trsvcid
Specifies the port number for the listener. If not specified, the default port is
`4420`
.
--adrfam
Specifies the IP address family for the listener, such as
ipv4
.
--gw_group
Specifies the gateway group on which to run the command.
--server-address
Specifies the IP address of the gateway on which to run the command.
--secure
Use to enable TLS-secured connections. For more information, see
Configuring TLS-PSK authentication for NVMe-oF
.

### Listing listeners

Use the
listener list
command to list listeners of an NVMe-oF subsystem.

> 📝 **Note:** Note:
Run this command for each subsystem.

```plaintext-ibm
ceph nvmeof listener list --nqn NQN [--clear-alerts] [gw_group GW_GROUP] [--server-address SERVER_ADDRESS]
```

Copy to clipboard

See the following example output for two gateways on a subsystem.

```
[root@host01 ~]# ceph nvmeof listener list

Host           Transport    Address Family    Address             Secure    Active    Manual

cephnvme-vm27  TCP          IPv4              10.243.64.150:4420  No        No        No
```

See the Manual output column to monitor if listeners were created automatically or manually. For more information about auto-listeners, see Defining an NVMe-oF subsystem.

For more information about getting details about automatically created listeners, see Viewing automatically created listener information.

### Viewing listener information

Use the
gateway listener_info
command to get listener information of an NVMe-oF subsystem on a specific gateway. The output includes on which load balancing group this listener is optimized.

> 📝 **Note:** Note:
Run this command for each subsystem.

```plaintext-ibm
ceph nvmeof gateway listener_info --nqn NQN
```

Copy to clipboard

See the following example output for two gateways on a subsystem.

```
[root@host01 ~]# ceph nvmeof gateway listener_info --nqn nqn.2016-06.io.spdk:cnode1.group1
+---------------------------------------------------------------------------------------------------------------------------------------------+
|Listener                                                                                                                                     |
+---------------------------------------------------------------------------------------------------------------------------------------------+
|{'host_name': 'cephnvme-vm29', 'trtype': 'TCP', 'traddr': '10.242.64.51', 'secure': False, 'active': True, 'adrfam': 'ipv4', 'trsvcid': 4420}|
+---------------------------------------------------------------------------------------------------------------------------------------------+
```

### Viewing automatically created listener information

Use the
ceph nvme-gw listeners
command to view detailed information about automatically created NVMe-oF listeners.
For more information about automatically created listeners, see
Defining an NVMe-oF subsystem
.

```plaintext-ibm
ceph nvme-gw listeners POOL_NAME GW_GROUP
```

### Deleting listeners

Use the
listener del
command to delete a listener from an NVMe-oF subsystem.

```plaintext-ibm
ceph nvmeof listener del --nqn NQN --host_name HOST_NAME [--traddr LISTENER_ADDRESS] [--server-address SERVER_ADDRESS] [trsvcid:int PORT] [adrfam:int IPV_TYPE] [--force] [gw_group GW_GROUP]
```

Copy to clipboard

Use the optional --force parameter to force the listener deletion, even if active connections for the address exist, or if the name does not match.

The following optional parameters are available:

--trsvcid
Specifies the port number for the listener. If not specified, the default port is
`4420`
.
--adrfam
Specifies the IP address family for the listener, such as
ipv4
.
--traddr
Specifies the listener IP address.
--gw_group
Specifies the gateway group on which to run the command.
--server-address
Specifies the IP address of the gateway on which to run the command.

For example,

```
[root@host01 ~]# ceph nvmeof listener del --nqn nqn.2016-06.io.spdk:cnode1.group1 --host_name host02
```
