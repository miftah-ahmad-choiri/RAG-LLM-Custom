## Using ceph nvmeof commands

Last Updated
: 2026-06-25

Use the integrated `ceph nvmeof` command for seamlessly using NVMe-oF gateway commands from within the IBM Storage Ceph command-line interface.

The integrated `ceph nvmeof` command set helps simplify using the NVMe-oF gateway within the IBM Storage Ceph command-line interface (CLI). With the `nvmeof` integration in place, it is no longer required to use Docker or an alias and the server address (traddr) is taken directly from the provided NQN.

Use the ceph nvmeof --help or ceph nvmeof -h command at any time to view all NVMe-oF commands, their parameters, and descriptions.

> 📝 **Note:** Note:
The following are interchangeable within
ceph nvmeof
commands:

- `gateway` and `gw`
- `namespace` and `ns`

Table 1 provides ceph nvmeof command parameters and their descriptions.

> 📝 **Note:** Note:
For real‑time monitoring of gateway CPU and subsystem I/O performance, see
Monitoring NVMe-oF performance with ceph nvmeof top
.

| Parameter | Description |
| --- | --- |
| --adrfam:int | IPv type. Input type: Integer. Allowed value types are 0 for IPv4 and 1 for IPv6. |
| --block_size<int> | Provide the block size in megabytes. Input type: Integer |
| --dhchap_controller_key | Specifies a DH‑HMAC‑CHAP key that is used only for the controller created for a specific host. Input type: String |
| --create-image | Create an image within any Ceph Block Device (RBD) application-enabled pool. Note: The --rbd_image_size parameter must be used together with --create-image. |
| --dhchap_key | Use this flag to add a generated DH-HMAC-CHAP key for use with bidirectional in-band authentication. Input type: String |
| --format | View the output for each of these commands in any of the following format options: text, json, yaml, plain, or python. If not specified, the default is text. |
| --gw_group | Use the optional --gw_group at any time to specify a specific gateway group in the ceph nvmeof command. The GW_GROUP value is a user defined string. Input type: String |
| --host_nqn | NQN of the host. |
| --nqn | Subsystem NQN Important: NQN value must not contain an underscore character. |
| --nsid | Specify the namespace ID of the subsystem. Note: When this parameter is not used with add or create commands, the gateway automatically generates an NSID value, the next available value on the subsystem, starting with 1. |
| --psk | TLS Pre-Shared Key (PSK). |
| --rbd_image_size | Provide the Ceph Block Device image size. When provided as a string, the set value is used. When provided as an integer the value is read as megabytes (MBs), by default. Supported size units are as follows: KB, KiB, MB, MiB, GB, GiB, TB, and TiB. Input type: String. |
| --serial-number | If the serial number is not specified, the number is randomly generated. Input type: String |
| --server-address | Use the optional --server-address parameter to specify a particular gateway IP address in the nvmeof command. Use this parameter when you need to connect to a specific gateway in the group. If you do not set it, the CLI selects an arbitrary gateway to run the command. The default port value is 5500. |
| --trsvcid | Port number. The default port value is 4420. Note: To define the IP port on the gateway, be sure to include the --trsvcid information. |
| --uuid | Specify the namespace UUID. When multiple namespaces exist on the same subsystem, each namespace has its own UUID. Note: When this parameter is not used, the gateway automatically generates a UUID value. |
