## Configuring the NVMe-oF gateway target with nvmeof-cli

Last Updated
: 2026-06-25

Use the `nvmeof-cli` utility commands to configure targets, LUNs, and clients.

Configuring the NVMe-oF gateway target requires a storage system that is running
IBM Storage Ceph
9.9.0
or later cluster and a running Ceph NVMe-oF gateway.

> 📝 **Note:** Note:
The
`nvmeof-cli`
versions should be equal to or greater than the gateway version.
